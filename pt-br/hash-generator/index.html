Gerador de Hash - SHA-1, SHA-256, SHA-384 e SHA-512

Em resumo: o Gerador de Hashes calcula resumos SHA-1, SHA-256, SHA-384 e SHA-512 do seu texto com a criptografia integrada do seu navegador - o mesmo motor Web Crypto que o site do seu banco utiliza. O SHA-1 está rotulado honestamente: para somas de verificação, não segurança.

Precisa de verificar que duas cópias de uma string são idênticas, produzir uma impressão digital para invalidar cache, ou seguir um tutorial que pede um resumo SHA-256? Cole o texto e todos os quatro resumos padrão aparecem juntos, prontos para copiar.

Nota: SHA-1 é incluído apenas para somas de verificação e compatibilidade legada - é não seguro para senhas ou segurança. Para segurança utilize SHA-256 ou mais forte, com um esquema de hashing de senhas adequado como bcrypt ou Argon2 para senhas.

Privado por concepção: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. A sua entrada nunca é carregada para um servidor, nunca salva e nunca vista por nós - feche a aba e tudo desaparece.

Como utilizar o Gerador de Hash

  1. Escreva ou cole o texto para fazer hash.
  2. Clique em Gerar Hashes.
  3. Copie o resumo de que precisa a partir dos resultados.

Como funciona

Um hash criptográfico transforma qualquer entrada numa impressão digital de comprimento fixo. A mesma entrada dá sempre a mesma impressão digital; alterar um único carácter muda-a completamente; e a entrada não pode ser reconstruída a partir da impressão digital. Esta ferramenta alimenta os bytes UTF-8 do seu texto à Web Crypto API (crypto.subtle.digest) - criptografia de navegador nativa e auditada, não uma reimplementação em JavaScript. SHA-256 produz 64 caracteres hexadecimais, SHA-512 produz 128 e SHA-1 produz 40. A resistência a colisões do SHA-1 está quebrada, razão pela qual só é oferecido para somas de verificação e sistemas legados que ainda o pedem.

Perguntas Frequentes

Este gerador de hash é grátis?

Sim - grátis, sem registro, sem limites.

Hashing é o mesmo que encriptação?

Não. Um hash é unidirecional: cria uma impressão digital que pode comparar, mas não pode desencriptá-lo de volta para o texto original.

Porque é que SHA-1 está marcado como "not for security"?

Investigadores produziram colisões SHA-1 reais, pelo que não deve proteger senhas, assinaturas ou certificados. Continua a servir como soma de verificação rápida de arquivos onde ataques não são uma preocupação.

Devo fazer hash de senhas com SHA-256?

Não diretamente. As senhas precisam de funções de hashing de senhas lentas e com salt, como bcrypt, scrypt ou Argon2 - hashes rápidos como SHA-256 permitem aos atacantes adivinhar bilhões de senhas por segundo.

O meu texto é carregado para ser hashed?

Não. O hashing funciona no seu navegador através de Web Crypto; o seu texto nunca sai do seu dispositivo.
