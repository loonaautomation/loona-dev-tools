GZIP कंप्रेसर — एक फ़ाइल को .gz में समेटें

संक्षेप में: GZIP कंप्रेसर एक single फ़ाइल को आपके browser में built gzip engine उपयोग करके .gz में shrink करता है — कोई library download नहीं, कोई upload नहीं — और आपको ठीक दिखाता है कि आपने कितनी space बचाई।

Gzip web और Linux का compression workhorse है: log files, CSV exports, database dumps और TAR archives सभी इसके नीचे नाटकीय रूप से सिकुड़ते हैं। यह पेज modern browsers में built-in Compression Streams API से एक फ़ाइल को .gz में compress करता है — सबसे तेज़ संभव रास्ता, और पूरी तरह आपके device पर।

Gzip एक फ़ाइल compress करता है — यह archive format नहीं है। कई फ़ाइलों को एक .gz में compress करने के लिए, पहले उन्हें इसके साथ bundle करें TAR फ़ाइल निर्माता, फिर .tar को compress करें (यह combination ठीक वही है जो .tar.gz होता है)। .gz को वापस मूल फ़ाइल में बदलने के लिए, इसका उपयोग करें GZ फ़ाइल एक्सट्रैक्टर.

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपकी फ़ाइलें कभी server पर upload नहीं होतीं, कभी stored नहीं होतीं और कभी हमारे द्वारा नहीं देखी जातीं — tab बंद करें और सब चला गया। एक ईमानदार limit: conversion आपके device की memory में होता है, इसलिए बहुत बड़े archives (सैकड़ों megabytes) low-memory phone पर slow या fail हो सकते हैं।

GZIP कंप्रेसर का उपयोग कैसे करें

  1. ऊपर के box पर एक फ़ाइल डालें, या उस पर click करें और अपने device से फ़ाइल चुनें।
  2. Compress to .gz पर click करें। आपके ब्राउज़र का अपना gzip engine आपके device पर काम करता है।
  3. Summary में sizes की तुलना करें: original, compressed, और बचाई गई percentage।
  4. .gz फ़ाइल save करने के लिए Download पर click करें। यह gzip, tar, 7-Zip, WinRAR से खुलती है — या हमारे GZ File Extractor से।

यह कैसे काम करता है

Gzip DEFLATE algorithm (LZ77 matching साथ में Huffman coding) को एक छोटे container में लपेटता है: magic bytes 1F 8B से शुरू होता एक 10-byte header, compressed डेटा, और trailer के रूप में एक checksum साथ में मूल size। यह पेज आपकी फ़ाइल को CompressionStream API से गुज़ारता है — Chrome, Edge, Firefox और Safari में natively implement की गई gzip compression — इसलिए download करने के लिए कोई JavaScript compressor नहीं है और काम native speed से चलता है। एक फ़ाइल अंदर, एक फ़ाइल बाहर: gzip में folders की कोई अवधारणा नहीं है, इसीलिए classic .tar.gz pairing मौजूद है — tar bundle करता है, gzip समेटता है।

काम किया हुआ उदाहरण

आप access.log डालते हैं, एक 4.2 MB web server log। Logs repetitive text हैं — वही addresses, timestamps और status codes बार-बार — इसलिए gzip इसे 380 KB तक crush करता है, 91% बचत, और access.log.gz archive या email करने के लिए तैयार है। इसके बजाय 4.2 MB JPEG डालें और .gz भी 4.2 MB निकलता है: JPEG data पहले से compressed है, और page आपको ईमानदारी से यह बताता है वरना का दिखावा करने के बजाय।

अक्सर पूछे जाने वाले सवाल

क्या यह GZIP compressor मुफ़्त है?

हाँ — मुफ़्त, कोई साइन-अप नहीं, कोई limits नहीं और कोई watermarks नहीं।

क्या मेरी फ़ाइलें किसी server पर अपलोड होती हैं?

नहीं। Compression आपके ब्राउज़र में built-in gzip engine (Compression Streams API) उपयोग करती है। आपकी फ़ाइल कभी आपके device से बाहर नहीं जाती।

मैं कई फ़ाइलों को एक .gz में कैसे compress करूँ?

Gzip ठीक एक फ़ाइल संभालता है। फ़ाइलों को पहले TAR File Creator से एक single .tar में bundle करें, फिर उस .tar को यहाँ compress करें — परिणाम एक standard .tar.gz है (ज़रूरत हो तो बस file.tar.gz rename करें)।

मैं .gz से अपनी मूल फ़ाइल वापस कैसे पाऊँ?

इस site पर GZ File Extractor उपयोग करें — यह आपके ब्राउज़र में process को उलटता है। Linux और macOS पर, gunzip file.gz वही काम करता है।

मेरी फ़ाइल थोड़ी बड़ी क्यों हो गई?

Already-compressed formats (JPG, PNG, MP4, PDF, ZIP) में gzip के exploit करने के लिए लगभग कोई repetition नहीं बची होती, और .gz wrapper कुछ bytes header और checksum जोड़ देता है। उन फ़ाइलों के लिए छोटी वृद्धि — आम तौर पर 1% से काफ़ी कम — सामान्य और हानिरहित है।
