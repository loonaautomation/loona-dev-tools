CSS 축소기 & 정리 도구 - CSS를 압축하거나 읽기 쉽게 만들기

요약하면: CSS 축소기는 주석과 불필요한 공백을 제거해 스타일시트를 줄이고 정확한 크기 절약을 보고하며, 다듬기 모드는 축소된 CSS를 깨끗하고 들여쓰기된 코드로 다시 바꿔요.

CSS의 모든 킬로바이트가 페이지의 첫 페인트를 지연시켜요. 아래에 스타일시트를 붙여넣어 운영용으로 압축하거나, 다시 읽고 편집해야 할 때는 축소된 파일을 정리 도구로 실행하세요.

CSS 축소기 사용법

  1. CSS를 위 상자에 붙여넣거나 입력하세요.
  2. 압축하려면 CSS 축소를, 들여쓰기로 포맷하려면 CSS 정리를 클릭하세요.
  3. 크기 패널을 확인하세요 - 원래 크기, 결과 크기, 절약된 백분율을 보여줘요.
  4. 결과를 복사하거나 .css 파일로 다운로드하세요.

작동 방식

축소기는 먼저 CSS를 문자 단위로 순회하고 주석을 제거해요 - 따옴표 문자열은 완전히 손대지 않은 채 두고요, 그래서 content 주석 같은 텍스트를 포함하는 값은 온전하게 살아남아요. 그다음 공백 연속을 축소하고 중괄호, 세미콜론, 쉼표, 결합자 주변의 공백과 콜론 뒤의 공백을 제거해요. 의도적으로 절대 안쪽을 건드리지 않아요 calc() 식이나 문자열 값, 공백이 의미를 담는 곳이에요. 다듬기 모드는 과정을 뒤집어요: 압축된 CSS를 중첩 수준당 두 칸 들여쓰기로 줄에 선언 하나씩으로 다시 열어요.

풀이된 예시

주석과 넉넉한 간격이 있는 전형적인 손글씨 스타일시트 규칙 - 예를 들어 240-byte 헤더 블록 - 은 보통 약 150 bytes로 축소돼 약 35-40% 절약돼요. 사이트 전체로 보면 눈에 띄게 빠른 첫 렌더링이 되며, 특히 모바일 연결에서 그래요.

자주 묻는 질문

이 CSS 축소기는 무료인가요?

네 - 완전히 무료, 회원가입 없음, 크기 제한 없음, 일일 상한 없음이에요.

축소된 CSS는 배포해도 안전한가요?

축소기는 CSS가 필요로 하지 않는 주석과 공백만 제거해요. 선택자, 속성, 값은 변하지 않고, 문자열 값과 calc() 식은 절대 변경되지 않아요. 모든 축소기와 마찬가지로, 배포 후 페이지를 한 번 테스트하세요.

선택자에서 콜론 앞에 왜 공백을 유지하나요?

콜론 앞의 공백은 CSS에서 의미가 있을 수 있어요 - ".a :hover"는 호버된 자손을 선택하고, ".a:hover"는 요소 자체를 선택해요. 안전을 위해 도구는 콜론 뒤의 공백은 제거하지만 앞의 공백은 절대 추측하지 않아요.

CSS도 정리할 수 있나요?

네. 다듬기 모드는 압축된 CSS를 가져와 일관된 들여쓰기로 줄에 선언 하나씩으로 확장해요. 축소된 파일을 물려받아 편집해야 할 때 이상적이에요.

제 CSS가 서버에 업로드되나요?

아니요. 축소와 정리는 브라우저에서 100% 일어나요. 스타일시트는 기기를 절대 떠나지 않아요.
