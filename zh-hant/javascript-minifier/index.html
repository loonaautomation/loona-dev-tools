JavaScript 壓縮工具 - 尊重您程式碼的保守壓縮

簡而言之： JavaScript 壓縮工具使用真正的標記器刪除註釋和不需要的空白，因此字串內容、模板字面量和正規表示式永不損壞，承載含義的換行符（如 return 後的換行）始終保留。

把 JavaScript 當作純文字的樸素壓縮工具，會在字串包含 "//" 或正則包含引號的那一刻破壞程式碼。本工具先把您的程式碼分詞為標記，然後才決定什麼可以安全地移除。

如何使用 JavaScript 壓縮工具

  1. 把您的 JavaScript 貼上或輸入到上方框中。
  2. 點選“壓縮 JavaScript”。
  3. 檢視大小面板，瞭解節省了多少。
  4. 複製結果，或把它下載為 .js 檔案——並且，像使用任何壓縮工具一樣，執行一次您的程式碼，確認它的行為相同。

它如何工作

本工具首先把您的程式碼拆分為標記：識別符號、數字、字串、模板字面量、正規表示式和標點。註釋在此掃描期間被識別並丟棄，掃描器知道除號與正規表示式開頭之間的區別，也從不檢視字串內部的註釋標記。然後標記被重新連線，僅在刪除空格會改變含義的地方新增分隔空格——在兩個詞之間、在加號和另一個加號之間，等等。換行保留在 JavaScript 的自動分號插入使它們有意義的任何地方，最重要的是在……之後 return, break 和 繼續，以及在一個開頭的 ++ 或 --.

常見問題

這個 JavaScript 壓縮工具免費嗎？

是的——完全免費，無需註冊，沒有大小限制，也沒有每日上限。

這與完整的構建工具壓縮器有什麼不同？

像 Terser 這樣的構建工具還會重新命名變數和重寫程式碼，從而再多擠出幾個百分點。本工具有意保持保守：它從不重新命名任何東西，也從不重寫表示式，所以輸出容易肉眼檢查，適合快速的一次性使用。

它會破壞我的程式碼嗎？

它的設計正是為了不這樣：字串、模板字面量和正則字面量受到保護，承載意義的換行得以保留。沒有任何壓縮工具能承諾在每種奇特模式上都完美，所以壓縮後請始終執行您的測試套件或開啟一次頁面——這條建議適用於每個壓縮工具，包括我們的。

它能處理正規表示式和模板字面量嗎？

是的。標記器可識別正規表示式字面量（包括字元類和轉義）和模板字面量，包括巢狀的 ${ } 表示式，並將它們原樣傳遞。

我的程式碼會被上傳到伺服器嗎？

不會。分詞和壓縮 100% 在您的瀏覽器中進行。您的原始碼從不離開您的裝置。
