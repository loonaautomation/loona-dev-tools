CSS Clip-Path 生成器 - 以視覺化方式塑造您的元素

簡而言之： CSS Clip-Path 生成器為您提供現成的 clip-path CSS，適用於多邊形（從三角形到星形）、圓形、橢圓和 inset——選擇一個形狀，微調它的點，觀看實時預覽並複製程式碼。注意：本站的姐妹圖片工具已經涵蓋了漸變；clip-path 在這裡是因為它是佈局 CSS，而不是圖片編輯。

Clip-path 把矩形變成設計：用一個 CSS 屬性實現傾斜的區塊、徽章、箭頭和星星。困難的部分是座標——本工具負責處理它們。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 CSS Clip-Path 生成器

  1. 選擇一個形狀預設。
  2. 對於多邊形，調整任何點的 x、y 百分比。
  3. 觀看預覽實時更新。
  4. 複製 CSS——標準屬性和 -webkit- 屬性都包含在內。

它如何工作

多邊形點是元素框的百分比，所以形狀隨元素縮放。預設編碼了眾所周知的座標集（正五邊形、六邊形、十角星等），生成器同時輸出 clip-path 和這個 -webkit- 這是 Safari 歷史上一直接需要的帶字首的孿生版本。Circle、ellipse 和 inset 涵蓋了該屬性支援的非多邊形形狀，包括圓角的 inset。

常見問題

這個生成器免費嗎？

是的——完全免費，無需註冊。

為什麼 Image 網站上也有一個漸變生成器？

那裡的漸變被當作影象/設計資產處理。Clip-path 是給開發者的佈局 CSS，所以它住在這裡——每個工具恰好只存在於一個 Loona 網站上。

clip-path 會影響點選嗎？

是的——被裁剪掉的區域不可點選，這通常正是形狀按鈕和卡片想要的效果。

瀏覽器支援情況？

所有現代瀏覽器都支援 clip-path；輸出中的 -webkit- 字首覆蓋較舊的 Safari。

有任何東西被上傳嗎？

不會。一切都在您的瀏覽器中執行。
