JSON फ़ॉर्मेटर & Validator — JSON Pretty Print और Minify करें

संक्षेप में: JSON फ़ॉर्मेटर आपका JSON check करता है, इसे 2-space, 4-space या tab indentation से pretty-print करता है, अनुरोध पर minify करता है, और अगर कुछ ग़लत हो तो आपको समस्या की exact line और column बताता है।

टूटा JSON developer के दिन की सबसे आम पाँच-मिनट की देरी है — एक comma छूटा और पूरा payload fail। अपना JSON नीचे paste करें: अगर यह valid है तो आपको साफ़, पठनीय output मिलता है; अगर नहीं है, तो बेकार "parse failed" के बजाय error की ठीक position मिलती है।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

JSON फ़ॉर्मेटर का उपयोग कैसे करें

  1. अपना JSON ऊपर के box में paste करें या type करें।
  2. Indent style चुनें — 2 spaces, 4 spaces या tab।
  3. पठनीय output के लिए Format / Validate पर click करें, या सबसे छोटे valid रूप के लिए Minify।
  4. परिणाम copy करें या इसे .json फ़ाइल के रूप में download करें।

यह कैसे काम करता है

Tool आपके browser के built-in JSON parser का उपयोग करता है — वही strict parser जो आपका अपना JavaScript code उपयोग करता है — इसलिए यहाँ green light का मतलब है आपका JSON सच में valid है। Pretty-printing parsed value को आपकी चुनी indentation से दोबारा serialise करती है; key order ठीक जैसे लिखा गया सुरक्षित रहता है। Minifying एक भी value बदले बिना हर अनावश्यक space और newline हटाती है। जब parsing fail होती है, tool parser की character position को line और column में बदलता है और आपको offending line दिखाता है।

काम किया हुआ उदाहरण

आप प्राप्त करते हैं {"user":"ahmed","roles":["admin","editor"],"active":true} किसी API से। 2 spaces से formatted यह एक साफ़ nine-line document बन जाता है जिसे आप सच में पढ़ सकते हैं — और अगर आप "ahmed" के बाद comma ग़लती से delete कर दें, तो tool error को exact line और column पर report करता है आपको इसके लिए hunt करने पर छोड़ने के बजाय।

अक्सर पूछे जाने वाले सवाल

क्या यह JSON formatter मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, बिना साइन-अप, बिना size limit और बिना daily cap।

जब मेरा JSON invalid हो तो क्या होता है?

आपको parser का error message साथ में exact line और column मिलता है जहाँ parsing fail हुई, और उस line का text, ताकि आप इसे seconds में ठीक कर सकें।

क्या formatting मेरा डेटा बदल देता है?

नहीं। Formatting सिर्फ़ whitespace बदलती है। Minifying सिर्फ़ whitespace हटाती है। Keys, values और उनका order untouched हैं।

क्या मेरा JSON किसी server पर अपलोड होता है?

नहीं। Parsing और formatting 100% आपके ब्राउज़र में होता है। API payloads और config files कभी आपके device से बाहर नहीं जाते।

क्या मैं सच में बड़ा JSON format कर सकता हूँ?

हाँ — practical limit आपके device की memory है। कई megabytes की फ़ाइलें typical laptop पर एक second से कम में format होती हैं।
