Извлекатель файлов GZ — распаковка файлов GZ онлайн

Короче говоря: экстрактор файлов GZ распаковывает один файл .gz в вашем браузере и возвращает вам исходный файл — журнал, экспорт CSV, дамп базы данных — с восстановленным исходным именем. Ничего не загружается.

Файл .gz — это не архив, полный файлов, — это ровно один файл, сжатый с помощью gzip, рабочей лошадки мира Unix. Так перемещаются журналы серверов, экспорты данных и дампы баз данных, а в Windows нет встроенного способа их открыть. Эта страница распаковывает файл с помощью собственного встроенного движка gzip вашего браузера (API DecompressionStream), поэтому это быстро и полностью конфиденциально.

Перетащите сюда ваш файл .gz или нажмите, чтобы выбрать файл на вашем устройстве
Приватность по замыслу: всё в этом инструменте происходит на 100% в вашем браузере с использованием распаковки gzip, встроенной в сам браузер. Ваш файл .gz никогда не загружается на сервер, никогда не хранится и никогда не виден нам. Одно честное ограничение: распаковка происходит в памяти вашего устройства, поэтому .gz, разворачивающийся до нескольких гигабайт, может испытывать трудности на телефоне с малым объёмом памяти.

Как использовать извлекатель файлов GZ

  1. Перетащите ваш файл .gz в поле выше или нажмите на него и выберите файл на вашем устройстве.
  2. Файл распаковывается немедленно — следите за строкой, показывающей исходное имя файла и его полный размер.
  3. Нажмите «Загрузить распакованный файл», чтобы сохранить исходный файл (например, access.log из access.log.gz).

Как это работает

Gzip хранит небольшой заголовок (включая исходное имя файла, когда создавший инструмент его записал), данные, сжатые алгоритмом DEFLATE, и контрольную сумму плюс исходный размер в конце. Современные браузеры поставляются со встроенным нативным декодировщиком gzip — тем же, который они используют для получения сжатых веб-страниц, — и эта страница пропускает ваш файл через него с помощью API DecompressionStream. Никакая библиотека не скачивается и ничего никуда не отправляется: браузер раздувает данные и вручает вам исходные байты.

Разобранный пример

Ваш сервер предоставляет вам access.log.gz (2.1 MB). Вы помещаете его сюда, и он распаковывается в access.log (18.4 MB) примерно за секунду. Вы скачиваете его и открываете в текстовом редакторе, чтобы найти ошибку прошлой ночи, — без установки ни одного инструмента.

Часто задаваемые вопросы

В чём разница между .gz и .tar.gz?

Файл .gz содержит ровно один сжатый файл. Файл .tar.gz сначала объединяет много файлов в архив TAR, а затем сжимает этот пакет с помощью gzip, поэтому он содержит целое дерево файлов. Для .tar.gz используйте распаковщик файлов TAR.GZ, ссылка на который приведена ниже.

Будет ли у распакованного файла правильное имя?

Да — этот инструмент восстанавливает исходное имя, удаляя окончание .gz (access.log.gz становится access.log). В подавляющем большинстве случаев это совпадает с именем, записанным при сжатии файла.

Может ли этот инструмент открывать файлы .zip или .rar, которые по ошибке заканчиваются на .gz?

Нет — переименование файла не меняет того, что внутри него. Если содержимое на самом деле не является данными gzip, распаковка завершится неудачей с понятным сообщением. Используйте распаковщик архивных файлов для ZIP, RAR и других настоящих архивов.

Есть ли ограничение на размер?

В инструмент не встроено ограничение, но распакованный файл хранится в памяти вашего браузера. Повседневные журналы и экспорты (до нескольких сотен мегабайт) подходят для большинства устройств; дампы в несколько гигабайт лучше обрабатывать на настольном компьютере нативным инструментом.

Загружаются ли мои файлы на сервер?

Нет. Распаковка использует собственный встроенный движок браузера на вашем устройстве. Файл никогда не покидает вашу машину — для этого инструмента даже нет загрузки библиотеки.
