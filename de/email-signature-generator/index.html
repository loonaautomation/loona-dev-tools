HTML-E-Mail-Signatur-Generator - Professionelle Abmeldungen, die E-Mail-Clients überleben

Kurz gesagt: das HTML-E-Mail-Signatur-Generator baut Ihre Signatur als E-Mail-sicheres Tabellen-HTML – die einzige Layout-Technik, die Gmail, Outlook und Apple Mail alle zuverlässig rendern – mit Ihrer Akzentfarbe, Kontakt-Links und einer optionalen Tagline.

E-Mail-Clients entfernen modernes CSS, weshalb mit divs gebaute Signaturen in Outlook auseinanderfallen. Diese ist auf die alte, korrekte Weise gebaut: nur Tabellen und Inline-Styles.

Vorschau

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Eingabe wird niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg.

So verwenden Sie den HTML-E-Mail-Signatur-Generator

  1. Geben Sie Ihren Namen, Titel und Ihre Firma ein.
  2. Fügen Sie Telefon, E-Mail und Website hinzu – sie werden zu antippbaren Links.
  3. Wählen Sie eine Akzentfarbe und eine optionale Tagline.
  4. Prüfen Sie die Vorschau und kopieren Sie dann das HTML (oder kopieren Sie die gerenderte Vorschau direkt in Gmails Signatur-Editor).

So funktioniert es

E-Mail-HTML ist eine Zeitkapsel: Outlooks Word-Engine ignoriert flexbox, grids und das meiste moderne CSS, also werden professionelle Signaturen immer noch mit verschachtelten Tabellen und Inline-Styles gebaut – genau das, was dieser Generator ausgibt. Kontaktdaten werden zu echten tel:-, mailto:- und Web-Links, der Akzentbalken und der Name nutzen Ihre Farbe, und jeder Textwert wird escaped, sodass ein Name mit einem Ampersand das Markup nicht zerbrechen kann. Es werden keine Bilder verwendet, sodass die Signatur sofort angezeigt wird und niemals Warnungen zum Bilderherunterladen auslöst.

Häufig gestellte Fragen

Ist dieser Generator kostenlos?

Ja – völlig kostenlos, keine Registrierung.

Wie füge ich es in Gmail hinzu?

Kopieren Sie die gerenderte Vorschau (nicht den Code), gehen Sie dann in Gmail zu Einstellungen → Alle Einstellungen ansehen → Signatur, erstellen Sie eine Signatur und fügen Sie sie ein. Die Formatierung wird übernommen.

Warum Tabellen statt divs?

Desktop-Outlook rendert E-Mails mit der Engine von Microsoft Word, die nur Tabellen und Inline-Styles zuverlässig unterstützt.

Kann ich ein Logo-Foto hinzufügen?

Dieser Generator ist per Design nur Text – bildfreie Signaturen laden sofort und werden niemals blockiert. Ein gehostetes Logo kann bei Bedarf von Hand zum HTML hinzugefügt werden.

Wird irgendetwas hochgeladen?

Nein. Ihre Details verlassen Ihren Browser nie.
