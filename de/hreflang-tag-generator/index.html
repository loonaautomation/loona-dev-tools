Hreflang-Tag-Generator - Die richtige Sprachversion für jeden Besucher

Kurz gesagt: das Hreflang-Tag-Generator verwandelt Sprach/URL-Paare in den vollständigen Satz alternativer Link-Tags – inklusive x-default – und prüft Sprach-Tags und URLs, bevor Sie sie ausliefern, weil ein falsches Tag den ganzen Cluster ungültig machen kann.

Hreflang ist unversöhnlich: Tags müssen wechselseitig sein, URLs absolut und Codes exakt. Bauen Sie das Set einmal hier und fügen Sie dann den identischen Block auf jeder Version der Seite ein.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Eingabe wird niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg.

So verwenden Sie den Hreflang-Tag-Generator

  1. Listen Sie jede Sprach-/Regionalversion auf: Tag | vollständige URL, eine pro Zeile.
  2. Fügen Sie die x-default-URL hinzu, wenn Sie eine Fallback- oder Auswahlseite haben.
  3. Klicken Sie auf Generieren und lesen Sie die Prüfungen.
  4. Fügen Sie den identischen Block in den head JEDER Version im Set ein – Wechselseitigkeit ist erforderlich.

So funktioniert es

Hreflang sagt Google, welche Sprach- oder Regionalversion einer Seite angezeigt werden soll. Die Regeln, die dieser Generator durchsetzt, stammen direkt aus Googles Dokumentation: Sprachwerte müssen gültige BCP-47-Tags sein (en, en-GB, pt-BR – niemals EN-gb oder en_UK), jede URL muss vollständig absolut sein, jede Seite im Set muss auf alle anderen einschließlich sich selbst verlinken, und x-default zeigt auf den Fallback für nicht übereinstimmende Sprachen. Der Prüfer markiert fehlerhafte Tags, relative URLs und doppelte Sprachwerte – die drei Fehler, die Google am häufigsten ein ganzes Cluster ignorieren lassen.

Häufig gestellte Fragen

Ist dieser Generator kostenlos?

Ja – völlig kostenlos, keine Registrierung.

Muss jede Seite dieselben Tags tragen?

Ja. Wenn Seite A auf Seite B verlinkt, muss Seite B auf Seite A zurücklinken, sonst könnte Google beide Annotationen fallen lassen.

Sprache oder Sprach-Region – welche sollte ich verwenden?

Nutzen Sie einfache Sprache (es), wenn eine Version allen Sprechern dient; nutzen Sie Regionen (en-GB, en-US), wenn Inhalt, Währung oder Schreibweise sich wirklich je nach Land unterscheiden.

Was ist x-default?

Die Fallback-Seite für Nutzer, deren Sprache zu keiner Ihrer Versionen passt – oft ein Sprachauswähler oder Ihre globale Startseite.

Wird irgendetwas hochgeladen?

Nein. Generierung und Prüfungen laufen in Ihrem Browser.
