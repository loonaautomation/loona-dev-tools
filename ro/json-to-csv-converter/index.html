Convertizor JSON în CSV - Transformă tablouri JSON în foi de calcul

Pe scurt: Convertizorul JSON în CSV ia un tablou JSON de obiecte și produce un fișier CSV corect: coloanele sunt uniunea fiecărei chei din tablou, valorile cu virgule sau ghilimele sunt puse corect între ghilimele, iar obiectele imbricate sunt păstrate ca JSON compact în celula lor.

API-urile vorbesc JSON; foile de calcul, importurile și managerii vorbesc CSV. Lipește un tablou JSON mai jos și obține un fișier CSV care se deschide curat în Excel, Google Sheets sau orice importator - fără virgule distruse, fără ghilimele stricate.

Privat prin concepție: totul în acest instrument se întâmplă 100% în browserul tău cu JavaScript. Datele tale introduse nu sunt încărcate niciodată pe un server, nu sunt stocate și nu sunt văzute de noi - închide fila și totul a dispărut.

Cum se folosește Convertizorul JSON în CSV

  1. Lipește un tablou JSON de obiecte în caseta de sus (un singur obiect funcționează și el - devine un rând).
  2. Dă clic pe Convertește în CSV.
  3. Revizuiește CSV-ul: primul rând este antetul, construit din fiecare cheie găsită în tablou.
  4. Copiază-l sau descarcă-l ca fișier .csv, gata pentru Excel sau Google Sheets.

Cum funcționează

Convertizorul parsează JSON-ul tău cu parserul încorporat al browserului, apoi parcurge fiecare obiect din tablou și adună uniunea tuturor cheilor, în ordinea în care apar prima dată - așa că un obiect cu un câmp suplimentar nu îl pierde niciodată. Fiecare celulă este escapată după regulile CSV: valorile care conțin o virgulă, o ghilimea sau un rând nou sunt înfășurate în ghilimele duble, iar ghilimelele din interior sunt dublate. Numerele și booleenii sunt scrise simplu, null și cheile lipsă devin celule goale, iar un obiect sau tablou imbricat este scris ca JSON compact în celula sa, așa încât nicio dată nu este eliminată în tăcere.

Exemplu rezolvat

Tabloul [{"name":"Ali","city":"Lahore"},{"name":"Ana","city":"Porto","vip":true}] devine trei coloane (name, city, vip): Ali primește o celulă vip goală, iar Ana primește true - abordarea uniunii cheilor păstrează ambele rânduri complete.

Întrebări frecvente

Acest convertizor JSON în CSV este gratuit?

Da - complet gratuit, fără înregistrare, fără limită de dimensiune și fără plafon zilnic.

Ce forme JSON sunt acceptate?

Un tablou de obiecte este cazul principal. Un singur obiect devine un CSV cu un rând, iar un tablou de valori simple (numere, șiruri) devine o singură coloană "value". Orice altceva este respins cu o explicație.

Ce se întâmplă cu obiectele și tablourile imbricate?

Ele sunt scrise ca text JSON compact în interiorul celulei lor. Nimic nu este aplatizat sau eliminat, iar convertirea înapoi cu instrumentul nostru CSV în JSON le păstrează lizibile.

De ce unele celule au ghilimele în jurul lor?

Regulile CSV cer ghilimele când o valoare conține o virgulă, o ghilimea dublă sau o linie nouă - altfel coloanele s-ar deplasa. Excel și Google Sheets citesc corect această punere standard între ghilimele.

Datele mele sunt încărcate pe un server?

Nu. Analiza și conversia au loc 100% în browserul tău. Datele tale nu părăsesc niciodată dispozitivul tău.
