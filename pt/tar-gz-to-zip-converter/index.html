Conversor de TAR.GZ para ZIP - Transforme .tar.gz e .tgz em .zip

Em resumo: o Conversor de TAR.GZ para ZIP desembrulha ambas as camadas de um arquivo .tar.gz (ou .tgz) no seu dispositivo - gzip primeiro, depois tar - e reempacota os ficheiros como um único .zip padrão.

Um .tar.gz são dois formatos num só: ficheiros agrupados com tar e depois comprimidos com gzip. O Linux produz-os em todo o lado - lançamentos de código, cópias de segurança, registos - mas o Windows e os telemóveis não os abrem nativamente. Este conversor desembrulha ambas as camadas localmente no seu navegador e entrega-lhe um ZIP comum.

Os seus ficheiros nunca são carregados para um servidor, nunca guardados e nunca vistos por nós - feche o separador e tudo desaparece. Um limite honesto: a conversão acontece na memória do seu dispositivo, pelo que arquivos muito grandes (centenas de megabytes) podem ser lentos ou falhar num telemóvel com pouca memória.

Como utilizar o Conversor de TAR.GZ para ZIP

  1. Largue o seu ficheiro .tar.gz ou .tgz na caixa acima, ou clique nela e escolha o ficheiro do seu dispositivo.
  2. Clique em Converter para ZIP. Ambas as camadas gzip e tar são desembrulhadas no seu dispositivo e os ficheiros são reempacotados como ZIP.
  3. Verifique o resumo: número de ficheiros encontrados e o tamanho do novo ZIP.
  4. Clique em Transferir para guardar o ficheiro .zip - abre com as ferramentas integradas de qualquer sistema.

Como funciona

Por baixo, esta página entrega o seu ficheiro a uma compilação WebAssembly de libarchive, que compreende o invólucro gzip e o arquivo tar dentro dele como um fluxo - exatamente como tar -xzf o trata no Linux. Os ficheiros extraídos são depois escritos num ZIP novo pelo JSZip, cada um no seu caminho original. Note a diferença entre isto e um ficheiro .gz simples: um .tar.gz contém muitos ficheiros, enquanto um .gz isolado envolve normalmente um único ficheiro (é para isso que serve o Extrator de Ficheiros GZ). Esta página aceita tanto .tar.gz como a grafia abreviada .tgz - são o mesmo formato.

Exemplo resolvido

Transfere release-2.4.tar.gz (18 MB) de uma ferramenta de código aberto para um PC Windows. A ferramenta desembrulha-o aqui e produz release-2.4.zip (19 MB) contendo os mesmos 86 ficheiros nas mesmas pastas - pronto para abrir no Explorer, sem Linux e sem software extra envolvido.

Perguntas Frequentes

Este conversor de TAR.GZ para ZIP é grátis?

Sim - grátis, sem registo, sem limites e sem marcas de água.

Os meus ficheiros são carregados para um servidor?

Não. Ambas as camadas são desembrulhadas e o ZIP é construído inteiramente no seu navegador; nada sai do seu dispositivo.

Qual é a diferença entre .tar.gz e .tgz?

Nenhuma - .tgz é simplesmente uma grafia abreviada de .tar.gz, criada para sistemas que outrora só permitiam extensões de três letras. Esta ferramenta aceita ambos.

O meu ficheiro é um .gz simples, não .tar.gz. O que devo utilizar?

Um .gz simples envolve um único ficheiro comprimido, não um arquivo de muitos ficheiros. Utilize o Extrator de Ficheiros GZ para recuperar o ficheiro original.

Porque é que o ZIP tem cerca do mesmo tamanho que o .tar.gz?

Ambos os formatos comprimem bem - gzip no tar, DEFLATE dentro do ZIP - pelo que tamanhos de saída semelhantes são esperados. A vitória é a compatibilidade: o ZIP abre em todo o lado.
