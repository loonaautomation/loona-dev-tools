HTML 엔터티 인코더 & 디코더 - 이름 또는 숫자

요약하면: HTML 엔티티 인코더는 텍스트를 이스케이프해 브라우저가 코드로 해석하는 대신 표시하게 해요 - 이름이 존재하는 곳에서는 이름 스타일로, 또는 완전히 번호 스타일로 - 그리고 다른 사람의 마크업에서 엔티티를 읽을 수 있는 텍스트로 다시 디코딩해요.

실제를 보여주는 튜토리얼 쓰기 태그? 사용자 댓글을 안전하게 게시하기? 다음이 포함된 텍스트 순간 <, > 또는 &가 이스케이프 없이 웹 페이지에 들어가면, 브라우저는 마크업으로 취급해요. 엔티티로 인코딩하면 쓴 그대로 정확히 표시돼요 - 그리고 이 도구는 &copy;와 &#8212;로 가득 찬 마크업을 물려받을 때를 위해 디코딩도 해요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

HTML 엔터티 인코더 사용법

  1. 텍스트를 붙여넣거나 입력하세요.
  2. 읽기 쉬운 엔터티에는 이름 스타일을, 최대 호환성에는 숫자 스타일을 선택하세요.
  3. 인코딩을 클릭하세요 - 또는 디코딩으로 엔터티를 다시 텍스트로 바꾸세요.

작동 방식

HTML 엔터티는 브라우저가 렌더링할 때 문자로 바꾸는 코드예요: &lt;는 <로, &amp;는 &로, &copy;는 ©로 표시돼요. 모든 문자에는 Unicode 코드 포인트에 기반한 숫자 형태도 있어요 - ©가 ©예요. 이름 모드는 이 도구의 표에 친숙한 이름이 있으면 그것을 사용하고 마크업에 중요한 다섯 문자에 대해서는 숫자 형태로 대체해요; 숫자 모드는 모든 특수 문자와 비 ASCII 문자를 숫자로 인코딩하는데, 일부 예전 시스템이 이를 더 안정적으로 처리해요. 디코딩은 브라우저 자체의 HTML 파서를 사용하므로 플랫폼이 아는 모든 이름 및 숫자 엔터티를 이해해요.

풀이된 예시

Tom & Jerry <3 © 2026로 입력된 문장 "Tom & Jerry <3 © 2026"은 이름 스타일로 Tom &amp; Jerry &lt;3 &copy; 2026으로 인코딩돼요 - 그것을 웹 페이지에 붙여넣으면 방문자는 하트까지 포함해 입력한 문장을 정확히 봐요.

자주 묻는 질문

이 HTML 엔터티 인코더는 무료인가요?

네 - 무료, 회원가입 없음, 제한 없음이에요.

이름인가요, 숫자인가요 - 어느 것을 선택해야 하나요?

이름 엔터티는 사람이 소스 코드에서 읽기 쉬워요. 숫자 엔터티는 아주 오래된 시스템과 일부 이름이 정의되지 않은 XML 맥락을 포함해 어디서든 작동해요. 둘 다 동일하게 표시돼요.

&amp;와 &lt;가 왜 항상 인코딩되어야 하나요?

HTML 자체가 만들어진 두 문자이기 때문이에요: &는 엔터티를 시작하고 <는 태그를 시작해요. 가공하지 않고 두면 페이지 구조가 손상돼요.

모든 엔터티를 디코딩할 수 있나요?

디코딩은 브라우저 자체의 파서를 통해 실행되므로, 이름 엔터티의 전체 표준 집합과 십진수 및 십육진수 숫자 형태를 이해해요.

제 텍스트가 업로드되나요?

아니요 - 인코딩과 디코딩은 전적으로 브라우저에서 일어나요.
