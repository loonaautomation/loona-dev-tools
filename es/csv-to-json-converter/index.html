Convertidor de CSV a JSON - Datos de hoja de cálculo como un array JSON limpio

En resumen: el Convertidor de CSV a JSON analiza tu CSV con un analizador real carácter por carácter (campos entrecomillados, comas dentro de comillas y escapes de comilla duplicada, todo manejado) y convierte cada fila en un objeto JSON con clave de la fila de encabezado.

Dividir un CSV por comas funciona hasta que el primer campo de dirección contiene una. Pega tu CSV abajo y obtén un array JSON correcto, construido por un analizador que sigue las reglas reales de CSV.

Privado por diseño: todo en esta herramienta sucede 100% en tu navegador con JavaScript. Tu entrada nunca se sube a un servidor, nunca se almacena y nunca la vemos nosotros: cierra la pestaña y todo desaparece.

Cómo usar el Convertidor de CSV a JSON

  1. Pega tu CSV en el cuadro superior.
  2. Deja marcada «La primera fila es el encabezado» si tu archivo tiene nombres de columna (desmárcala para obtener claves generadas column1, column2...).
  3. Haz clic en Convertir a JSON.
  4. Copia el resultado o descárgalo como un archivo .json.

Cómo funciona

El convertidor ejecuta una máquina de estados CSV adecuada sobre tu texto, un carácter a la vez. Rastrea si está dentro de un campo entrecomillado, así que las comas e incluso los saltos de línea dentro de comillas permanecen como parte del valor, y una comilla duplicada ("") dentro de un campo entrecomillado se convierte en una comilla simple en la salida. Se aceptan los saltos de línea de Windows (CRLF) y de Unix (LF), y las líneas en blanco se omiten. Con la opción de encabezado activada, la primera fila proporciona las claves del objeto: los nombres de columna duplicados se hacen únicos con sufijos _2, _3 para que ninguna columna sobrescriba a otra en silencio. Todos los valores permanecen como cadenas, exactamente como los almacena CSV; convertir "30" en el número 30 es tarea de tu código, no una suposición de esta herramienta.

Ejemplo resuelto

La fila "Ali, A",30,"said ""hi""" bajo los encabezados name,age,note se convierte en {"name":"Ali, A","age":"30","note":"said \"hi\""} - la coma dentro del nombre y las comillas dentro de la nota se conservan.

Preguntas frecuentes

¿Este convertidor de CSV a JSON es gratuito?

Sí: completamente gratis, sin registro, sin límite de tamaño y sin límite diario.

¿Por qué todos los valores salen como cadenas?

CSV no tiene tipos: cada celda es texto. Adivinar que "007" es un número corrompería códigos e ID, así que la herramienta mantiene los valores exactamente como están escritos y deja que tu código decida qué convertir.

¿Qué pasa si dos columnas comparten el mismo nombre?

Los duplicados posteriores se renombran con un sufijo (name, name_2, name_3) para que cada columna sobreviva en la salida en lugar de sobrescribir la anterior.

¿Puede manejar campos entrecomillados con saltos de línea?

Sí. Un campo entrecomillado puede contener comas, comillas (duplicadas) e incluso saltos de línea: el analizador trata todo entre la comilla de apertura y la de cierre como un valor.

¿Mis datos se suben a un servidor?

No. El análisis y la conversión ocurren 100% en tu navegador. Tus datos nunca salen de tu dispositivo.
