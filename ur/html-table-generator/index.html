HTML ٹیبل جنریٹر - گرڈ بنائیں، صاف ٹیبل کوڈ پائیں

مختصراً: HTML ٹیبل جنریٹر بصری گرڈ کو صاف، سیمینٹک HTML ٹیبل کوڈ میں بدلتا ہے - ہیڈر قطار کے لیے thead اور th, ڈیٹا کے لیے tbody, اختیاری caption، اور ہر خانہ درست escaped۔

ٹیبل مارک اپ ہاتھ سے لکھنا غلطی کا شکار ہے: ایک غائب اختتامی ٹیگ پورا لے آؤٹ توڑ دیتا ہے۔ گرڈ یہاں بھریں اور ایسا کوڈ کاپی کریں جو تعمیر سے درست ہو۔

ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کا ان پٹ کبھی سرور پر اپ لوڈ نہیں ہوتا، کبھی محفوظ نہیں ہوتا اور ہمارے دیکھنے میں نہیں آتا - ٹیب بند کریں اور سب کچھ ختم۔

HTML ٹیبل جنریٹر کا استعمال کیسے کریں

  1. قطاروں اور کالموں کی تعداد مقرر کریں اور Create grid پر کلک کریں۔
  2. اپنی قدریں خانوں میں لکھیں۔
  3. ہیڈر آپشن پر نشان لگائیں اگر پہلی قطار کالموں کو لیبل کرتی ہے۔
  4. HTML بنائیں پر کلک کریں، پیش منظر دیکھیں، اور کوڈ کاپی کریں۔

یہ کیسے کام کرتا ہے

جنریٹر سیمینٹک ٹیبل مارک اپ خارج کرتا ہے - ایک اصل thead کے ساتھ th خانے جب ہیڈر آپشن آن ہو، جو وہ ہے جس کی screen readers اور تلاش انجن توقع کرتے ہیں، علاوہ ایک اختیاری caption. ہر خانے کی قدر HTML-escaped ہوتی ہے، لہٰذا ٹائپ کرنا a < b متن بناتا ہے، ٹوٹا ٹیگ نہیں۔ آؤٹ پٹ اپنی کوئی اسٹائلنگ نہیں رکھتا؛ اپنی CSS کلاس اپنی اسٹائل شیٹ میں شامل کریں تاکہ ٹیبل آپ کی سائٹ سے ملے بجائے inline اسٹائلز سے لڑنے کے۔
