JavaScript 축소기 - 코드를 존중하는 보수적인 압축

요약하면: JavaScript 축소기는 실제 토큰화기를 사용해 주석과 필요 없는 공백을 제거해, 문자열 내용, 템플릿 리터럴, 정규식이 절대 손상되지 않고, 의미를 담는 줄바꿈(return 뒤의 것 같은)은 항상 유지돼요.

JavaScript를 일반 텍스트로 취급하는 순진한 축소기는 문자열에 "//"가 포함되거나 정규식에 따옴표가 포함되는 순간 코드를 깨뜨려요. 이 도구는 먼저 코드를 토큰으로 어휘 분석한 뒤에야 무엇을 안전하게 제거할 수 있는지 결정해요.

JavaScript 축소기 사용법

  1. JavaScript를 위 상자에 붙여넣거나 입력하세요.
  2. JavaScript 축소를 클릭하세요.
  3. 크기 패널을 확인해 얼마나 절약됐는지 보세요.
  4. 결과를 복사하거나 .js 파일로 다운로드하세요 - 그리고 모든 축소기와 마찬가지로, 코드가 동일하게 동작하는지 확인하기 위해 한 번 실행하세요.

작동 방식

도구는 먼저 코드를 토큰으로 분할해요: 식별자, 숫자, 문자열, 템플릿 리터럴, 정규식, 구두점이에요. 주석은 이 스캔 중에 인식되고 버려지며, 스캐너는 나누기 기호와 정규식 시작의 차이를 알고, 문자열 안에서 주석 표시를 절대 찾지 않아요. 토큰은 그다음 다시 결합돼, 제거하면 의미가 바뀔 곳에서만 구분 공백을 추가해요 - 두 단어 사이, 플러스와 또 다른 플러스 사이 등에서요. 줄바꿈은 JavaScript의 자동 세미콜론 삽입이 의미 있게 만드는 곳마다 유지돼요, 가장 중요하게는 다음 뒤에 return, break 그리고 continue, 그리고 앞에 오는 ++ 또는 --.

풀이된 예시

주석이 있는 약 400 bytes의 유틸리티 함수는 보통 약 260 bytes로 압축돼요 - 대략 삼분의 일 작게요 - 반면 다음과 같은 문자열은 "see https://example.com // docs" 그 안은 완전히 손대지 않은 채로 통과해요.

자주 묻는 질문

이 JavaScript 축소기는 무료인가요?

네 - 완전히 무료, 회원가입 없음, 크기 제한 없음, 일일 상한 없음이에요.

완전한 빌드 도구 축소기와 어떻게 다른가요?

Terser 같은 빌드 도구도 변수 이름을 바꾸고 코드를 다시 써서 몇 퍼센트를 더 쥐어짜요. 이 도구는 의도적으로 보수적이에요: 아무것도 이름을 바꾸지 않고 표현식을 다시 쓰지 않으므로, 출력을 눈으로 확인하기 쉽고 빠르게 한 번 쓰는 용도에 안전해요.

코드를 망가뜨릴 수 있나요?

그렇게 하지 않도록 설계됐어요: 문자열, 템플릿 리터럴, 정규식 리터럴은 보호되고, 의미를 담은 줄바꿈은 보존돼요. 어떤 축소기도 모든 특이한 패턴에서 완벽을 약속할 수 없으므로, 축소한 뒤에는 항상 테스트 스위트를 실행하거나 페이지를 한 번 여세요 - 그 조언은 저희 것을 포함한 모든 축소기에 적용돼요.

정규식과 템플릿 리터럴을 처리하나요?

네. 토큰화기는 정규식 리터럴(문자 클래스와 이스케이프 포함)과 템플릿 리터럴, 중첩 ${ } 식을 포함해, 인식하고 변하지 않은 채 옮겨요.

제 코드가 서버에 업로드되나요?

아니요. 토큰화와 축소는 브라우저에서 100% 일어나요. 소스 코드는 기기를 절대 떠나지 않아요.
