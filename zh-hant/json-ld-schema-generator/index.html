JSON-LD Schema 生成器 - 無需手寫 JSON 的結構化資料

簡而言之： JSON-LD Schema 生成器為 16 種型別構建有效的 schema.org 結構化資料——文章、本地企業、產品、活動、食譜、人物、組織、網站、FAQ 頁面、操作指南、影片、書籍、課程、職位釋出、軟體應用和麵包屑列表，並將其包裝在 Google 期望的確切指令碼塊中。

結構化資料幫助搜尋引擎理解頁面，並可以解鎖富媒體結果。本生成器為您構建 JSON——並在您複製之前把它作為 JSON 驗證。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 JSON-LD Schema 生成器

  1. 選擇與您的頁面匹配的 schema 型別。
  2. 填寫適用的欄位——空白欄位會被簡單地省略。
  3. 點選“生成”並檢查 JSON-LD 程式碼塊。
  4. 把它貼上到頁面 head 中或閉合 body 標籤之前，然後用 Google 的富媒體搜尋結果測試測試線上頁面。

它如何工作

生成器以 schema.org 詞彙組裝一個 JavaScript 物件——@context、@type 和所選型別的屬性，包括巢狀物件，如 Product 的 Offer 和 AggregateRating、Article 的作者 Person，或 LocalBusiness PostalAddress——然後用嚴格的 JSON 格式化把它序列化，並重新解析自己的輸出以證明它是有效的 JSON，然後才顯示它。空欄位被完全省略，因為空屬性比缺失的屬性更糟。誠實的範圍：有效的 JSON-LD 使頁面 符合條件 以獲取富結果；Google 決定是否顯示它們，並且資料必須與頁面上可見的內容相匹配。

常見問題

這個生成器免費嗎？

是的——完全免費，無需註冊。

這會保證富媒體結果嗎？

沒有任何工具能保證這一點。正確的 JSON-LD 讓您有資格；Google 根據頁面、查詢及其政策做出選擇。

我把程式碼塊貼上在哪裡？

在頁面的 head 部分，或在閉合的 body 標籤之前——Google 在兩個位置都會讀取它。

資料必須與我的頁面匹配嗎？

是的。描述頁面上不可見內容的結構化資料可能會被忽略或被視為垃圾資訊。

有任何東西被上傳嗎？

不會。生成和驗證在您的瀏覽器中執行。
