Генератор таблиц HTML — создайте сетку, получите чистый код таблицы

Короче говоря: генератор таблиц HTML превращает визуальную сетку в чистый, семантический код таблицы HTML: thead и th для строки заголовков, tbody для данных, необязательная подпись и каждая ячейка правильно экранирована.

Написание табличной разметки вручную чревато ошибками: один отсутствующий закрывающий тег ломает всю вёрстку. Заполните сетку здесь и скопируйте код, который правилен по построению.

Приватность по замыслу: всё в этом инструменте происходит на 100% в вашем браузере с помощью JavaScript. Ваш ввод никогда не загружается на сервер, никогда не хранится и никогда не виден нам: закройте вкладку, и всё исчезнет.

Как использовать генератор таблиц HTML

  1. Установите количество строк и столбцов и нажмите «Создать сетку».
  2. Введите ваши значения в ячейки.
  3. Отметьте опцию заголовка, если первая строка обозначает столбцы.
  4. Нажмите «Сгенерировать HTML», проверьте предпросмотр и скопируйте код.

Как это работает

Генератор выдаёт семантическую разметку таблицы — настоящий thead с th ячейки, когда опция заголовка включена, чего ожидают программы чтения экрана и поисковые системы, плюс необязательный подпись. Каждое значение ячейки экранируется средствами HTML, поэтому ввод a < b создаёт текст, а не сломанный тег. Вывод не имеет собственного оформления; добавьте свой класс CSS в вашу таблицу стилей, чтобы таблица соответствовала вашему сайту, а не боролась со встроенными стилями.

Часто задаваемые вопросы

Бесплатен ли этот генератор?

Да — полностью бесплатно, без регистрации.

Включает ли результат стили?

Нет — только чистая семантическая разметка, поэтому ваш собственный CSS управляет внешним видом. Предварительный просмотр заимствует стиль таблицы этого сайта только для показа структуры.

Почему используются th и thead?

Ячейки заголовка объявляют значение столбца программам чтения с экрана и браузерам, улучшая доступность и то, как таблица понимается.

Могу ли я создать очень большую таблицу?

Сетка поддерживает до 30 строк и 10 столбцов, что охватывает подавляющее большинство таблиц содержимого, созданных вручную.

Загружается ли что-нибудь?

Нет. Всё происходит в вашем браузере.
