JavaScript 压缩工具 - 尊重您代码的保守压缩

简而言之： JavaScript 压缩工具使用真正的标记器删除注释和不需要的空白，因此字符串内容、模板字面量和正则表达式永不损坏，承载含义的换行符（如 return 后的换行）始终保留。

把 JavaScript 当作纯文本的朴素压缩工具，会在字符串包含 "//" 或正则包含引号的那一刻破坏代码。本工具先把您的代码分词为标记，然后才决定什么可以安全地移除。

  1. 把您的 JavaScript 粘贴或输入到上方框中。

  3. 查看大小面板，了解节省了多少。
  4. 复制结果，或把它下载为 .js 文件——并且，像使用任何压缩工具一样，运行一次您的代码，确认它的行为相同。

它如何工作

本工具首先把您的代码拆分为标记：标识符、数字、字符串、模板字面量、正则表达式和标点。注释在此扫描期间被识别并丢弃，扫描器知道除号与正则表达式开头之间的区别，也从不查看字符串内部的注释标记。然后标记被重新连接，仅在删除空格会改变含义的地方添加分隔空格——在两个词之间、在加号和另一个加号之间，等等。换行保留在 JavaScript 的自动分号插入使它们有意义的任何地方，最重要的是在……之后 return, break 和 继续，以及在一个开头的 ++ 或 --.

实例

一个约 400 字节的带注释的实用函数通常会压缩到约 260 字节——大约小三分之一——而像这样的字符串 "see https://example.com // docs" 在它内部的内容会完全原封不动地通过。

常见问题

这个 JavaScript 压缩工具免费吗？

是的——完全免费，无需注册，没有大小限制，也没有每日上限。

这与完整的构建工具压缩器有什么不同？

像 Terser 这样的构建工具还会重命名变量和重写代码，从而再多挤出几个百分点。本工具有意保持保守：它从不重命名任何东西，也从不重写表达式，所以输出容易肉眼检查，适合快速的一次性使用。

它会破坏我的代码吗？

它的设计正是为了不这样：字符串、模板字面量和正则字面量受到保护，承载意义的换行得以保留。没有任何压缩工具能承诺在每种奇特模式上都完美，所以压缩后请始终运行您的测试套件或打开一次页面——这条建议适用于每个压缩工具，包括我们的。

它能处理正则表达式和模板字面量吗？

是的。标记器可识别正则表达式字面量（包括字符类和转义）和模板字面量，包括嵌套的 ${ } 表达式，并将它们原样传递。

我的代码会被上传到服务器吗？

不会。分词和压缩 100% 在您的浏览器中进行。您的源代码从不离开您的设备。
