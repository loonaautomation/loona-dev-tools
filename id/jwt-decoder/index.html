Decoder JWT - Baca Header & Payload, Periksa Kedaluwarsa

Singkatnya: Decoder JWT membagi JSON Web Token menjadi header dan payload-nya, menunjukkan keduanya sebagai JSON yang mudah dibaca, dan menerjemahkan timestamp kedaluwarsa dan diterbitkan-pada menjadi tanggal polos. Ia tidak - dan tidak ada decoder yang dapat - membuktikan token asli.

JWT terlihat seperti satu string panjang yang tidak dapat dibaca, tetapi dua bagian pertamanya hanyalah JSON yang di-encode Base64url. Tempelkan token untuk membaca klaimnya - untuk siapa token itu, kapan kedaluwarsanya - saat debugging. Gunakan hanya untuk pemeriksaan; kepercayaan yang sesungguhnya membutuhkan verifikasi signature di server.

Penting: decoder ini melakukan TIDAK memverifikasi signature. Alat ini hanya membaca isi token. Jangan pernah memercayai JWT yang sudah didekode begitu saja - siapa pun dapat membuat atau mengubah token yang belum terverifikasi. Selalu validasi token dengan benar di server Anda.
Privat berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di browser Anda dengan JavaScript. Input Anda tidak pernah diunggah ke server, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Cara menggunakan Decoder JWT

  1. Tempel token lengkap (ketiga bagian) ke kotak.
  2. Klik Dekode Token.
  3. Baca header dan payload, dan periksa baris kedaluwarsa - lalu verifikasi token dengan benar di sistem Anda sendiri sebelum mempercayainya.

Cara kerja

JWT terdiri dari tiga string Base64url yang digabungkan dengan titik: header.payload.signature. Header menyebutkan algoritma penandatanganan; payload membawa klaim seperti sub (subject), iat (issued-at) dan exp (expiry, sebagai timestamp Unix dalam detik). Alat ini mendekode dua bagian pertama dari Base64url ke JSON - dekode yang persis sama dengan yang dilakukan kode Anda sendiri - dan mengonversi klaim waktu numerik menjadi tanggal yang dapat dibaca manusia. Bagian ketiga, signature, ditampilkan sebagai ada tetapi TIDAK diperiksa: memverifikasinya membutuhkan kunci rahasia atau kunci publik dan harus dilakukan di backend Anda.

Contoh yang dikerjakan

Mendekode token sampel klasik menunjukkan header {"alg":"HS256","typ":"JWT"} dan payload dengan sub "1234567890" dan iat 1516239022 - yang dirender alat ini sebagai "Thu, 18 Jan 2018 01:30:22 GMT", jauh lebih mudah dipahami daripada angka mentahnya.

Pertanyaan yang Sering Diajukan

Apakah decoder JWT ini gratis?

Ya - gratis, tanpa pendaftaran, tanpa batas.

Apakah alat ini memverifikasi token?

Tidak. Ia hanya mendekode. Token yang terdekode tidak membuktikan apa pun tentang keaslian - siapa pun dapat menulis payload apa pun dan meng-encode-nya. Verifikasi signature membutuhkan kunci dan termasuk di server Anda.

Mengapa payload tampak dapat dibaca sama sekali?

Bagian JWT di-encode, bukan dienkripsi. Encoding adalah untuk transportasi, bukan kerahasiaan - jangan pernah menaruh rahasia di payload JWT.

Apakah aman menempel token nyata di sini?

Token Anda terdekode 100% di browser Anda dan tidak pernah diunggah. Meski begitu, praktik baik adalah menghindari menempel token produksi langsung ke alat apa pun - gunakan token uji dengan bentuk yang sama.

Apa arti "exp"?

Waktu kedaluwarsa token sebagai timestamp Unix dalam detik. Alat ini mengonversinya menjadi tanggal yang mudah dibaca dan memberi tahu Anda apakah ia sudah kedaluwarsa.
