CSV 合并工具 - 按键列合并两张表

简而言之： CSV 连接工具以数据库 JOIN 的方式合并两个 CSV：选择每个文件中的关键列，选择内连接（仅匹配）或左连接（所有左行，右侧无匹配处为空），并获得一个合并的表格。

订单在一个文件中，客户在另一个文件中，共享列是 ID。这就是 VLOOKUP 的工作，做得妥妥当当——带数据库连接语义。

按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中使用 JavaScript 完成。您的输入从不上传到服务器，从不存储，我们也从不见过它——关闭标签，一切都消失了。

如何使用 CSV 合并工具

  1. 粘贴左侧（主）CSV 和右侧（查找）CSV。
  2. 指明每个文件中的键列——按标题名称或其编号。
  3. 选择 Left join 保留每一个左行，或选择 Inner join 仅保留匹配项。
  4. 点击“合并”并下载组合后的 CSV。

它如何工作

匹配遵循数据库规则：如果右表两次包含同一个键，一个左行会为每个匹配产生一个输出行（试试示例——Ken 出现了两次）。右键列本身不会在输出中重复，与左侧名称碰撞的右侧列名会获得 _2 后缀，这样任何东西都不会被覆盖。键按精确文本比较，所以 '001' 和 '1' 是不同的键——这是对 ID 和代码的安全行为。

常见问题

这个工具免费吗？

是的——完全免费，无需注册。

内连接和左连接有什么区别？

内连接仅保留两侧都匹配的行。左连接保留每个左行，在没有匹配时用空白填充右侧的列。

如果右侧文件有一个键出现两次怎么办？

您会为每个匹配得到一行输出，就像 SQL 连接一样——不会有任何东西被悄悄丢弃。

我的数据会被上传吗？

不会。合并 100% 在您的浏览器中运行。
