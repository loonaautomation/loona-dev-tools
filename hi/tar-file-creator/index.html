TAR फ़ाइल निर्माता — अपनी फ़ाइलों से .tar Archive बनाएँ

संक्षेप में: TAR फ़ाइल निर्माता किसी files के set को आपके browser में spec-correct ustar writer उपयोग करके एक single standard .tar archive में bundle करता है — फ़ाइलें जोड़ें, वैकल्पिक रूप से उन्हें folder में group करें, और download करें।

TAR अब भी Linux, servers और backups की lingua franca है — लेकिन Windows users जिन्हें tarball बनाना होता है उन्हें आम तौर पर पहले कुछ install करना पड़ता है। यह पेज असली TAR archives आपके ब्राउज़र में लिखता है: proper ustar headers, checksums और timestamps, आपके device पर बने कुछ अपलोड किए बिना।

याद रखें: TAR compress नहीं करता। .tar लगभग सभी जोड़ी गई फ़ाइलों के कुल size के बराबर होगा (512-byte blocks तक rounded)। इसे छोटा चाहिए? परिणाम को बाद में GZIP Compressor से गुज़ारें, या इसके बजाय ZIP File Creator उपयोग करें।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपकी फ़ाइलें कभी server पर upload नहीं होतीं, कभी stored नहीं होतीं और कभी हमारे द्वारा नहीं देखी जातीं — tab बंद करें और सब चला गया। एक ईमानदार limit: conversion आपके device की memory में होता है, इसलिए बहुत बड़े archives (सैकड़ों megabytes) low-memory phone पर slow या fail हो सकते हैं।

TAR फ़ाइल क्रिएटर का उपयोग कैसे करें

  1. अपनी फ़ाइलें ऊपर के box पर डालें, या उस पर click करें और अपने device से फ़ाइलें चुनें। आप कई rounds में फ़ाइलें जोड़ सकते हैं।
  2. List check करें — ग़लती से जोड़ा गया कुछ भी हटाएँ, और total size पर नज़र रखें।
  3. वैकल्पिक रूप से folder name type करें ताकि हर फ़ाइल archive में एक folder के अंदर रहे, और TAR को नाम दें।
  4. Create TAR & Download पर click करें। .tar Linux/macOS पर tar से, और Windows पर 7-Zip या WinRAR से खुलता है।

यह कैसे काम करता है

TAR archive records की एक stream है: हर फ़ाइल के लिए, एक 512-byte ustar header block (फ़ाइल नाम, octal में size, modification time, header का अपना checksum, 'ustar' magic, और एक prefix field जो paths को 100 characters से लंबे चलने देता है — उससे भी आगे के paths के लिए GNU longname entries के साथ), उसके बाद फ़ाइल की contents जो 512-byte blocks की पूरी संख्या तक padded होती हैं। दो zero blocks archive को बंद करते हैं। यह पेज उस format को सीधे implement करता है — कोई library नहीं, कोई server नहीं — और writer को Python के tarfile module से उसकी output को byte-for-byte वापस पढ़वाकर verify किया गया था। TAR फ़ाइलों को uncompressed रखता है, इसलिए archive उसके हिस्सों का जोड़ है; compression एक अलग step है (वही जो .tar.gz जोड़ता है)।

काम किया हुआ उदाहरण

आप तीन फ़ाइलें जोड़ते हैं: deploy.sh (1 KB), config.yml (3 KB) और logo.png (48 KB), folder name 'release' set के साथ। Tool release.tar बनाता है — या आपका चुना नाम — एक release folder रखते हुए सभी तीन फ़ाइलों के साथ, हर एक अपना असली modification time रखते हुए। 52 KB content पर TAR लगभग 54 KB निकलता है: फ़ाइलें स्वयं, तीन headers और padding, बिना compression — ठीक वही जो tar Linux पर बनाता।

अक्सर पूछे जाने वाले सवाल

क्या यह TAR file creator मुफ़्त है?

हाँ — मुफ़्त, कोई साइन-अप नहीं, कोई limits नहीं और कोई watermarks नहीं।

क्या मेरी फ़ाइलें किसी server पर अपलोड होती हैं?

नहीं। TAR आपके ब्राउज़र में चल रहे JavaScript द्वारा, आपके device पर लिखा जाता है। आपकी फ़ाइलें इसे कभी नहीं छोड़तीं।

TAR मेरी फ़ाइलों के same size क्यों है — या थोड़ा बड़ा?

TAR कुछ compress नहीं करता; यह सिर्फ़ bundle करता है। हर फ़ाइल एक 512-byte header भी जोड़ती है और 512-byte boundary तक padded होती है, इसलिए archive कच्चे total से थोड़ा बड़ा होता है। एक compressed tarball के लिए, TAR यहाँ बनाएँ और फिर इसे GZIP Compressor से गुज़ारें — ठीक ऐसे ही .tar.gz बनता है।

क्या Linux और GNU tar यहाँ बने archives स्वीकार करेंगे?

हाँ। Writer ustar specification का पालन करता है — correct octal fields और header checksum, ustar magic, long paths के लिए prefix splitting और बहुत लंबे वालों के लिए GNU longname entries — और इसका output testing के दौरान Python के tarfile module से इसे वापस पढ़कर verified था।

क्या मैं मौजूदा TAR में फ़ाइलें जोड़ सकता हूँ या सीधे .tar.gz बना सकता हूँ?

इस tool में नहीं — यह हर बार एक fresh archive बनाता है। मौजूदा ZIP को एक step में .tar.gz में बदलने के लिए, ZIP to TAR.GZ Converter उपयोग करें; इस TAR को .tar.gz में compress करने के लिए, बाद में GZIP Compressor उपयोग करें और परिणाम को .tar.gz rename करें।
