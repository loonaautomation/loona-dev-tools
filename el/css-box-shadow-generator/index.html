Γεννήτρια CSS Box Shadow - Πολυστρωματικές, Ρεαλιστικές Σκιές Οπτικά

Εν συντομία: η Γεννήτρια Σκιάς Πλαισίου CSS χτίζει CSS box-shadow στρώμα ανά στρώμα - μετατοπίσεις, θάμπωμα, εξάπλωση, χρώμα, αδιαφάνεια και εσωτερικό - με ζωντανή προεπισκόπηση, οπότε οι κάρτες και τα κουμπιά παίρνουν ρεαλιστικό βάθος αντί για ένα επίπεδο γκρι θάμπωμα.

Μια σκληρή σκιά φαίνεται ψεύτικη· δύο ή τρεις απαλές στρώσεις φαίνονται σαν φως. Αυτή η γεννήτρια κάνει τη στρώση εύκολη και δείχνει το αποτέλεσμα καθώς τη ρυθμίζετε.

Ιδιωτικό εκ σχεδιασμού: τα πάντα σε αυτό το εργαλείο συμβαίνουν 100% στο πρόγραμμα περιήγησής σας με JavaScript. Η είσοδός σας δεν ανεβαίνει ποτέ σε διακομιστή, δεν αποθηκεύεται ποτέ και δεν φαίνεται ποτέ από εμάς - κλείστε την καρτέλα και τα πάντα χάνονται.

Πώς να χρησιμοποιήσετε τη Γεννήτρια CSS Box Shadow

  1. Ρυθμίστε το πρώτο στρώμα: η κατακόρυφη μετατόπιση και το θάμπωμα κάνουν το μεγαλύτερο μέρος της δουλειάς.
  2. Ορίστε το χρώμα και χαμηλώστε την αδιαφάνεια για απαλότητα (το 0.1-0.3 είναι το ρεαλιστικό εύρος).
  3. Προσθέστε ένα δεύτερο, πιο σφιχτό στρώμα για βάθος επαφής, ή επιλέξτε Inset για εσωτερική σκιά.
  4. Αντιγράψτε το παραγόμενο CSS.

Πώς λειτουργεί

Ένα στρώμα box-shadow είναι offset-x offset-y blur spread colour, και τα πολλαπλά στρώματα χωρίζονται με κόμματα - το πρώτο στρώμα ζωγραφίζεται στην κορυφή. Η ρεαλιστική ανύψωση συνήθως συνδυάζει μια μικρή, πιο σκούρα σκιά επαφής με μια μεγαλύτερη, πιο απαλή σκιά περιβάλλοντος, γι' αυτό αυτό το εργαλείο είναι χτισμένο γύρω από στρώματα και όχι γύρω από μία μόνο σκιά. Τα χρώματα εκδίδονται ως rgba() ώστε η αδιαφάνεια να ταξιδεύει μαζί με το χρώμα, και το πλαίσιο προεπισκόπησης ενημερώνεται σε κάθε πάτημα πλήκτρου.
