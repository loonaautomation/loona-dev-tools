Генератор Clip-Path CSS - Формуйте свої елементи візуально

Коротко: генератор Clip-Path CSS дає вам готовий CSS clip-path для многокутників (від трикутника до зірки), кіл, еліпсів і вставок: виберіть фігуру, посуньте її точки, стежте за живим попереднім переглядом і копіюйте код. Зауважте: споріднені інструменти зображень цього сайту вже охоплюють градієнти; clip-path живе тут, бо це CSS макета, а не редагування зображень.

Clip-path перетворює прямокутники на дизайн: скошені секції, бейджі, стрілки й зірки однією властивістю CSS. Складна частина — координати, — цей інструмент бере їх на себе.

Приватно за задумом: усе в цьому інструменті відбувається на 100% у вашому браузері за допомогою JavaScript. Ваші вхідні дані ніколи не передаються на сервер, ніколи не зберігаються й ніколи не бачаться нами: закрийте вкладку — і все зникло.

Як користуватися генератором Clip-Path CSS

  1. Виберіть пресет фігури.
  2. Для многокутників налаштуйте відсотки x,y будь-якої точки.
  3. Стежте, як попередній перегляд оновлюється наживо.
  4. Скопіюйте CSS — включено і стандартну властивість, і -webkit-.

Як це працює

Точки многокутника — це відсотки від рамки елемента, тож фігури масштабуються разом з елементом. Пресети кодують добре відомі набори координат (правильний п’ятикутник, шестикутник, десятипроменева зірка та інше), а генератор видає обидва clip-path і -webkit- префіксним двійником, який Safari історично потребував. Коло, еліпс і вставка охоплюють не-многокутні фігури, які властивість підтримує, включно із заокругленими вставками.

Часті запитання

Чи цей генератор безкоштовний?

Так — цілком безкоштовно, без реєстрації.

Чому на сайті зображень також є генератор градієнтів?

Градієнти там трактуються як ресурси зображень/дизайну. Clip-path — це CSS макета для розробників, тож він живе тут, — кожен інструмент існує рівно на одному сайті Loona.

Чи впливає clip-path на кліки?

Так — відрізана область не клікабельна, що зазвичай саме те, що треба для фігурних кнопок і карток.

Підтримка браузерів?

Усі сучасні браузери підтримують clip-path; префікс -webkit- у результаті покриває старіші Safari.

Чи завантажується щось?

Ні. Усе виконується у вашому браузері.
