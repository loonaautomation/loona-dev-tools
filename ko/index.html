URL 파서 & 빌더

ZIP

ZIP 파일 생성기

여러 파일을 단일 ZIP 아카이브로 묶어요 - 브라우저에서 만들어지고, 업로드되는 것은 없어요.

UNZIP

압축 풀기 파일 추출기

ZIP을 열고, 크기와 함께 안의 모든 파일을 보고, 파일 하나 또는 모든 파일을 추출하세요.

RAR

RAR 파일 추출기

브라우저에서 RAR 파일(RAR4와 RAR5)을 여세요 - 안의 모든 파일을 보고, 파일 하나 또는 모든 것을 ZIP으로 다운로드하세요.

7Z

7Z 파일 추출기

브라우저에서 7z 아카이브를 여세요 - 내용을 보고 단일 파일이나 모든 것을 ZIP으로 추출하세요.

TAR

TAR 파일 추출기

브라우저에서 .tar, .tar.bz2, .tar.xz 아카이브를 열고 안의 파일을 추출하세요 - 업로드되는 것은 없어요.

TGZ

TAR.GZ 파일 추출기

브라우저에서 .tar.gz와 .tgz 아카이브를 여세요 - 안의 파일을 살펴보고 필요한 것을 추출하세요.

GZ

GZ 파일 추출기

브라우저에서 단일 .gz 파일의 압축을 풀고 원본을 다운로드하세요 - 로그, 데이터 내보내기, 데이터베이스 덤프예요.

ISO

ISO 파일 추출기

브라우저에서 ISO 디스크 이미지를 열고, 가상 디스크에 저장된 파일 시스템을 살펴보고 파일을 다운로드하세요.

ARC

아카이브 파일 추출기

ZIP, RAR, 7Z, TAR, ISO 등을 위한 하나의 보편적인 아카이브 열기 도구 - 형식은 자동으로 감지돼요.

R→ZIP

RAR를 ZIP으로 변환

RAR 아카이브를 브라우저에서 표준 ZIP으로 변환해요 - 폴더 구조 보존, 업로드되는 것 없어요.

7→ZIP

7Z를 ZIP으로 변환

7Z 아카이브를 어디서든 열리는 ZIP으로 변환해요 - 7-Zip 필요 없음, 업로드되는 것 없어요.

T→ZIP

TAR를 ZIP으로 변환

Linux나 Unix의 TAR 아카이브를 Windows, macOS, 휴대폰에서 기본으로 열리는 ZIP으로 변환해요.

G→ZIP

TAR.GZ를 ZIP으로 변환

.tar.gz나 .tgz를 하나의 ZIP으로 변환해요 - gzip과 tar 층이 모두 기기에서 풀려요.

Z→TGZ

ZIP을 TAR.GZ로 변환

ZIP 아카이브를 .tar.gz tarball로 변환해요 - Linux 서버, Docker, 빌드 도구가 기대하는 형식이에요.

+TAR

TAR 파일 생성기

브라우저에서 여러 파일로 사양에 맞는 .tar 아카이브를 만드세요 - 모든 tar 도구로 열려요.

GZIP

GZIP 압축기

브라우저의 내장 gzip 엔진으로 모든 단일 파일을 .gz로 압축해요 - 즉각적인 전후 크기예요.

Loona Developer Tools의 작동 방식

  1. 모든 도구를 열고 데이터를 붙여넣거나, 입력하거나, 불러오세요 - 설치할 것도 회원가입할 것도 없어요.
  2. 도구는 자체 브라우저 안에서 실행되는 JavaScript를 사용해, 즉시 작업을 해요.
  3. 결과를 복사하거나 다운로드하세요. 입력은 절대 업로드되지 않고, 저장되지 않으며, 저희가 보지도 않아요.
