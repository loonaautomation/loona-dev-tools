Kibadilishaji cha YAML ⇄ JSON - Kwa Faili za Usanidi za Kila Siku

Kwa ufupi: Kibadilishaji cha YAML ⇄ JSON hutafsiri seti ndogo ya YAML inayoshughulikia karibu kila faili halisi ya usanidi - jozi za key: value, ramani zilizoungiliana kwa ujongezaji, orodha zenye vistari, na scalar za mifululizo, nambari, boolean na null - kwa pande zote mbili, na kukwambia wazi kisichoungwa mkono.

Faili za usanidi huishi katika YAML; API na msimbo huishi katika JSON. Bandika mojawapo hapa chini kupata nyingine - na kichanganua cha sehemu ndogo cha uaminifu kinachoshughulikia miundo ambayo usanidi wa ulimwengu halisi hutumia kweli.

Faragha kwa muundo: kila kitu katika zana hii hutokea 100% kwenye kivinjari chako kwa JavaScript. Ingizo lako kamwe halipakiwi kwenye seva, kamwe halihifadhiwi na kamwe hatulioni - funga kichupo na kila kitu kimeondoka.

Jinsi ya kutumia Kibadilishaji cha YAML kwenda JSON

  1. Bandika YAML au JSON kwenye kisanduku cha juu.
  2. Bofya YAML → JSON au JSON → YAML kulingana na ingizo lako.
  3. Pitia tokeo - ingizo la YAML huwa JSON iliyochapishwa kwa uzuri; ingizo la JSON huwa YAML safi ya mtindo wa kizuizi.
  4. Nakili tokeo au lipakue.

Jinsi inavyofanya kazi

Kisomaji cha YAML hufanya kazi kwa mizunguko miwili: kwanza husawazisha hati yako kuwa mistari yenye ujongezaji wake (ikiondoa maoni nje ya nukuu), kisha huchanganua vizuizi kwa kurudia - mkusanyiko wa mistari kwa ujongezaji ule ule ni orodha ikiwa mistari huanza na kistari, ramani ikiwa hubeba funguo, au scalar moja. Funguo zisizo na thamani kwenye mstari ule ule huchukua kizuizi kilichojongezwa zaidi kinachofuata kama thamani yake. Scalar huandikwa kwa aina kwa njia ya YAML: maandishi yaliyonukuliwa hubaki mfululizo, true/false huwa boolean, null na ~ huwa null, na nambari wazi huwa nambari za JSON. Mwandishi kwa mwelekeo mwingine hutoa seti ndogo ile ile: ujongezaji wa nafasi mbili, vistari kwa orodha, na nukuu pale tu ambapo mfululizo ungekosoelewa vinginevyo.

Mfano uliofanyiwa kazi

Kipande cha mtindo wa docker-compose - jina la huduma, picha, orodha ya milango miwili - hubadilika kuwa kitu cha JSON chenye ramani iliyoingiliana na safu halisi, na kubadilisha JSON hiyo moja kwa moja kurudi hurejesha YAML ile ile, ambayo ndiyo hasa safari ya kurudi ambayo seti ya majaribio hukagua.

Maswali Yanayoulizwa Mara kwa Mara

Je, kibadilishaji hiki cha YAML kwenda JSON ni bure?

Ndiyo - bure kabisa, bila kujisajili, bila kikomo cha ukubwa na bila kikomo cha kila siku.

Ni vipengele vipi vya YAML vinavyoungwa mkono?

Seti ndogo ya kila siku: ramani zilizoungiliana kwa ujongezaji, orodha zenye vistari (pamoja na orodha za ramani), scalar zilizonukuliwa na wazi, nambari, boolean, null, na maoni. Hii hushughulikia sehemu kubwa zaidi ya faili za usanidi zilizoandikwa kwa mkono.

Ni vipengele vipi vya YAML AMBAVYO HAVIAUNIWI?

Viunga na majina mbadala (&a / *a), scalar za vizuizi vya mistari mingi (| na >), mtindo wa mtiririko ({a: 1} / [1, 2]), tegi, na faili za hati nyingi (---) hazichanganuliwi. Ikiwa faili yako inazitumia, badilisha kwa maktaba kamili ya YAML badala yake - tungependelea kusema hivyo kuliko kuzalisha ubadilishaji usio sahihi.

Je, JSON → YAML hunukuu mifululizo?

Wakati inahitajika tu: mfululizo unaoonekana kama nambari au boolean, ni tupu, au una herufi kama koloni ikifuatiwa na nafasi hunukuliwa mara mbili ili usomeke kurudi kama mfululizo ule ule.

Je, data yangu hupakiwa kwenye seva?

Hapana. Ubadilishaji hufanyika 100% kwenye kivinjari chako. Faili zako za usanidi haziondoki kamwe kwenye kifaa chako.
