CSV Join — एक Key Column पर दो Tables जोड़ें

संक्षेप में: CSV Join दो CSVs को वैसे merge करता है जैसे database JOIN करता है: हर फ़ाइल में key column चुनें, inner join (सिर्फ़ matches) या left join (सभी left rows, blanks जहाँ right side का कोई match न हो) चुनें, और एक combined table पाएँ।

एक फ़ाइल में orders, दूसरी में customers, और shared column एक ID है। यह VLOOKUP काम है, ठीक से किया गया — database join semantics के साथ।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

CSV Join का उपयोग कैसे करें

  1. Left (main) CSV और right (lookup) CSV paste करें।
  2. हर एक में key column का नाम दें — header name से या उसकी संख्या से।
  3. हर left row रखने के लिए Left join चुनें, या सिर्फ़ matches के लिए Inner join।
  4. Join पर click करें और combined CSV download करें।

यह कैसे काम करता है

Matching database rules का पालन करती है: अगर right table में एक ही key दो बार है, तो एक left row प्रति match एक output row बनाती है (sample आज़माएँ — Ken दो बार आता है)। Right key column खुद output में दोहराया नहीं जाता, और left-side नामों से टकराने वाले right-side column नामों को _2 suffixes मिलते हैं ताकि कुछ overwrite न हो। Keys exact text के रूप में compared होती हैं, इसलिए '001' और '1' अलग keys हैं — IDs और codes के लिए सुरक्षित behaviour।

अक्सर पूछे जाने वाले सवाल

क्या यह tool मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, कोई साइन-अप नहीं।

Inner और left join के बीच क्या अंतर है?

Inner join सिर्फ़ वे rows रखता है जो दोनों तरफ़ match करती हैं। Left join हर left row रखता है, right-side columns को blanks से भरते हुए जब कोई match न हो।

अगर right फ़ाइल में key दो बार हो तो क्या होगा?

आपको प्रति match एक output row मिलती है, ठीक SQL join की तरह — कुछ चुपके से drop नहीं होता।

क्या मेरा डेटा अपलोड होता है?

नहीं। Join 100% आपके ब्राउज़र में चलता है।
