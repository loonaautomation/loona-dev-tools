Estrattore Unzip - Apri ed estrai file ZIP

In breve: l'Estrattore Unzip apre un archivio .zip direttamente nel tuo browser con JSZip, elenca ogni file dentro con il suo percorso completo e dimensione, e ti lascia estrarre singoli file o tutti - nessun caricamento, nessuna installazione.

Qualcuno ti ha inviato uno ZIP e ti serve solo un file da esso - o vuoi sbirciare dentro prima di fidarti. Gli estrattori basati su caricamento fanno viaggiare il tuo archivio prima sul server di uno sconosciuto. Questo legge lo ZIP sul tuo dispositivo: guarda il contenuto, estrai esattamente ciò che ti serve, fatto.

Estrai tutto scarica i file uno dopo l'altro. Se il tuo browser chiede se consentire download multipli da questo sito, scegli Consenti - altrimenti estrai i file uno per uno con i loro pulsanti Estrai. I file estratti vengono salvati con il loro nome file semplice (le cartelle sono mostrate nell'elenco così puoi vedere la struttura dell'archivio, ma i browser salvano i download piatti).

Privato per design: tutto in questo strumento accade al 100% nel tuo browser con JavaScript. Il tuo archivio non viene mai caricato su un server, mai memorizzato e mai visto da noi - chiudi la scheda e tutto è andato. Un limite onesto: l'archivio viene spacchettato nella memoria del tuo dispositivo, quindi uno ZIP molto grande (centinaia di megabyte) può essere lento o fallire su un telefono con poca memoria.

Come usare l'Estrattore Unzip

  1. Trascina il tuo file .zip sulla casella sopra, o fai clic e scegli l'archivio dal tuo dispositivo.
  2. Leggi l'elenco: ogni voce appare con il suo percorso completo dentro l'archivio e la sua dimensione reale (non compressa). Le voci cartella sono marcate "folder".
  3. Fai clic su Estrai accanto a qualsiasi singolo file per scaricare solo quello, o usa Estrai tutti i file per scaricare tutto un file dopo l'altro.

Come funziona

Ogni ZIP finisce con una directory centrale che elenca ogni voce, dove si trovano i suoi dati nel file e quanto è grande compresso e non compresso. Questa pagina usa la libreria JSZip nel tuo browser per leggere quella directory nel momento in cui scegli un archivio - ed è per questo che l'elenco appare istantaneamente, prima che qualsiasi cosa venga estratta. Quando estrai un file, JSZip gonfia (de-DEFLATE) i suoi dati in memoria e il tuo browser lo salva come un normale download. Poiché tutto questo accade localmente, la stessa pagina funziona offline una volta caricata ed è sicura per archivi che non invieresti mai a un sito di caricamento.

Esempio pratico

Apri backup.zip (4.8 MB). L'elenco mostra una cartella photos contenente photos/img1.jpg (1.9 MB) e photos/img2.jpg (2.1 MB), più un readme.txt (1 KB) al livello superiore. Ti serve solo il readme - fai clic sul suo pulsante Estrai e solo quel file da 1 KB si scarica, senza spacchettare affatto le foto.

Domande frequenti

Questo strumento unzip è gratuito?

Sì - gratuito, nessuna registrazione, nessun limite e nessuna filigrana.

I miei file vengono caricati su un server?

No. L'archivio viene letto da JavaScript (JSZip) dentro il tuo browser e i file estratti vanno direttamente ai tuoi download. Lo ZIP e i suoi contenuti non lasciano mai il tuo dispositivo.

Può aprire uno ZIP protetto da password?

No. JSZip non può leggere archivi crittografati, quindi uno ZIP protetto da password fallirà nell'aprirsi qui. Usa uno strumento archivio desktop per i file crittografati.

Perché Extract All si è fermato dopo pochi file?

I browser proteggono dal download di molti file contemporaneamente da parte delle pagine. Questo strumento scarica i file uno dopo l'altro con una breve pausa; se il tuo browser lo chiede, consenti i download multipli per questo sito - o estrai i file uno per uno, che funziona sempre.

Funziona per file RAR, 7z o TAR?

No - questo estrattore gestisce solo archivi .zip standard. RAR e 7z usano formati di compressione diversi che richiedono librerie diverse.
