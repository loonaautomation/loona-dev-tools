Extrator de Ficheiros Unzip - Abra e Extraia Ficheiros ZIP

Em resumo: o Extrator de Ficheiros Unzip abre um ficheiro .zip diretamente no seu navegador com JSZip, lista cada ficheiro dentro com o seu caminho completo e tamanho, e permite-lhe extrair ficheiros individuais ou todos - sem carregamento, sem instalação.

Alguém lhe enviou um ZIP e só precisa de um ficheiro dele - ou quer espreitar dentro antes de confiar nele. Extratores baseados em carregamento fazem o seu ficheiro viajar primeiro para o servidor de um estranho. Este lê o ZIP no seu próprio dispositivo: veja o conteúdo, extraia exatamente o que precisa, pronto.

Largue um ficheiro .zip aqui ou clique para escolher um do seu dispositivo
Caminho dentro do ZIPTamanho

Extrair Tudo transfere os ficheiros um após outro. Se o seu navegador perguntar se permite várias transferências deste site, escolha Permitir - caso contrário, extraia os ficheiros um a um com os seus botões Extrair. Os ficheiros extraídos são guardados com o seu nome de ficheiro simples (as pastas são mostradas na lista para ver a estrutura do ficheiro, mas os navegadores guardam as transferências planas).

Privado por conceção: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. O seu ficheiro nunca é carregado para um servidor, nunca guardado e nunca visto por nós - feche o separador e tudo desaparece. Um limite honesto: o ficheiro é desempacotado na memória do seu dispositivo, pelo que um ZIP muito grande (centenas de megabytes) pode ser lento ou falhar num telemóvel com pouca memória.

Como utilizar o Extrator de Ficheiros Unzip

  1. Largue o seu ficheiro .zip na caixa acima, ou clique nela e escolha o arquivo do seu dispositivo.
  2. Leia a listagem: cada entrada aparece com o seu caminho completo dentro do ficheiro e o seu tamanho real (sem compressão). As entradas de pasta estão marcadas como "folder".
  3. Clique em Extrair junto a qualquer ficheiro para transferir apenas esse, ou utilize Extrair Todos os Ficheiros para transferir tudo, um ficheiro após outro.

Como funciona

Cada ZIP termina com um diretório central que lista cada entrada, onde os seus dados estão no ficheiro e qual o seu tamanho comprimido e sem compressão. Esta página utiliza a biblioteca JSZip no seu navegador para ler esse diretório no momento em que escolhe um ficheiro - razão pela qual a listagem aparece instantaneamente, antes de qualquer coisa ser extraída. Quando extrai um ficheiro, o JSZip insufla (des-DEFLATE) os seus dados em memória e o seu navegador guarda-o como uma transferência normal. Como tudo isto acontece localmente, a mesma página funciona offline depois de carregada e é segura para arquivos que nunca enviaria para um site de carregamento.

Exemplo resolvido

Abre backup.zip (4.8 MB). A listagem mostra uma pasta photos contendo photos/img1.jpg (1.9 MB) e photos/img2.jpg (2.1 MB), mais um readme.txt (1 KB) no nível superior. Só precisa do readme - clique no seu botão Extrair e apenas esse ficheiro de 1 KB é transferido, sem desempacotar as fotos de todo.

Perguntas Frequentes

Esta ferramenta de unzip é grátis?

Sim - grátis, sem registo, sem limites e sem marcas de água.

Os meus ficheiros são carregados para um servidor?

Não. O ficheiro é lido por JavaScript (JSZip) dentro do seu navegador e os ficheiros extraídos vão diretamente para as suas transferências. O ZIP e o seu conteúdo nunca saem do seu dispositivo.

Pode abrir um ZIP protegido por palavra-passe?

Não. O JSZip não consegue ler arquivos encriptados, pelo que um ZIP protegido por palavra-passe falhará ao abrir aqui. Utilize uma ferramenta de arquivos de ambiente de trabalho para ficheiros encriptados.

Porque é que Extrair Tudo parou depois de alguns ficheiros?

Os navegadores protegem contra páginas que transferem muitos ficheiros de uma vez. Esta ferramenta transfere os ficheiros um após outro com uma pequena pausa; se o seu navegador perguntar, permita várias transferências para este site - ou extraia os ficheiros um a um, o que funciona sempre.

Funciona para ficheiros RAR, 7z ou TAR?

Não - este extrator trata apenas arquivos .zip padrão. RAR e 7z utilizam formatos de compressão diferentes que precisam de bibliotecas diferentes.
