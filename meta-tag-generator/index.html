Meta Tag Generator - A Ready-to-Paste Head Block With SERP Preview

In short: the Meta Tag Generator builds the standard head meta block - charset, viewport, title, description, keywords, author, robots and canonical - while a live SERP-style preview and character counts show how the page may appear on Google.

Meta tags are small, easy to mistype and painful to redo per page. Fill the form, check the preview and counts, and copy a correct block straight into your head section.

How to use the Meta Tag Generator

  1. Type the page title and meta description - watch the character counts.
  2. Add keywords and author if you use them, and pick the robots setting.
  3. Paste the canonical URL (the one true address of the page).
  4. Copy the generated block into the <head> of your page.

How it works

Charset and viewport are always emitted first, in the order browsers and crawlers expect, because a charset declared late can be ignored. Values are attribute-escaped, so a quote inside a description can never break out of its attribute. The preview mirrors how Google typically renders a result - site name line, blue title, grey description - and the counters flag the ranges most SEOs aim for: roughly 50-60 characters for titles and 150-160 for descriptions, beyond which Google usually truncates. The keywords tag is included for completeness; Google has ignored it for ranking for many years, and the generator says so honestly rather than promising it helps.

Frequently Asked Questions

Is this generator free?

Yes - completely free, no sign-up.

Does the keywords meta tag help ranking?

Google has not used it for web ranking since 2009. It is included because some other tools and internal search systems still read it.

What robots value should I pick?

index, follow for normal pages. Use noindex for thank-you pages, internal search results and anything you do not want in search results.

What is a canonical URL?

The single address you declare as the official version of a page, so duplicate URLs (with tracking parameters, www vs non-www) consolidate onto it.

Is anything uploaded?

No. The block is generated in your browser.
