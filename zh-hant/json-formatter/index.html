JSON 格式化與驗證工具 - 美觀列印和壓縮 JSON

簡而言之： JSON 格式化工具檢查您的 JSON，以 2 空格、4 空格或製表符縮排對其進行精美列印，按要求對其進行壓縮，如果有任何問題，它會告訴您問題確切的行和列。

損壞的 JSON 是開發者一天中最常見的五分鐘延誤——少一個逗號，整個負載就失敗了。把您的 JSON 貼上到下面：如果有效，您會得到乾淨、可讀的輸出；如果無效，您會得到錯誤的準確位置，而不是一句無用的“解析失敗”。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 JSON 格式化工具

  1. 把您的 JSON 貼上或輸入到上方框中。
  2. 選擇縮排樣式——2 個空格、4 個空格或製表符。
  3. 點選“格式化 / 驗證”獲得可讀的輸出，或點選“壓縮”獲得最小的有效形式。
  4. 複製結果，或把它下載為 .json 檔案。

它如何工作

本工具使用您瀏覽器內建的 JSON 解析器——您的 JavaScript 程式碼使用的同一個嚴格解析器——所以這裡的綠燈意味著您的 JSON 真的有效。美化列印用您選擇的縮排重新序列化解析後的值；鍵的順序精確保留原樣。壓縮刪除每個不必要的空格和換行，不改變單個值。當解析失敗時，本工具把解析器的字元位置轉換為行和列，並向您展示出問題的那一行。

例項

您收到 {"user":"ahmed","roles":["admin","editor"],"active":true} 來自一個 API。用 2 個空格格式化後，它會變成一個乾淨的九行文件，您真正可以閱讀——如果您不小心刪除了 "ahmed" 後的逗號，工具會在確切的行和列報告錯誤，而不是讓您自己去尋找。

常見問題

這個 JSON 格式化工具免費嗎？

是的——完全免費，無需註冊，沒有大小限制，也沒有每日上限。

當我的 JSON 無效時會發生什麼？

您會得到解析器的錯誤訊息，以及解析失敗的確切行和列，還有該行的文字，讓您可以在幾秒鐘內修復它。

格式化會改變我的資料嗎？

不會。格式化只改變空白。壓縮只移除空白。鍵、值及其順序不受影響。

我的 JSON 會被上傳到伺服器嗎？

不會。解析和格式化 100% 在您的瀏覽器中進行。API 負載和配置檔案從不離開您的裝置。

我可以格式化非常大的 JSON 嗎？

是的——實際限制是您裝置的記憶體。幾兆位元組的檔案在普通膝上型電腦上不到一秒就能完成格式化。
