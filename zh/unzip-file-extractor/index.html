解压文件提取工具 - 打开并解压 ZIP 文件

简而言之： 解压文件提取器使用 JSZip 直接在您的浏览器中打开一个 .zip 归档，列出里面的每个文件及其完整路径和大小，并让您提取单个文件或全部文件——无需上传，无需安装。

有人给您发了一个 ZIP，而您只需要其中的一个文件——或者您想在信任它之前先窥探里面。基于上传的解压工具让您的归档先去陌生人的服务器。这个在您自己的设备上读取 ZIP：查看内容，取出您正好需要的东西，完成。

“全部解压”会一个接一个地下载文件。如果您的浏览器询问是否允许来自本站的多个下载，请选择“允许”——否则就用每个文件的解压按钮逐个解压。解压出的文件以其纯文件名保存（文件夹会显示在列表中，让您能看到归档的结构，但浏览器以扁平方式保存下载）。

按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中使用 JavaScript 完成。您的归档从不上传到服务器，从不存储，我们也从不见过它——关闭标签，一切都消失了。一个诚实的限制：归档在您设备的内存中解压，所以一个非常大的 ZIP（数百兆字节）在内存不足的手机上可能会很慢或失败。

如何使用 ZIP 文件解压工具

  1. 把您的 .zip 文件拖到上面的框中，或点击它从您的设备中选择归档。
  2. 阅读列表：每个条目都以其在归档内的完整路径和真实（未压缩）大小出现。文件夹条目标记为“文件夹”。
  3. 点击任何单个文件旁边的“解压”只下载那一个，或使用“解压全部文件”一个接一个地下载所有内容。

它如何工作

每个 ZIP 都以一个中央目录结尾，它列出每个条目、其数据在文件中的位置以及压缩和未压缩的大小。本页在您的浏览器中使用 JSZip 库，在您选择归档的那一刻读取该目录——这正是列表在任何东西被解压之前就瞬间出现的原因。当您解压一个文件时，JSZip 在内存中膨胀（解除 DEFLATE）其数据，您的浏览器把它保存为普通下载。因为这一切都在本地发生，同一页面加载后可以离线工作，并且对您永远不会发送到上传网站的归档也是安全的。

实例

您打开 backup.zip（4.8 MB）。列表显示一个 photos 文件夹，其中包含 photos/img1.jpg（1.9 MB）和 photos/img2.jpg（2.1 MB），再加上顶层的一个 readme.txt（1 KB）。您只需要 readme——点击它的提取按钮，就只下载那 1 KB 的文件，完全不用解压照片。

常见问题

这个解压工具免费吗？

是的——免费，无需注册，没有限制，也没有水印。

我的文件会被上传到服务器吗？

不会。归档由您浏览器内部的 JavaScript（JSZip）读取，解压出的文件直接进入您的下载。ZIP 及其内容从不离开您的设备。

它能打开受密码保护的 ZIP 吗？

不会。JSZip 无法读取加密的归档，所以受密码保护的 ZIP 在这里会打开失败。加密文件请使用桌面归档工具。

为什么“全部解压”在几个文件后停止了？

浏览器会阻止页面一次下载许多文件。本工具会以短暂的间隔一个接一个地下载文件；如果您的浏览器询问，请允许本站的多个下载——或者逐个解压文件，这种方法永远有效。

它适用于 RAR、7z 或 TAR 文件吗？

不会——本解压工具只处理标准的 .zip 归档。RAR 和 7z 使用不同的压缩格式，需要不同的库。
