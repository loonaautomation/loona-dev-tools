ZIPファイル作成ツール - 複数のファイルからZIPを作成

要するに： ZIPファイル作成ツールは、ファイルのセットを単一の標準 .zip アーカイブにまとめます。JSZipを使ってブラウザで完全に構築されます。ファイルを追加し、任意でフォルダにグループ化し、圧縮レベルを選んでダウンロードしてください。

十の添付ファイルを一つずつ送ること、プロジェクトフォルダを引き渡すこと、写真のバッチをアーカイブすること。ZIPはファイルの山を一つの整ったダウンロードに変えます。ほとんどのオンラインZIPツールは、まずファイルをサーバーにアップロードします。これは違います。アーカイブはあなたのデバイス上で組み立てられるため、プライベートなファイルでさえどこにも移動しません。

圧縮に関する注意：テキスト、コード、CSVファイルは DEFLATE で大きく縮みます。写真、ビデオ、PDFはすでに圧縮されているため、ZIPはどちらの方法でもほぼ同じサイズになります — それらには「保存」を選ぶと即座に完了します。

設計上プライベート： このツールのすべては、JavaScriptを使ってブラウザで100%行われます。あなたのファイルはサーバーにアップロードされることは決してなく、保存されることも、私たちに見られることもありません。タブを閉じるとすべてが消えます。一つの正直な制限：ZIPはあなたのデバイスのメモリ内で構築されるため、非常に大きなファイルセット（数百メガバイト）は、低メモリの電話では遅くなったり失敗したりすることがあります。

ZIPファイル作成ツールの使い方

  1. ファイルを上のボックスにドロップするか、ボックスをクリックしてデバイスからファイルを選んでください。ファイルは数回に分けて追加できます。
  2. リストを確認してください — 間違って追加したものは取り除き、合計サイズに注意してください。
  3. すべてのファイルをアーカイブ内の一つのフォルダに入れたい場合は、任意でフォルダ名を入力し、ZIPに名前を付けてください。
  4. 圧縮レベルを選び（ほとんどの作業には「圧縮」が適切です）、「ZIPを作成＆ダウンロード」をクリックしてください。

仕組み

ZIPアーカイブは、各ファイルのデータと、末尾にあるセントラルディレクトリを保存します。セントラルディレクトリには、すべてのエントリ、その名前とサイズが一覧されています。そのため、どのシステムの解凍ツールでも開くことができます。このページは、ブラウザ内でJSZipライブラリを使います。選んだファイルをメモリに読み取り、任意で各ファイルをDEFLATEアルゴリズム（古典的なZIPツールが使うのと同じもの）で圧縮し、ディレクトリを書き込み、完成したアーカイブを一つのダウンロードとしてお渡しします。同名のファイルは保持され、自動的に番号が付けられます — 二番目の report.pdf は report (1).pdf になります — そのため、黙って上書きされるものは何もありません。

実例

三つのファイルを追加します：report.pdf（240 KB）、photo.jpg（1.2 MB）、notes.txt（2 KB）。フォルダ名は「handover」に設定します。このツールはhandover.zip（または選んだ名前）を生成し、内部に三つのファイルすべてを含むhandoverフォルダを持ちます。ダウンロードは約1.4 MBです。PDFとJPGがすでに圧縮されていたためです。ファイルが通常のテキストとCSVエクスポートであったら、同じアーカイブは簡単に元のサイズの三分の一になっていたでしょう。

よくある質問

このZIPファイル作成ツールは無料ですか？

はい - 無料、登録不要、制限なし、透かしなし。

私のファイルはサーバーにアップロードされますか？

いいえ。ZIPは、ブラウザで動作するJavaScript（JSZip）によって構築されます。ファイルがデバイスから出ることは決してありません。そのため、プライベートドキュメントにも安全です。

なぜ私のZIPは元のファイルとほぼ同じサイズなのですか？

JPG、PNG、MP4、MP3、PDFのような形式はすでに圧縮されているため、ZIP圧縮でそれ以上大きく縮めることはできません。テキストベースのファイル（TXT、CSV、HTML、JSON、ソースコード、ログ）は通常大きく縮みます。

ファイルサイズの制限はありますか？

ツールには制限が組み込まれていませんが、アーカイブはブラウザのメモリ内に組み立てられます。数百メガバイトはほとんどのデスクトップで問題ありません。非常に大きなセットは、低価格帯の電話では遅くなったりメモリ不足になったりすることがあります。苦労する場合は、ファイルを小さいZIPに分割してください。

ZIPをパスワードで保護したり、既存のものにファイルを追加したりできますか？

このツールではできません。暗号化のない、新しい標準ZIPを作成します。ファイルを受け取った誰もが開けるため、秘密を守るのにZIPだけを頼りにしないでください。
