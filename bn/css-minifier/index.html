CSS মিনিফায়ার ও বিউটিফায়ার - CSS সংকুচিত করুন বা পাঠযোগ্য করুন

সংক্ষেপে: CSS Minifier মন্তব্য এবং অপ্রয়োজনীয় হোয়াইটস্পেস ছেঁটে আপনার স্টাইলশিট সঙ্কুচিত করে এবং হুবহু আকারের সাশ্রয় রিপোর্ট করে, যেখানে Beautify মোড মিনিফাই করা CSS-কে পরিষ্কার, ইন্ডেন্ট করা কোডে ফিরিয়ে দেয়।

CSS-এর প্রতিটি কিলোবাইট আপনার পেজের প্রথম পেইন্ট বিলম্বিত করে। প্রোডাকশনের জন্য সংকুচিত করতে নিচে একটি স্টাইলশিট পেস্ট করুন, বা আবার পড়তে ও সম্পাদনা করতে হলে Beautify-এর মাধ্যমে একটি মিনিফাই করা ফাইল চালান।

মূল আকার-
ফলাফলের আকার-
আপনি সংরক্ষণ করেছেন-
নকশায় ব্যক্তিগত: এই টুলে সবকিছু JavaScript দিয়ে আপনার ব্রাউজারে 100% ঘটে। আপনার ইনপুট কখনও একটি সার্ভারে আপলোড হয় না, কখনও সংরক্ষিত হয় না এবং কখনও আমাদের দ্বারা দেখা হয় না - ট্যাব বন্ধ করুন এবং সবকিছু চলে গেছে।

CSS মিনিফায়ার কীভাবে ব্যবহার করবেন

  1. আপনার CSS উপরের বাক্সে পেস্ট করুন বা টাইপ করুন।
  2. এটি সংকুচিত করতে CSS মিনিফাই করুন-এ ক্লিক করুন, বা ইনডেন্টেশনসহ ফরম্যাট করতে CSS সুন্দর করুন।
  3. আকার প্যানেল পরীক্ষা করুন - এটি মূল আকার, ফলাফলের আকার ও সাশ্রয় করা শতাংশ দেখায়।
  4. ফলাফল কপি করুন বা এটি একটি .css ফাইল হিসেবে ডাউনলোড করুন।

এটি কীভাবে কাজ করে

মিনিফায়ার প্রথমে আপনার CSS অক্ষর-দ্বারা-অক্ষর হাঁটে ও মন্তব্য সরায় - উদ্ধৃত স্ট্রিং সম্পূর্ণ অস্পর্শিত রেখে, তাই একটি content মন্তব্য-সদৃশ টেক্সট ধারণকারী একটি মান অক্ষত টিকে থাকে। তারপর এটি হোয়াইটস্পেস রান ভেঙে দেয় এবং ব্রেস, সেমিকোলন, কমা এবং কম্বিনেটরের চারপাশের স্পেস এবং কোলনের পরের স্পেস সরিয়ে দেয়। এটি ইচ্ছাকৃতভাবে কখনও স্পর্শ করে না ভিতরের calc() এক্সপ্রেশন বা স্ট্রিং মান, যেখানে স্পেস অর্থ বহন করে। Beautify মোড প্রক্রিয়াটি উল্টে দেয়: এটি সংকুচিত CSS-কে প্রতি লাইনে একটি ঘোষণা হিসেবে নেস্টিং স্তর অনুযায়ী দুই-স্পেস ইন্ডেন্টেশনসহ পুনরায় খোলে।

কাজ করা উদাহরণ

মন্তব্য ও উদার স্পেসিংসহ একটি সাধারণ হাতে-লেখা স্টাইলশিট নিয়ম - ধরুন একটি 240-বাইট হেডার ব্লক - সাধারণত প্রায় 150 বাইটে মিনিফাই হয়, প্রায় 35-40% সাশ্রয়। একটি পুরো সাইটে তা একটি দৃশ্যত দ্রুততর প্রথম রেন্ডারে যোগ হয়, বিশেষ করে মোবাইল সংযোগে।

প্রায়শই জিজ্ঞাসিত প্রশ্ন

এই CSS মিনিফায়ার কি বিনামূল্যে?

হ্যাঁ - সম্পূর্ণ বিনামূল্যে, কোনো সাইন-আপ ছাড়া, কোনো আকারের সীমা ছাড়া এবং কোনো দৈনিক সীমা ছাড়া।

মিনিফাই করা CSS কি স্থাপন করা নিরাপদ?

মিনিফায়ার শুধু মন্তব্য ও হোয়াইটস্পেস সরায় যা CSS-এর দরকার নেই। নির্বাচক, বৈশিষ্ট্য ও মান অপরিবর্তিত, এবং স্ট্রিং মান ও calc() এক্সপ্রেশন কখনও বদলানো হয় না। যেকোনো মিনিফায়ারের মতো, মোতায়েনের পর পেজ একবার পরীক্ষা করুন।

এটি নির্বাচকদের মধ্যে একটি কোলনের আগে কেন একটি স্পেস রাখে?

কলনের আগে একটি স্পেস CSS-এ অর্থবহ হতে পারে - ".a :hover" হোভার করা বংশধরদের নির্বাচন করে, যখন ".a:hover" উপাদানটিকেই নির্বাচন করে। নিরাপদ থাকতে, টুলটি কলনের পরের স্পেস সরায় কিন্তু আগেরটি নিয়ে কখনও অনুমান করে না।

এটি কি CSS-ও সুন্দর করতে পারে?

হ্যাঁ। Beautify মোড সংকুচিত CSS নেয় এবং সামঞ্জস্যপূর্ণ ইন্ডেন্টেশনসহ প্রতি লাইনে একটি ঘোষণা হিসেবে প্রসারিত করে, যা আদর্শ যখন আপনি একটি মিনিফাই করা ফাইল উত্তরাধিকার সূত্রে পান এবং এটি সম্পাদনা করতে হয়।

আমার CSS কি সার্ভারে আপলোড হয়?

না। মিনিফাই ও সুন্দর করা 100% আপনার ব্রাউজারে হয়। আপনার স্টাইলশিট কখনও আপনার ডিভাইস ছাড়ে না।
