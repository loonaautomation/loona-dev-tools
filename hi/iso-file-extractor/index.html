ISO फ़ाइल एक्सट्रैक्टर — ISO Disc Images ऑनलाइन खोलें

संक्षेप में: ISO फ़ाइल एक्सट्रैक्टर .iso disc images आपके browser में खोलता है — virtual CD या DVD पर stored folders और फ़ाइलें browse करें, single फ़ाइलें download करें, या सब कुछ ZIP के रूप में save करें। कोई disc mounting नहीं, कोई install नहीं, कोई upload नहीं।

.iso फ़ाइल एक CD या DVD की एक single फ़ाइल में पूरी copy है: Linux installers, पुराने software discs, और archived game या driver CDs सभी ISO के रूप में रहते हैं। Windows उन्हें mount कर सकता है, लेकिन सिर्फ़ administrator के रूप में और सिर्फ़ browse करने के लिए — एक फ़ाइल निकालना अब भी झंझट है। यह पेज image के अंदर के ISO9660 file system को libarchive के WebAssembly port से पढ़ता है, ठीक आपके ब्राउज़र में।

अपनी .iso फ़ाइल यहाँ डालें या अपने device से फ़ाइल चुनने के लिए click करें
Archive के अंदर की फ़ाइलSize
Design से निजी: इस tool में सब कुछ 100% आपके browser में होता है। Disc image आपके अपने device पर WebAssembly engine द्वारा पढ़ी जाती है — कभी upload नहीं, कभी stored नहीं, कभी हमारे द्वारा नहीं देखी गई। एक ईमानदार limit: disc images स्वभाव से बड़ी होती हैं और listing आपके device की memory में built होती है, इसलिए full dual-layer DVD image (8 GB) सिर्फ़ पर्याप्त RAM वाले desktop पर realistic है।

ISO फ़ाइल एक्सट्रैक्टर का उपयोग कैसे करें

  1. अपनी .iso फ़ाइल ऊपर के box पर डालें, या उस पर click करें और अपने device से फ़ाइल चुनें।
  2. एक क्षण प्रतीक्षा करें जबकि image पढ़ी जाती है — पहले उपयोग पर engine (लगभग 1 MB) एक बार load होता है और फिर आपके browser द्वारा cached होता है।
  3. Virtual disc पर रखी फ़ाइलों को browse करें, उनके folders और sizes के साथ।
  4. किसी single फ़ाइल के बगल में Download पर click करें, या disc की contents को एक standard ZIP फ़ाइल के रूप में save करने के लिए Download all as ZIP उपयोग करें।

यह कैसे काम करता है

ISO image एक ISO9660 file system रखती है: शुरुआत के पास एक volume descriptor records के directory tree की ओर इशारा करता है, और हर record उन disc sectors की ओर जो किसी फ़ाइल का डेटा रखते हैं। यह पेज उस structure को WebAssembly में compile किए गए libarchive से पढ़ता है — Joliet extension समेत जिसे Windows-authored discs लंबे, mixed-case फ़ाइल नामों के लिए उपयोग करती हैं — और हर फ़ाइल को उसके path और size के साथ सूचीबद्ध करता है। फ़ाइलें तभी copy होती हैं जब आप download करते हैं; Download all as ZIP उन्हें JSZip से दोबारा pack करता है।

काम किया हुआ उदाहरण

आप एक पुराना language-course CD course.iso (640 MB) के रूप में रखते हैं बहुत बाद तक जब आपके laptop ने अपनी disc drive खो दी। आप image यहाँ खोलते हैं, audio folder खोजते हैं, और वे बारह lesson MP3s download करते हैं जो आपको चाहिए (180 MB) — कोई mounting नहीं, कोई burning नहीं, कोई external drive नहीं।

अक्सर पूछे जाने वाले सवाल

क्या यह tool bootable installer ISOs खोल सकता है, जैसे Linux या Windows installer?

हाँ, browsing और फ़ाइलें extract करने के लिए — अंदर का file system वही ISO9660 format है। नोट करें कि फ़ाइलें extract करना आपको bootable USB stick नहीं देता; operating system install करने के लिए आपको अब भी Rufus या Balena Etcher जैसा proper imaging tool चाहिए।

कुछ file names SHOUTY और छोटे क्यों दिखते हैं, जैसे SETUP.EXE;1?

यह सादा ISO9660 naming style है (uppercase, limited characters, एक ;1 version tag) जो पुराने mastering software द्वारा उपयोग होती है। Joliet या Rock Ridge extensions से mastered discs अपने सामान्य long names रखती हैं, और यह tool उन्हें दिखाता है जब वे मौजूद हों।

क्या यह .img, .bin या .dmg फ़ाइलें खोल सकता है?

कुछ .img फ़ाइलें दूसरे नाम के नीचे raw ISO images हैं और खुलेंगी अगर उनकी content सच में ISO9660 है। .dmg Apple का अपना compressed format है और इस engine से supported नहीं है — अगर कोई फ़ाइल ISO image नहीं है, तो tool कहेगा कि यह खोली नहीं जा सकी, अंदाज़ा लगाने के बजाय।

क्या पूरा ISO memory में load होता है?

फ़ाइल आपके browser द्वारा आपके device से पढ़ी जाती है और listing memory में बनती है। Everyday CD-sized images (लगभग 1 GB तक) ज़्यादातर desktops पर ठीक हैं; बहुत बड़ी DVD images phones या low-memory machines पर slow हो सकती हैं।

क्या मेरी फ़ाइलें कहीं अपलोड होती हैं?

नहीं। Image आपके browser tab के अंदर WebAssembly द्वारा parse होती है। न ISO न उसके अंदर की फ़ाइलें कभी आपके device से बाहर जाती हैं।
