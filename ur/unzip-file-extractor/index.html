ان زِپ فائل ایکسٹریکٹر - ZIP فائلیں کھولیں اور نکالیں

مختصراً: ان زِپ فائل ایکسٹریکٹر .zip آرکائیو عین آپ کے براؤزر میں JSZip سے کھولتا ہے، اندر ہر فائل اس کے مکمل راستے اور سائز کے ساتھ درج کرتا ہے، اور آپ کو واحد فائلیں یا ان سب کو نکالنے دیتا ہے - کوئی اپ لوڈ نہیں، کوئی انسٹال نہیں۔

کسی نے آپ کو ZIP بھیجا اور آپ کو اس سے صرف ایک فائل چاہیے - یا آپ اس پر بھروسہ کرنے سے پہلے اندر جھانکنا چاہتے ہیں۔ اپ لوڈ-مبنی ایکسٹریکٹرز آپ کے آرکائیو کو پہلے اجنبی کے سرور تک سفر کراتے ہیں۔ یہ آپ کے اپنے آلے پر ZIP پڑھتا ہے: مندرجات دیکھیں، عین جو چاہیے نکالیں، ختم۔

ایک .zip فائل یہاں ڈالیں یا ایک اپنے آلے سے منتخب کرنے کے لیے کلک کریں
ZIP کے اندر راستہسائز

Extract All فائلیں ایک کے بعد ایک ڈاؤن لوڈ کرتا ہے۔ اگر آپ کا براؤزر پوچھے کہ آیا اس سائٹ سے متعدد ڈاؤن لوڈز کی اجازت دی جائے، تو Allow منتخب کریں - ورنہ فائلیں ایک ایک کر کے ان کے Extract بٹنوں سے نکالیں۔ نکالی گئی فائلیں ان کے سادہ فائل نام سے محفوظ ہوتی ہیں (فولڈرز فہرست میں دکھائے جاتے ہیں تاکہ آپ آرکائیو کی ساخت دیکھ سکیں، لیکن براؤزرز ڈاؤن لوڈز سادہ محفوظ کرتے ہیں)۔

ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کا آرکائیو کبھی سرور پر اپ لوڈ نہیں ہوتا، کبھی محفوظ نہیں ہوتا اور ہمارے دیکھنے میں نہیں آتا - ٹیب بند کریں اور سب کچھ ختم۔ ایک ایماندار حد: آرکائیو آپ کے آلے کی میموری میں کھولا جاتا ہے، لہٰذا بہت بڑا ZIP (کئی سو میگا بائٹ) کم-میموری فون پر سست یا ناکام ہو سکتا ہے۔

اَن زِپ فائل ایکسٹریکٹر کا استعمال کیسے کریں

  1. اپنی .zip فائل اوپر والے خانے پر ڈالیں، یا اس پر کلک کریں اور اپنے آلے سے آرکائیو منتخب کریں۔
  2. فہرست پڑھیں: ہر اندراج آرکائیو کے اندر اپنے مکمل راستے اور اپنے اصل (غیر کمپریس شدہ) سائز کے ساتھ ظاہر ہوتا ہے۔ فولڈر اندراجات "folder" نشان زد ہیں۔
  3. کسی بھی واحد فائل کے ساتھ نکالیں پر کلک کریں تاکہ صرف وہی ڈاؤن لوڈ ہو، یا سب کچھ ایک کے بعد ایک ڈاؤن لوڈ کرنے کے لیے تمام فائلیں نکالیں استعمال کریں۔

یہ کیسے کام کرتا ہے

ہر ZIP ایک مرکزی ڈائریکٹری پر ختم ہوتا ہے جو ہر اندراج، فائل میں اس کا ڈیٹا کہاں ہے اور کمپریس شدہ اور غیر کمپریس شدہ کتنا بڑا ہے، درج کرتی ہے۔ یہ صفحہ آپ کے براؤزر میں JSZip لائبریری استعمال کرتا ہے اس ڈائریکٹری کو اسی لمحے پڑھنے کے لیے جب آپ آرکائیو منتخب کرتے ہیں - اسی لیے فہرست فوراً ظاہر ہوتی ہے، کسی چیز کے نکالے جانے سے پہلے۔ جب آپ فائل نکالتے ہیں، JSZip اس کا ڈیٹا میموری میں پھلاتا ہے (un-DEFLATE کرتا ہے) اور آپ کا براؤزر اسے عام ڈاؤن لوڈ کے طور پر محفوظ کرتا ہے۔ چونکہ یہ سب مقامی طور پر ہوتا ہے، یہی صفحہ ایک بار لوڈ ہونے کے بعد آف لائن کام کرتا ہے اور ان آرکائیوز کے لیے محفوظ ہے جنہیں آپ کبھی اپ لوڈ سائٹ پر نہیں بھیجیں گے۔

کام شدہ مثال

آپ backup.zip کھولتے ہیں (4.8 MB)۔ فہرست ایک photos فولڈر دکھاتی ہے جس میں photos/img1.jpg (1.9 MB) اور photos/img2.jpg (2.1 MB) ہیں، علاوہ اعلیٰ سطح پر ایک readme.txt (1 KB)۔ آپ کو صرف readme چاہیے - اس کے Extract بٹن پر کلک کریں اور صرف وہ 1 KB فائل ڈاؤن لوڈ ہوتی ہے، تصاویر کو بالکل کھولے بغیر۔

اکثر پوچھے گئے سوالات

کیا یہ unzip ٹول مفت ہے؟

ہاں - مفت، کوئی سائن اپ نہیں، کوئی حد نہیں اور کوئی واٹر مارک نہیں۔

کیا میری فائلیں کسی سرور پر اپ لوڈ ہوتی ہیں؟

نہیں۔ آرکائیو آپ کے براؤزر کے اندر JavaScript (JSZip) سے پڑھا جاتا ہے اور نکالی گئی فائلیں سیدھی آپ کے ڈاؤن لوڈز میں جاتی ہیں۔ ZIP اور اس کے مندرجات آپ کے آلے سے کبھی نہیں نکلتے۔

کیا یہ پاس ورڈ سے محفوظ ZIP کھول سکتا ہے؟

نہیں۔ JSZip خفیہ کردہ آرکائیوز نہیں پڑھ سکتا، لہٰذا پاس ورڈ-محفوظ ZIP یہاں کھلنے میں ناکام ہوگا۔ خفیہ کردہ فائلوں کے لیے desktop آرکائیو ٹول استعمال کریں۔

Extract All چند فائلوں کے بعد کیوں رک گیا؟

براؤزرز صفحات کو ایک ساتھ بہت سی فائلیں ڈاؤن لوڈ کرنے سے روکتے ہیں۔ یہ ٹول فائلوں کو ایک مختصر وقفے کے ساتھ ایک کے بعد ایک ڈاؤن لوڈ کرتا ہے؛ اگر آپ کا براؤزر پوچھے، تو اس سائٹ کے لیے متعدد ڈاؤن لوڈز کی اجازت دیں - یا فائلیں ایک ایک کر کے نکالیں، جو ہمیشہ کام کرتا ہے۔

کیا یہ RAR, 7z یا TAR فائلوں کے لیے کام کرتا ہے؟

نہیں - یہ ایکسٹریکٹر صرف معیاری .zip آرکائیوز سنبھالتا ہے۔ RAR اور 7z مختلف کمپریشن فارمیٹس استعمال کرتے ہیں جنہیں مختلف لائبریریاں چاہئیں۔
