JavaScript منی فائر - محتاط کمپریشن جو آپ کے کوڈ کا احترام کرے

مختصراً: JavaScript منی فائر اصل tokenizer سے تبصرے اور غیر ضروری اسپیس ہٹاتا ہے، لہٰذا اسٹرنگ مواد، template literals اور regular expressions کبھی خراب نہیں ہوتے، اور معنی رکھنے والی نئی لائنیں (جیسے return کے بعد والی) ہمیشہ رکھی جاتی ہیں۔

سادہ لوح منی فائرز جو JavaScript کو سادہ متن سمجھتے ہیں کوڈ توڑ دیتے ہیں جیسے ہی ایک اسٹرنگ میں "//" ہو یا regex میں کوٹ ہو۔ یہ ٹول پہلے آپ کے کوڈ کو ٹوکنز میں تقسیم کرتا ہے اور تب ہی فیصلہ کرتا ہے کہ کیا محفوظ ہٹایا جا سکتا ہے۔

JavaScript منی فائر کا استعمال کیسے کریں

  1. اپنی JavaScript اوپر والے باکس میں پیسٹ کریں یا لکھیں۔
  2. JavaScript منی فائی کریں پر کلک کریں۔
  3. سائز پینل دیکھیں کہ کتنا بچایا گیا۔
  4. نتیجہ کاپی کریں یا اسے .js فائل کے طور پر ڈاؤن لوڈ کریں - اور، کسی بھی منی فائر کی طرح، اپنا کوڈ ایک بار چلا کر تصدیق کریں کہ یہ ویسا ہی برتاؤ کرتا ہے۔

یہ کیسے کام کرتا ہے

ٹول پہلے آپ کے کوڈ کو ٹوکنز میں تقسیم کرتا ہے: شناخت کنندگان، اعداد، اسٹرنگز، template literals, regular expressions اور اوقاف۔ تبصرے اس اسکین کے دوران پہچانے جاتے ہیں اور گرائے جاتے ہیں، اور اسکینر تقسیم نشان اور regex کے آغاز کے درمیان فرق جانتا ہے، اور تبصرہ نشانات کے لیے کبھی اسٹرنگ کے اندر نہیں دیکھتا۔ ٹوکنز پھر دوبارہ جوڑے جاتے ہیں، الگ کرنے والی اسپیس صرف وہاں شامل کرتے ہوئے جہاں اسے ہٹانا مطلب بدل دے - دو الفاظ کے درمیان، ایک جمع اور دوسرے جمع کے درمیان، اور اسی طرح۔ نئی لائنیں وہاں رکھی جاتی ہیں جہاں JavaScript کی خودکار سیمی کولن شمولیت انہیں معنی خیز بناتی ہے، سب سے اہم بعد میں return, break اور continue، اور ابتدائی سے پہلے ++ یا --.

کام شدہ مثال

تقریباً 400 بائٹس کی تبصرہ شدہ utility فنکشن عام طور پر تقریباً 260 بائٹس تک کمپریس ہوتی ہے - تقریباً ایک تہائی چھوٹی - جبکہ ایک اسٹرنگ جیسے "see https://example.com // docs" اس کے اندر یہ مکمل اچھوتا آتا ہے۔

اکثر پوچھے گئے سوالات

کیا یہ JavaScript منی فائر مفت ہے؟

ہاں - مکمل مفت، بغیر سائن اپ، بغیر سائز حد اور بغیر یومیہ حد۔

یہ مکمل build-tool منی فائر سے کیسے مختلف ہے؟

Terser جیسے تعمیراتی ٹولز متغیرات کے نام بھی بدلتے ہیں اور کوڈ دوبارہ لکھتے ہیں، جس سے چند فیصد مزید نچوڑا جاتا ہے۔ یہ ٹول جان بوجھ کر محتاط ہے: یہ کبھی کسی چیز کا نام نہیں بدلتا اور کبھی expressions دوبارہ نہیں لکھتا، لہٰذا آؤٹ پٹ دیکھنا آسان اور فوری یک وقتی استعمال کے لیے محفوظ ہے۔

کیا یہ میرا کوڈ توڑ سکتا ہے؟

یہ اس طرح ڈیزائن کیا گیا ہے کہ نہ ہو: اسٹرنگز، template literals اور regex literals محفوظ ہیں، اور معنی رکھنے والی نئی لائنیں محفوظ ہیں۔ کوئی منی فائر ہر غیر ملکی پیٹرن پر کمال کا وعدہ نہیں کر سکتا، لہٰذا منی فائی کرنے کے بعد ہمیشہ اپنا test suite چلائیں یا صفحہ ایک بار کھولیں - یہ مشورہ ہر منی فائر پر لاگو ہوتا ہے، بشمول ہمارے۔

کیا یہ regular expressions اور template literals سنبھالتا ہے؟

ہاں۔ Tokenizer, regex literals (بشمول character classes اور escapes) اور template literals، بشمول nested ${ } expressions، پہچانتا ہے، اور انہیں بغیر تبدیلی لے جاتا ہے۔

کیا میرا کوڈ کسی سرور پر اپ لوڈ ہوتا ہے؟

نہیں۔ Tokenising اور منی فائی کرنا 100% آپ کے براؤزر میں ہوتا ہے۔ آپ کا سورس کوڈ آپ کے آلے سے کبھی نہیں نکلتا۔
