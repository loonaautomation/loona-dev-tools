מחולל CSS Box Shadow - צללים מרובדים ומציאותיים באופן חזותי

בקצרה: מחולל צל התיבה של CSS בונה CSS של box-shadow שכבה אחר שכבה - היסטים, טשטוש, התפשטות, צבע, אטימות ומוטבע - עם תצוגה מקדימה חיה, כך שכרטיסים וכפתורים מקבלים עומק ריאלי במקום טשטוש אפור שטוח אחד.

צל קשה אחד נראה מזויף; שתי או שלוש שכבות רכות נראות כמו אור. המחולל הזה הופך שכבות לקלות ומציג את התוצאה בזמן הכוונון.

פרטי לפי עיצוב: כל דבר בכלי הזה קורה 100% בדפדפן שלכם עם JavaScript. הקלט שלכם לעולם לא מועלה לשרת, לעולם לא מאוחסן ולעולם לא נראה על ידינו - סגרו את הלשונית והכול נעלם.

איך להשתמש במחולל CSS Box Shadow

  1. כווננו את השכבה הראשונה: ההיסט האנכי והטשטוש עושים את רוב העבודה.
  2. הגדירו את הצבע והנמיכו את האטימות לרכות (0.1-0.3 הוא הטווח הריאלי).
  3. הוסיפו שכבה שנייה והדוקה יותר לעומק מגע, או סמנו Inset לצל פנימי.
  4. העתיקו את ה-CSS שנוצר.

איך זה עובד

שכבת box-shadow היא offset-x offset-y blur spread colour, ושכבות מרובות מופרדות בפסיקים - השכבה הראשונה נצבעת למעלה. גובה מציאותי בדרך כלל משלב צל מגע קטן וכהה יותר עם צל סביבתי גדול ורך יותר, ולכן הכלי הזה בנוי סביב שכבות ולא סביב צל בודד. צבעים נפלטים כ-rgba() כך שהאטימות נעה עם הצבע, ותיבת התצוגה המקדימה מתעדכנת בכל הקשה.
