ISO 文件解压工具 - 在线打开 ISO 光盘镜像

简而言之： ISO 文件提取器在您的浏览器中打开 .iso 光盘镜像——浏览存储在虚拟 CD 或 DVD 上的文件夹和文件，下载单个文件，或将所有内容保存为 ZIP。无需挂载光盘，无需安装，无需上传。

.iso 文件是 CD 或 DVD 在单个文件中的完整副本：Linux 安装程序、旧软件光盘以及归档的游戏或驱动 CD 都以 ISO 的形式存在。Windows 可以挂载它们，但只能以管理员身份、且只能浏览——解压出一个文件仍然很麻烦。本页使用 libarchive 的 WebAssembly 移植版本读取镜像内部的 ISO9660 文件系统，就在您的浏览器中完成。

如何使用 ISO 文件解压工具

  1. 把您的 .iso 文件拖到上面的框中，或点击它从您的设备中选择文件。
  2. 等待片刻，镜像正在读取——首次使用时，引擎（约 1 MB）加载一次，然后由您的浏览器缓存。
  3. 浏览存储在虚拟光盘上的文件，包括它们的文件夹和大小。
  4. 点击任何单个文件旁边的“下载”，或使用“全部下载为 ZIP”把光盘内容保存为一个标准 ZIP 文件。

它如何工作

ISO 镜像存储着一个 ISO9660 文件系统：靠近开头的卷描述符指向一棵记录目录树，每个记录指向保存文件数据的光盘扇区。本页使用编译为 WebAssembly 的 libarchive 读取这一结构——包括 Windows 制作的光盘用于长、混合大小写文件名的 Joliet 扩展——并列出每个文件及其路径和大小。文件只有在您下载时才会被复制出来；“全部下载为 ZIP”会用 JSZip 重新打包它们。

常见问题

本工具能打开可引导的安装程序 ISO 吗，比如 Linux 或 Windows 安装程序？

是的，可用于浏览和提取文件——内部文件系统是相同的 ISO9660 格式。请注意，提取文件并不能给您一个可启动的 USB 盘；安装操作系统仍需要 Rufus 或 Balena Etcher 这样的专业镜像工具。

为什么一些文件名看起来很“喊叫”且很短，像 SETUP.EXE;1？

这是较旧母带制作软件使用的普通 ISO9660 命名风格（大写、有限字符、;1 版本标签）。用 Joliet 或 Rock Ridge 扩展制作母带的光盘保留其正常的长名称，本工具在它们存在时显示那些名称。

它能打开 .img、.bin 或 .dmg 文件吗？

一些 .img 文件是换了个名字的原始 ISO 镜像，如果它们的内容真的是 ISO9660，就会打开。.dmg 是 Apple 自己的压缩格式，本引擎不支持——如果文件不是 ISO 镜像，本工具会说它无法打开，而不是猜测。

整个 ISO 会被加载到内存中吗？

文件由您的浏览器从您的设备读取，列表在内存中构建。日常 CD 大小的镜像（高达约 1 GB）在大多数桌面上都没问题；非常大的 DVD 镜像在手机或低内存机器上可能很慢。

我的文件会被上传到任何地方吗？

不会。镜像由您浏览器标签页内的 WebAssembly 解析。ISO 及其内部的文件都从不离开您的设备。
