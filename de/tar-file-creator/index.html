TAR-Datei-Ersteller - Ein .tar-Archiv aus Ihren Dateien erstellen

Kurz gesagt: das TAR-Datei-Ersteller bündelt einen beliebigen Satz Dateien in ein einzelnes Standard-.tar-Archiv mit einem spezifikationskorrekten ustar-Writer in Ihrem Browser – fügen Sie Dateien hinzu, gruppieren Sie sie optional in einem Ordner und laden Sie herunter.

TAR ist immer noch die Verkehrssprache von Linux, Servern und Backups – aber Windows-Nutzer, die einen Tarball erzeugen müssen, müssen üblicherweise zuerst etwas installieren. Diese Seite schreibt echte TAR-Archive in Ihrem Browser: ordentliche ustar-Header, Prüfsummen und Zeitstempel, auf Ihrem Gerät gebaut, ohne dass etwas hochgeladen wird.

Dateien hierher ziehen oder klicken Sie, um Dateien von Ihrem Gerät zu wählen
DateinameGröße

Denken Sie daran: TAR komprimiert nicht. Das .tar wird etwa die Größe aller hinzugefügten Dateien zusammen haben (aufgerundet auf 512-Byte-Blöcke). Brauchen Sie es kleiner? Lassen Sie das Ergebnis danach durch den GZIP-Kompressor laufen, oder nutzen Sie stattdessen den ZIP-Datei-Ersteller.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Dateien werden niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg. Ein ehrliches Limit: Die Konvertierung geschieht im Speicher Ihres Geräts, also können sehr große Archive (hunderte Megabytes) auf einem Handy mit wenig Speicher langsam sein oder fehlschlagen.

So verwenden Sie den TAR-Datei-Ersteller

  1. Ziehen Sie Ihre Dateien auf das Feld oben, oder klicken Sie es an und wählen Sie Dateien von Ihrem Gerät. Sie können Dateien in mehreren Runden hinzufügen.
  2. Prüfen Sie die Liste – entfernen Sie alles versehentlich Hinzugefügte und achten Sie auf die Gesamtgröße.
  3. Tippen Sie optional einen Ordnernamen ein, damit jede Datei in einem Ordner im Archiv sitzt, und geben Sie dem TAR einen Namen.
  4. Klicken Sie auf „TAR erstellen & herunterladen“. Das .tar öffnet sich mit tar unter Linux/macOS und mit 7-Zip oder WinRAR unter Windows.

So funktioniert es

Ein TAR-Archiv ist ein Strom von Datensätzen: Für jede Datei ein 512-Byte-ustar-Headerblock (Dateiname, Größe in Oktal, Änderungszeit, eine Prüfsumme des Headers selbst, die ‚ustar‘-Magie und ein Präfixfeld, das Pfade länger als 100 Zeichen erlaubt – mit GNU-longname-Einträgen für Pfade darüber hinaus), gefolgt vom Dateiinhalt, aufgefüllt auf eine ganze Zahl von 512-Byte-Blöcken. Zwei Nullblöcke schließen das Archiv. Diese Seite implementiert dieses Format direkt – keine Bibliothek, kein Server –, und der Writer wurde verifiziert, indem Pythons tarfile-Modul seine Ausgabe Byte für Byte zurückgelesen hat. TAR speichert Dateien unkomprimiert, das Archiv ist also die Summe seiner Teile; Kompression ist ein separater Schritt (das fügt .tar.gz hinzu).

Durchgerechnetes Beispiel

Sie fügen drei Dateien hinzu: deploy.sh (1 KB), config.yml (3 KB) und logo.png (48 KB), mit dem Ordnernamen 'release'. Das Tool erzeugt release.tar – oder Ihren gewählten Namen –, das einen release-Ordner mit allen drei Dateien hält, jede mit ihrer echten Änderungszeit. Bei 52 KB Inhalt kommt das TAR bei etwa 54 KB heraus: die Dateien selbst, drei Header und Auffüllung, ohne Kompression – exakt das, was tar unter Linux erzeugen würde.

Häufig gestellte Fragen

Ist dieser TAR-Datei-Ersteller kostenlos?

Ja – kostenlos, keine Registrierung, keine Limits und keine Wasserzeichen.

Werden meine Dateien auf einen Server hochgeladen?

Nein. Das TAR wird von JavaScript geschrieben, das in Ihrem Browser auf Ihrem Gerät läuft. Ihre Dateien verlassen es nie.

Warum ist das TAR so groß wie meine Dateien – oder etwas größer?

TAR komprimiert nichts; es bündelt nur. Jede Datei fügt auch einen 512-Byte-Header hinzu und wird auf eine 512-Byte-Grenze aufgefüllt, sodass das Archiv etwas größer ist als die rohe Gesamtsumme. Erstellen Sie für einen komprimierten Tarball das TAR hier und lassen Sie es dann durch den GZIP-Kompressor laufen – so wird .tar.gz buchstäblich gemacht.

Werden Linux und GNU tar hier erstellte Archive akzeptieren?

Ja. Der Writer folgt der ustar-Spezifikation – korrekte Oktalfelder und Header-Prüfsumme, die ustar-Magie, Präfix-Aufteilung für lange Pfade und GNU-Longname-Einträge für sehr lange – und seine Ausgabe wurde während des Testens verifiziert, indem sie mit Pythons tarfile-Modul zurückgelesen wurde.

Kann ich Dateien zu einem bestehenden TAR hinzufügen oder direkt ein .tar.gz erstellen?

Nicht in diesem Tool – es erstellt jedes Mal ein frisches Archiv. Um ein bestehendes ZIP in einem Schritt zu einem .tar.gz zu machen, nutzen Sie den ZIP-zu-TAR.GZ-Konverter; um dieses TAR zu einem .tar.gz zu komprimieren, nutzen Sie danach den GZIP-Kompressor und benennen Sie das Ergebnis zu .tar.gz um.
