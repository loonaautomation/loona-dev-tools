GZ 文件解压工具 - 在线解压 GZ 文件

简而言之： GZ 文件提取器在您的浏览器中解压单个 .gz 文件，并将原始文件还给您——日志、CSV 导出、数据库转储——并恢复其原始名称。不会上传任何内容。

.gz 文件不是装满文件的归档——它恰好是一个文件，用 gzip 压缩，gzip 是 Unix 世界的主力。服务器日志、数据导出和数据库转储都以这种方式传播，而 Windows 没有内置的打开方法。本页使用您浏览器自带的内置 gzip 引擎（DecompressionStream API）解压文件，因此既快速又完全私密。

把您的 .gz 文件拖到这里 或点击从您的设备中选择一个文件
按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中完成，使用浏览器本身内置的 gzip 解压缩。您的 .gz 文件从不上传到服务器，从不存储，我们也从不见过它。一个诚实的限制：解压在您设备的内存中进行，所以一个展开到几吉字节的 .gz 在内存不足的手机上可能吃力。

如何使用 GZ 文件解压工具

  1. 把您的 .gz 文件拖到上面的框中，或点击它从您的设备中选择文件。
  2. 文件会立即解压——留意显示原始文件名及其完整大小的那一行。
  3. 点击“下载解压后的文件”来保存原始文件（例如从 access.log.gz 得到 access.log）。

它如何工作

Gzip 存储一个小标头（包括原始文件名，当创建工具记录了它时）、用 DEFLATE 算法压缩的数据，以及末尾的校验和加上原始大小。现代浏览器内置了原生的 gzip 解码器——与它们接收压缩网页所用的同一个——本页用 DecompressionStream API 把您的文件送入其中。不下载任何库，不发送任何东西：浏览器膨胀数据并把原始字节交还给您。

实例

您的服务器为您提供 access.log.gz（2.1 MB）。您将其放在这里，它在大约一秒钟内解压为 access.log（18.4 MB）。您下载它并在文本编辑器中打开它，以查找昨晚的错误——无需安装任何工具。

常见问题

.gz 和 .tar.gz 有什么区别？

一个 .gz 文件恰好包含一个压缩文件。而 .tar.gz 先把许多文件捆绑成一个 TAR 归档，然后用 gzip 压缩这个捆绑包，所以它包含整棵文件树。对于 .tar.gz，请使用下方链接的 TAR.GZ 文件解压工具。

解压后的文件会有正确的名称吗？

是的——这个工具通过删除 .gz 结尾来恢复原始名称（access.log.gz 变为 access.log）。这与绝大多数情况下文件压缩时记录的名称一致。

本工具能打开被错误地以 .gz 结尾的 .zip 或 .rar 文件吗？

不会——重命名文件不会改变其内部内容。如果内容不是真正的 gzip 数据，解压会以清晰的消息失败。对于 ZIP、RAR 和其他真正的归档，请使用归档文件解压工具。

有大小限制吗？

本工具没有内置限制，但解压后的文件保存在您浏览器的内存中。日常日志和导出（高达几百兆字节）在大多数设备上都没问题；多 GB 的转储最好在桌面上用原生工具处理。

我的文件会被上传到服务器吗？

不会。解压使用浏览器在您设备上的自带内置引擎。文件从不离开您的机器——本工具甚至没有库需要下载。
