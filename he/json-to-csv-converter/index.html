ממיר JSON ל-CSV - הפכו מערכי JSON לגיליונות אלקטרוניים

בקצרה: ממיר ה-JSON ל-CSV לוקח מערך JSON של אובייקטים ומייצר קובץ CSV מתאים: העמודות הן איחוד כל מפתח במערך, ערכים עם פסיקים או מרכאות ממוסגרים נכון, ואובייקטים מקוננים נשמרים כ-JSON קומפקטי בתוך התא שלהם.

ממשקי API מדברים JSON; גיליונות אלקטרוניים, ייבואים ומנהלים מדברים CSV. הדביקו מערך JSON למטה וקבלו קובץ CSV שנפתח בניקיון ב-Excel, ב-Google Sheets או בכל מייבא - בלי פסיקים מעוותים, בלי מרכאות שבורות.

פרטי לפי עיצוב: כל דבר בכלי הזה קורה 100% בדפדפן שלכם עם JavaScript. הקלט שלכם לעולם לא מועלה לשרת, לעולם לא מאוחסן ולעולם לא נראה על ידינו - סגרו את הלשונית והכול נעלם.

איך להשתמש בממיר JSON ל-CSV

  1. הדביקו מערך JSON של אובייקטים לתיבה העליונה (אובייקט יחיד גם עובד - הוא הופך לשורה אחת).
  2. לחצו על המר ל-CSV.
  3. סקור את ה-CSV: השורה הראשונה היא הכותרת, בנויה מכל מפתח שנמצא במערך.
  4. העתיקו אותו או הורידו אותו כקובץ .csv, מוכן ל-Excel או ל-Google Sheets.

איך זה עובד

הממיר מנתח את ה-JSON שלכם עם מנתח הדפדפן המובנה, ואז הולך על כל אובייקט במערך ואוסף את האיחוד של כל המפתחות, בסדר שבו הם מופיעים לראשונה - כך שאובייקט עם שדה נוסף לעולם לא מאבד אותו. כל תא מבורח לפי כללי ה-CSV: ערכים המכילים פסיק, מרכאה או מעבר שורה נעטפים במרכאות כפולות, ומרכאות בפנים מוכפלות. מספרים ובוליאניים נכתבים בפשטות, null ומפתחות חסרים הופכים לתאים ריקים, ואובייקט או מערך מקונן נכתב כ-JSON קומפקטי בתוך התא שלו כך ששום נתון לא מושלך בשקט.

דוגמה מעובדת

המערך [{"name":"Ali","city":"Lahore"},{"name":"Ana","city":"Porto","vip":true}] הופך לשלוש עמודות (name, city, vip): ‏Ali מקבל תא vip ריק, ו-Ana מקבלת true - גישת איחוד-המפתחות שומרת את שתי השורות שלמות.

שאלות נפוצות

האם ממיר JSON ל-CSV הזה בחינם?

כן - לגמרי בחינם, בלי הרשמה, בלי מגבלת גודל ובלי תקרה יומית.

אילו צורות JSON מתקבלות?

מערך של אובייקטים הוא המקרה העיקרי. אובייקט בודד הופך ל-CSV של שורה אחת, ומערך של ערכים פשוטים (מספרים, מחרוזות) הופך לעמודת "value" אחת. כל דבר אחר נדחה עם הסבר.

מה קורה לאובייקטים ומערכים מקוננים?

הם נכתבים כטקסט JSON קומפקטי בתוך התא שלהם. שום דבר לא משוטח או מושלך, והמרה בחזרה עם כלי ה-CSV ל-JSON שלנו שומרת אותם קריאים.

מדוע לחלק מהתאים יש מרכאות סביבם?

כללי CSV דורשים מרכאות כשערך מכיל פסיק, מרכאות כפולות או שורה חדשה - אחרת העמודות יזוזו. Excel ו-Google Sheets קוראים את המרכאות הסטנדרטיות האלה כראוי.

האם הנתונים שלי מועלים לשרת?

לא. הניתוח וההמרה קורים 100% בדפדפן שלכם. הנתונים שלכם לעולם לא עוזבים את המכשיר שלכם.
