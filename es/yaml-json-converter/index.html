Convertidor YAML ⇄ JSON - Para archivos de configuración cotidianos

En resumen: el Convertidor YAML ⇄ JSON traduce el subconjunto de YAML que cubre casi cada archivo de configuración real (pares clave: valor, mapas anidados por sangría, listas con guiones y escalares de cadena, número, booleano y null) en ambas direcciones, y te dice claramente qué no admite.

Los archivos de configuración viven en YAML; las API y el código viven en JSON. Pega cualquiera de los dos abajo para obtener el otro, con un analizador de subconjunto honesto que maneja las construcciones que las configuraciones del mundo real realmente usan.

Privado por diseño: todo en esta herramienta sucede 100% en tu navegador con JavaScript. Tu entrada nunca se sube a un servidor, nunca se almacena y nunca la vemos nosotros: cierra la pestaña y todo desaparece.

Cómo usar el Convertidor de YAML a JSON

  1. Pega YAML o JSON en el cuadro superior.
  2. Haz clic en YAML → JSON o JSON → YAML según tu entrada.
  3. Revisa el resultado: la entrada YAML se convierte en JSON impreso bonito; la entrada JSON se convierte en YAML limpio estilo bloque.
  4. Copia el resultado o descárgalo.

Cómo funciona

El lector YAML trabaja en dos pasadas: primero normaliza tu documento en líneas con su sangría (eliminando los comentarios fuera de comillas) y luego analiza los bloques recursivamente: una secuencia de líneas con la misma sangría es una lista si las líneas empiezan con un guion, un mapa si llevan claves, o un único escalar. Las claves sin valor en la misma línea toman como valor el bloque con sangría más profunda que sigue. Los escalares se tipan a la manera YAML: el texto entrecomillado permanece como cadena, true/false se convierten en booleanos, null y ~ se convierten en null, y los números simples se convierten en números JSON. El escritor en la otra dirección emite el mismo subconjunto: sangría de dos espacios, guiones para las listas y comillas solo donde una cadena se leería mal de otro modo.

Ejemplo resuelto

Un fragmento estilo docker-compose (un nombre de servicio, una imagen, una lista de dos puertos) se convierte en un objeto JSON con un mapa anidado y un array real, y convertir ese JSON directamente de vuelta devuelve el mismo YAML, que es exactamente el viaje de ida y vuelta que comprueba la suite de pruebas.

Preguntas frecuentes

¿Este convertidor de YAML a JSON es gratuito?

Sí: completamente gratis, sin registro, sin límite de tamaño y sin límite diario.

¿Qué características de YAML son admitidas?

El subconjunto cotidiano: mapas anidados por sangría, listas con guiones (incluidas listas de mapas), escalares entrecomillados y simples, números, booleanos, null y comentarios. Esto cubre la gran mayoría de los archivos de configuración escritos a mano.

¿Qué características de YAML NO son admitidas?

Las anclas y alias (&a / *a), los escalares de bloque multilínea (| y >), el estilo de flujo ({a: 1} / [1, 2]), las etiquetas y los archivos de varios documentos (---) no se analizan. Si tu archivo los usa, convierte con una biblioteca YAML completa en su lugar: preferimos decirlo a producir una conversión incorrecta.

¿JSON → YAML entrecomilla las cadenas?

Solo cuando hace falta: una cadena que parece un número o un booleano, está vacía o contiene caracteres como dos puntos seguidos de un espacio se entrecomilla con comillas dobles para que se lea de vuelta como la misma cadena.

¿Mis datos se suben a un servidor?

No. La conversión ocurre 100% en tu navegador. Tus archivos de configuración nunca salen de tu dispositivo.
