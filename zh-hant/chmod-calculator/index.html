Chmod 計算器 - 許可權轉八進位制和符號形式，雙向轉換

簡而言之： Chmod 計算器將所有者、組和其他人的熟悉的讀/寫/執行復選框變成八進位制值（如 755）和符號字串（如 rwxr-xr-x）——並將任何八進位制值轉換回核取方塊，還提供常見值的通俗含義。

每個人都記得 755 是“資料夾那個”、644 是“檔案那個”——直到某次部署需要 750 或 640 的那一天。勾選下面的框，或輸入一個八進位制值，不要再猜了。

如何使用 Chmod 計算器

  1. 為所有者、組和其他人勾選讀、寫和執行——或使用預設。
  2. 閱讀八進位制值、符號字串和可直接貼上的 chmod 命令。
  3. 或者輸入任意 3 位八進位制值（如 750），然後點選“應用八進位制”以核取方塊形式檢視它。
  4. 把命令複製到您的終端中。

它如何工作

Unix 許可權是三組、每組三個位。在每組內，讀值 4、寫值 2、執行值 1，所以一組是一個從 0（---）到 7（rwx）的單個八進位制數字。計算器把每組勾選的值相加構建三位數八進位制，並把相同的框渲染為您在……中看到的符號字串 ls -l 輸出。應用八進位制值則反向執行數學：每個數字被拆回其 4-2-1 部分以設定核取方塊。

例項

所有者讀+寫+執行（4+2+1 = 7）、組讀+執行（4+1 = 5）、其他人讀+執行（5）得到八進位制 755，符號表示 rwxr-xr-x——經典設定，讓每個人都能讀取和執行檔案或資料夾，而只有所有者能更改它。

常見問題

這個 chmod 計算器免費嗎？

是的——完全免費，無需註冊，沒有每日上限。

八進位制和符號表示有什麼區別？

它們描述相同的許可權。八進位制（755）是您在 chmod 之後輸入的；符號表示（rwxr-xr-x）是 ls -l 向您展示的。本工具在兩方向上在兩者之間轉換。

setuid、setgid 和粘滯位（4755、1777）呢？

那些是特殊位的第四個、前導數字。本計算器涵蓋主要的三個許可權數字，這是日常 chmod 工作使用的；如果您在別處輸入 4 位值，最後三位是在這裡顯示的。

為什麼資料夾需要執行許可權？

對資料夾來說，“執行”意味著進入它並訪問內部檔案的許可權——一個有讀許可權但沒有執行許可權的資料夾會顯示您實際上打不開的名稱。這正是資料夾通常是 755、而檔案是 644 的原因。

不會。計算器 100% 在您的瀏覽器中執行。
