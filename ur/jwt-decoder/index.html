JWT ڈیکوڈر - ہیڈر اور پے لوڈ پڑھیں، میعاد ختم جانچیں

مختصراً: JWT ڈیکوڈر JSON Web Token کو اس کے ہیڈر اور پے لوڈ میں تقسیم کرتا ہے، دونوں کو پڑھنے کے قابل JSON کے طور پر دکھاتا ہے، اور میعاد ختم اور جاری-کردہ ٹائم اسٹیمپس کو سادہ تاریخوں میں بدلتا ہے۔ یہ نہیں کرتا - اور کوئی ڈیکوڈر نہیں کر سکتا - ثابت کہ ٹوکن اصل ہے۔

ایک JWT ایک لمبی ناقابل مطالعہ اسٹرنگ جیسی لگتی ہے، لیکن پہلے دو حصے بس Base64url-انکوڈ شدہ JSON ہیں۔ ایک ٹوکن پیسٹ کریں یہ پڑھنے کے لیے کہ یہ کیا دعویٰ کرتا ہے - یہ کس کے لیے ہے، کب ختم ہوتا ہے - ڈی بگنگ کے دوران۔ اسے صرف جائزے کے لیے استعمال کریں؛ اصل اعتماد کے لیے سرور پر دستخط کی تصدیق چاہیے۔

اہم: یہ ڈیکوڈر کرتا ہے دستخط کی توثیق نہیں کرتا. یہ صرف ٹوکن کے مواد کو پڑھتا ہے۔ کبھی بھی ڈی کوڈ شدہ JWT پر اکیلے بھروسا نہ کریں - کوئی بھی غیر تصدیق شدہ ٹوکن بنا یا بدل سکتا ہے۔ ہمیشہ اپنے سرور پر ٹوکنز کی درست تصدیق کریں۔
ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کا ان پٹ کبھی سرور پر اپ لوڈ نہیں ہوتا، کبھی محفوظ نہیں ہوتا اور ہمارے دیکھنے میں نہیں آتا - ٹیب بند کریں اور سب کچھ ختم۔

JWT ڈیکوڈر کا استعمال کیسے کریں

  1. مکمل ٹوکن (تینوں حصے) باکس میں پیسٹ کریں۔
  2. ٹوکن ڈی کوڈ کریں پر کلک کریں۔
  3. ہیڈر اور پے لوڈ پڑھیں، اور میعاد ختم لائن جانچیں - پھر اس پر بھروسہ کرنے سے پہلے ٹوکن کو اپنے سسٹم میں درست توثیق کریں۔

یہ کیسے کام کرتا ہے

ایک JWT تین Base64url اسٹرنگز ہیں جو نقطوں سے جڑی ہیں: header.payload.signature۔ ہیڈر دستخطی الگورتھم کا نام دیتا ہے؛ پے لوڈ sub (موضوع)، iat (جاری کردہ) اور exp (میعاد ختم، سیکنڈز میں Unix ٹائم اسٹیمپ کے طور پر) جیسے دعوے رکھتا ہے۔ یہ ٹول پہلے دو حصوں کو Base64url سے JSON میں ڈی کوڈ کرتا ہے - عین وہی ڈی کوڈنگ جو آپ کا اپنا کوڈ کرتا ہے - اور عددی وقت کے دعووں کو انسانی تاریخوں میں بدلتا ہے۔ تیسرا حصہ، دستخط، موجود دکھایا جاتا ہے لیکن جانچا نہیں جاتا: اس کی تصدیق کے لیے راز یا عوامی کنجی چاہیے اور یہ آپ کے backend میں ہونی چاہیے۔

کام شدہ مثال

کلاسیکی نمونہ ٹوکن ڈی کوڈ کرنا ہیڈر {"alg":"HS256","typ":"JWT"} اور ایک پے لوڈ دکھاتا ہے جس میں sub '1234567890' اور iat 1516239022 ہے - جسے ٹول 'Thu, 18 Jan 2018 01:30:22 GMT' کے طور پر رینڈر کرتا ہے، خام عدد کے مقابل سوچنا کہیں آسان۔

کیا یہ ٹول ٹوکن کی تصدیق کرتا ہے؟

نہیں۔ یہ صرف ڈی کوڈ کرتا ہے۔ ایک ڈی کوڈ شدہ ٹوکن اصلیت کے بارے میں کچھ ثابت نہیں کرتا - کوئی بھی کوئی پے لوڈ لکھ کر انکوڈ کر سکتا ہے۔ دستخط توثیق کو کنجی چاہیے اور یہ آپ کے سرور پر ہونی چاہیے۔

پے لوڈ بالکل پڑھنے کے قابل کیوں لگتا ہے؟

JWT حصے انکوڈ شدہ ہیں، خفیہ کردہ نہیں۔ انکوڈنگ نقل و حمل کے لیے ہے، راز کے لیے نہیں - کبھی JWT پے لوڈ میں راز نہ رکھیں۔

کیا یہاں اصل ٹوکن پیسٹ کرنا محفوظ ہے؟

آپ کا ٹوکن 100% آپ کے براؤزر میں ڈی کوڈ ہوتا ہے اور کبھی اپ لوڈ نہیں ہوتا۔ پھر بھی، اچھا عمل یہ ہے کہ لائیو production ٹوکنز کسی ٹول میں پیسٹ کرنے سے گریز کریں - ایک ہی شکل والا test ٹوکن استعمال کریں۔

"exp" کا مطلب کیا ہے؟

ٹوکن کی میعاد ختم وقت بطور Unix ٹائم اسٹیمپ سیکنڈز میں۔ یہ ٹول اسے پڑھنے کے قابل تاریخ میں بدلتا ہے اور آپ کو بتاتا ہے کہ آیا یہ پہلے ہی ختم ہو چکا ہے۔
