Markdown을 HTML로 변환 - Markdown에서 깔끔한 HTML

요약하면: Markdown을 HTML로 변환기는 일상적인 Markdown - 제목, 강조, 링크, 이미지, 목록, 인용구, 코드, 가로줄 - 을 깨끗한 HTML로 바꾸고, 안전을 위해 원시 HTML을 이스케이프하며, 실시간 렌더링 미리보기를 표시해요.

작가는 Markdown으로 초안을 써요; 웹은 HTML을 게시해요. 이 변환기는 사람들이 매일 실제로 쓰는 Markdown을 위해 둘을 이어줘요.

렌더링된 미리보기

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

Markdown을 HTML로 변환 사용법

  1. Markdown을 붙여넣거나 쓰세요.
  2. HTML로 변환을 클릭하세요.
  3. 렌더링된 미리보기가 의도와 맞는지 확인하세요.
  4. HTML을 사이트, CMS 또는 이메일 도구에 복사하세요.

작동 방식

변환기는 핵심 Markdown 구문을 정직하게 처리해요: ATX 제목(#부터 ######까지), 굵게와 기울임, 취소선, 인라인 코드와 펜스 코드 블록, 링크와 이미지, 순서 있는 목록과 순서 없는 목록, 인용구와 가로줄, Markdown이 지정하는 대로 연속 줄이 문단으로 결합돼요. 소스의 원시 HTML은 통과되지 않고 이스케이프돼, 붙여넣은 내용이 출력에 마크업을 절대 삽입할 수 없어요 - 코드 구간이 먼저 보호돼, 별표나 태그가 포함된 예시가 손대지 않은 채 살아남아요. 이국적인 확장(표, 각주, 작업 목록)은 범위 밖에 있고 출력은 그것들을 단순히 문단으로 취급함으로써 그렇게 말해요.

자주 묻는 질문

이 변환기는 무료인가요?

네 - 완전히 무료, 회원가입 없음이에요.

어떤 Markdown 기능이 지원되나요?

제목, 굵게, 기울임, 취소선, 인라인 및 펜스 코드, 링크, 이미지, 목록, 인용문, 수평선 - 일상적인 핵심이에요.

표와 각주는 어떤가요?

그것들은 GitHub 스타일 확장이라 이 도구가 변환하지 않아요; 일반 문단으로 통과해요.

원시 HTML이 보존되나요?

아니요 - 안전을 위해 이스케이프되어, 출력을 마크업을 삽입하지 않고 페이지에 붙여넣을 수 있어요.

무엇이든 업로드되나요?

아니요. 변환은 브라우저에서 실행돼요.
