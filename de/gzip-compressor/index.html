GZIP-Kompressor - Eine Datei in eine .gz pressen

Kurz gesagt: das GZIP-Kompressor verkleinert eine einzelne Datei zu einer .gz mit der in Ihren Browser eingebauten gzip-Engine – kein Bibliotheks-Download, kein Upload – und zeigt Ihnen exakt, wie viel Platz Sie gespart haben.

Gzip ist das Kompressions-Arbeitstier des Webs und von Linux: Protokolldateien, CSV-Exporte, Datenbank-Dumps und TAR-Archive schrumpfen alle dramatisch darunter. Diese Seite komprimiert eine Datei mit der Compression Streams API, die in moderne Browser eingebaut ist, zu .gz – der schnellstmögliche Weg, und vollständig auf Ihrem Gerät.

Gzip komprimiert EINE Datei – es ist kein Archivformat. Um mehrere Dateien zu einer .gz zu komprimieren, bündeln Sie sie zuerst mit dem TAR-Datei-Ersteller, und komprimieren Sie dann die .tar-Datei (genau diese Kombination ist eine .tar.gz). Um aus einer .gz wieder die Originaldatei zu machen, verwenden Sie den GZ-Datei-Extraktor.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Dateien werden niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg. Ein ehrliches Limit: Die Konvertierung geschieht im Speicher Ihres Geräts, also können sehr große Archive (hunderte Megabytes) auf einem Handy mit wenig Speicher langsam sein oder fehlschlagen.

So verwenden Sie den GZIP-Kompressor

  1. Ziehen Sie eine Datei auf das Feld oben, oder klicken Sie es an und wählen Sie die Datei von Ihrem Gerät.
  2. Klicken Sie auf „Zu .gz komprimieren“. Die eigene gzip-Engine Ihres Browsers erledigt die Arbeit auf Ihrem Gerät.
  3. Vergleichen Sie die Größen in der Zusammenfassung: Original, komprimiert und den gesparten Prozentsatz.
  4. Klicken Sie auf Herunterladen, um die .gz-Datei zu speichern. Sie öffnet sich mit gzip, tar, 7-Zip, WinRAR – oder unserem GZ-Datei-Extraktor.

So funktioniert es

Gzip umhüllt den DEFLATE-Algorithmus (LZ77-Abgleich plus Huffman-Codierung) in einem kleinen Container: ein 10-Byte-Header, der mit den magischen Bytes 1F 8B beginnt, die komprimierten Daten und eine Prüfsumme plus die Originalgröße als Trailer. Diese Seite speist Ihre Datei durch die CompressionStream API – gzip-Kompression, nativ implementiert in Chrome, Edge, Firefox und Safari –, sodass kein JavaScript-Kompressor heruntergeladen werden muss und die Arbeit mit nativer Geschwindigkeit läuft. Eine Datei hinein, eine Datei heraus: Gzip kennt keine Ordner, weshalb die klassische .tar.gz-Paarung existiert – tar bündelt, gzip presst.

Durchgerechnetes Beispiel

Sie legen access.log ab, ein 4.2 MB großes Webserver-Protokoll. Protokolle sind repetitiver Text – dieselben Adressen, Zeitstempel und Statuscodes immer und immer wieder –, also zerquetscht gzip es auf 380 KB, eine Ersparnis von 91 %, und access.log.gz ist bereit zum Archivieren oder Mailen. Legen Sie stattdessen ein 4.2 MB großes JPEG ab und das .gz kommt auch bei 4.2 MB heraus: JPEG-Daten sind bereits komprimiert, und die Seite sagt Ihnen das ehrlich, statt etwas anderes vorzutäuschen.

Häufig gestellte Fragen

Ist dieser GZIP-Kompressor kostenlos?

Ja – kostenlos, keine Registrierung, keine Limits und keine Wasserzeichen.

Werden meine Dateien auf einen Server hochgeladen?

Nein. Die Kompression nutzt die in Ihren Browser eingebaute gzip-Engine (die Compression Streams API). Ihre Datei verlässt Ihr Gerät nie.

Wie komprimiere ich mehrere Dateien zu einer .gz?

Gzip verarbeitet genau eine Datei. Bündeln Sie die Dateien zuerst mit dem TAR-Datei-Ersteller zu einem einzelnen .tar und komprimieren Sie dieses .tar dann hier – das Ergebnis ist ein Standard-.tar.gz (benennen Sie file.tar.gz bei Bedarf einfach um).

Wie erhalte ich meine Originaldatei aus einer .gz zurück?

Nutzen Sie den GZ-Datei-Extraktor auf dieser Website – er kehrt den Prozess in Ihrem Browser um. Unter Linux und macOS erledigt gunzip file.gz denselben Job.

Warum ist meine Datei etwas größer geworden?

Bereits komprimierte Formate (JPG, PNG, MP4, PDF, ZIP) enthalten fast keine Wiederholung mehr, die gzip ausnutzen könnte, und die .gz-Hülle fügt einige Bytes Header und Prüfsumme hinzu. Bei diesen Dateien ist eine winzige Zunahme – üblicherweise deutlich unter 1 % – normal und harmlos.
