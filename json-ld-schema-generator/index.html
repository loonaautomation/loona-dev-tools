JSON-LD Schema Generator - Structured Data Without Hand-Writing JSON

In short: the JSON-LD Schema Generator builds valid schema.org structured data for Articles, Local Businesses, Products, Events, Recipes, People, Organizations and Websites, and wraps it in the exact script block Google expects.

Structured data helps search engines understand a page and can unlock rich results. This generator builds the JSON for you - and validates it as JSON before you copy it.

Private by design: everything in this tool happens 100% in your browser with JavaScript. Your input is never uploaded to a server, never stored and never seen by us - close the tab and everything is gone.

How to use the JSON-LD Schema Generator

  1. Choose the schema type that matches your page.
  2. Fill the fields that apply - blank fields are simply left out.
  3. Click Generate and check the JSON-LD block.
  4. Paste it into your page head or before the closing body tag, then test the live page with Google's Rich Results Test.

How it works

The generator assembles a JavaScript object in the schema.org vocabulary - @context, @type and the properties for the chosen type, including nested objects such as a Product's Offer and AggregateRating, an Article's author Person, or a LocalBusiness PostalAddress - then serialises it with strict JSON formatting and re-parses its own output to prove it is valid JSON before showing it. Empty fields are omitted entirely, because an empty property is worse than a missing one. Honest scope: valid JSON-LD makes a page eligible for rich results; Google decides whether to show them, and the data must match what is visibly on the page.

Frequently Asked Questions

Is this generator free?

Yes - completely free, no sign-up.

Will this guarantee rich results?

No tool can guarantee that. Correct JSON-LD makes you eligible; Google chooses based on the page, the query and its policies.

Where do I paste the block?

In the page's head section, or just before the closing body tag - Google reads it in either place.

Must the data match my page?

Yes. Structured data that describes things not visible on the page can be ignored or treated as spam.

Is anything uploaded?

No. Generation and validation run in your browser.
