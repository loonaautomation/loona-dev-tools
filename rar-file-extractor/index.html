RAR File Extractor - Open RAR Files Online

In short: the RAR File Extractor opens .rar archives (both the older RAR4 and current RAR5 formats) directly in your browser - pick a file, see everything inside it, download single files or grab the whole archive re-packed as a ZIP. No WinRAR, no install, no upload.

RAR is the format that refuses to die: game mods, e-book packs, old backups and half the attachments from the 2000s still arrive as .rar - usually on a machine with nothing installed that can open it. This page opens RAR files where you already are, in the browser, using a WebAssembly port of the libarchive library. Your archive never leaves your device.

Private by design: everything in this tool happens 100% in your browser. The RAR archive is read by a WebAssembly engine running on your own device - it is never uploaded to a server, never stored and never seen by us. Two honest limits: password-protected RAR archives are not opened (this tool never asks for, guesses or cracks passwords), and the archive is unpacked in your device's memory, so extremely large archives can be slow on a low-memory phone.

How to use the RAR File Extractor

  1. Drop your .rar file onto the box above, or click it and pick the file from your device.
  2. Wait a moment while the archive is read - on first use the extraction engine (about 1 MB) loads once and is then cached by your browser.
  3. Browse the list of files inside the archive, with the size of each one.
  4. Click Download next to any single file you need, or use Download all as ZIP to get everything in one standard ZIP file.

How it works

RAR is a proprietary archive format created by Eugene Roshal and owned by win.rar GmbH. This page reads it with libarchive - the same open-source archive library that powers the tar tools on macOS and BSD - compiled to WebAssembly so it can run inside a browser tab at near-native speed. The engine reads the RAR central records, lists every entry with its uncompressed size, and decompresses only the entries you actually download. If you ask for everything, the extracted files are re-packed into a plain ZIP with JSZip so any device can open the result.

Worked example

A friend sends you photos.rar (18 MB) from an old hard drive. You drop it onto this page and it lists 24 JPG files with their sizes. You download the three photos you actually need one by one, then use Download all as ZIP to save the complete set as photos-extracted.zip (about 17.5 MB, since JPGs barely compress) - all without installing anything.

Frequently Asked Questions

Can this tool create RAR files too?

No - and no free tool can. RAR is a proprietary format: opening RAR files is allowed and widely supported, but creating them requires win.rar GmbH's licensed encoder (the one inside WinRAR). This tool only extracts. If you need to send the files on, use Download all as ZIP - the ZIP format is open and works everywhere.

Which RAR versions are supported?

Both RAR4 (the classic format from WinRAR 4 and earlier) and RAR5 (the current format, used since WinRAR 5). Both were verified against real test archives when this tool was built.

My RAR file is password-protected. Can you open it?

No. This tool does not open password-protected archives and never tries to guess or crack passwords. If you know the password, open the archive in WinRAR or 7-Zip on a computer, remove the password, and the result will open here.

Are my files uploaded to a server for extraction?

No. The extraction engine is WebAssembly code that runs entirely inside your browser tab. Your RAR file and everything inside it stay on your device - you can even disconnect from the internet after the page has loaded and the tool still works.

What about split RAR archives (.part1.rar, .part2.rar, .r00)?

Multi-volume archives are not supported by this tool, because all volumes would have to be combined first. Join them with WinRAR or 7-Zip into a single .rar file and that file will open here.
