Number Base कन्वर्टर — Binary, Octal, Decimal और Hex, ठीक-ठीक

संक्षेप में: Number Base कन्वर्टर arbitrary-precision arithmetic उपयोग करके integers को binary, octal, decimal और hexadecimal के बीच बदलता है, इसलिए सामान्य 2^53 JavaScript limit से कहीं आगे की values ठीक बदलती हैं, digit by digit — और invalid digits नाम से बताए जाते हैं।

File permissions, colour codes, memory addresses, bitwise flags — bases development में हर जगह हैं। किसी भी base में value type करें और इसे चारों में पढ़ें, ऐसी precision के साथ जो आपकी बड़ी संख्याओं को चुपचाप round नहीं करती।

  2. चुनें कि value किस base में लिखी गई है।
  3. वही value binary, octal, decimal और hexadecimal में पढ़ें — results update होते हैं जैसे आप type करते हैं।
  4. किसी representation को अपने साथ लेने के लिए Copy buttons उपयोग करें।

यह कैसे काम करता है

Converter पहले हर character को आपके चुने base में allowed digits के विरुद्ध validate करता है — binary value में 2 डालें और यह आपको ठीक वही बताता है, अंदाज़ा लगाने के बजाय। फिर यह arbitrary-precision integer arithmetic (BigInt) से value बनाता है: हर digit running total को base से गुणा करता है और खुद को जोड़ता है, एक process जो किसी भी length की संख्याओं के लिए exact रहता है। अंत में यह उस exact value को चारों bases में से हर एक में render करता है। Negative values हर step में अपना sign रखते हैं।

काम किया हुआ उदाहरण

Decimal value 18446744073709551617 — 2^64 से एक अधिक — किसी सामान्य JavaScript number के exact रखने से बड़ा है। यहाँ यह अब भी ठीक बदलता है: hexadecimal 10000000000000001, और 1 पर समाप्त होने वाली 65-digit binary string, जहाँ floating-point converter इसे चुपके से round कर देता।

अक्सर पूछे जाने वाले सवाल

क्या यह number base converter मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, बिना साइन-अप, बिना size limit और बिना daily cap।

यह कितनी बड़ी संख्या बदल सकता है?

प्रभावी रूप से असीमित। Conversion BigInt arithmetic का उपयोग करती है, इसलिए सैकड़ों digits वाली values ठीक बदलती हैं। साधारण JavaScript numbers की परिचित 2^53 limit लागू नहीं होती।

क्या यह 3.14 जैसे fractions संभालता है?

नहीं — यह converter integers के लिए है, जिसके लिए bases व्यवहार में उपयोग होते हैं (addresses, permissions, colours, flags)। Input में decimal point invalid digit के रूप में बताया जाता है, चुपचाप हटाए जाने के बजाय।

अगर मैं ऐसा digit type करूँ जो base में मौजूद नहीं है तो क्या होगा?

आपको digit और base का नाम देने वाली specific error मिलती है — उदाहरण के लिए, digit "8" octal value में नहीं आ सकता, और "g" hexadecimal में नहीं आ सकता।

क्या मेरा input किसी server पर अपलोड होता है?

नहीं। Conversion 100% आपके ब्राउज़र में होती है। आपकी values कभी आपके device से बाहर नहीं जातीं।
