CSV-zu-Markdown-Tabellen-Konverter - Tabellen für READMEs und Docs

Kurz gesagt: das CSV-zu-Markdown-Konverter verwandelt Ihre CSV in eine GitHub-bereite Markdown-Tabelle, richtet numerische Spalten automatisch rechts aus und escaped Pipe-Zeichen in Werten, sodass die Tabelle niemals bricht.

READMEs, Docs und Issue-Kommentare rendern alle Markdown-Tabellen. Fügen Sie CSV ein und erhalten Sie eine Tabelle, die beim ersten Mal korrekt rendert – Ausrichtung und Escaping behandelt.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Eingabe wird niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg.

So verwenden Sie den CSV-zu-Markdown-Tabellen-Konverter

  1. Fügen Sie Ihre CSV ein – die erste Zeile wird zur Tabellen-Kopfzeile.
  2. Klicken Sie auf „Zu Markdown konvertieren“.
  3. Kopieren Sie die Tabelle in Ihr README, Dokument oder Ihren Kommentar.
  4. Numerische Spalten werden automatisch rechtsbündig ausgerichtet.

So funktioniert es

Die Ausrichtung wird pro Spalte erkannt: Wenn jeder nicht leere Wert in einer Spalte wie eine Zahl aussieht (Tausendertrennzeichen und ein abschließendes % sind erlaubt), verwendet die Trennzeile ---: um sie rechts auszurichten, so wie Zahlen sich aufreihen sollten; andere Spalten verwenden die standardmäßige Linksausrichtung. Pipe-Zeichen in einem Wert werden escaped als \| sodass ein Wert niemals eine Zelle teilen kann, und Zeilenumbrüche in Feldern in Anführungszeichen werden zu <br>, die Markdown-Renderer innerhalb der Tabellenzeile belassen.

Häufig gestellte Fragen

Ist dieser Konverter kostenlos?

Ja – völlig kostenlos, keine Registrierung.

Wo kann ich die Ausgabe verwenden?

Überall, wo Markdown-Tabellen gerendert werden: GitHub- und GitLab-READMEs, Docs-Websites, Notion-artige Tools und Issue-Tracker.

Wie wird die Ausrichtung entschieden?

Eine Spalte, deren Werte alle numerisch sind, wird rechtsbündig ausgerichtet; alle anderen Spalten werden linksbündig ausgerichtet.

Was, wenn ein Wert ein Pipe-Zeichen enthält?

Es wird als \| escaped, sodass es in seiner Zelle bleibt, statt die Tabelle zu zerbrechen.

Werden meine Daten hochgeladen?

Nein. Die Konvertierung läuft vollständig in Ihrem Browser.
