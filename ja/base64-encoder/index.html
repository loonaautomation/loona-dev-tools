Base64エンコーダー＆デコーダー - テキストとファイル、UTF-8安全

要するに： Base64エンコーダーはテキストとファイルをBase64に変換し、Base64をテキストにデコードし直します。アクセント、ウルドゥー語、中国語、絵文字を正しく処理し、任意のURLセーフアルファベットがあります。

Base64はあらゆる場所に現れます：APIペイロード、メールの添付ファイル、data URI、basic-authヘッダー、JWTのパート。多くの手軽なエンコーダーの落とし穴は、英語以外のテキストで壊れることです。こちらは、あなたのテキストのUTF-8バイトをエンコードするため、入力できるものはすべて往復に耐えます。

ファイルをBase64に

ファイルを選んで、そのBase64データ文字列を取得します（data URIやテストペイロードに便利）。ファイルはローカルで読み取られます — アップロードされることは決してありません。

設計上プライベート： このツールのすべては、JavaScriptを使ってブラウザで100%行われます。あなたの入力はサーバーにアップロードされることは決してなく、保存されることも、私たちに見られることもありません。タブを閉じるとすべてが消えます。

Base64エンコーダー＆デコーダーの使い方

  1. テキストを入力または貼り付けてください（またはファイルからBase64用にファイルを選んでください）。
  2. 結果がURLやJWTに入る場合は、任意でURLセーフにチェックを入れてください。
  3. 「エンコード」または「デコード」をクリックし、結果をコピーまたはダウンロードしてください。

仕組み

Base64は、64文字のアルファベットから、データの3バイトごとに4文字で表現します。これにより、バイナリデータをJSON、XML、URLのようなテキスト形式の中で安全に運べます。このツールは、まずあなたのテキストをUTF-8バイト（テキストのための普遍的なエンコーディング）に変換し、それからそのバイトをエンコードします。そのため、アクセント付き文字、アラビア文字のテキスト、絵文字が、すべて完璧にデコードして戻ります。URL安全バリアントは、+ と / を - と _ に置き換え、= のパディングを落とします。これは、JSON Web Tokenで使われる形そのものです。

実例

テキスト「Loona」は TG9vbmE= にエンコードされます。「Assalam-o-Alaikum」という挨拶は、ウルドゥー文字と絵文字（السلام علیكم 👋）とともに、一文字ずつエンコードとデコードが往復します。通常のASCIIしか処理できない素朴なエンコーダーにはできないことです。

よくある質問

このBase64ツールは無料ですか？

はい - 無料、登録不要、制限なし。

なぜ一部のBase64ツールは非英語テキストを文字化けさせますか？

それらは各文字を単一バイトとしてエンコードします。これは通常のASCIIでのみ動作します。このツールは代わりにUTF-8バイトをエンコードするため、すべての言語と絵文字が正確に往復します。

URLセーフオプションとは何ですか？

標準Base64は + と / を含むことがあります。これらはURLの特殊文字です。URLセーフアルファベットはそれらを - と _ に置き換え、パディングを除去します。JWTで使われるバリエーションです。

Base64は暗号化ですか？

いいえ。Base64はエンコーディングであり、暗号化ではありません。誰でも即座にデコードできます。秘密を守るために決して使わないでください。

私のファイルはアップロードされますか？

いいえ。ファイルはあなたのデバイス上のブラウザによって読まれ、デバイスから出ることは決してありません。
