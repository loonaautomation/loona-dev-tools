Archive फ़ाइल एक्सट्रैक्टर - कोई भी Archive ऑनलाइन खोलें

संक्षेप में: Archive फ़ाइल एक्सट्रैक्टर universal opener है: कोई common archive डालें — ZIP, RAR, 7Z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ या ISO — और यह format स्वयं detect करता है, अंदर क्या है list करता है, और आपको single फ़ाइलें या सब कुछ ZIP के रूप में download करने देता है। कुछ upload नहीं होता।

पक्का नहीं कि आपको किस तरह का archive भेजा गया? ठीक यही इस पेज के लिए है। अंदाज़ा लगाने के बजाय कि कौन सा tool अजीब extension से match करता है, फ़ाइल यहाँ डालें: libarchive engine फ़ाइल की actual content पढ़ता है (सिर्फ़ उसका नाम नहीं), format पहचानता है, और सूचीबद्ध करता है कि अंदर क्या है। यह वही engine है जो इस site के dedicated RAR, 7Z, TAR और ISO pages के पीछे है, हर format चालू के साथ।

कोई भी archive फ़ाइल यहाँ डालें (ZIP, RAR, 7Z, TAR, ISO...) या अपने device से फ़ाइल चुनने के लिए click करें
Archive के अंदर की फ़ाइलSize
Design से निजी: इस tool में सब कुछ 100% आपके browser में होता है। Archive आपके अपने device पर WebAssembly engine द्वारा पढ़ा जाता है — कभी upload नहीं, कभी stored नहीं, कभी हमारे द्वारा नहीं देखा गया। दो ईमानदार limits: password-protected archives नहीं खोले जाते (यह tool कभी passwords नहीं माँगता, guess नहीं करता या crack नहीं करता), और archives आपके device की memory में unpacked होते हैं, इसलिए अत्यधिक बड़ी फ़ाइलें low-memory phone पर slow हो सकती हैं।

Archive फ़ाइल एक्सट्रैक्टर का उपयोग कैसे करें

  1. अपनी archive फ़ाइल ऊपर के box पर डालें, या उस पर click करें और अपने device से फ़ाइल चुनें — कोई भी आम format काम करता है।
  2. एक क्षण प्रतीक्षा करें जबकि format detected होता है और contents पढ़े जाते हैं — पहले उपयोग पर engine (लगभग 1 MB) एक बार load होता है और फिर आपके browser द्वारा cached होता है।
  3. Archive के अंदर की फ़ाइलों की list browse करें, paths और sizes के साथ।
  4. किसी single फ़ाइल के बगल में Download पर click करें, या सब कुछ एक standard ZIP फ़ाइल के रूप में save करने के लिए Download all as ZIP उपयोग करें।

यह कैसे काम करता है

यह पेज libarchive से powered है — वह open-source library जो macOS और BSD के archive tools के पीछे है — WebAssembly में compile किया गया। Libarchive फ़ाइल extension पर भरोसा नहीं करता: यह असली bytes probe करता है, हर format reader को बारी-बारी test करते हुए (ZIP signatures, RAR marker, 7z header, TAR checksums, ISO9660 volume descriptors, और gzip, bzip2 और XZ compression layers जो उन्हें wrap कर सकती हैं)। एक बार format identified हो जाए, वही reader हर entry list करता है और जिन्हें आप download करते हैं उन्हें decompress करता है। Download all as ZIP contents को JSZip से दोबारा pack करता है।

काम किया हुआ उदाहरण

एक client project-files.2026 भेजता है बिना किसी मददगार extension के, और आपका computer इसे unknown file कहता है। आप इसे यहाँ डालते हैं: engine एक TAR.XZ archive पहचानता है, 58 source files सूचीबद्ध करता है, और आप वे दो download करते हैं जिनकी आपको ज़रूरत है। रहस्यमय format को कभी मौका ही नहीं मिला।

अक्सर पूछे जाने वाले सवाल

यह universal extractor कौन से formats खोल सकता है?

ZIP, RAR (RAR4 और RAR5), 7Z, TAR, TAR.GZ / TGZ, TAR.BZ2, TAR.XZ, ISO disc images, और कई दुर्लभ जिन्हें libarchive engine समझता है, जैसे CPIO और XAR। यहाँ नाम दिया गया हर format असली test archives के विरुद्ध verified था जब यह tool बनाया गया था।

फ़ाइल extension ग़लत लगती है या पूरी तरह missing है। क्या यह अब भी काम करेगा?

आम तौर पर, हाँ। Detection फ़ाइल की content पर based है, उसके name पर नहीं, इसलिए .bin का नाम दिया गया ZIP या extension खो चुकी download अब भी खुलती है। अगर content सच में archive नहीं है, तो tool अंदाज़ा लगाने के बजाय वह बताता है।

यह tool क्या नहीं खोल सकता?

Password-protected archives (password कभी पूछा, अंदाज़ा या crack नहीं किया जाता), multi-volume split archives (.part1.rar style sets), Apple के .dmg images, और self-extracting .exe archives। उनके लिए, 7-Zip जैसा desktop tool सही विकल्प है।

RAR, 7Z और TAR के लिए अलग pages भी क्यों हैं?

Dedicated pages format-specific guidance रखती हैं और वही हैं जो ज़्यादातर लोग search करते हैं; यह universal page बाकी सब के लिए safety net है — mixed downloads, unknown extensions, और वे formats जिनका अपना page नहीं है। वही engine, वही privacy, अलग front door।

क्या detection या extraction के लिए मेरी फ़ाइलें किसी server पर अपलोड होती हैं?

नहीं। Format detection और extraction दोनों आपके browser tab के अंदर WebAssembly में चलते हैं। आपका archive कभी आपके device से बाहर नहीं जाता, और पेज load होने के बाद tool offline काम करता रहता है।
