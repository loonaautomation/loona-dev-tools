TAR.GZ-Datei-Extraktor - TAR.GZ- & TGZ-Dateien online öffnen

Kurz gesagt: das TAR.GZ-Datei-Extraktor öffnet .tar.gz- und .tgz-Archive direkt in Ihrem Browser – durchsuchen Sie die Dateien darin, laden Sie einzelne Dateien herunter oder speichern Sie alles als ZIP neu gepackt. Keine Installation, kein Upload: Die Extraktion läuft auf Ihrem Gerät.

Wenn Sie Quellcode, WordPress-Backups, Server-Snapshots oder irgendetwas aus der Linux-Welt herunterladen, kommt es als .tar.gz an – ein mit gzip gepresstes TAR-Bündel. Der Windows Explorer kann es nicht öffnen, was viele Menschen mit einer Datei stecken lässt, in die sie nicht einmal hineinschauen können. Diese Seite öffnet es mit einem WebAssembly-Port von libarchive, vollständig in Ihrem Browser.

Ziehen Sie Ihre .tar.gz- oder .tgz-Datei hierher oder klicken Sie, um eine Datei von Ihrem Gerät zu wählen
Datei im ArchivGröße
Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser. Das Archiv wird von einer WebAssembly-Engine auf Ihrem eigenen Gerät dekomprimiert – niemals hochgeladen, niemals gespeichert, niemals von uns gesehen. Ein ehrliches Limit: Das Archiv wird im Speicher Ihres Geräts ausgepackt, also kann ein riesiges Backup-Archiv (hunderte Megabytes unkomprimiert) auf einem Handy mit wenig Speicher langsam sein oder fehlschlagen.

So verwenden Sie den TAR.GZ-Datei-Extraktor

  1. Ziehen Sie Ihre .tar.gz- oder .tgz-Datei auf das Feld oben, oder klicken Sie es an und wählen Sie die Datei von Ihrem Gerät.
  2. Warten Sie einen Moment, während das Archiv gelesen wird – beim ersten Einsatz lädt die Extraktions-Engine (etwa 1 MB) einmal und wird dann von Ihrem Browser zwischengespeichert.
  3. Durchsuchen Sie die Liste der Dateien im Archiv mit ihren Ordnern und Größen.
  4. Klicken Sie auf Herunterladen neben jeder einzelnen Datei, oder nutzen Sie „Alle als ZIP herunterladen“, um das ganze Archiv als eine Standard-ZIP-Datei zu speichern.

So funktioniert es

Eine .tar.gz hat zwei Schichten: eine äußere gzip-Schicht, die komprimiert, und eine innere TAR-Schicht, die viele Dateien zu einem Strom bündelt. Diese Seite schält beide mit libarchive, kompiliert zu WebAssembly – zuerst die gzip-Dekompression, dann ein Durchlauf über die TAR-Header, der jeden Eintrag mit Pfad und unkomprimierter Größe auflistet. Dateien werden erst extrahiert, wenn Sie sie herunterladen, und die Option „Alle als ZIP herunterladen“ packt sie mit JSZip neu, sodass sich das Ergebnis überall öffnet.

Durchgerechnetes Beispiel

Ihr Hosting-Panel gibt Ihnen ein vollständiges Website-Backup als backup-2026-11-01.tar.gz (260 MB). Sie öffnen es hier, navigieren die Auflistung zu wp-content/uploads und laden die drei Fotos herunter, die Sie versehentlich gelöscht haben (4 MB gesamt) – statt das gesamte Backup wiederherzustellen oder Tools zu installieren, um hineinzuschauen.

Häufig gestellte Fragen

Was ist der Unterschied zwischen .tar.gz und .tgz?

Keine – sie sind exakt dasselbe Format. Der Name .tgz ist nur eine verkürzte Version aus den Tagen, als Dateierweiterungen auf drei Zeichen begrenzt waren. Diese Seite akzeptiert beide.

Ich habe eine einfache .gz-Datei, kein .tar.gz. Funktioniert es hier?

Eine einfache .gz enthält genau eine komprimierte Datei, kein Archiv. Verwenden Sie dafür den unten verlinkten GZ-Datei-Extraktor – er dekomprimiert die einzelne Datei direkt. Diese Seite ist für Archive, die viele Dateien enthalten.

Kann dieses Tool .tar.gz-Dateien erstellen?

Nein, diese Seite ist nur ein Extraktor. Um Dateien hier zu einem Archiv zu bündeln, nutzen Sie den ZIP-Datei-Ersteller – ZIP öffnet sich überall, auch auf den Linux-Systemen, die .tar.gz-Dateien produzieren.

Warum hat sich mein Archiv geöffnet, aber seltsame lange Namen oder Links gezeigt?

TAR-Archive von Servern enthalten oft symbolische Links und Geräte-Einträge neben regulären Dateien. Dieses Tool listet reguläre Dateien auf und extrahiert sie; Links werden in der Auflistung gezeigt, wo das Format sie aufzeichnet, aber sie werden in Ihren Downloads nicht als Links neu erstellt.

Werden meine Dateien zur Extraktion irgendwohin hochgeladen?

Nein. Die Dekompression läuft in WebAssembly in Ihrem Browser-Tab. Das Backup und alles darin bleibt von Anfang bis Ende auf Ihrem Gerät.
