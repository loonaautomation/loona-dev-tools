Generator de sitemap XML - Transformă o listă de URL-uri într-un sitemap.xml valid

Pe scurt: Generatorul de sitemap XML ia o listă simplă de URL-uri - câte unul pe linie - și emite un sitemap.xml valid cu valori implicite opționale lastmod, changefreq și prioritate, escapând URL-urile corect pentru XML.

Ai lista de URL-uri; înfășurarea XML este partea obositoare. Lipește lista, setează valorile implicite o dată și descarcă un sitemap pe care motoarele de căutare îl acceptă.

Privat prin concepție: totul în acest instrument se întâmplă 100% în browserul tău cu JavaScript. Datele tale introduse nu sunt încărcate niciodată pe un server, nu sunt stocate și nu sunt văzute de noi - închide fila și totul a dispărut.

Cum se folosește Generatorul de sitemap XML

  1. Lipește URL-urile tale, câte unul pe linie, sau încarcă-le dintr-un fișier .txt.
  2. Setează lastmod, changefreq și prioritatea implicite dacă le vrei pe fiecare intrare.
  3. Dă clic pe Generează sitemap.xml.
  4. Descarcă fișierul, pune-l la rădăcina site-ului tău și trimite-l în Search Console și Bing Webmaster Tools.

Cum funcționează

Generatorul urmează protocolul sitemaps.org: un urlset în spațiul de nume oficial, un element url per adresă și valori loc care sunt atât sigure pentru URL (spațiile devin %20), cât și escapate XML (un & într-un șir de interogare devine &amp;, ceea ce este necesar - un & brut face fișierul XML nevalid). Protocolul limitează un sitemap la 50,000 de URL-uri și 50 MB; acest instrument impune limita de URL-uri și îți spune când o atingi, moment în care mișcarea corectă este mai multe sitemap-uri unite printr-un fișier index de sitemap. Observă că Google ignoră în mare parte changefreq și priority, dar lastmod este folosit când este precis - așa că setează doar un lastmod care reflectă o schimbare reală.

Întrebări frecvente

Acest generator este gratuit?

Da - complet gratuit, fără înregistrare.

Câte URL-uri poate conține un sitemap?

50,000 cel mult, conform protocolului sitemap - și 50 MB necomprimat. Site-urile mai mari folosesc un indice sitemap care indică mai multe sitemap-uri.

Google folosește prioritatea și frecvența de schimbare?

Google a spus că le ignoră în mare măsură pe amândouă. lastmod este folosit când reflectă consecvent modificări reale.

De ce & trebuie să devină & în URL-uri?

Pentru că sitemap.xml este XML: un ampersand brut începe o referință de entitate și face documentul invalid, așa că trebuie escapat.

Se încarcă ceva?

Nu. Sitemap-ul este construit în browserul tău.
