Tentang

HTML memiliki lebih dari 2,200 entitas bernama; jadual ini adalah set kerja yang dijangkau pembangun setiap hari: escape struktural (& < > "), tipografi (tanda hubung, tanda kutip, elipsis), simbol mata uang dan matematika, panah, tanda centang, dan huruf beraksen umum. Setiap entitas juga memiliki referensi numerik desimal (©) dan heks (©) yang berfungsi bahkan ketika tidak ada nama — lajur Aksara dan Desimal di sini memberi Anda kedua fallback. Senarai rasmi lengkap hidup dalam standard HTML WHATWG; jika entitas tidak ada dalam jadual ini, referensi numeriknya adalah rute yang andal.

Pertanyaan yang Sering Diajukan

Mengapa menggunakan entitas alih-alih aksara itu sendiri?

Untuk lima struktural (& < > " ') entitas adalah kebenaran, bukan gaya — tanpa escape mereka merusak markup. Untuk sisanya, entitas adalah pilihan portabilitas ketika encoding tidak pasti.

Bagaimana jika entitas hilang di sini?

Gunakan referensi numerik desimalnya dari bagan Unicode apa pun: &#<code>; selalu berfungsi.
