진법 변환기 - 이진수, 팔진수, 십진수, 십육진수, 정확히

요약하면: 숫자 진법 변환기는 임의 정밀도 연산을 사용해 이진수, 팔진수, 십진수, 십육진수 사이에서 정수를 변환해, 일반적인 2^53 JavaScript 제한을 훨씬 넘는 값도 정확히, 자리 단위로 변환돼요 - 그리고 유효하지 않은 숫자는 이름으로 지적돼요.

파일 권한, 색상 코드, 메모리 주소, 비트 플래그 - 진법은 개발 곳곳에 있어요. 모든 진법으로 값을 입력하고 네 가지 모두로 읽으세요. 큰 숫자를 조용히 반올림하지 않는 정밀도와 함께요.

진법 변환기 사용법

  1. 숫자를 값 상자에 입력하거나 붙여넣으세요.
  2. 값이 쓰인 진법을 선택하세요.
  3. 같은 값을 이진수, 팔진수, 십진수, 십육진수로 읽으세요 - 입력하면 결과가 업데이트돼요.
  4. 복사 버튼을 사용해 모든 표현을 가져가세요.

작동 방식

변환기는 먼저 선택한 진법에서 허용된 숫자에 대해 모든 문자를 검증해요 - 이진수 값에 2를 입력하면 추측하는 대신 정확히 그것을 알려줘요. 그다음 임의 정밀도 정수 연산(BigInt)으로 값을 만들어요: 각 숫자는 진행 중인 총합에 진법을 곱하고 자신을 더해요. 어떤 길이의 숫자에도 정확하게 유지되는 과정이에요. 마지막으로 그 정확한 값을 네 가지 진법 각각으로 렌더링해요. 음수 값은 모든 단계에서 부호를 유지해요.

풀이된 예시

십진수 값 18446744073709551617 - 2^64보다 하나 큰 - 은 모든 일반 JavaScript 숫자가 정확히 담을 수 있는 것보다 커요. 여기서도 여전히 정확히 변환돼요: 십육진수 10000000000000001, 그리고 1로 끝나는 65자리 이진수 문자열, 부동소수점 변환기는 조용히 반올림했을 거예요.

자주 묻는 질문

이 진법 변환기는 무료인가요?

네 - 완전히 무료, 회원가입 없음, 크기 제한 없음, 일일 상한 없음이에요.

얼마나 큰 숫자를 변환할 수 있나요?

사실상 무제한이에요. 변환은 BigInt 연산을 사용하므로 수백 자리의 값도 정확히 변환돼요. 일반 JavaScript 숫자의 익숙한 2^53 제한은 적용되지 않아요.

3.14 같은 분수를 처리하나요?

아니요 - 이 변환기는 정수를 위한 것이에요. 실제로 진법이 사용되는 것이 바로 그것이에요(주소, 권한, 색상, 플래그). 입력의 소수점은 조용히 버려지는 대신 잘못된 숫자로 보고돼요.

진법에 존재하지 않는 숫자를 입력하면 어떻게 되나요?

숫자와 진법을 이름으로 알리는 구체적인 오류를 얻어요 - 예를 들어, 숫자 "8"은 팔진수 값에 나타날 수 없고, "g"는 십육진수에 나타날 수 없어요.

제 입력이 서버에 업로드되나요?

아니요. 변환은 브라우저에서 100% 일어나요. 값은 기기를 절대 떠나지 않아요.
