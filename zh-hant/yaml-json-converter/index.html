YAML ⇄ JSON 轉換器 - 適合日常配置檔案

簡而言之： YAML ⇄ JSON 轉換器翻譯涵蓋幾乎每個真實配置檔案的 YAML 子集——key: value 鍵值對、按縮排巢狀的對映、帶短橫線的列表，以及字串、數字、布林和 null 標量——在兩個方向上進行，並坦率地告訴您它不支援什麼。

配置檔案生活在 YAML 中；API 和程式碼生活在 JSON 中。把任意一種貼上到下面即可得到另一種——使用一個誠實的子集解析器，處理現實世界配置實際使用的構造。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 YAML 轉 JSON 轉換器

  1. 把 YAML 或 JSON 貼上到上方框中。
  2. 根據您的輸入，點選 YAML → JSON 或 JSON → YAML。
  3. 審查結果——YAML 輸入變成美化列印的 JSON；JSON 輸入變成乾淨的塊風格 YAML。
  4. 複製結果或下載它。

它如何工作

YAML 讀取器分兩步工作：它首先把您的文件規範化為帶縮排的行（去掉引號外的註釋），然後遞迴解析塊——一串相同縮排的行，如果以破折號開頭就是列表，如果帶鍵就是對映，或者是單個標量。同一行沒有值的鍵把其後縮排更深的塊作為它們的值。標量按 YAML 的方式定型：帶引號的文字保持為字串，true/false 變成布林值，null 和 ~ 變成 null，普通數字變成 JSON 數字。反方向的寫入器發出相同的子集：兩空格縮排、列表用破折號、僅在字串否則會被誤讀的地方加引號。

例項

一個 docker-compose 風格的片段——一個服務名稱、一個映象、兩個埠的列表——會轉換成帶巢狀對映和真正陣列的 JSON 物件，把該 JSON 直接轉回去會得到相同的 YAML，這正是測試套件檢查的往返轉換。

常見問題

這個 YAML 轉 JSON 轉換器免費嗎？

是的——完全免費，無需註冊，沒有大小限制，也沒有每日上限。

支援哪些 YAML 功能？

日常子集：按縮排巢狀的對映、帶破折號的列表（包括對映列表）、帶引號和普通的標量、數字、布林值、null 和註釋。這涵蓋了絕大多數手寫的配置檔案。

哪些 YAML 功能不受支援？

錨點和別名（&a / *a）、多行塊標量（| 和 >）、流式風格（{a: 1} / [1, 2]）、標籤和多文件檔案（---）不會被解析。如果您的檔案使用了它們，請改用完整的 YAML 庫來轉換——我們寧願明說，也不願產生錯誤的轉換。

JSON → YAML 會給字串加引號嗎？

僅在需要時：看起來像數字或布林值、為空，或包含冒號後跟空格等字元的字串會用雙引號括起，這樣它讀回來是同一個字串。

我的資料會被上傳到伺服器嗎？

不會。轉換 100% 在您的瀏覽器中進行。您的配置檔案從不離開您的裝置。
