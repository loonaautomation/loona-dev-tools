Pembuat File ZIP - Buat ZIP dari Banyak File

Singkatnya: Pembuat File ZIP menggabungkan set file apa pun menjadi satu arsip .zip standar, dibangun sepenuhnya di browser Anda dengan JSZip - tambah file, secara opsional kelompokkan dalam folder, pilih tingkat kompresi dan unduh.

Mengirim sepuluh lampiran satu per satu, menyerahkan folder proyek, atau mengarsipkan sekumpulan foto - ZIP mengubah tumpukan file menjadi satu unduhan rapi. Sebagian besar zipper online mengunggah file Anda ke server terlebih dahulu. Yang ini tidak: arsip dirakit di perangkat Anda sendiri, jadi bahkan file privat tidak pernah bepergian ke mana pun.

Jatuhkan file di sini atau klik untuk memilih file dari perangkat Anda
Nama fileUkuran

Catatan kompresi: file teks, kode, dan CSV menyusut banyak dengan DEFLATE. Foto, video, dan PDF sudah terkompresi, jadi ZIP akan berukuran hampir sama dengan cara apa pun - pilih Tersimpan untuk file-file itu agar selesai seketika.

Privat berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di browser Anda dengan JavaScript. File Anda tidak pernah diunggah ke server, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang. Satu batas jujur: ZIP dibangun dalam memori perangkat Anda, jadi set file yang sangat besar (ratusan megabita) dapat lambat atau gagal di ponsel memori rendah.

Cara menggunakan Pembuat File ZIP

  1. Jatuhkan file Anda ke kotak di atas, atau klik dan pilih file dari perangkat Anda. Anda dapat menambahkan file dalam beberapa putaran.
  2. Periksa daftar - hapus apa pun yang Anda tambahkan karena kesalahan, dan perhatikan ukuran totalnya.
  3. Secara opsional ketik nama folder jika Anda ingin setiap file berada di dalam satu folder dalam arsip, dan beri ZIP sebuah nama.
  4. Pilih tingkat kompresi (Terkompresi tepat untuk sebagian besar pekerjaan) dan klik Buat ZIP & Unduh.

Cara kerja

Arsip ZIP menyimpan data setiap file ditambah direktori pusat di akhir yang mencantumkan setiap entri, namanya, dan ukurannya - itulah sebabnya alat unzip apa pun di sistem apa pun dapat membukanya. Halaman ini menggunakan pustaka JSZip di browser Anda: ia membaca file yang Anda pilih ke memori, secara opsional mengompresi masing-masing dengan algoritma DEFLATE (yang sama yang digunakan alat ZIP klasik), menulis direktori, dan memberikan arsip yang selesai kembali kepada Anda sebagai satu unduhan. File dengan nama yang sama dipertahankan dan diberi nomor otomatis - report.pdf kedua menjadi report (1).pdf - sehingga tidak ada yang ditimpa secara diam-diam.

Contoh yang dikerjakan

Anda menambahkan tiga file: report.pdf (240 KB), photo.jpg (1.2 MB), dan notes.txt (2 KB), dengan nama folder diatur ke "handover". Alat menghasilkan handover.zip - atau nama apa pun yang Anda pilih - mengandung folder handover dengan ketiga file di dalamnya. Unduhan kira-kira 1.4 MB, karena PDF dan JPG sudah terkompresi; seandainya file adalah teks polos dan ekspor CSV, arsip yang sama dapat dengan mudah menjadi sepertiga ukuran asli.

Pertanyaan yang Sering Diajukan

Apakah pembuat file ZIP ini gratis?

Ya - gratis, tanpa pendaftaran, tanpa batas, dan tanpa watermark.

Apakah file saya diunggah ke server?

Tidak. ZIP dibangun oleh JavaScript (JSZip) yang berjalan di browser Anda. File Anda tidak pernah meninggalkan perangkat Anda, yang juga membuat ini aman untuk dokumen privat.

Mengapa ZIP saya hampir sama ukurannya dengan file asli?

Format seperti JPG, PNG, MP4, MP3, dan PDF sudah terkompresi, jadi kompresi ZIP tidak dapat menyusutkannya lebih jauh. File berbasis teks - TXT, CSV, HTML, JSON, kode sumber, dan log - biasanya menyusut banyak.

Apakah ada batas ukuran file?

Tidak ada batas yang terpasang di alat, tetapi arsip dirakit dalam memori browser Anda. Beberapa ratus megabita baik-baik saja di sebagian besar desktop; set yang sangat besar dapat lambat atau kehabisan memori di ponsel kelas bawah. Jika ia berjuang, pisah file menjadi ZIP yang lebih kecil.

Dapatkah saya melindungi ZIP dengan kata sandi atau menambahkan file ke ZIP yang ada?

Tidak dengan alat ini. Ia membuat ZIP standar baru tanpa enkripsi. Siapa pun yang mendapatkan file dapat membukanya, jadi jangan mengandalkan ZIP saja untuk melindungi rahasia.
