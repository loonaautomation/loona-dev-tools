ZIP-Datei-Ersteller - Erstellen Sie ein ZIP aus mehreren Dateien

Kurz gesagt: das ZIP-Datei-Ersteller bündelt einen beliebigen Satz Dateien in ein einzelnes Standard-.zip-Archiv, vollständig in Ihrem Browser mit JSZip gebaut – fügen Sie Dateien hinzu, gruppieren Sie sie optional in einem Ordner, wählen Sie eine Kompressionsstufe und laden Sie herunter.

Zehn Anhänge einzeln senden, einen Projektordner übergeben oder einen Stapel Fotos archivieren – ein ZIP verwandelt einen Haufen Dateien in einen ordentlichen Download. Die meisten Online-Zipper laden Ihre Dateien zuerst auf einen Server hoch. Dieser tut es nicht: Das Archiv wird auf Ihrem eigenen Gerät zusammengebaut, sodass selbst private Dateien nirgendwohin reisen.

Dateien hierher ziehen oder klicken Sie, um Dateien von Ihrem Gerät zu wählen
DateinameGröße

Hinweis zur Kompression: Text-, Code- und CSV-Dateien schrumpfen mit DEFLATE stark. Fotos, Videos und PDFs sind bereits komprimiert, das ZIP wird also so oder so etwa gleich groß sein – wählen Sie für diese „Stored“, um sofort fertig zu werden.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Dateien werden niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg. Ein ehrliches Limit: Das ZIP wird im Speicher Ihres Geräts gebaut, also können sehr große Dateisätze (hunderte Megabytes) auf einem Handy mit wenig Speicher langsam sein oder fehlschlagen.

So verwenden Sie den ZIP-Datei-Ersteller

  1. Ziehen Sie Ihre Dateien auf das Feld oben, oder klicken Sie es an und wählen Sie Dateien von Ihrem Gerät. Sie können Dateien in mehreren Runden hinzufügen.
  2. Prüfen Sie die Liste – entfernen Sie alles, was Sie versehentlich hinzugefügt haben, und achten Sie auf die Gesamtgröße.
  3. Tippen Sie optional einen Ordnernamen ein, wenn jede Datei in einem Ordner im Archiv sitzen soll, und geben Sie dem ZIP einen Namen.
  4. Wählen Sie eine Kompressionsstufe (Komprimiert ist für die meisten Aufgaben richtig) und klicken Sie auf „ZIP erstellen & herunterladen“.

So funktioniert es

Ein ZIP-Archiv speichert die Daten jeder Datei plus ein zentrales Verzeichnis am Ende, das jeden Eintrag, seinen Namen und seine Größen auflistet – deshalb kann jedes Unzip-Tool auf jedem System es öffnen. Diese Seite nutzt die JSZip-Bibliothek in Ihrem Browser: Sie liest die von Ihnen gewählten Dateien in den Speicher, komprimiert jede optional mit dem DEFLATE-Algorithmus (demselben, den klassische ZIP-Tools nutzen), schreibt das Verzeichnis und übergibt Ihnen das fertige Archiv als einzelnen Download. Dateien mit demselben Namen werden behalten und automatisch nummeriert – die zweite report.pdf wird zu report (1).pdf –, sodass nichts still überschrieben wird.

Durchgerechnetes Beispiel

Sie fügen drei Dateien hinzu: report.pdf (240 KB), photo.jpg (1.2 MB) und notes.txt (2 KB), mit dem Ordnernamen "handover". Das Tool erzeugt handover.zip – oder welchen Namen Sie gewählt haben –, das einen handover-Ordner mit allen drei Dateien darin enthält. Der Download ist ungefähr 1.4 MB, weil PDF und JPG bereits komprimiert waren; wären die Dateien einfacher Text und CSV-Exporte gewesen, hätte dasselbe Archiv leicht ein Drittel der Originalgröße sein können.

Häufig gestellte Fragen

Ist dieser ZIP-Datei-Ersteller kostenlos?

Ja – kostenlos, keine Registrierung, keine Limits und keine Wasserzeichen.

Werden meine Dateien auf einen Server hochgeladen?

Nein. Das ZIP wird von JavaScript (JSZip) gebaut, das in Ihrem Browser läuft. Ihre Dateien verlassen Ihr Gerät nie, was dies auch für private Dokumente sicher macht.

Warum ist mein ZIP fast so groß wie die Originaldateien?

Formate wie JPG, PNG, MP4, MP3 und PDF sind bereits komprimiert, also kann die ZIP-Kompression sie nicht viel weiter schrumpfen. Textbasierte Dateien – TXT, CSV, HTML, JSON, Quellcode und Protokolle – schrumpfen üblicherweise stark.

Gibt es eine Dateigrößen-Grenze?

Es gibt keine in das Tool eingebaute Grenze, aber das Archiv wird im Speicher Ihres Browsers zusammengebaut. Einige hundert Megabytes sind auf den meisten Desktops in Ordnung; sehr große Sets können auf einem schwachen Telefon langsam sein oder den Speicher erschöpfen. Kämpft es, teilen Sie die Dateien in kleinere ZIPs.

Kann ich das ZIP mit einem Passwort schützen oder Dateien zu einem bestehenden hinzufügen?

Nicht mit diesem Tool. Es erstellt ein frisches, Standard-ZIP ohne Verschlüsselung. Jeder, der die Datei bekommt, kann sie öffnen, also verlassen Sie sich zum Schutz von Geheimnissen nicht allein auf ein ZIP.
