Конвертер JSON у CSV - Перетворюйте масиви JSON в електронні таблиці

Коротко: конвертер JSON у CSV бере масив об’єктів JSON і створює належний файл CSV: стовпці є об’єднанням кожного ключа в масиві, значення з комами або лапками взято в лапки правильно, а вкладені об’єкти зберігаються як компактний JSON усередині їхньої клітинки.

API говорять мовою JSON; електронні таблиці, імпорти та менеджери говорять мовою CSV. Вставте масив JSON нижче й отримайте файл CSV, який чисто відкривається в Excel, Google Sheets або будь-якому імпортері, — без понівечених ком і зламаних лапок.

Приватно за задумом: усе в цьому інструменті відбувається на 100% у вашому браузері за допомогою JavaScript. Ваші вхідні дані ніколи не передаються на сервер, ніколи не зберігаються й ніколи не бачаться нами: закрийте вкладку — і все зникло.

Як користуватися конвертером JSON у CSV

  1. Вставте масив об’єктів JSON у верхнє поле (один об’єкт також працює — він стане одним рядком).
  2. Натисніть «Конвертувати у CSV».
  3. Перегляньте CSV: перший рядок — це заголовок, побудований із кожного ключа, знайденого в масиві.
  4. Скопіюйте його або завантажте як файл .csv, готовий для Excel або Google Sheets.

Як це працює

Конвертер розбирає ваш JSON вбудованим парсером браузера, потім проходить кожен об’єкт у масиві й збирає об’єднання всіх ключів у порядку, у якому вони вперше з’являються, — тож об’єкт із додатковим полем ніколи його не втрачає. Кожна клітинка екранується за правилами CSV: значення, що містять кому, лапку або переведення рядка, обгортаються в подвійні лапки, а лапки всередині подвоюються. Числа й булеві значення записуються просто, null і відсутні ключі стають порожніми клітинками, а вкладений об’єкт або масив записується як компактний JSON усередині своєї клітинки, щоб жодні дані не губилися мовчки.

Розібраний приклад

Масив [{"name":"Ali","city":"Lahore"},{"name":"Ana","city":"Porto","vip":true}] стає трьома стовпцями (name, city, vip): Ali отримує порожню клітинку vip, а Ana отримує true — підхід об’єднання ключів зберігає обидва рядки повними.

Часті запитання

Чи цей конвертер JSON у CSV безкоштовний?

Так — цілком безкоштовно, без реєстрації, без обмеження розміру й без денного обмеження.

Які форми JSON приймаються?

Масив об’єктів — основний випадок. Один об’єкт стає однорядковим CSV, а масив звичайних значень (чисел, рядків) стає одним стовпцем "value". Усе інше відхиляється з поясненням.

Що відбувається з вкладеними об’єктами й масивами?

Їх записують як компактний текст JSON усередині їхньої клітинки. Нічого не сплющується й не відкидається, а конвертування назад нашим інструментом CSV у JSON зберігає їх читабельними.

Чому деякі клітинки мають лапки навколо себе?

Правила CSV вимагають лапок, коли значення містить кому, подвійну лапку або новий рядок, — інакше стовпці змістилися б. Excel і Google Sheets читають це стандартне взяття в лапки правильно.

Чи завантажуються мої дані на сервер?

Ні. Розбір і конвертування відбуваються на 100% у вашому браузері. Ваші дані ніколи не покидають ваш пристрій.
