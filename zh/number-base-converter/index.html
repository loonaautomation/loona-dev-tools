进制转换器 - 二进制、八进制、十进制和十六进制，精确转换

简而言之： 进制转换器使用任意精度算术在二进制、八进制、十进制和十六进制之间转换整数，因此远远超过通常的 2^53 JavaScript 限制的值也能逐位精确转换——无效的数字会被指名指出。

文件权限、颜色代码、内存地址、按位标志——进制在开发中无处不在。以任何进制输入一个值，以全部四种进制读取它，精度不会悄悄把您的大数字四舍五入掉。

如何使用进制转换器

  1. 把数字输入或粘贴到值框中。
  2. 选择值所写的进制。
  3. 以二进制、八进制、十进制和十六进制阅读相同的值——结果随您输入而更新。
  4. 使用复制按钮带走任何表示形式。

它如何工作

转换器首先根据您选择的进制允许的数字验证每个字符——在二进制值中输入 2，它会明确告诉您这一点，而不是猜测。然后它用任意精度整数算术（BigInt）构建值：每个数字把运行总计乘以进制并加上自身，这一过程对任何长度的数字都保持精确。最后它把那个精确值以四种进制中的每一种呈现。负值在每一步都保留其符号。

实例

十进制值 18446744073709551617——比 2^64 大一——比任何普通 JavaScript 数字能精确容纳的都大。在这里它仍然精确转换：十六进制 10000000000000001，以及以 1 结尾的 65 位二进制字符串，而浮点转换器会悄悄地把它四舍五入。

常见问题

这个进制转换器免费吗？

是的——完全免费，无需注册，没有大小限制，也没有每日上限。

它能转换多大的数字？

实际上没有限制。转换使用 BigInt 算术，所以几百位数字的值也能精确转换。普通 JavaScript 数字那个熟悉的 2^53 限制不适用。

它能处理像 3.14 这样的小数吗？

不会——本转换器用于整数，这正是进制在实践中的用途（地址、权限、颜色、标志）。输入中的小数点会被报告为无效数字，而不是悄悄丢弃。

如果我输入进制中不存在的数字怎么办？

您会得到一个具体的错误，指出数字和进制——例如，数字 "8" 不能出现在八进制值中，"g" 不能出现在十六进制中。

我的输入会被上传到服务器吗？

不会。转换 100% 在您的浏览器中进行。您的值从不离开您的设备。
