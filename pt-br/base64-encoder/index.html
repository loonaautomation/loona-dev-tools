Codificador e Descodificador Base64 - Texto e Arquivos, Seguro para UTF-8

Em resumo: o Codificador Base64 converte texto e arquivos para Base64 e descodifica Base64 de volta para texto - tratando corretamente acentos, urdu, chinês e emoji, com um alfabeto URL-safe opcional.

Base64 aparece em todo o lado: payloads de API, anexos de e-mail, data URIs, cabeçalhos basic-auth e partes de JWT. O problema de muitos codificadores rápidos é que falham com texto não-inglês. Este codifica os bytes UTF-8 do seu texto, pelo que tudo o que conseguir escrever sobrevive à ida e volta.

Como utilizar o Codificador e Descodificador Base64

  1. Escreva ou cole o seu texto (ou escolha um arquivo para arquivo-para-Base64).
  2. Opcionalmente assinale URL-safe se o resultado for para um URL ou um JWT.
  3. Clique em Codificar ou Descodificar e copie ou transfira o resultado.

Como funciona

Base64 representa cada 3 bytes de dados como 4 caracteres de um alfabeto de 64-caracteres, o que torna os dados binários seguros para transportar dentro de formatos de texto como JSON, XML e URLs. Esta ferramenta converte primeiro o seu texto para os seus bytes UTF-8 (a codificação universal para texto) e depois codifica esses bytes - razão pela qual letras acentuadas, texto em escrita árabe e emoji descodificam de volta perfeitamente. A variante segura para URL troca + e / por - e _ e elimina o preenchimento =, exatamente como utilizado em JSON Web Tokens.

Exemplo resolvido

O texto "Loona" codifica para TG9vbmE=. A saudação "Assalam-o-Alaikum" com escrita urdu e um emoji - السلام علیكم 👋 - codifica e descodifica de volta letra a letra, o que codificadores ingénuos que só tratam ASCII simples não conseguem fazer.

Perguntas Frequentes

Esta ferramenta Base64 é grátis?

Sim - grátis, sem registro, sem limites.

Porque é que algumas ferramentas Base64 adulteram texto não inglês?

Codificam cada carácter como um único byte, o que só funciona para ASCII simples. Esta ferramenta codifica antes os bytes UTF-8, pelo que cada língua e emoji fazem a viagem de ida e volta exatamente.

O que é a opção URL-safe?

O Base64 padrão pode conter + e /, que são caracteres especiais em URLs. O alfabeto URL-safe substitui-os por - e _ e remove o preenchimento - a variante utilizada em JWTs.

Base64 é encriptação?

Não. Base64 é uma codificação, não encriptação - qualquer pessoa o descodifica instantaneamente. Nunca o utilize para proteger segredos.

Os meus arquivos são carregados?

Não. Os arquivos são lidos pelo seu navegador no seu dispositivo e nunca saem dele.
