Convertitore da ZIP a TAR.GZ - Trasforma un .zip in un tarball .tar.gz

In breve: il Convertitore da ZIP a TAR.GZ reimpacchetta un archivio ZIP come tarball ustar adeguato e lo comprime con gzip, sul tuo stesso dispositivo - producendo il formato .tar.gz su cui gira il mondo Linux.

Distribuzione su un server Linux, alimentare una build Docker, o consegnare file a uno strumento che si aspetta un tarball? ZIP è l'intruso in quel mondo - .tar.gz è la lingua madre. Questo convertitore legge il tuo ZIP nel browser, scrive un archivio TAR corretto per specifica e lo comprime con gzip, tutto senza caricare nulla.

Privato per design: tutto in questo strumento accade al 100% nel tuo browser con JavaScript. I tuoi file non vengono mai caricati su un server, mai memorizzati e mai visti da noi - chiudi la scheda e tutto è andato. Un limite onesto: la conversione avviene nella memoria del tuo dispositivo, quindi archivi molto grandi (centinaia di megabyte) possono essere lenti o fallire su un telefono con poca memoria.

Come usare il Convertitore da ZIP a TAR.GZ

  1. Trascina il tuo file .zip sulla casella sopra, o fai clic e scegli il file dal tuo dispositivo.
  2. Fai clic su Converti in TAR.GZ. Lo ZIP viene letto sul tuo dispositivo, un archivio TAR viene scritto con gli stessi percorsi e gzip lo comprime.
  3. Controlla il riepilogo: numero di file convertiti e dimensione del nuovo tarball.
  4. Fai clic su Scarica per salvare il file .tar.gz - tar -xzf lo apre su qualsiasi sistema Linux o macOS.

Come funziona

Questa pagina legge lo ZIP con JSZip, poi scrive il contenuto come archivio TAR usando uno scrittore ustar corretto per specifica integrato nella pagina: ogni file riceve un blocco intestazione da 512-byte (nome, dimensione, modo, checksum, e un campo prefisso per percorsi lunghi - con voci GNU longname per percorsi troppo lunghi anche per quello), il suo contenuto riempito a un confine da 512-byte, e due blocchi zero per chiudere l'archivio. Il TAR finito viene compresso con il motore gzip integrato del tuo browser (l'API Compression Streams). L'output è stato verificato contro il modulo tarfile di Python e le convenzioni GNU tar durante i test - è un vero tarball, non uno ZIP rinominato.

Esempio pratico

Hai site-assets.zip (12 MB, 240 file) da caricare su un VPS Linux il cui script di deploy esegue tar -xzf. Convertito qui, ottieni site-assets.tar.gz (11.6 MB) con gli stessi 240 file agli stessi percorsi e i loro timestamp ZIP mantenuti. Il server lo estrae esattamente come se il tarball fosse stato creato su Linux.

Domande frequenti

Questo convertitore da ZIP a TAR.GZ è gratuito?

Sì - gratuito, nessuna registrazione, nessun limite e nessuna filigrana.

I miei file vengono caricati su un server?

No. JSZip legge lo ZIP, il TAR viene scritto dal codice in questa pagina, e gzip viene fatto dal motore integrato del tuo browser. Tutto resta sul tuo dispositivo.

GNU tar e gli strumenti Linux accetteranno l'output?

Sì. Lo scrittore TAR segue la specifica ustar - checksum intestazione corretti, campi dimensione ottali, suddivisione prefisso ustar per percorsi lunghi e voci GNU longname quando un percorso supera anche quello - e il risultato è stato verificato leggendo di ritorno con il modulo tarfile di Python.

Timestamp e permessi dei file vengono conservati?

I timestamp memorizzati nello ZIP vengono trasportati nelle intestazioni TAR. I permessi sono scritti come predefiniti standard (file 0644, cartelle 0755), perché ZIP non memorizza in modo affidabile i permessi Unix - se hai bisogno di modi esatti, impostali dopo l'estrazione con chmod.

Perché non convertire in semplice .tar invece?

Un TAR semplice è non compresso, quindi sarebbe circa la dimensione di tutti i file sommati. .tar.gz è ciò che gli strumenti Linux si aspettano e resta vicino alla dimensione dello ZIP. Per un TAR semplice di file sciolti, usa il Creatore di file TAR.
