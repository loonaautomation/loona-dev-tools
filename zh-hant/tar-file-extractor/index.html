TAR 檔案解壓工具 - 線上開啟 TAR 檔案

簡而言之： TAR 檔案提取器在您的瀏覽器中開啟 .tar 歸檔——包括壓縮變體 .tar.bz2 和 .tar.xz。瀏覽裡面的檔案，下載單個檔案，或抓取重新打包為 ZIP 的所有內容。不會上傳任何內容；工作在您的裝置上完成。

TAR 是磁帶時代的歸檔格式祖輩：在 Linux 和 macOS 伺服器上，原始碼、備份和日誌包仍然以 .tar 檔案的形式流轉——而 Windows 仍然無法原生開啟它們。本頁用 libarchive 的 WebAssembly 移植版本開啟普通 TAR 及其 BZIP2 和 XZ 壓縮變體，完全在您的裝置上。（對於更常見的 .tar.gz，下方連結了一個專門頁面。）

歸檔內的檔案大小
按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中完成。這個 TAR 歸檔由您自己裝置上的 WebAssembly 引擎讀取——從不上傳，從不儲存，我們也從不見過它。一個誠實的限制：歸檔在您裝置的記憶體中解壓，所以極大的歸檔（數百兆位元組）在記憶體不足的手機上可能會很慢或失敗——那種請在電腦上拆分。

如何使用 TAR 檔案解壓工具

  1. 把您的 .tar、.tar.bz2 或 .tar.xz 檔案拖到上面的框中，或點選它從您的裝置中選擇檔案。
  2. 等待片刻，歸檔正在讀取——首次使用時，解壓引擎（約 1 MB）載入一次，然後由您的瀏覽器快取。
  3. 瀏覽歸檔內檔案的列表，包括路徑和大小。
  4. 點選任何單個檔案旁邊的“下載”，或使用“全部下載為 ZIP”把一切儲存為一個標準 ZIP 檔案。

它如何工作

TAR 檔案根本沒有壓縮——它是一系列 512 位元組標頭塊和檔案資料，填充到固定的記錄大小，這使它非常適合磁帶驅動器。本頁先移除任何外層壓縮層（BZIP2 或 XZ），然後用編譯為 WebAssembly 的 libarchive 遍歷 TAR 標頭，列出每個條目及其路徑和大小。檔案只有在您下載時才會被解壓；“全部下載為 ZIP”選項會用 JSZip 重新打包它們。

例項

一份伺服器備份以 logs-2026.tar.xz（9 MB）的形式送到。您在這裡開啟它，看到按日期歸檔的資料夾中有 143 個日誌檔案。您無需解壓全部內容，只下載故障當天那兩個日誌（每個約 300 KB），其餘的保持打包狀態。

常見問題

.tar、.tar.bz2 和 .tar.xz 有什麼區別？

內部是相同的 TAR 結構；只有外部壓縮不同。普通 .tar 未壓縮，.tar.bz2 使用 BZIP2（壓縮好，較慢），.tar.xz 使用 XZ/LZMA2（通常結果最小）。三者都能在本頁開啟。

.tar.gz 在哪裡？它是我看到的最常見的。

它有自己專門的頁面——下方連結的 TAR.GZ 檔案解壓工具——因為 .tar.gz 是大多數人實際收到的格式。從技術上講，本頁的引擎也能讀取 .tar.gz；專門頁面只是直接針對那次搜尋和那種檔案型別。

本工具能開啟 .tgz、.tbz2 或 .txz 檔案嗎？

.tbz2 和 .txz 只是 .tar.bz2 和 .tar.xz 的簡稱，這裡兩者都接受。.tgz 是 .tar.gz 的簡稱——這類檔案請使用 TAR.GZ 檔案解壓工具頁面。

為什麼我的 .tar 檔案與相同檔案的 ZIP 相比這麼大？

因為普通的 TAR 根本不做任何壓縮——它只負責捆綁。一個 100 MB 的資料夾會變成大約 100 MB 的 .tar。如果大小重要，壓縮變體（.tar.gz、.tar.xz）或 ZIP 是更好的選擇。

我的檔案會被上傳到伺服器嗎？

不會。引擎是在您瀏覽器標籤頁中執行的 WebAssembly；歸檔從不離開您的裝置，頁面載入後本工具離線也能工作。
