Diff चेकर — दो Texts की Line by Line तुलना करें

संक्षेप में: Diff चेकर text के दो versions को line by line longest-common-subsequence diff उपयोग करके compare करता है, added lines को green और removed lines को red में highlight करता है, और सारांश देता है कि कितनी lines added, removed और unchanged रहीं।

एक config file बदली और कुछ टूट गया, या किसी document के दो versions में मतभेद है — दोनों versions यहाँ paste करने से आपको seconds में ठीक पता चलता है कि कौन सी लाइनें हिलीं, बिना किसी को कहीं upload किए।

जोड़ी गई लाइनें-
हटाई गई lines-
Unchanged lines-
(अभी कोई तुलना नहीं)
Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

Diff चेकर का उपयोग कैसे करें

  1. मूल text बाएँ box में paste करें।
  2. संशोधित text दाएँ box में paste करें।
  3. Compare पर click करें।
  4. परिणाम पढ़ें: - से marked lines हटाई गईं, + से marked lines जोड़ी गईं, और unmarked lines unchanged हैं।

यह कैसे काम करता है

Checker दोनों texts को lines में विभाजित करता है और दो line lists का longest common subsequence (LCS) compute करता है — lines का सबसे बड़ा set जो दोनों में same order में आता है। Subsequence में lines unchanged हैं; original में लेकिन subsequence में नहीं lines हटाई गईं, और सिर्फ़ revision में lines जोड़ी गईं। यह Unix diff जैसे tools के पीछे algorithm की वही family है, इसलिए comparison उसी तरह line up होती है जैसी आप उम्मीद करते हैं भले पूरे blocks एक-दो lines खिसक गए हों।

काम किया हुआ उदाहरण

तीन-line shopping list के दो versions की तुलना जहाँ "eggs" "egg whites" बन गया, एक लाल line और एक हरी line दिखाती है, बाकी दो lines unchanged — 1 added, 1 removed, 2 unchanged का summary, लगभग एक जैसी text की दीवार को आँखों से परखने के बजाय।

अक्सर पूछे जाने वाले सवाल

क्या यह diff checker मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, बिना साइन-अप और बिना daily cap।

क्या तुलना line-based है या character-based?

Line-based, Unix diff की तरह: एक line या तो unchanged, removed या added होती है। अगर लंबी line के अंदर एक शब्द बदलता है, तो पूरी line एक removal और एक addition के रूप में दिखती है।

यह कितने बड़े text की तुलना कर सकता है?

हर तरफ़ 1,500 lines तक। LCS table दो line counts के product के साथ बढ़ती है, इसलिए बहुत बड़ी फ़ाइलें desktop diff tool से बेहतर compare होती हैं।

क्या यह whitespace या case को अनदेखा करता है?

नहीं — lines को unchanged गिने जाने के लिए ठीक match करना चाहिए, इसलिए सिर्फ़ trailing space पाने वाली line changed के रूप में दिखती है। वह सख़्ती जानबूझकर है: configs और code की तुलना करते समय आमतौर पर ठीक यही आप चाहते हैं।

क्या मेरा text किसी server पर अपलोड होता है?

नहीं। Comparison 100% आपके ब्राउज़र में होती है। कोई text कभी आपके device से बाहर नहीं जाता।
