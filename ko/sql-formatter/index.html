SQL 포맷터 - 읽기 쉬운 쿼리, 줄에 절 하나

요약하면: SQL 포맷터는 키워드를 대문자로 하고, 모든 주요 절(SELECT, FROM, WHERE, GROUP BY, ORDER BY, LIMIT, 각 JOIN)을 자체 줄에 넣고, AND / OR 조건을 들여쓰기해요 - 문자열 리터럴은 쓴 그대로 정확히 두면서요.

조인이 다섯 개 있는 한 줄 쿼리는 기술적으로 유효하지만 사실상 읽을 수 없어요. 아래에 붙여넣으면 컨디션 좋은 날 손으로 쓸 법한 레이아웃으로 같은 쿼리를 돌려받아요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

SQL 포맷터 사용법

  1. SQL 쿼리를 위 상자에 붙여넣으세요.
  2. 고전적인 모양을 위해 "키워드 대문자화"를 선택한 채로 두거나, 원래 키워드 대소문자를 유지하려면 선택을 해제하세요.
  3. SQL 포맷을 클릭하세요.
  4. 포맷된 쿼리를 복사하거나 .sql 파일로 다운로드하세요.

작동 방식

포맷터는 쿼리를 먼저 토큰화해, 따옴표 문자열, 큰따옴표와 백틱 식별자가 손대지 않은 채 옮겨져요 - 다음과 같은 리터럴 'select me' 절대 대문자가 되거나 분할되지 않아요. 그다음 토큰 스트림을 순회하며 GROUP BY, ORDER BY, LEFT OUTER JOIN 같은 여러 단어 절을 인식하고, 각 주요 절을 새 줄에서 시작하며, AND와 OR 조건을 자체 들여쓰기 줄에 넣어요. 연산자와 쉼표 주변의 간격은 관례적인 단일 공백으로 정규화돼요.

풀이된 예시

한 줄짜리 select id, name from users where age > 18 and city = 'New York' order by name limit 10 여섯 개의 깨끗한 줄 - SELECT, FROM, WHERE, 들여쓰기된 AND, ORDER BY, LIMIT - 이 돼요. 검토나 티켓에 붙여넣을 준비가 됐어요.

자주 묻는 질문

이 SQL 포맷터는 무료인가요?

네 - 완전히 무료, 회원가입 없음, 크기 제한 없음, 일일 상한 없음이에요.

어떤 SQL 방언을 지원하나요?

포맷터는 방언 규칙이 아니라 절 구조에 작용해, MySQL, PostgreSQL, SQL Server, SQLite 등의 표준 SQL이 모두 같은 방식으로 포맷돼요. 레이아웃만 다듬어요 - 쿼리가 실행될지 검증하지는 않아요.

서브쿼리를 다시 들여쓰나요?

아니요 - 괄호로 감싼 서브쿼리는 나타나는 줄에 그대로 남아요. 깊은 서브쿼리 들여쓰기는 포맷터가 가장 자주 잘못 추측하는 곳이라, 이 도구는 절 수준 레이아웃을 고수하고 솔직히 그렇게 말해요.

문자열 리터럴이 안전한가요?

네. 작은따옴표 문자열(이중 따옴표 이스케이프 포함), 큰따옴표와 백틱 식별자는 바이트 단위로 통과해요; 그것들 밖의 키워드만 대문자가 돼요.

제 SQL이 서버에 업로드되나요?

아니요. 포맷은 브라우저에서 100% 일어나요. 쿼리 - 스키마 이름과 모든 것 - 는 기기를 절대 떠나지 않아요.
