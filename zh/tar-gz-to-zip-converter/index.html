TAR.GZ 转 ZIP 转换器 - 把 .tar.gz 和 .tgz 变成 .zip

简而言之： TAR.GZ 转 ZIP 转换器在您的设备上解开 .tar.gz（或 .tgz）归档的两层——先 gzip，然后 tar——并将文件重新打包为一个单一的标准 .zip。

.tar.gz 是穿着一件外套的两种格式：先用 tar 捆绑文件，再用 gzip 压缩。Linux 到处都在生成它们——源码发布、备份、日志——但 Windows 和手机无法原生打开。本转换器在您的浏览器中本地解开这两层，交给您一个普通的 ZIP。

如何使用 TAR.GZ 转 ZIP 转换器

  1. 把您的 .tar.gz 或 .tgz 文件拖到上面的框中，或点击它从您的设备中选择文件。
  2. 点击“转换为 ZIP”。gzip 和 tar 两层都在您的设备上解开，文件被重新打包为一个 ZIP。
  3. 查看摘要：找到的文件数和新 ZIP 的大小。
  4. 点击“下载”保存 .zip 文件——它能用任何系统的内置工具打开。

它如何工作

在底层，本页把您的文件交给 libarchive 的 WebAssembly 构建版本，它把 gzip 包装和内部的 tar 归档理解为一个流——正是 tar -xzf 在 Linux 上对待它的方式。解压出的文件然后由 JSZip 写入一个全新的 ZIP，每个都在其原始路径上。请注意这与普通 .gz 文件之间的区别：.tar.gz 包含许多文件，而单独的 .gz 通常包装单个文件（这正是 GZ 文件解压工具的用途）。本页接受 .tar.gz 和缩短的 .tgz 拼写——它们是相同的格式。

实例

您将一个开源工具的 release-2.4.tar.gz（18 MB）下载到一台 Windows PC 上。工具在这里将其解包，并生成 release-2.4.zip（19 MB），其中包含相同文件夹中的相同 86 个文件——可在资源管理器中打开，不需要 Linux，也不需要额外软件。

常见问题

这个 TAR.GZ 转 ZIP 转换器免费吗？

是的——免费，无需注册，没有限制，也没有水印。

我的文件会被上传到服务器吗？

不会。两层都被解开，ZIP 完全在您的浏览器中构建；没有任何东西离开您的设备。

.tar.gz 和 .tgz 有什么区别？

没有区别——.tgz 只是 .tar.gz 的缩短拼写，是为曾经只允许三字母扩展名的系统创建的。本工具两者都接受。

我的文件是普通的 .gz，不是 .tar.gz。我应该用什么？

普通的 .gz 包裹着单个压缩文件，而不是许多文件的归档。使用 GZ 文件解压工具从中取回原始文件。

为什么 ZIP 与 .tar.gz 大小差不多？

两种格式都压缩得很好——tar 上是 gzip，ZIP 内部是 DEFLATE——所以输出大小相近是预料之中的。赢在兼容性：ZIP 在任何地方都能打开。
