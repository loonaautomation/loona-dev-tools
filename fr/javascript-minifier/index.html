Minifieur JavaScript - Une compression conservatrice qui respecte votre code

En bref : le Minifieur JavaScript retire les commentaires et les espaces inutiles à l’aide d’un vrai tokeniseur, afin que le contenu des chaînes, les littéraux de gabarits et les expressions régulières ne soient jamais endommagés, et que les sauts de ligne porteurs de sens (comme celui après return) soient toujours gardés.

Les minifieurs naïfs qui traitent JavaScript comme du texte simple cassent le code dès qu’une chaîne contient « // » ou qu’une regex contient un guillemet. Cet outil lexique d’abord votre code en jetons et décide seulement ensuite ce qui peut être retiré en sécurité.

Comment utiliser le Minifieur JavaScript

  1. Collez ou saisissez votre JavaScript dans la boîte du haut.
  2. Cliquez sur Minifier le JavaScript.
  3. Vérifiez le panneau des tailles pour voir combien a été économisé.
  4. Copiez le résultat ou téléchargez-le dans un fichier .js - et, comme avec tout minifieur, exécutez votre code une fois pour confirmer qu’il se comporte de la même façon.

Comment ça fonctionne

L’outil divise d’abord votre code en jetons : identifiants, nombres, chaînes, littéraux de gabarits, expressions régulières et ponctuation. Les commentaires sont reconnus pendant ce balayage et abandonnés, et le scanner connaît la différence entre un signe de division et le début d’une regex, et ne cherche jamais à l’intérieur d’une chaîne des marqueurs de commentaires. Les jetons sont ensuite rejoints, en n’ajoutant une espace de séparation que là où la retirer changerait le sens - entre deux mots, entre un plus et un autre plus, et ainsi de suite. Les sauts de ligne sont conservés partout où l’insertion automatique de points-virgules de JavaScript les rend significatifs, surtout après return, break et continue, et avant un premier ++ ou --.

Exemple travaillé

Une fonction utilitaire commentée d’environ 400 octets se compresse typiquement à environ 260 octets - environ un tiers plus petite - tandis qu’une chaîne comme "see https://example.com // docs" à l’intérieur, il passe complètement intact.

Questions fréquemment posées

Ce minifieur JavaScript est-il gratuit ?

Oui - entièrement gratuit, sans inscription, sans limite de taille et sans plafond quotidien.

En quoi ceci diffère-t-il d’un minifieur d’outil de build complet ?

Les outils de build comme Terser renomment aussi les variables et réécrivent le code, ce qui extrait quelques pour cent supplémentaires. Cet outil est délibérément conservateur : il ne renomme jamais rien et ne réécrit jamais les expressions, de sorte que la sortie est facile à examiner et sûre pour un usage ponctuel rapide.

Peut-il casser mon code ?

Il est conçu pour ne pas le faire : les chaînes, les littéraux de gabarits et les littéraux de regex sont protégés, et les sauts de ligne porteurs de sens sont préservés. Aucun minifieur ne peut promettre la perfection sur chaque motif exotique : exécutez donc toujours votre suite de tests ou ouvrez la page une fois après la minification - ce conseil s’applique à chaque minifieur, y compris le nôtre.

Gère-t-il les expressions régulières et les littéraux de gabarits ?

Oui. Le tokeniseur reconnaît les littéraux de regex (y compris les classes de caractères et les échappements) et les littéraux de gabarits, y compris les expressions ${ } imbriquées, et les transporte inchangés.

Mon code est-il téléversé vers un serveur ?

Non. La tokenisation et la minification se passent à 100 % dans votre navigateur. Votre code source ne quitte jamais votre appareil.
