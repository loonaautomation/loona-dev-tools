CSS clip-path-generator - Vorm je elementen visueel

Kortom: de CSS Clip-Path-generator geeft je kant-en-klare clip-path CSS voor polygonen (driehoek tot ster), cirkels, ellipsen en insets - kies een vorm, verschuif zijn punten, bekijk het live voorbeeld en kopieer de code. Let op: de verwante Image-tools van deze site dekken gradients al; clip-path leeft hier omdat het layout-CSS is, geen afbeeldingsbewerking.

Clip-path verandert rechthoeken in design: schuine secties, badges, pijlen en sterren met één CSS-eigenschap. Het moeilijke deel zijn de coördinaten - deze tool verwerkt ze.

Privacy in het ontwerp: alles in deze tool gebeurt 100% in je browser met JavaScript. Je invoer wordt nooit naar een server geüpload, nooit opgeslagen en nooit door ons gezien - sluit het tabblad en alles is weg.

De CSS clip-path-generator gebruiken

  1. Kies een vormpreset.
  2. Pas voor polygonen de x,y-percentages van een punt aan.
  3. Bekijk hoe het voorbeeld live wordt bijgewerkt.
  4. Kopieer de CSS - zowel de standaard- als de -webkit-eigenschap is inbegrepen.

Hoe het werkt

Polygoonpunten zijn percentages van de box van het element, dus vormen schalen mee met het element. De presets coderen bekende coördinatensets (een regelmatige vijfhoek, zeshoek, een tienpuntige ster en meer), en de generator stuurt beide uit clip-path en de -webkit- geprefixte tweeling die Safari historisch nodig heeft gehad. Cirkel, ellips en inset dekken de niet-polygoonvormen die de eigenschap ondersteunt, inclusief afgeronde insets.

Veelgestelde vragen

Is deze generator gratis?

Ja - volledig gratis, geen registratie.

Waarom is er ook een gradiëntgenerator op de Image-site?

Gradiënten worden daar als afbeeldings-/designassets behandeld. Clip-path is layout-CSS voor developers, dus hij leeft hier - elke tool bestaat op precies één Loona-site.

Beïnvloedt clip-path klikken?

Ja - het weggeknipte gebied is niet klikbaar, wat meestal is wat je wilt voor gevormde knoppen en kaarten.

Browserondersteuning?

Alle moderne browsers ondersteunen clip-path; het -webkit-prefix in de uitvoer dekt oudere Safari.

Wordt er iets geüpload?

Nee. Alles gebeurt in je browser.
