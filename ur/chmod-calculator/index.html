Chmod کیلکولیٹر - اجازتیں Octal اور Symbolic میں، دونوں طرف

مختصراً: Chmod کیلکولیٹر مالک، گروپ اور دیگر کے لیے مانوس read/write/execute checkboxes کو آکٹل قدر (جیسے 755) اور علامتی اسٹرنگ (جیسے rwxr-xr-x) میں بدلتا ہے - اور کسی آکٹل قدر کو واپس باکسز میں بدلتا ہے، عام قدروں کے لیے سادہ-زبان معانی کے ساتھ۔

ہر کوئی یاد رکھتا ہے کہ 755 'فولڈر والا' ہے اور 644 'فائل والا' ہے - اس دن تک جب deploy کو 750 یا 640 چاہیے ہو۔ نیچے خانوں پر نشان لگائیں، یا ایک octal قدر ٹائپ کریں، اور اندازہ لگانا بند کریں۔

ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کا ان پٹ کبھی سرور پر اپ لوڈ نہیں ہوتا، کبھی محفوظ نہیں ہوتا اور ہمارے دیکھنے میں نہیں آتا - ٹیب بند کریں اور سب کچھ ختم۔

Chmod کیلکولیٹر کا استعمال کیسے کریں

  1. مالک، گروپ اور دیگر کے لیے Read, Write اور Execute پر نشان لگائیں - یا preset استعمال کریں۔
  2. آکٹل قدر، علامتی اسٹرنگ اور پیسٹ کے لیے تیار chmod کمانڈ پڑھیں۔
  3. یا کوئی 3-عددی آکٹل قدر (جیسے 750) لکھیں اور Apply octal پر کلک کریں اسے checkboxes کے طور پر دیکھنے کے لیے۔
  4. کمانڈ کو اپنے ٹرمینل میں کاپی کریں۔

یہ کیسے کام کرتا ہے

Unix اجازتیں تین bits کے تین گروپس ہیں۔ ہر گروپ کے اندر، Read کی قیمت 4 ہے، Write کی 2 اور Execute کی 1، لہٰذا ایک گروپ 0 (---) سے 7 (rwx) تک واحد آکٹل عدد ہے۔ کیلکولیٹر فی گروپ نشان زد قدریں جمع کر کے تین-عددی آکٹل بناتا ہے، اور انہی باکسز کو علامتی اسٹرنگ کے طور پر پیش کرتا ہے جو آپ دیکھتے ہیں میں ls -l آؤٹ پٹ۔ آکٹل قدر لگانا ریاضی کو الٹ میں چلاتا ہے: ہر عدد اپنے 4-2-1 حصوں میں واپس تقسیم ہوتا ہے checkboxes مقرر کرنے کے لیے۔

کام شدہ مثال

مالک read+write+execute (4+2+1 = 7)، گروپ read+execute (4+1 = 5)، دیگر read+execute (5) آکٹل 755 دیتا ہے، علامتی rwxr-xr-x - کلاسیکی سیٹنگ جو ہر کسی کو فائل یا فولڈر پڑھنے اور چلانے دیتی ہے جبکہ صرف مالک اسے بدل سکتا ہے۔

اکثر پوچھے گئے سوالات

کیا یہ chmod کیلکولیٹر مفت ہے؟

ہاں - مکمل مفت، بغیر سائن اپ اور بغیر یومیہ حد۔

آکٹل اور علامتی کے درمیان فرق کیا ہے؟

یہ ایک ہی اجازتوں کی تفصیل ہیں۔ آکٹل (755) وہ ہے جو آپ chmod کے بعد لکھتے ہیں؛ علامتی (rwxr-xr-x) وہ ہے جو ls -l آپ کو دکھاتا ہے۔ یہ ٹول دونوں سمتوں میں ان کے درمیان بدلتا ہے۔

setuid, setgid اور sticky bit (4755, 1777) کے بارے میں کیا؟

وہ خصوصی bits کے لیے چوتھا، ابتدائی عدد ہیں۔ یہ کیلکولیٹر مرکزی تین اجازت اعداد کا احاطہ کرتا ہے، جو روزمرہ chmod کام استعمال کرتا ہے؛ اگر آپ کہیں اور 4-عددی قدر لکھیں، تو آخری تین اعداد وہ ہیں جو یہاں دکھائے جاتے ہیں۔

فولڈرز کو Execute کیوں چاہیے؟

ایک فولڈر پر، "execute" کا مطلب ہے اس میں داخل ہونے اور اندر کی فائلوں تک رسائی کی اجازت - ایک فولڈر جس میں read ہو لیکن execute نہ ہو وہ نام دکھاتا ہے جو آپ اصل میں کھول نہیں سکتے۔ اسی لیے فولڈرز عام طور پر 755 ہوتے ہیں جبکہ فائلیں 644۔
