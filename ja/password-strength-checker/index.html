パスワード強度チェッカー - エントロピー、フィードバック、解読時間

要するに： パスワード強度チェッカーは、長さと文字プールからパスワードのエントロピーをビットで推定し、繰り返しとシーケンスに対してオープンなペナルティを適用し、具体的な修正と解読時間の推定を表示します。あなたのパスワードはローカルで分析され、どこにも送信、保存、記録されることは決してありません。

ほとんどの強度メーターは「弱い」と言って推測させるだけのブラックボックスです。これは仕組みを見せます。正確なプール計算、ペナルティ、何を変更すべきかです。すべて自分のデバイスで計算されます。パスワードをツールに入力すべき唯一の場所です。

設計上プライベート： このツールのすべては、JavaScriptを使ってブラウザで100%行われます。あなたの入力はサーバーにアップロードされることは決してなく、保存されることも、私たちに見られることもありません。タブを閉じるとすべてが消えます。

パスワード強度チェッカーの使い方

  1. パスワードをボックスに入力または貼り付けてください。分析はライブで、完全にあなたのデバイス上で行われます。
  2. エントロピーをビット単位で読み、強度ラベルを確認してください。
  3. フィードバックリストを順に処理してください。各項目は推定を引き上げる具体的な修正です。
  4. 終わったらボックスをクリアしてください。何も送信も保存もされていません。

仕組み

チェッカーは標準的な情報理論の推定を、公然と使います。パスワードがどの文字プールから引いているかを検出し（小文字 26、大文字 26、数字 10、記号 33）、エントロピー = 長さ x log2(pool) を計算します。次に二つの透明なペナルティを適用します。3つ以上の繰り返し文字の連なりと、4つ以上の文字の昇順または降順の列です。それぞれが実効エントロピーを20%削減します。推測攻撃はそれらの形を早期に試すためです。スコア帯は <28 ビットが非常に弱い、<36 弱い、<60 普通、<90 強い、90+ 優秀です。解読時間は毎秒10ビリオン回の推測（高速なオフライン攻撃）を想定し、キー空間を半分にします。攻撃者は平均して途中でパスワードを見つけるためです。

実例

"password" は小文字8文字です。プールは26、素のエントロピーは37.6ビット — すでに「まあまあ」程度でしかなく、しかもあらゆる流出パスワードリストの最上位に載っていることは、どの計算式にも見えません。数字と記号を含むランダムな四つの単語なら90ビットを軽く超え、覚えやすさも上です。長さこそが、あなたが持つ最も強力なレバーです。

よくある質問

このパスワード強度チェッカーは無料ですか？

はい - 完全に無料、登録不要で、毎日の上限もありません。

本物のパスワードをここに入力しても安全ですか？

分析はブラウザで100%実行されます。パスワードはサーバーに送信されることは決してなく、保存されることも、ログに書かれることもありません。ページを読み込み、入力する前にオフラインにすることで確認できます。それでも、ベストプラクティスは、正確な銀行パスワードではなく、あなたのパスワードに似た形のパスワードをテストすることです。

エントロピーの推定はどのくらい正確ですか？

これは正直なモデルであり、神託ではありません。プールベースのエントロピーはランダムな文字を前提とします。人間が選んだパスワードには、公式では完全には見えないパターンがあります。そのためこのチェッカーは繰り返しや連続も検出し、本当にランダムなパスワードを生成するパスワードマネージャーが常に最も強力な選択肢なのです。

なぜ辞書やzxcvbnのチェックがないのですか？

このツールは、大きな不透明なライブラリの代わりに、このページで計算式を読める、小さく透明なスコア関数を意図的に使います。辞書単語がギャップです。「correct horse battery staple」は長さで高得点ですが実在の単語を使います。推定は、人間が選んだパスワードの上限として扱ってください。

最も大きな違いを生むのは何ですか？

長さです。文字が一つ増えるごとに、推測作業はプールサイズ倍になります。覚えられる長いパスフレーズは、覚えられない短い記号の絡まりに勝ります。
