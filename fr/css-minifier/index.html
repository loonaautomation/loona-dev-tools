Minifieur et embellisseur CSS - Compressez le CSS ou rendez-le lisible

En bref : le Minifieur CSS retire les commentaires et les espaces inutiles pour rétrécir votre feuille de style et signale l’économie de taille exacte, tandis que le mode Embellir reconvertit le CSS minifié en code propre et indenté.

Chaque kilo-octet de CSS retarde la première peinture de votre page. Collez une feuille de style ci-dessous pour la compresser pour la production, ou passez un fichier minifié dans Embellir lorsque vous devez le relire et le modifier.

Comment utiliser le Minifieur CSS

  1. Collez ou saisissez votre CSS dans la boîte du haut.
  2. Cliquez sur Minifier le CSS pour le compresser, ou sur Embellir le CSS pour le formater avec indentation.
  3. Vérifiez le panneau des tailles - il affiche la taille d’origine, la taille du résultat et le pourcentage économisé.
  4. Copiez le résultat ou téléchargez-le dans un fichier .css.

Comment ça fonctionne

Le minifieur parcourt d’abord votre CSS caractère par caractère et supprime les commentaires - tout en laissant les chaînes entre guillemets complètement intactes, de sorte qu’un content valeur qui contient par hasard un texte ressemblant à un commentaire survit intacte. Elle réduit ensuite les suites d’espaces et retire les espaces autour des accolades, des points-virgules, des virgules et des combinateurs, plus l’espace après les deux-points. Elle ne touche délibérément jamais à l’intérieur de calc() expressions ou valeurs de chaînes, où les espaces portent un sens. Le mode Embellir inverse le processus : il rouvre le CSS compressé en une déclaration par ligne avec une indentation de deux espaces par niveau d’imbrication.

Exemple travaillé

Une règle de feuille de style typique écrite à la main, avec des commentaires et un espacement généreux - disons un bloc d’en-tête de 240 octets - se minifie généralement à environ 150 octets, soit une économie d’environ 35 à 40 %. Sur un site entier, cela s’additionne en un premier rendu visiblement plus rapide, surtout sur les connexions mobiles.

Questions fréquemment posées

Ce minifieur CSS est-il gratuit ?

Oui - entièrement gratuit, sans inscription, sans limite de taille et sans plafond quotidien.

Le CSS minifié est-il sûr à déployer ?

Le minifieur ne supprime que les commentaires et les espaces dont le CSS n’a pas besoin. Les sélecteurs, les propriétés et les valeurs sont inchangés, et les valeurs de chaînes et les expressions calc() ne sont jamais altérées. Comme avec tout minifieur, testez la page une fois après le déploiement.

Pourquoi garde-t-il une espace avant un deux-points dans les sélecteurs ?

Une espace avant deux points peut être significative en CSS - « .a :hover » sélectionne les descendants survolés, tandis que « .a:hover » sélectionne l’élément lui-même. Pour rester sûr, l’outil supprime l’espace après les deux points, mais ne devine jamais pour l’espace avant.

Peut-il embellir le CSS aussi ?

Oui. Le mode Embellir prend du CSS compressé et l’étend à une déclaration par ligne avec une indentation cohérente, ce qui est idéal lorsque vous héritez d’un fichier minifié et devez le modifier.

Mon CSS est-il téléversé vers un serveur ?

Non. La minification et l’embellissement se passent à 100 % dans votre navigateur. Vos feuilles de style ne quittent jamais votre appareil.
