Penukar Markdown ke HTML - HTML Bersih dari Markdown Anda

Singkatnya: Penukar Markdown ke HTML mengubah Markdown sehari-hari - heading, penekanan, pautan, imej, senarai, blockquote, kode, dan aturan horizontal - menjadi HTML bersih, meng-escape HTML mentah demi keselamatan, dan menunjukkan pratonton yang di-render langsung.

Penulis membuat draf dalam Markdown; web menerbitkan HTML. Penukar ini menjembatani keduanya untuk Markdown yang benar-benar ditulis orang setiap hari.

Pratonton yang di-render

Peribadi berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di pelayar Anda dengan JavaScript. Input Anda tidak pernah dimuat naik ke pelayan, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Cara menggunakan Penukar Markdown ke HTML

  1. Tampal atau tulis Markdown Anda.
  2. Klik Penukaran ke HTML.
  3. Semak pratonton yang ter-render sesuai dengan maksud Anda.
  4. Salin HTML ke laman web, CMS, atau alat emel Anda.

Cara kerja

Penukar menangani sintaks inti Markdown dengan jujur: heading ATX (# hingga ######), tebal dan miring, coret, kode sebaris dan blok kode berpagar, pautan dan imej, senarai berurutan dan tidak berurutan, blockquote dan aturan horizontal, dengan baris berurutan digabung menjadi paragraf seperti yang ditentukan Markdown. HTML mentah dalam sumber di-escape alih-alih dilewatkan, jadi kandungan yang ditampal tidak pernah dapat menyuntikkan markup ke output - rentang kode dilindungi terlebih dahulu, jadi contoh yang mengandung asterisk atau tag bertahan tanpa disentuh. Ekstensi eksotis (jadual, nota kaki, senarai tugas) di luar cakupannya dan output menyatakannya dengan cukup memperlakukannya sebagai paragraf.

Pertanyaan yang Sering Diajukan

Apakah penukar ini percuma?

Ya - sepenuhnya percuma, tanpa pendaftaran.

Ciri Markdown mana yang didukung?

Heading, tebal, miring, coret, kode sebaris dan berpagar, pautan, imej, senarai, blockquote, dan garis horizontal - inti sehari-hari.

Bagaimana dengan jadual dan nota kaki?

Itu adalah ekstensi rasa GitHub dan tidak ditukar oleh alat ini; mereka lewat sebagai paragraf polos.

Apakah HTML mentah dipertahankan?

Tidak - ia di-escape demi keselamatan, jadi output dapat ditampal ke halaman tanpa menyuntikkan markup.

Apakah ada yang dimuat naik?

Tidak. Penukaran berjalan di pelayar Anda.
