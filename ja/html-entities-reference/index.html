私たちについて

HTMLには2,200を超える名前付きエンティティがあります。この表は開発者が毎日手に取る実用セットです。構造的なエスケープ（& < > "）、タイポグラフィ（ダッシュ、引用符、省略記号）、通貨と数学の記号、矢印、チェックマーク、よくあるアクセント付き文字です。すべてのエンティティには、名前が存在しない場合でも機能する十進数値参照（©）と十六進数参照（©）もあります。ここの文字列と十進列が両方のフォールバックを提供します。完全な公式リストはWHATWG HTML標準にあります。エンティティがこの表にない場合、その数値参照が確実な方法です。

よくある質問

なぜ文字自体の代わりにエンティティを使うのですか？

構造的な五つ（& < > " '）については、エンティティはスタイルではなく正確さの問題です。エスケープしないとマークアップが壊れます。それ以外については、エンコーディングが不確かな場合の移植性の選択です。

エンティティがここに欠けている場合はどうなりますか？

任意のUnicode表から、その十進数値参照を使ってください：&#<code>; は常に動作します。
