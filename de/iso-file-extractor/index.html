ISO-Datei-Extraktor - ISO-Disc-Images online öffnen

Kurz gesagt: das ISO-Datei-Extraktor öffnet .iso-Disc-Images in Ihrem Browser – durchsuchen Sie die Ordner und Dateien, die auf der virtuellen CD oder DVD gespeichert sind, laden Sie einzelne Dateien herunter oder speichern Sie alles als ZIP. Kein Disc-Mounten, keine Installation, kein Upload.

Eine .iso-Datei ist eine vollständige Kopie einer CD oder DVD in einer einzigen Datei: Linux-Installer, alte Software-Discs und archivierte Spiele- oder Treiber-CDs leben alle als ISOs. Windows kann sie einbinden, aber nur als Administrator und nur zum Durchsuchen – eine einzelne Datei zu extrahieren, bleibt mühsam. Diese Seite liest das ISO9660-Dateisystem im Image mit einem WebAssembly-Port von libarchive, direkt in Ihrem Browser.

Ziehen Sie Ihre .iso-Datei hierher oder klicken Sie, um eine Datei von Ihrem Gerät zu wählen

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser. Das Disc-Image wird von einer WebAssembly-Engine auf Ihrem eigenen Gerät gelesen – niemals hochgeladen, niemals gespeichert, niemals von uns gesehen. Ein ehrliches Limit: Disc-Images sind von Natur aus groß und die Auflistung wird im Speicher Ihres Geräts gebaut, also ist ein volles Dual-Layer-DVD-Image (8 GB) nur auf einem Desktop mit viel RAM realistisch.

So verwenden Sie den ISO-Datei-Extraktor

  1. Ziehen Sie Ihre .iso-Datei auf das Feld oben, oder klicken Sie es an und wählen Sie die Datei von Ihrem Gerät.
  2. Warten Sie einen Moment, während das Image gelesen wird – beim ersten Einsatz lädt die Engine (etwa 1 MB) einmal und wird dann von Ihrem Browser zwischengespeichert.
  3. Durchsuchen Sie die auf der virtuellen Disc gespeicherten Dateien mit ihren Ordnern und Größen.
  4. Klicken Sie auf Herunterladen neben jeder einzelnen Datei, oder nutzen Sie „Alle als ZIP herunterladen“, um den Inhalt der Disc als eine Standard-ZIP-Datei zu speichern.

So funktioniert es

Ein ISO-Image speichert ein ISO9660-Dateisystem: Ein Volume-Descriptor nahe dem Anfang zeigt auf einen Verzeichnisbaum von Datensätzen, und jeder Datensatz zeigt auf die Disc-Sektoren mit den Daten einer Datei. Diese Seite liest diese Struktur mit libarchive, kompiliert zu WebAssembly – einschließlich der Joliet-Erweiterung, die von Windows erstellte Discs für lange Dateinamen mit gemischter Groß-/Kleinschreibung nutzen – und listet jede Datei mit Pfad und Größe auf. Dateien werden erst herauskopiert, wenn Sie sie herunterladen; „Alle als ZIP herunterladen“ packt sie mit JSZip neu.

Durchgerechnetes Beispiel

Sie bewahren eine alte Sprachkurs-CD als course.iso (640 MB) auf, lange nachdem Ihr Laptop sein Disc-Laufwerk verloren hat. Sie öffnen das Image hier, finden den Audio-Ordner und laden die zwölf Lektions-MP3s herunter, die Sie brauchen (180 MB) – kein Mounten, kein Brennen, kein externes Laufwerk.

Häufig gestellte Fragen

Kann dieses Tool bootfähige Installer-ISOs öffnen, wie einen Linux- oder Windows-Installer?

Ja, zum Durchsuchen und Extrahieren von Dateien – das Dateisystem darin ist dasselbe ISO9660-Format. Beachten Sie, dass das Extrahieren von Dateien Ihnen keinen bootfähigen USB-Stick gibt; zum Installieren eines Betriebssystems brauchen Sie weiterhin ein ordentliches Imaging-Tool wie Rufus oder Balena Etcher.

Warum sehen manche Dateinamen LAUT und kurz aus, wie SETUP.EXE;1?

Das ist der einfache ISO9660-Benennungsstil (Großbuchstaben, begrenzte Zeichen, ein ;1-Versions-Tag), den ältere Mastering-Software verwendet. Discs, die mit den Joliet- oder Rock-Ridge-Erweiterungen gemastert wurden, behalten ihre normalen langen Namen, und dieses Tool zeigt diese, wann immer sie vorhanden sind.

Kann es .img-, .bin- oder .dmg-Dateien öffnen?

Manche .img-Dateien sind rohe ISO-Images unter einem anderen Namen und öffnen sich, wenn ihr Inhalt wirklich ISO9660 ist. .dmg ist Apples eigenes komprimiertes Format und wird von dieser Engine nicht unterstützt – wenn eine Datei kein ISO-Image ist, sagt das Tool, dass sie nicht geöffnet werden konnte, statt zu raten.

Wird die ganze ISO in den Speicher geladen?

Die Datei wird von Ihrem Browser von Ihrem Gerät gelesen, und die Auflistung wird im Speicher gebaut. Alltägliche CD-große Images (bis etwa 1 GB) sind auf den meisten Desktops in Ordnung; sehr große DVD-Images können auf Telefonen oder Maschinen mit wenig Speicher langsam sein.

Werden meine Dateien irgendwohin hochgeladen?

Nein. Das Image wird von WebAssembly in Ihrem Browser-Tab geparst. Weder die ISO noch die Dateien darin verlassen je Ihr Gerät.
