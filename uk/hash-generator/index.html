Генератор хешів - SHA-1, SHA-256, SHA-384 і SHA-512

Коротко: генератор хешів обчислює дайджести SHA-1, SHA-256, SHA-384 і SHA-512 вашого тексту за допомогою вбудованої криптографії вашого браузера — того самого рушія Web Crypto, який використовує вебсайт вашого банку. SHA-1 позначено чесно: для контрольних сум, не для безпеки.

Треба перевірити, чи дві копії рядка однакові, створити відбиток для скидання кешу або виконати посібник, який просить дайджест SHA-256? Вставте текст — і всі чотири стандартні дайджести з’являться разом, готові до копіювання.

Примітка: SHA-1 включено лише для контрольних сум і застарілої сумісності — він є не безпечний для паролів або безпеки. Для безпеки використовуйте SHA-256 або сильніший, із належною схемою хешування паролів, як-от bcrypt або Argon2 для паролів.

Приватно за задумом: усе в цьому інструменті відбувається на 100% у вашому браузері за допомогою JavaScript. Ваші вхідні дані ніколи не передаються на сервер, ніколи не зберігаються й ніколи не бачаться нами: закрийте вкладку — і все зникло.

Як користуватися генератором хешів

  1. Введіть або вставте текст для хешування.
  2. Натисніть «Згенерувати хеші».
  3. Скопіюйте потрібний вам дайджест із результатів.

Як це працює

Криптографічний хеш перетворює будь-які вхідні дані на відбиток фіксованої довжини. Ті самі вхідні дані завжди дають той самий відбиток; зміна навіть одного символа змінює його повністю; а вхідні дані не можна відновити з відбитка. Цей інструмент подає байти вашого тексту в UTF-8 до Web Crypto API (crypto.subtle.digest) — нативної, перевіреної криптографії браузера, а не повторної реалізації на JavaScript. SHA-256 дає 64 шістнадцяткові символи, SHA-512 дає 128, а SHA-1 дає 40. Стійкість SHA-1 до колізій зламано, саме тому він пропонується лише для контрольних сум і застарілих систем, які досі його запитують.

Розібраний приклад

Хешування слова "abc" за допомогою SHA-256 завжди дає ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad — опублікований тестовий вектор, який інженери в усьому світі використовують, щоб перевірити, чи реалізація хешу правильна. Спробуйте тут і порівняйте.

Часті запитання

Чи цей генератор хешів безкоштовний?

Так — безкоштовно, без реєстрації, без обмежень.

Чи хешування — те саме, що шифрування?

Ні. Хеш односторонній: він створює відбиток, який можна порівняти, але розшифрувати його назад у початковий текст не можна.

Чому SHA-1 позначено "не для безпеки"?

Дослідники створили справжні колізії SHA-1, тож він не повинен захищати паролі, підписи чи сертифікати. Він усе ще годиться як швидка контрольна сума файлу там, де атаки не викликають занепокоєння.

Чи варто хешувати паролі за допомогою SHA-256?

Не прямо. Паролям потрібні повільні функції хешування паролів із сіллю, як-от bcrypt, scrypt або Argon2: швидкі хеші, як-от SHA-256, дають зловмисникам змогу вгадувати мільярди паролів на секунду.

Чи завантажується мій текст для хешування?

Ні. Хешування виконується у вашому браузері через Web Crypto; ваш текст ніколи не покидає ваш пристрій.
