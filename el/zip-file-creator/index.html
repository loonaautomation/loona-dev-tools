Δημιουργός Αρχείων ZIP - Φτιάξτε ένα ZIP από Πολλά Αρχεία

Εν συντομία: ο Δημιουργός Αρχείων ZIP συνδυάζει οποιοδήποτε σύνολο αρχείων σε μια μοναδική τυπική αρχειοθήκη .zip, χτισμένη εξ ολοκλήρου στο πρόγραμμα περιήγησής σας με JSZip - προσθέστε αρχεία, προαιρετικά ομαδοποιήστε τα σε έναν φάκελο, επιλέξτε ένα επίπεδο συμπίεσης και κατεβάστε.

Η αποστολή δέκα συνημμένων ένα προς ένα, η παράδοση ενός φακέλου έργου, ή η αρχειοθέτηση μιας παρτίδας φωτογραφιών - ένα ZIP μετατρέπει έναν σωρό αρχείων σε μία τακτοποιημένη λήψη. Οι περισσότεροι διαδικτυακοί συμπιεστές ZIP ανεβάζουν πρώτα τα αρχεία σας σε έναν διακομιστή. Αυτός δεν το κάνει: η αρχειοθήκη συναρμολογείται στη δική σας συσκευή, οπότε ακόμη και ιδιωτικά αρχεία δεν ταξιδεύουν ποτέ πουθενά.

Αποθέστε αρχεία εδώ ή κάντε κλικ για να επιλέξετε αρχεία από τη συσκευή σας
Όνομα αρχείουΜέγεθος

Σημείωση συμπίεσης: τα αρχεία κειμένου, κώδικα και CSV συρρικνώνονται πολύ με DEFLATE. Οι φωτογραφίες, τα βίντεο και τα PDF είναι ήδη συμπιεσμένα, οπότε το ZIP θα είναι περίπου το ίδιο μέγεθος έτσι κι αλλιώς - επιλέξτε Αποθηκευμένο για αυτά ώστε να ολοκληρωθεί αμέσως.

Ιδιωτικό εκ σχεδιασμού: τα πάντα σε αυτό το εργαλείο συμβαίνουν 100% στο πρόγραμμα περιήγησής σας με JavaScript. Τα αρχεία σας δεν ανεβαίνουν ποτέ σε διακομιστή, δεν αποθηκεύονται ποτέ και δεν φαίνονται ποτέ από εμάς - κλείστε την καρτέλα και τα πάντα χάνονται. Ένα ειλικρινές όριο: το ZIP χτίζεται στη μνήμη της συσκευής σας, οπότε πολύ μεγάλα σύνολα αρχείων (εκατοντάδες megabytes) μπορεί να είναι αργά ή να αποτύχουν σε ένα τηλέφωνο με χαμηλή μνήμη.

Πώς να χρησιμοποιήσετε τον Δημιουργό Αρχείων ZIP

  1. Αποθέστε τα αρχεία σας στο πλαίσιο παραπάνω ή κάντε κλικ σε αυτό και επιλέξτε αρχεία από τη συσκευή σας. Μπορείτε να προσθέσετε αρχεία σε αρκετούς γύρους.
  2. Ελέγξτε τη λίστα - αφαιρέστε οτιδήποτε προσθέσατε κατά λάθος και παρακολουθήστε το συνολικό μέγεθος.
  3. Προαιρετικά πληκτρολογήστε ένα όνομα φακέλου αν θέλετε κάθε αρχείο να κάθεται μέσα σε έναν φάκελο στην αρχειοθήκη, και δώστε στο ZIP ένα όνομα.
  4. Επιλέξτε ένα επίπεδο συμπίεσης (Το Συμπιεσμένο είναι σωστό για τις περισσότερες δουλειές) και κάντε κλικ στο Δημιουργία ZIP & Λήψη.

Πώς λειτουργεί

Μια αρχειοθήκη ZIP αποθηκεύει τα δεδομένα κάθε αρχείου συν έναν κεντρικό κατάλογο στο τέλος που παραθέτει κάθε καταχώριση, το όνομά της και τα μεγέθη της - γι' αυτό οποιοδήποτε εργαλείο unzip σε οποιοδήποτε σύστημα μπορεί να την ανοίξει. Αυτή η σελίδα χρησιμοποιεί τη βιβλιοθήκη JSZip στο πρόγραμμα περιήγησής σας: διαβάζει τα αρχεία που επιλέξατε στη μνήμη, προαιρετικά συμπιέζει το καθένα με τον αλγόριθμο DEFLATE (τον ίδιο που χρησιμοποιούν τα κλασικά εργαλεία ZIP), γράφει τον κατάλογο και σας παραδίδει την ολοκληρωμένη αρχειοθήκη ως μία λήψη. Τα αρχεία με το ίδιο όνομα διατηρούνται και αριθμούνται αυτόματα - το δεύτερο report.pdf γίνεται report (1).pdf - ώστε τίποτα να μην αντικαθίσταται σιωπηρά.

Παράδειγμα με επεξεργασία

Προσθέτετε τρία αρχεία: report.pdf (240 KB), photo.jpg (1.2 MB) και notes.txt (2 KB), με το όνομα φακέλου ορισμένο σε "handover". Το εργαλείο παράγει handover.zip - ή όποιο όνομα επιλέξατε - περιέχοντας έναν φάκελο handover με και τα τρία αρχεία μέσα. Η λήψη είναι περίπου 1.4 MB, επειδή τα PDF και JPG ήταν ήδη συμπιεσμένα· αν τα αρχεία ήταν απλό κείμενο και εξαγωγές CSV, η ίδια αρχειοθήκη θα μπορούσε εύκολα να είναι το ένα τρίτο του αρχικού μεγέθους.

Συχνές Ερωτήσεις

Είναι αυτός ο δημιουργός αρχείων ZIP δωρεάν;

Ναι - δωρεάν, χωρίς εγγραφή, χωρίς όρια και χωρίς υδατογραφήματα.

Ανεβαίνουν τα αρχεία μου σε διακομιστή;

Όχι. Το ZIP χτίζεται από JavaScript (JSZip) που τρέχει στο πρόγραμμα περιήγησής σας. Τα αρχεία σας δεν φεύγουν ποτέ από τη συσκευή σας, γεγονός που το καθιστά ασφαλές και για ιδιωτικά έγγραφα.

Γιατί το ZIP μου είναι σχεδόν το ίδιο μέγεθος με τα αρχικά αρχεία;

Μορφές όπως JPG, PNG, MP4, MP3 και PDF είναι ήδη συμπιεσμένες, οπότε η συμπίεση ZIP δεν μπορεί να τις συρρικνώσει πολύ περισσότερο. Τα αρχεία βασισμένα σε κείμενο - TXT, CSV, HTML, JSON, πηγαίος κώδικας και αρχεία καταγραφής - συνήθως συρρικνώνονται πολύ.

Υπάρχει όριο μεγέθους αρχείου;

Δεν υπάρχει όριο ενσωματωμένο στο εργαλείο, αλλά η αρχειοθήκη συναρμολογείται στη μνήμη του προγράμματος περιήγησής σας. Μερικές εκατοντάδες megabytes είναι εντάξει στους περισσότερους επιτραπέζιους· πολύ μεγάλα σετ μπορεί να είναι αργά ή να ξεμείνουν από μνήμη σε ένα τηλέφωνο χαμηλού επιπέδου. Αν δυσκολεύεται, χωρίστε τα αρχεία σε μικρότερα ZIP.

Μπορώ να προστατεύσω το ZIP με κωδικό πρόσβασης ή να προσθέσω αρχεία σε ένα υπάρχον;

Όχι με αυτό το εργαλείο. Δημιουργεί ένα φρέσκο, τυπικό ZIP χωρίς κρυπτογράφηση. Όποιος πάρει το αρχείο μπορεί να το ανοίξει, οπότε μην βασίζεστε σε ένα ZIP μόνο του για να προστατεύσετε μυστικά.
