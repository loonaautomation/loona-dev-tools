JWT

CSS

CSS মিনিফায়ার & বিউটিফায়ার

JS

JavaScript মিনিফায়ার

রক্ষণশীলভাবে JavaScript মিনিফাই করুন - মন্তব্য ও মৃত হোয়াইটস্পেস সরানো, স্ট্রিং ও রেজেক্স অক্ষত রাখা।

ডিফ চেকার

লাইন অনুযায়ী দুটি টেক্সট তুলনা করুন - যোগ করা ও সরানো লাইন হাইলাইট করা, একটি পরিবর্তনের সারসংক্ষেপসহ।

JSON

CSV থেকে JSON কনভার্টার

CSV অবজেক্টের একটি JSON অ্যারেতে রূপান্তর করুন - একটি আসল পার্সার যা উদ্ধৃত কমা ও এস্কেপ করা উদ্ধৃতি পরিচালনা করে।

YAML

YAML ⇄ JSON কনভার্টার

সাধারণ YAML উপসেট (ম্যাপ, তালিকা, স্কেলার) JSON-এ এবং JSON আবার YAML-এ রূপান্তর করুন - সৎভাবে সীমাবদ্ধ।

SQL

SQL ফরম্যাটার

বড় হাতের কীওয়ার্ডসহ SQL ফরম্যাট করুন এবং প্রতিটি প্রধান ধারা নিজস্ব লাইনে - এক ক্লিকে পাঠযোগ্য কুয়েরি।

URL

URL পার্সার & বিল্ডার

একটি URL-কে প্রোটোকল, হোস্ট, পোর্ট, পথ, কুয়েরি প্যারামিটার ও হ্যাশে ভাগ করুন - তারপর প্যারামিটারগুলো সম্পাদনা করুন ও আবার তৈরি করুন।

ZIP

ZIP ফাইল নির্মাতা

একাধিক ফাইলকে একটি একক ZIP আর্কাইভে গুছান - আপনার ব্রাউজারে তৈরি, কিছু আপলোড নয়।

UNZIP

Unzip ফাইল এক্সট্র্যাক্টর

একটি ZIP খুলুন, আকারসহ ভিতরের প্রতিটি ফাইল দেখুন, এবং একটি ফাইল বা সব এক্সট্র্যাক্ট করুন।

RAR

RAR ফাইল এক্সট্র্যাক্টর

আপনার ব্রাউজারে RAR ফাইল (RAR4 ও RAR5) খুলুন - ভিতরের প্রতিটি ফাইল দেখুন, একটি ফাইল বা সব একটি ZIP হিসেবে ডাউনলোড করুন।

7Z

7Z ফাইল এক্সট্র্যাক্টর

আপনার ব্রাউজারে 7z আর্কাইভ খুলুন - বিষয়বস্তু দেখুন ও একক ফাইল বা সব একটি ZIP হিসেবে এক্সট্র্যাক্ট করুন।

TAR

TAR ফাইল এক্সট্র্যাক্টর

আপনার ব্রাউজারে .tar, .tar.bz2 ও .tar.xz আর্কাইভ খুলুন ও ভিতরের ফাইল এক্সট্র্যাক্ট করুন - কিছুই আপলোড হয় না।

TGZ

TAR.GZ ফাইল এক্সট্র্যাক্টর

আপনার ব্রাউজারে .tar.gz ও .tgz আর্কাইভ খুলুন - ভিতরের ফাইল ব্রাউজ করুন ও যা দরকার এক্সট্র্যাক্ট করুন।

GZ

GZ ফাইল এক্সট্র্যাক্টর

আপনার ব্রাউজারে একটি একক .gz ফাইল ডিকম্প্রেস করুন এবং মূলটি ডাউনলোড করুন - লগ, ডেটা এক্সপোর্ট ও ডাটাবেস ডাম্প।

ISO

ISO ফাইল এক্সট্র্যাক্টর

আপনার ব্রাউজারে ISO ডিস্ক ছবি খুলুন, ভার্চুয়াল ডিস্কে সংরক্ষিত ফাইল সিস্টেম ব্রাউজ করুন ও ফাইল ডাউনলোড করুন।

ARC

আর্কাইভ ফাইল এক্সট্র্যাক্টর

ZIP, RAR, 7Z, TAR, ISO ও আরও অনেক কিছুর জন্য একটি সার্বজনীন আর্কাইভ খুলনেওয়ালা - ফরম্যাট স্বয়ংক্রিয়ভাবে শনাক্ত করা হয়।

R→ZIP

RAR থেকে ZIP রূপান্তরকারী

আপনার ব্রাউজারে একটি RAR আর্কাইভ একটি মানক ZIP-এ রূপান্তর করুন - ফোল্ডার কাঠামো সংরক্ষিত, কিছু আপলোড নয়।

7→ZIP

7Z থেকে ZIP কনভার্টার

একটি 7Z আর্কাইভ একটি ZIP-এ রূপান্তর করুন যা যেকোনো জায়গায় খোলে - 7-Zip দরকার নেই, কিছু আপলোড নয়।

T→ZIP

TAR থেকে ZIP রূপান্তরকারী

Linux বা Unix থেকে একটি TAR আর্কাইভ একটি ZIP-এ রূপান্তর করুন যা Windows, macOS ও ফোনে নিজে নিজে খোলে।

G→ZIP

TAR.GZ থেকে ZIP রূপান্তরকারী

.tar.gz বা .tgz একটি ZIP-এ রূপান্তর করুন - gzip ও tar উভয় স্তর আপনার ডিভাইসে খোলা হয়।

Z→TGZ

ZIP থেকে TAR.GZ কনভার্টার

একটি ZIP আর্কাইভ একটি .tar.gz tarball-এ রূপান্তর করুন - যে ফরম্যাট Linux সার্ভার, Docker ও বিল্ড টুল প্রত্যাশা করে।

+TAR

TAR ফাইল নির্মাতা

আপনার ব্রাউজারে একাধিক ফাইল থেকে একটি spec-সঠিক .tar আর্কাইভ তৈরি করুন - যেকোনো tar টুল দিয়ে খোলে।

GZIP

GZIP কম্প্রেসর

আপনার ব্রাউজারের অন্তর্নির্মিত gzip ইঞ্জিন দিয়ে যেকোনো একক ফাইলকে একটি .gz-তে সংকুচিত করুন - তাৎক্ষণিক আগের/পরের আকার।
