差异检查器 - 逐行对比两段文本

简而言之： 差异检查器使用最长公共子序列差异算法逐行比较文本的两个版本，以绿色突出显示新增的行、红色突出显示删除的行，并汇总新增、删除和未更改的行数。

某个配置文件变了、出了问题，或者一份文档的两个版本不一致——把两个版本都粘贴到这里，几秒钟内就能准确看到哪些行发生了变化，而且两个版本都不需要上传到任何地方。

如何使用差异检查器

  1. 把原始文本粘贴到左侧框中。
  2. 把修订后的文本粘贴到右侧框中。
  3. 点击“对比”。
  4. 阅读结果：标有 - 的行被删除，标有 + 的行被添加，未标记的行未更改。

它如何工作

检查器把两个文本都拆分成行，并计算两个行列表的最长公共子序列（LCS）——在两者中以相同顺序出现的最大行集。子序列中的行未更改；原文中但不在子序列中的行被删除，只在修订版中的行被添加。这是 Unix diff 等工具背后的同一算法家族，所以即使整个块移动了一两行，比较也会按您预期的方式对齐。

实例

对比一个三行购物清单的两个版本，其中 "eggs" 变成了 "egg whites"，会显示一行红色和一行绿色，另外两行未变——摘要是 1 行新增、1 行删除、2 行未变，而不是一整墙几乎相同的文本让人肉眼去找。

常见问题

这个差异检查器免费吗？

是的——完全免费，无需注册，没有每日上限。

对比是基于行还是基于字符？

基于行，像 Unix diff 一样：一行要么未变、被删除或被添加。如果一个长行内部有一个词改变，整行显示为一次删除加一次添加。

它能对比多大的文本？

每侧最多 1,500 行。LCS 表随两个行数的乘积增长，所以非常大的文件最好用桌面差异工具比较。

它会忽略空白或大小写吗？

不会——行必须完全匹配才算未更改，所以一行只是多了尾随空格也会显示为已更改。这种严格是有意的：在比较配置和代码时，这通常正是您想要的。

我的文本会被上传到服务器吗？

不会。对比 100% 在您的浏览器中进行。两段文本都从不离开您的设备。
