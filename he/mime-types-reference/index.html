אודות

סוג MIME (סוג מדיה) הוא הדרך שבה שרת אומר לדפדפן מהו קובץ באמת — כותרת ה-Content-Type הנגזרת מהטבלה הזו היא מה שמונע מ-.png להיות מוגש כטקסט או מהורדה להיות מורחת כ-HTML (וקטור XSS, ולכן קיים X-Content-Type-Options: nosniff). הטבלה מכסה את הפורמטים של עבודת האינטרנט היומיומית. שתי רשומות גורמות לבאגים חוזרים שכדאי לזכור: JavaScript הוא text/javascript (ה-application/javascript הישן הוצא משימוש), ו-.svg הוא image/svg+xml — בהגשה שגויה, אייקוני SVG נכשלים בשקט.

שאלות נפוצות

מדוע הקובץ שלי מוריד במקום להציג?

השרת שלח application/octet-stream או סוג שגוי, או Content-Disposition: attachment. בדקו את כותרות התגובה מול הטבלה הזו.

האם הסיומת או הכותרת היא הסמכותית?

הכותרת — דפדפנים פועלים על Content-Type (עם רחרוח כנפילה לאחור המסוכנת ש-nosniff מבטלת). סיומות משנות רק לשרת הבוחר את הכותרת.
