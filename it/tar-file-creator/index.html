Creatore di file TAR - Crea un archivio .tar dai tuoi file

In breve: il Creatore di file TAR raggruppa qualsiasi insieme di file in un singolo archivio .tar standard usando uno scrittore ustar corretto per specifica nel tuo browser - aggiungi file, opzionalmente raggruppali in una cartella, e scarica.

TAR è ancora la lingua franca di Linux, server e backup - ma gli utenti Windows che devono produrre un tarball di solito devono prima installare qualcosa. Questa pagina scrive genuini archivi TAR nel tuo browser: intestazioni ustar corrette, checksum e timestamp, costruiti sul tuo dispositivo con nulla caricato.

Ricorda: TAR non comprime. Il .tar sarà circa la dimensione di tutti i file sommati (arrotondata ai blocchi da 512-byte). Ti serve più piccolo? Fai passare il risultato attraverso il Compressore GZIP dopo, o usa invece il Creatore di file ZIP.

Privato per design: tutto in questo strumento accade al 100% nel tuo browser con JavaScript. I tuoi file non vengono mai caricati su un server, mai memorizzati e mai visti da noi - chiudi la scheda e tutto è andato. Un limite onesto: la conversione avviene nella memoria del tuo dispositivo, quindi archivi molto grandi (centinaia di megabyte) possono essere lenti o fallire su un telefono con poca memoria.

Come usare il Creatore di file TAR

  1. Trascina i tuoi file sulla casella sopra, o fai clic e sceglili dal tuo dispositivo. Puoi aggiungere file in più riprese.
  2. Controlla l'elenco - rimuovi qualsiasi cosa aggiunta per errore, e osserva la dimensione totale.
  3. Opzionalmente digita un nome cartella così ogni file sta dentro una cartella nell'archivio, e dai un nome al TAR.
  4. Fai clic su Crea TAR e scarica. Il .tar si apre con tar su Linux/macOS, e con 7-Zip o WinRAR su Windows.

Come funziona

Un archivio TAR è un flusso di record: per ogni file, un blocco intestazione ustar di 512-byte (nome file, dimensione in ottale, ora di modifica, un checksum dell'intestazione stessa, il magic 'ustar', e un campo prefisso che permette percorsi più lunghi di 100 caratteri - con voci GNU longname per percorsi ancora oltre), seguito dal contenuto del file riempito fino a un numero intero di blocchi da 512-byte. Due blocchi zero chiudono l'archivio. Questa pagina implementa quel formato direttamente - nessuna libreria, nessun server - e lo scrittore è stato verificato facendo rileggere il suo output byte per byte dal modulo tarfile di Python. TAR memorizza i file non compressi, quindi l'archivio è la somma delle sue parti; la compressione è un passo separato (che è ciò che aggiunge .tar.gz).

Esempio pratico

Aggiungi tre file: deploy.sh (1 KB), config.yml (3 KB) e logo.png (48 KB), con il nome cartella impostato su 'release'. Lo strumento produce release.tar - o il tuo nome scelto - contenente una cartella release con tutti e tre i file, ciascuno mantenendo la sua reale ora di modifica. A 52 KB di contenuto il TAR esce a circa 54 KB: i file stessi, tre intestazioni e padding, senza compressione - esattamente ciò che tar produrrebbe su Linux.

Domande frequenti

Questo creatore di file TAR è gratuito?

Sì - gratuito, nessuna registrazione, nessun limite e nessuna filigrana.

I miei file vengono caricati su un server?

No. Il TAR viene scritto da JavaScript in esecuzione nel tuo browser, sul tuo dispositivo. I tuoi file non lo lasciano mai.

Perché il TAR ha la stessa dimensione dei miei file - o un po' più grande?

TAR non comprime nulla; raggruppa solo. Ogni file aggiunge anche un'intestazione da 512-byte ed è riempito a un confine da 512-byte, quindi l'archivio è leggermente più grande del totale grezzo. Per un tarball compresso, crea il TAR qui e poi fallo passare attraverso il Compressore GZIP - è letteralmente come si fa .tar.gz.

Linux e GNU tar accetteranno gli archivi creati qui?

Sì. Lo scrittore segue la specifica ustar - campi ottali e checksum intestazione corretti, la magia ustar, suddivisione prefisso per percorsi lunghi e voci GNU longname per quelli molto lunghi - e il suo output è stato verificato leggendolo di ritorno con il modulo tarfile di Python durante i test.

Posso aggiungere file a un TAR esistente o creare un .tar.gz direttamente?

Non in questo strumento - crea un archivio fresco ogni volta. Per trasformare uno ZIP esistente in un .tar.gz in un passo, usa il Convertitore da ZIP a TAR.GZ; per comprimere questo TAR in un .tar.gz, usa dopo il Compressore GZIP e rinomina il risultato in .tar.gz.
