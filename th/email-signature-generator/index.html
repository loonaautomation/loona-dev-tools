ตัวสร้างลายเซ็นอีเมล HTML - ลายเซ็นปิดท้ายระดับมืออาชีพที่รอดในไคลเอนต์อีเมล

สรุปสั้น ๆ: ตัวสร้างลายเซ็นอีเมล HTML สร้างลายเซ็นของคุณเป็น HTML ตารางที่ปลอดภัยสำหรับอีเมล - เทคนิคเลย์เอาต์เดียวที่ Gmail, Outlook และ Apple Mail ล้วนเรนเดอร์ได้อย่างเชื่อถือได้ - พร้อมสีเน้นของคุณ ลิงก์ติดต่อ และสโลแกนเพิ่มเติม

ไคลเอนต์อีเมลตัด CSS สมัยใหม่ออก ซึ่งเป็นเหตุผลว่าทำไมลายเซ็นที่สร้างด้วย div จึงพังใน Outlook อันนี้สร้างด้วยวิธีเก่าที่ถูกต้อง: ตารางและสไตล์แบบอินไลน์เท่านั้น

ตัวอย่าง

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวสร้างลายเซ็นอีเมล HTML

  1. กรอกชื่อ ตำแหน่ง และบริษัทของคุณ
  2. เพิ่มโทรศัพท์ อีเมล และเว็บไซต์ - พวกมันจะกลายเป็นลิงก์ที่แตะได้
  3. เลือกสีเน้นและสโลแกนเพิ่มเติม
  4. ตรวจสอบตัวอย่าง จากนั้นคัดลอก HTML (หรือคัดลอกตัวอย่างที่เรนเดอร์แล้วตรงเข้าสู่ตัวแก้ไขลายเซ็นของ Gmail)

วิธีการทำงาน

HTML ของอีเมลคือแคปซูลเวลา: กลไก Word ของ Outlook เพิกเฉย flexbox กริด และ CSS สมัยใหม่ส่วนใหญ่ ดังนั้นลายเซ็นระดับมืออาชีพจึงยังสร้างด้วยตารางที่ซ้อนกันและสไตล์แบบอินไลน์ - ตรงกันกับสิ่งที่ตัวสร้างนี้แสดงออกมา รายละเอียดการติดต่อกลายเป็นลิงก์ tel:, mailto: และเว็บจริง แถบเน้นและชื่อใช้สีของคุณ และค่าข้อความทุกค่าถูก escape เพื่อให้ชื่อที่มีเครื่องหมายแอมเพอร์แซนด์ไม่สามารถทำลายมาร์กอัปได้ ไม่มีการใช้รูปภาพ ดังนั้นลายเซ็นจึงแสดงทันทีและไม่เคยกระตุ้นคำเตือน 'ดาวน์โหลดรูปภาพ'

คำถามที่พบบ่อย

ตัวสร้างนี้ฟรีหรือไม่?

ใช่ - ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก

ฉันเพิ่มมันใน Gmail ได้อย่างไร?

คัดลอกตัวอย่างที่เรนเดอร์แล้ว (ไม่ใช่โค้ด) จากนั้นใน Gmail ไปที่ การตั้งค่า → ดูการตั้งค่าทั้งหมด → ลายเซ็น สร้างลายเซ็นแล้ววางลงไป รูปแบบจะถูกส่งต่อไปด้วย

ทำไมจึงใช้ตารางแทน div?

Outlook บนเดสก์ท็อปเรนเดอร์จดหมายด้วยกลไกของ Microsoft Word ซึ่งรองรับเฉพาะตารางและสไตล์แบบอินไลน์อย่างเชื่อถือได้

ฉันเพิ่มรูปโลโก้ได้หรือไม่?

ตัวสร้างนี้เป็นข้อความเท่านั้นโดยการออกแบบ - ลายเซ็นที่ไม่มีรูปภาพโหลดทันทีและไม่เคยถูกบล็อก โลโก้ที่โฮสต์ไว้สามารถเพิ่มลงใน HTML ด้วยมือได้หากคุณต้องการ

มีอะไรถูกอัปโหลดหรือไม่?

ไม่ รายละเอียดของคุณไม่เคยออกจากเบราว์เซอร์ของคุณ
