如何使用 CSS 压缩工具

  1. 把您的 CSS 粘贴或输入到上方框中。
  2. 点击“压缩 CSS”来压缩它，或点击“美化 CSS”用缩进格式化它。

  4. 复制结果，或把它下载为 .css 文件。

它如何工作

压缩工具首先逐个字符遍历您的 CSS 并删除注释——同时让带引号的字符串完全不受影响，所以 content 恰好包含类似注释文本的值完整无损地保留下来。然后它折叠空白序列，并删除大括号、分号、逗号和组合器周围的空格，以及冒号后的空格。它特意从不触碰以下内容的内部 calc() 表达式或字符串值，其中空格承载着意义。美化模式会逆转这个过程：它将压缩的 CSS 重新展开为每行一条声明，每个嵌套级别以两个空格缩进。

实例

一条带注释和宽松间距的手写样式表规则——比如一个 240 字节的标头块——通常会压缩到约 150 字节，节省约 35-40%。在整个网站范围内，这累积起来会带来明显更快的首次渲染，尤其是在移动网络连接下。

常见问题

这个 CSS 压缩工具免费吗？

是的——完全免费，无需注册，没有大小限制，也没有每日上限。

压缩后的 CSS 部署起来安全吗？

压缩工具只删除 CSS 不需要的注释和空白。选择器、属性和值不变，字符串值和 calc() 表达式从不改变。与任何压缩工具一样，部署后测试一次页面。

为什么它在选择器中的冒号前保留空格？

冒号前的空格在 CSS 中可能有意义——".a :hover" 选择被悬停的后代元素，而 ".a:hover" 选择元素本身。为安全起见，本工具会移除冒号后的空格，但从不猜测冒号前的空格。

它也能美化 CSS 吗？

是的。美化模式会将压缩的 CSS 展开为每行一条声明，并保持一致的缩进，这非常适合在您接手压缩文件并需要编辑它时使用。

我的 CSS 会被上传到服务器吗？

不会。压缩和美化 100% 在您的浏览器中进行。您的样式表从不离开您的设备。
