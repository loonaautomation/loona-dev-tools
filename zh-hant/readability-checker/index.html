SEO 可讀性檢查器 - 網路文案的六項評分

簡而言之： SEO 可讀性檢查器使用六種既定公式對貼上的網頁文案進行評分——Flesch 易讀度、Flesch-Kincaid、Gunning Fog、Coleman-Liau、SMOG 和 ARI——外加真正驅動它們的句子統計資料，以搜尋內容而不是學校作業為框架。

範圍說明：Text Tools 有一個閱讀水平計算器，涵蓋一般寫作的 Flesch 易讀度和年級水平。本檢查器是 SEO 內容版本——六個公式、句子長度診斷和網路受眾目標——這正是它與網站管理員工具住在一起的原因。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 SEO 可讀性檢查器

  1. 貼上您的頁面文案或文章草稿（幾段的評分最可靠）。
  2. 點選“可讀性評分”。
  3. 對比六個分數——它們應該大體一致；某個明顯的異常值指向非常長的單詞或句子。
  4. 先修復最長的句子；那會同時推動每個分數。

它如何工作

每個公式對相同的原始材料賦予不同的權重：Flesch 分數使用句子長度和每詞音節數；Gunning Fog 計算三個或更多音節的詞（‘複雜詞’）；Coleman-Liau 使用字母而不是音節，所以它最難作弊；SMOG 是為醫療文字設計的；ARI 使用每詞字元數。音節用標準的母音組啟發法計數。短樣本波動劇烈，所以請對完整的章節評分，而不是單個句子。

常見問題

這個檢查器免費嗎？

是的——完全免費，無需註冊。

這與 Text Tools 的閱讀水平計算器有什麼不同？

那個工具涵蓋一般寫作的兩種評分。這個是為 SEO 內容工作構建的：六個公式加上句子長度診斷和網路受眾目標，位於網站管理員套件中。

網路文案應該以什麼分數為目標？

Flesch 易讀度在 60-70 左右（通俗英語）適合大多數讀者。技術和法律內容得分較低是合理的。

可讀性分數會直接影響排名嗎？

Google 說可讀性不是直接的排名因素——但可讀的文案能讓訪問者繼續讀下去，這正是釋出它的意義。

我的文字會被上傳嗎？

不會。評分 100% 在您的瀏覽器中執行。
