Convertidor de Base64 a imagen

En resumen: pega Base64 (o una URI de datos completa) y ve la imagen que codifica: luego descárgala como archivo con el tipo correcto.
🔒 Privado por diseño: todo se ejecuta en tu navegador en este dispositivo. Tu entrada nunca se sube a un servidor.

Acerca de

Las cadenas de imagen Base64 salen a raudales de API, archivos CSS, correos y llamadas canvas.toDataURL(); esta página las convierte de nuevo en imágenes. Acepta una carga Base64 simple o una URI de datos completa, detecta el formato real desde los bytes mágicos (89 50 4E 47 de PNG, FF D8 de JPEG, GIF8 de GIF, RIFF/WEBP de WebP) en lugar de confiar en lo que afirme el prefijo, renderiza la imagen y habilita una descarga con el tipo detectado. Si los bytes se decodifican pero no se renderizan, nunca fueron una imagen: el Base64 de un texto se decodifica «con éxito» a bytes de texto, y la línea de estado te lo dice en lugar de mostrar un icono de imagen rota.

Preguntas frecuentes

¿Necesito el prefijo data:image/...?

No: el Base64 desnudo funciona; el tipo se detecta desde los propios bytes.

¿Por qué mi SVG no se renderiza?

SVG es texto XML, no bytes binarios de imagen; un Base64 de SVG se decodifica a marcado. Decodifícalo con el decodificador de Base64 a texto y guárdalo como .svg.
