ตัวแปลง TAR.GZ เป็น ZIP - เปลี่ยน .tar.gz และ .tgz ให้เป็น .zip

สรุปสั้น ๆ: ตัวแปลง TAR.GZ เป็น ZIP แกะทั้งสองชั้นของไฟล์บีบอัด .tar.gz (หรือ .tgz) บนอุปกรณ์ของคุณ - gzip ก่อน จากนั้น tar - และแพ็กไฟล์ใหม่เป็น .zip มาตรฐานเดียว

.tar.gz คือสองรูปแบบในเสื้อตัวเดียว: ไฟล์ที่รวมมัดด้วย tar จากนั้นบีบอัดด้วย gzip Linux สร้างมันทุกที่ - รุ่นเผยแพร่ซอร์สโค้ด ข้อมูลสำรอง ล็อก - แต่ Windows และโทรศัพท์เปิดมันโดยตรงไม่ได้ ตัวแปลงนี้แกะทั้งสองชั้นภายในเบราว์เซอร์ของคุณและส่งมอบ ZIP ธรรมดาหนึ่งไฟล์ให้คุณ

วางไฟล์ .tar.gz / .tgz ของคุณที่นี่ หรือคลิกเพื่อเลือกมันจากอุปกรณ์ของคุณ

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ไฟล์ของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป ขีดจำกัดที่ซื่อตรงหนึ่งข้อ: การแปลงเกิดขึ้นในหน่วยความจำของอุปกรณ์ของคุณ ดังนั้นไฟล์บีบอัดที่ใหญ่มาก (หลายร้อยเมกะไบต์) อาจช้าหรือล้มเหลวบนโทรศัพท์ที่มีหน่วยความจำน้อย

วิธีใช้ ตัวแปลง TAR.GZ เป็น ZIP

  1. วางไฟล์ .tar.gz หรือ .tgz ของคุณลงบนกล่องด้านบน หรือคลิกมันแล้วเลือกไฟล์จากอุปกรณ์ของคุณ
  2. คลิกแปลงเป็น ZIP ทั้งชั้น gzip และ tar จะถูกแกะบนอุปกรณ์ของคุณ และไฟล์จะถูกบรรจุใหม่เป็น ZIP
  3. ตรวจสอบบทสรุป: จำนวนไฟล์ที่พบและขนาดของ ZIP ใหม่
  4. คลิกดาวน์โหลดเพื่อบันทึกไฟล์ .zip - มันเปิดด้วยเครื่องมือในตัวของระบบใดก็ได้

วิธีการทำงาน

ภายใต้ฝากระโปรง หน้านี้ส่งไฟล์ของคุณไปยังรุ่น WebAssembly ของ libarchive ซึ่งเข้าใจตัวห่อ gzip และไฟล์บีบอัด tar ภายในมันเป็นสตรีมเดียว - อย่างแม่นยำกับวิธีที่ tar -xzf ปฏิบัติต่อมันบน Linux ไฟล์ที่แยกออกมาจากนั้นถูกเขียนลงใน ZIP ใหม่โดย JSZip แต่ละไฟล์อยู่ที่เส้นทางเดิมของมัน โปรดทราบความแตกต่างระหว่างสิ่งนี้กับไฟล์ .gz ธรรมดา: .tar.gz มีไฟล์หลายไฟล์ ในขณะที่ .gz เดี่ยว ๆ มักห่อไฟล์เดียว (นั่นคือสิ่งที่ ตัวแยกไฟล์ GZ มีไว้เพื่อ) หน้านี้ยอมรับทั้ง .tar.gz และการสะกดย่อ .tgz - พวกมันเป็นรูปแบบเดียวกัน

ตัวอย่างที่ทำแล้ว

คุณดาวน์โหลด release-2.4.tar.gz (18 MB) ของเครื่องมือโอเพนซอร์สไปยัง PC Windows เครื่องมือแกะมันที่นี่และสร้าง release-2.4.zip (19 MB) ที่มีไฟล์ 86 ไฟล์เดียวกันในโฟลเดอร์เดียวกัน - พร้อมเปิดใน Explorer ไม่มี Linux และไม่มีซอฟต์แวร์เพิ่มเติมเกี่ยวข้อง

คำถามที่พบบ่อย

ตัวแปลง TAR.GZ เป็น ZIP นี้ฟรีหรือไม่?

ใช่ - ฟรี ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดและไม่มีลายน้ำ

ไฟล์ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ ทั้งสองชั้นถูกแกะออกและ ZIP ถูกสร้างทั้งหมดในเบราว์เซอร์ของคุณ; ไม่มีอะไรออกจากอุปกรณ์ของคุณ

อะไรคือความแตกต่างระหว่าง .tar.gz และ .tgz?

ไม่มี - .tgz เป็นเพียงการสะกดที่ย่อของ .tar.gz สร้างขึ้นสำหรับระบบที่ครั้งหนึ่งอนุญาตเฉพาะนามสกุลสามตัวอักษร เครื่องมือนี้ยอมรับทั้งสองอย่าง

ไฟล์ของฉันเป็น .gz ธรรมดา ไม่ใช่ .tar.gz ฉันควรใช้อะไร?

ไฟล์ .gz ธรรมดาห่อหุ้มไฟล์ที่บีบอัดเพียงไฟล์เดียว ไม่ใช่ไฟล์บีบอัดของหลายไฟล์ ใช้ ตัวแยกไฟล์ GZ เพื่อดึงไฟล์ต้นฉบับกลับออกมาจากมัน

ทำไม ZIP จึงมีขนาดประมาณเท่ากับ .tar.gz?

ทั้งสองรูปแบบบีบอัดได้ดี - gzip บน tar และ DEFLATE ภายใน ZIP - ดังนั้นขนาดผลลัพธ์ที่ใกล้เคียงกันจึงเป็นสิ่งที่คาดหวังได้ ชัยชนะอยู่ที่ความเข้ากันได้: ZIP เปิดได้ทุกที่
