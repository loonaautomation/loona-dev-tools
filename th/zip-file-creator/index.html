ตัวสร้างไฟล์ ZIP - สร้าง ZIP จากหลายไฟล์

สรุปสั้น ๆ: ตัวสร้างไฟล์ ZIP รวมชุดไฟล์ใด ๆ เป็นไฟล์บีบอัด .zip มาตรฐานเดียว สร้างทั้งหมดในเบราว์เซอร์ของคุณด้วย JSZip - เพิ่มไฟล์ เลือกจัดกลุ่มพวกมันในโฟลเดอร์ เลือกระดับการบีบอัด และดาวน์โหลด

การส่งไฟล์แนบสิบไฟล์ทีละไฟล์ การส่งมอบโฟลเดอร์โปรเจกต์ หรือการจัดเก็บชุดรูปภาพ - ZIP เปลี่ยนกองไฟล์ให้เป็นการดาวน์โหลดที่เรียบร้อยครั้งเดียว โปรแกรม zip ออนไลน์ส่วนใหญ่ อัปโหลดไฟล์ของคุณไปยังเซิร์ฟเวอร์ก่อน อันนี้ไม่ทำ: ไฟล์บีบอัดถูกประกอบบนอุปกรณ์ของคุณเอง ดังนั้นแม้แต่ไฟล์ส่วนตัวก็ไม่เคยเดินทางไปไหน

วางไฟล์ที่นี่ หรือคลิกเพื่อเลือกหลายไฟล์จากอุปกรณ์ของคุณ
ชื่อไฟล์ขนาด

หมายเหตุเรื่องการบีบอัด: ไฟล์ข้อความ โค้ด และ CSV หดลงมากด้วย DEFLATE ส่วนรูปภาพ วิดีโอ และ PDF ถูกบีบอัดมาแล้ว ดังนั้น ZIP จะมีขนาดประมาณเดียวกันไม่ว่าอย่างไร - เลือกแบบจัดเก็บสำหรับไฟล์เหล่านั้นเพื่อให้เสร็จทันที

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ไฟล์ของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป ขีดจำกัดที่ซื่อตรงหนึ่งข้อ: ZIP ถูกสร้างในหน่วยความจำของอุปกรณ์ของคุณ ดังนั้นชุดไฟล์ที่ใหญ่มาก (หลายร้อยเมกะไบต์) อาจช้าหรือล้มเหลวบนโทรศัพท์ที่มีหน่วยความจำน้อย

วิธีใช้ ตัวสร้างไฟล์ ZIP

  1. วางไฟล์ของคุณลงบนกล่องด้านบน หรือคลิกมันแล้วเลือกไฟล์จากอุปกรณ์ของคุณ คุณสามารถเพิ่มไฟล์ได้หลายรอบ
  2. ตรวจสอบรายการ - ลบสิ่งที่คุณเพิ่มเข้ามาโดยไม่ได้ตั้งใจ และดูขนาดรวม
  3. เลือกที่จะพิมพ์ชื่อโฟลเดอร์หากคุณต้องการให้ทุกไฟล์อยู่ภายในโฟลเดอร์เดียวในไฟล์บีบอัด และตั้งชื่อให้ ZIP
  4. เลือกระดับการบีบอัด (แบบบีบอัดเหมาะกับงานส่วนใหญ่) แล้วคลิก สร้าง ZIP และดาวน์โหลด

วิธีการทำงาน

ไฟล์บีบอัด ZIP เก็บข้อมูลของแต่ละไฟล์บวกไดเรกทอรีกลางที่ส่วนท้ายซึ่งแสดงรายการทุกรายการ ชื่อและขนาดของมัน - นั่นคือเหตุผลที่เครื่องมือเปิด zip ใด ๆ บนระบบใดก็เปิดมันได้ หน้านี้ใช้ไลบรารี JSZip ในเบราว์เซอร์ของคุณ: มันอ่านไฟล์ที่คุณเลือกเข้าสู่หน่วยความจำ บีบอัดแต่ละไฟล์ด้วยอัลกอริทึม DEFLATE (ตัวเดียวกับที่เครื่องมือ ZIP แบบคลาสสิกใช้) หากต้องการ เขียนไดเรกทอรี และส่งไฟล์บีบอัดที่เสร็จแล้วกลับให้คุณเป็นไฟล์ดาวน์โหลดเดียว ไฟล์ที่มีชื่อเดียวกันจะถูกเก็บไว้และใส่หมายเลขโดยอัตโนมัติ - report.pdf ไฟล์ที่สองกลายเป็น report (1).pdf - จึงไม่มีอะไรถูกเขียนทับอย่างเงียบ ๆ

ตัวอย่างที่ทำแล้ว

คุณเพิ่มไฟล์สามไฟล์: report.pdf (240 KB), photo.jpg (1.2 MB) และ notes.txt (2 KB) โดยชื่อโฟลเดอร์ตั้งเป็น "handover" เครื่องมือสร้าง handover.zip - หรือชื่อใดก็ตามที่คุณเลือก - ซึ่งมีโฟลเดอร์ handover พร้อมไฟล์ทั้งสามไฟล์ภายใน การดาวน์โหลดประมาณ 1.4 MB เพราะ PDF และ JPG ถูกบีบอัดแล้ว; หากไฟล์เป็นข้อความธรรมดาและไฟล์ส่งออก CSV ไฟล์บีบอัดเดียวกันอาจเป็นหนึ่งในสามของขนาดต้นฉบับได้อย่างง่ายดาย

คำถามที่พบบ่อย

ตัวสร้างไฟล์ ZIP นี้ฟรีหรือไม่?

ใช่ - ฟรี ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดและไม่มีลายน้ำ

ไฟล์ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ ZIP ถูกสร้างโดย JavaScript (JSZip) ที่ทำงานในเบราว์เซอร์ของคุณ ไฟล์ของคุณไม่เคยออกจากอุปกรณ์ของคุณ ซึ่งทำให้สิ่งนี้ปลอดภัยสำหรับเอกสารส่วนตัวด้วย

ทำไม ZIP ของฉันจึงมีขนาดเกือบเท่ากับไฟล์ต้นฉบับ?

รูปแบบอย่าง JPG, PNG, MP4, MP3 และ PDF ถูกบีบอัดมาแล้ว ดังนั้นการบีบอัด ZIP จึงไม่สามารถทำให้มันหดลงไปมากกว่านี้ได้อีก ไฟล์ที่ใช้ข้อความ - TXT, CSV, HTML, JSON ซอร์สโค้ด และล็อก - มักหดลงมาก

มีขีดจำกัดขนาดไฟล์หรือไม่?

ไม่มีขีดจำกัดที่สร้างไว้ในเครื่องมือ แต่ไฟล์บีบอัดถูกประกอบในหน่วยความจำของเบราว์เซอร์ของคุณ ไม่กี่ร้อยเมกะไบต์ไม่มีปัญหาบนเดสก์ท็อปส่วนใหญ่; ชุดที่ใหญ่มากอาจช้าหรือหน่วยความจำหมดบนโทรศัพท์ระดับล่าง หากมันลำบาก ให้แยกไฟล์เป็น ZIP ที่เล็กลง

ฉันป้องกัน ZIP ด้วยรหัสผ่านหรือเพิ่มไฟล์ลงในไฟล์ที่มีอยู่ได้หรือไม่?

ไม่ใช่ด้วยเครื่องมือนี้ มันสร้าง ZIP มาตรฐานใหม่ที่ไม่มีการเข้ารหัส ใครก็ตามที่ได้ไฟล์ไปสามารถเปิดมันได้ ดังนั้นอย่าพึ่งพา ZIP เพียงอย่างเดียวเพื่อปกป้องความลับ
