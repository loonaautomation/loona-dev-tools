Создатель файлов ZIP - Создавайте ZIP из нескольких файлов

Короче говоря: создатель файлов ZIP объединяет любой набор файлов в один стандартный архив .zip, полностью построенный в вашем браузере с помощью JSZip: добавьте файлы, при желании сгруппируйте их в папке, выберите уровень сжатия и скачайте.

Отправка десяти вложений по одному, передача папки проекта или архивирование партии фотографий — ZIP превращает кучу файлов в одну аккуратную загрузку. Большинство онлайн-архиваторов сначала загружают ваши файлы на сервер. Этот — нет: архив собирается на вашем собственном устройстве, поэтому даже личные файлы никуда не путешествуют.

Примечание о сжатии: файлы текста, кода и CSV сильно уменьшаются с DEFLATE. Фотографии, видео и PDF уже сжаты, поэтому ZIP будет примерно того же размера в любом случае — выберите «Сохранённый» для них, чтобы закончить мгновенно.

Приватность по замыслу: всё в этом инструменте происходит на 100% в вашем браузере с помощью JavaScript. Ваши файлы никогда не загружаются на сервер, никогда не хранятся и никогда не видны нам: закройте вкладку, и всё исчезнет. Одно честное ограничение: ZIP строится в памяти вашего устройства, поэтому очень большие наборы файлов (сотни мегабайт) могут быть медленными или завершиться неудачей на телефоне с малым объёмом памяти.

Как использовать создатель файлов ZIP

  1. Перетащите ваши файлы в поле выше или нажмите на него и выберите файлы на вашем устройстве. Вы можете добавлять файлы в несколько заходов.
  2. Проверьте список — удалите всё, что вы добавили по ошибке, и следите за общим размером.
  3. При желании введите имя папки, если вы хотите, чтобы каждый файл находился внутри одной папки в архиве, и дайте ZIP имя.
  4. Выберите уровень сжатия (вариант «Сжатый» подходит для большинства задач) и нажмите «Создать ZIP & скачать».

Как это работает

Архив ZIP хранит данные каждого файла плюс центральный каталог в конце, в котором перечислены каждая запись, её имя и её размеры, — поэтому любой инструмент распаковки в любой системе может его открыть. Эта страница использует библиотеку JSZip в вашем браузере: она читает выбранные вами файлы в память, при желании сжимает каждый из них алгоритмом DEFLATE (тем же, который используют классические инструменты ZIP), записывает каталог и возвращает вам готовый архив как одну загрузку. Файлы с одинаковым именем сохраняются и нумеруются автоматически — второй report.pdf становится report (1).pdf, — поэтому ничего молча не перезаписывается.

Разобранный пример

Вы добавляете три файла: report.pdf (240 KB), photo.jpg (1.2 MB) и notes.txt (2 KB), с именем папки, установленным как «handover». Инструмент создаёт handover.zip — или любое выбранное вами имя, — содержащий папку handover со всеми тремя файлами внутри. Скачивание составляет примерно 1.4 MB, потому что PDF и JPG уже были сжаты; если бы файлы были обычным текстом и экспортами CSV, тот же архив легко мог бы составлять треть исходного размера.

Часто задаваемые вопросы

Бесплатен ли этот создатель файлов ZIP?

Да — бесплатно, без регистрации, без ограничений и без водяных знаков.

Загружаются ли мои файлы на сервер?

Нет. ZIP строится JavaScript (JSZip), работающим в вашем браузере. Ваши файлы никогда не покидают ваше устройство, что также делает это безопасным для личных документов.

Почему мой ZIP почти такого же размера, как исходные файлы?

Форматы вроде JPG, PNG, MP4, MP3 и PDF уже сжаты, поэтому сжатие ZIP не может уменьшить их намного больше. Текстовые файлы — TXT, CSV, HTML, JSON, исходный код и журналы — обычно сжимаются сильно.

Есть ли ограничение на размер файла?

В инструмент не встроено ограничение, но архив собирается в памяти вашего браузера. Несколько сотен мегабайт подходят для большинства настольных компьютеров; очень большие наборы могут быть медленными или исчерпать память на телефоне низкого класса. Если он испытывает трудности, разделите файлы на меньшие ZIP.

Могу ли я защитить ZIP паролем или добавить файлы к существующему?

Не с этим инструментом. Он создаёт новый стандартный ZIP без шифрования. Любой, кто получит файл, может его открыть, поэтому не полагайтесь только на ZIP для защиты секретов.
