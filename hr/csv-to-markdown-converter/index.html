Pretvarač CSV u Markdown tablicu - Tablice za README datoteke i dokumentaciju

Ukratko: pretvarač CSV u Markdown vaš CSV pretvara u Markdown tablicu spremnu za GitHub, automatski poravnavajući numeričke stupce udesno i escapirajući znakove okomite crte unutar vrijednosti pa se tablica nikada ne lomi.

README datoteke, dokumentacija i komentari na probleme svi iscrtavaju Markdown tablice. Zalijepite CSV i dobijte tablicu koja se ispravno iscrtava prvi put - poravnanje i escapiranje obrađeni.

Privatno po dizajnu: sve u ovom alatu događa se 100% u vašem pregledniku JavaScriptom. Vaš ulaz nikada se ne prenosi na poslužitelj, nikada se ne pohranjuje i nikada ga mi ne vidimo - zatvorite karticu i sve je nestalo.

Kako koristiti pretvarač CSV u Markdown tablicu

  1. Zalijepite svoj CSV - prvi redak postaje zaglavlje tablice.
  2. Kliknite Pretvori u Markdown.
  3. Kopirajte tablicu u svoj README, dokument ili komentar.
  4. Numerički stupci automatski se poravnavaju udesno.

Kako radi

Poravnanje se otkriva po stupcu: ako svaka neprazna vrijednost u stupcu izgleda kao broj (dopušteni su razdjelnici tisuća i završni %), redak razdjelnika koristi ---: da ga poravna udesno, kako bi se brojevi trebali poravnati; drugi stupci koriste zadano poravnanje ulijevo. Znakovi okomite crte unutar vrijednosti escapiraju se kao \| pa vrijednost nikada ne može razdvojiti ćeliju, a prijelomi redaka unutar citiranih polja postaju <br>, koji Markdown programi za prikaz zadržavaju unutar retka tablice.

Često postavljana pitanja

Je li ovaj pretvarač besplatan?

Da - potpuno besplatno, bez registracije.

Gdje mogu koristiti izlaz?

Svugdje gdje se Markdown tablice prikazuju: README datoteke GitHuba i GitLaba, stranice s dokumentacijom, alati u stilu Notiona i praćenje problema.

Kako se odlučuje poravnanje?

Stupac čije su vrijednosti sve numeričke poravnat je udesno; svi ostali stupci poravnati su ulijevo.

Što ako vrijednost sadrži znak okomite crte?

Escapira se kao \| pa ostaje unutar svoje ćelije umjesto da lomi tablicu.

Prenose li se moji podaci?

Ne. Pretvorba radi u cijelosti u vašem pregledniku.
