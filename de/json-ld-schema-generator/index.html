JSON-LD-Schema-Generator - Strukturierte Daten ohne handgeschriebenes JSON

Kurz gesagt: das JSON-LD-Schema-Generator baut gültige schema.org-strukturierte Daten für 16 Typen – Artikel, lokale Unternehmen, Produkte, Ereignisse, Rezepte, Personen, Organisationen, Websites, FAQ-Seiten, How-Tos, Videos, Bücher, Kurse, Job-Postings, Software-Apps und Breadcrumb-Listen, und hüllt sie in den exakten Skript-Block, den Google erwartet.

Strukturierte Daten helfen Suchmaschinen, eine Seite zu verstehen, und können Rich Results freischalten. Dieser Generator baut das JSON für Sie – und validiert es als JSON, bevor Sie es kopieren.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Eingabe wird niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg.

So verwenden Sie den JSON-LD-Schema-Generator

  1. Wählen Sie den Schema-Typ, der zu Ihrer Seite passt.
  2. Füllen Sie die Felder aus, die zutreffen – leere Felder werden einfach weggelassen.
  3. Klicken Sie auf Generieren und prüfen Sie den JSON-LD-Block.
  4. Fügen Sie es in den head Ihrer Seite oder vor das schließende body-Tag ein und testen Sie dann die Live-Seite mit Googles Rich Results Test.

So funktioniert es

Der Generator baut ein JavaScript-Objekt im schema.org-Vokabular zusammen – @context, @type und die Eigenschaften für den gewählten Typ, einschließlich verschachtelter Objekte wie das Offer und AggregateRating eines Products, die Autor-Person eines Articles oder die PostalAddress eines LocalBusiness –, serialisiert es dann mit strenger JSON-Formatierung und parst seine eigene Ausgabe erneut, um zu beweisen, dass sie gültiges JSON ist, bevor er sie zeigt. Leere Felder werden vollständig weggelassen, weil eine leere Eigenschaft schlimmer ist als eine fehlende. Ehrlicher Umfang: Gültiges JSON-LD macht eine Seite berechtigt für Rich Results; Google entscheidet, ob sie gezeigt werden, und die Daten müssen zu dem passen, was auf der Seite sichtbar ist.

Häufig gestellte Fragen

Ist dieser Generator kostenlos?

Ja – völlig kostenlos, keine Registrierung.

Wird dies Rich Results garantieren?

Kein Tool kann das garantieren. Korrektes JSON-LD macht Sie berechtigt; Google wählt auf Basis der Seite, der Abfrage und seiner Richtlinien.

Wo füge ich den Block ein?

Im head-Abschnitt der Seite, oder kurz vor dem schließenden body-Tag – Google liest es an beiden Stellen.

Müssen die Daten zu meiner Seite passen?

Ja. Strukturierte Daten, die Dinge beschreiben, die auf der Seite nicht sichtbar sind, können ignoriert oder als Spam behandelt werden.

Wird irgendetwas hochgeladen?

Nein. Generierung und Validierung laufen in Ihrem Browser.
