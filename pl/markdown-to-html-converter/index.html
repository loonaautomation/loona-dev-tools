Konwerter Markdown na HTML - Czysty HTML z Markdown

W skrócie: Konwerter Markdown na HTML zamienia codzienny Markdown - nagłówki, wyróżnienia, linki, obrazy, listy, bloki cytatów, kod oraz linie poziome - na czysty HTML, escapuje surowy HTML dla bezpieczeństwa i pokazuje podgląd renderowany na żywo.

Pisarze szkicują w Markdown; sieć publikuje HTML. Ten konwerter łączy te dwa światy dla Markdown, który ludzie naprawdę piszą codziennie.

Wyrenderowany podgląd

Prywatne z założenia: wszystko w tym narzędziu dzieje się w 100% w przeglądarce przy użyciu JavaScript. Dane wejściowe nigdy nie są przesyłane na serwer, nigdy nie są przechowywane i nigdy nie są przez nas widziane - zamknij kartę, a wszystko znika.

Jak korzystać z Konwertera Markdown na HTML

  1. Wklej lub napisz swój Markdown.
  2. Kliknij Konwertuj na HTML.
  3. Sprawdź, czy wyrenderowany podgląd zgadza się z intencją.
  4. Skopiuj HTML do swojej witryny, CMS lub narzędzia e-mail.

Jak to działa

Konwerter obsługuje rdzenną składnię Markdown uczciwie: nagłówki ATX (# do ######), pogrubienie i kursywę, przekreślenie, kod inline oraz bloki kodu ogrodzone, linki i obrazy, listy uporządkowane i nieuporządkowane, bloki cytatów oraz linie poziome, przy kolejnych liniach łączonych w akapity, jak określa Markdown. Surowy HTML w źródle jest escapowany, a nie przepuszczany, więc wklejona treść nigdy nie może wstrzyknąć znaczników do wyjścia - przedziały kodu są chronione najpierw, więc przykłady zawierające gwiazdki lub tagi przetrwają nienaruszone. Egzotyczne rozszerzenia (tabele, przypisy, listy zadań) są poza jego zakresem, a wyjście mówi to, po prostu traktując je jako akapity.

Często zadawane pytania

Czy ten konwerter jest bezpłatny?

Tak - całkowicie za darmo, bez rejestracji.

Które funkcje Markdown są obsługiwane?

Nagłówki, pogrubienie, kursywa, przekreślenie, kod inline i ogrodzony, linki, obrazy, listy, cytaty blokowe i linie poziome - codzienny rdzeń.

A co z tabelami i przypisami?

To są rozszerzenia w stylu GitHub i nie są konwertowane przez to narzędzie; przechodzą jako zwykłe akapity.

Czy surowy HTML jest zachowywany?

Nie - jest escapowany dla bezpieczeństwa, więc wynik można wkleić na stronę bez wstrzykiwania znaczników.

Czy cokolwiek jest przesyłane?

Nie. Konwersja działa w przeglądarce.
