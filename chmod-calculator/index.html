Chmod Calculator - Permissions to Octal and Symbolic, Both Ways

How to use the Chmod Calculator

  1. Tick Read, Write and Execute for Owner, Group and Others - or use a preset.
  2. Read the octal value, the symbolic string and the ready-to-paste chmod command.
  3. Or type any 3-digit octal value (like 750) and click Apply octal to see it as checkboxes.
  4. Copy the command into your terminal.

How it works

Unix permissions are three groups of three bits. Within each group, Read is worth 4, Write is worth 2 and Execute is worth 1, so one group is a single octal digit from 0 (---) to 7 (rwx). The calculator adds the ticked values per group to build the three-digit octal, and renders the same boxes as the symbolic string you see in ls -l output. Applying an octal value runs the maths in reverse: each digit is split back into its 4-2-1 parts to set the checkboxes.

Worked example

Owner read+write+execute (4+2+1 = 7), group read+execute (4+1 = 5), others read+execute (5) gives octal 755, symbolic rwxr-xr-x - the classic setting that lets everyone read and run a file or folder while only the owner can change it.

Frequently Asked Questions

Is this chmod calculator free?

Yes - completely free, with no sign-up and no daily cap.

What is the difference between octal and symbolic?

They describe the same permissions. Octal (755) is what you type after chmod; symbolic (rwxr-xr-x) is what ls -l shows you. This tool converts between the two in both directions.

What about setuid, setgid and the sticky bit (4755, 1777)?

Those are a fourth, leading digit for special bits. This calculator covers the main three permission digits, which are what day-to-day chmod work uses; if you type a 4-digit value elsewhere, the last three digits are the ones shown here.

Why do folders need Execute?

On a folder, "execute" means permission to enter it and access the files inside - a folder with read but no execute shows names you cannot actually open. That is why folders are usually 755 while files are 644.
