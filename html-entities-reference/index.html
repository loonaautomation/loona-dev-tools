About

HTML has over 2,200 named entities; this table is the working set developers reach for daily: the structural escapes (& < > "), typography (dashes, quotes, ellipsis), currency and math symbols, arrows, check marks and the common accented letters. Every entity also has a decimal numeric reference (©) and a hex one (©) that work even when no name exists — the Character and Decimal columns here give you both fallbacks. The full official list lives in the WHATWG HTML standard; if an entity is not in this table, its numeric reference is the reliable route.

Frequently Asked Questions

Why use an entity instead of the character itself?

For the structural five (& < > " ') entities are correctness, not style — unescaped they break markup. For the rest, entities are a portability choice when encoding is uncertain.

What if an entity is missing here?

Use its decimal numeric reference from any Unicode chart: &#<code>; always works.
