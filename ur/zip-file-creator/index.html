ZIP فائل کریئیٹر - متعدد فائلوں سے ایک ZIP بنائیں

مختصراً: ZIP فائل کریئیٹر فائلوں کے کسی سیٹ کو واحد معیاری .zip آرکائیو میں بنڈل کرتا ہے، مکمل آپ کے براؤزر میں JSZip سے بنایا گیا - فائلیں شامل کریں، اختیاری طور پر انہیں فولڈر میں گروپ کریں، کمپریشن سطح منتخب کریں اور ڈاؤن لوڈ کریں۔

دس منسلکات ایک ایک کر کے بھیجنا، ایک پروجیکٹ فولڈر حوالے کرنا، یا تصاویر کے بیچ کو محفوظ کرنا - ایک ZIP فائلوں کے ڈھیر کو ایک صاف ڈاؤن لوڈ میں بدلتا ہے۔ زیادہ تر آن لائن zippers پہلے آپ کی فائلیں سرور پر اپ لوڈ کرتے ہیں۔ یہ نہیں کرتا: آرکائیو آپ کے اپنے آلے پر جمع ہوتا ہے، لہٰذا حتیٰ کہ نجی فائلیں بھی کہیں سفر نہیں کرتیں۔

فائلیں یہاں ڈالیں یا اپنے آلے سے فائلیں منتخب کرنے کے لیے کلک کریں
فائل نامسائز

کمپریشن نوٹ: متن، کوڈ اور CSV فائلیں DEFLATE سے بہت سکڑتی ہیں۔ تصاویر، ویڈیوز اور PDFs پہلے سے کمپریس شدہ ہیں، لہٰذا ZIP دونوں صورتوں میں تقریباً ایک جتنا سائز ہوگا - ان کے لیے Stored منتخب کریں تاکہ فوراً مکمل ہو۔

ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کی فائلیں کبھی سرور پر اپ لوڈ نہیں ہوتیں، کبھی محفوظ نہیں ہوتیں اور ہمارے دیکھنے میں نہیں آتیں - ٹیب بند کریں اور سب کچھ ختم۔ ایک ایماندار حد: ZIP آپ کے آلے کی میموری میں بنتا ہے، لہٰذا بہت بڑے فائل سیٹس (کئی سو میگا بائٹ) کم-میموری فون پر سست یا ناکام ہو سکتے ہیں۔

ZIP فائل کریئیٹر کا استعمال کیسے کریں

  1. اپنی فائلیں اوپر والے خانے پر ڈالیں، یا اس پر کلک کریں اور اپنے آلے سے فائلیں منتخب کریں۔ آپ کئی مرحلوں میں فائلیں شامل کر سکتے ہیں۔
  2. فہرست دیکھیں - جو کچھ آپ نے غلطی سے شامل کیا ہٹائیں، اور کل سائز پر نظر رکھیں۔
  3. اختیاری طور پر فولڈر نام لکھیں اگر آپ چاہتے ہیں کہ ہر فائل آرکائیو میں ایک فولڈر کے اندر بیٹھے، اور ZIP کو نام دیں۔
  4. ایک کمپریشن سطح منتخب کریں (Compressed زیادہ تر کاموں کے لیے درست ہے) اور Create ZIP & Download پر کلک کریں۔

یہ کیسے کام کرتا ہے

ایک ZIP آرکائیو ہر فائل کا ڈیٹا علاوہ آخر میں ایک مرکزی ڈائریکٹری محفوظ کرتا ہے جو ہر اندراج، اس کا نام اور اس کے سائز درج کرتی ہے - اسی لیے کسی بھی سسٹم پر کوئی بھی unzip ٹول اسے کھول سکتا ہے۔ یہ صفحہ آپ کے براؤزر میں JSZip لائبریری استعمال کرتا ہے: یہ آپ کی منتخب فائلیں میموری میں پڑھتا ہے، اختیاری طور پر ہر ایک کو DEFLATE الگورتھم سے کمپریس کرتا ہے (وہی جو کلاسیکی ZIP ٹولز استعمال کرتے ہیں)، ڈائریکٹری لکھتا ہے، اور مکمل آرکائیو آپ کو ایک واحد ڈاؤن لوڈ کے طور پر واپس دیتا ہے۔ ایک ہی نام کی فائلیں رکھی جاتی ہیں اور خودکار نمبر دیے جاتے ہیں - دوسری report.pdf، report (1).pdf بن جاتی ہے - تاکہ کچھ خاموشی سے اوور رائٹ نہ ہو۔

کام شدہ مثال

آپ تین فائلیں شامل کرتے ہیں: report.pdf (240 KB), photo.jpg (1.2 MB) اور notes.txt (2 KB)، فولڈر نام "handover" مقرر کے ساتھ۔ ٹول handover.zip بناتا ہے - یا جو نام آپ نے منتخب کیا - ایک handover فولڈر رکھتے ہوئے تمام تین فائلوں کے ساتھ اندر۔ ڈاؤن لوڈ تقریباً 1.4 MB ہے، کیونکہ PDF اور JPG پہلے سے کمپریس تھے؛ اگر فائلیں سادہ متن اور CSV exports ہوتیں، تو وہی آرکائیو آسانی سے اصل سائز کا ایک تہائی ہو سکتا تھا۔

اکثر پوچھے گئے سوالات

کیا یہ ZIP فائل کریئیٹر مفت ہے؟

ہاں - مفت، کوئی سائن اپ نہیں، کوئی حد نہیں اور کوئی واٹر مارک نہیں۔

کیا میری فائلیں کسی سرور پر اپ لوڈ ہوتی ہیں؟

نہیں۔ ZIP آپ کے براؤزر میں چلنے والے JavaScript (JSZip) سے بنایا جاتا ہے۔ آپ کی فائلیں آپ کے آلے سے کبھی نہیں نکلتیں، جو اسے نجی دستاویزات کے لیے بھی محفوظ بناتا ہے۔

میرا ZIP تقریباً اصل فائلوں جتنے سائز کا کیوں ہے؟

JPG, PNG, MP4, MP3 اور PDF جیسے فارمیٹس پہلے سے کمپریس شدہ ہیں، لہٰذا ZIP کمپریشن انہیں زیادہ مزید نہیں سکڑا سکتی۔ متن پر مبنی فائلیں - TXT, CSV, HTML, JSON, سورس کوڈ اور لاگز - عام طور پر بہت سکڑتی ہیں۔

کیا فائل سائز کی کوئی حد ہے؟

ٹول میں کوئی حد نہیں بنی، لیکن آرکائیو آپ کے براؤزر کی میموری میں جمع ہوتا ہے۔ چند سو میگا بائٹ زیادہ تر desktops پر ٹھیک ہے؛ بہت بڑے سیٹس کم-درجہ فون پر سست ہو سکتے ہیں یا میموری ختم ہو سکتی ہے۔ اگر یہ جدوجہد کرے، تو فائلوں کو چھوٹے ZIPs میں تقسیم کریں۔

کیا میں ZIP کو پاس ورڈ سے محفوظ کر سکتا ہوں یا موجودہ میں فائلیں شامل کر سکتا ہوں؟

اس ٹول سے نہیں۔ یہ ایک تازہ، معیاری ZIP بناتا ہے بغیر خفیہ کاری کے۔ فائل حاصل کرنے والا کوئی بھی اسے کھول سکتا ہے، لہٰذا رازوں کی حفاظت کے لیے صرف ZIP پر بھروسہ نہ کریں۔
