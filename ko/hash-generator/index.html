해시 생성기 - SHA-1, SHA-256, SHA-384 & SHA-512

요약하면: 해시 생성기는 브라우저 내장 암호화로 텍스트의 SHA-1, SHA-256, SHA-384, SHA-512 다이제스트를 계산해요 - 은행 웹사이트가 사용하는 같은 Web Crypto 엔진이에요. SHA-1은 정직하게 라벨이 붙어요: 체크섬용, 보안용 아님.

문자열의 두 복사본이 동일한지 확인하거나, 캐시를 무효화하는 지문을 만들거나, SHA-256 다이제스트를 요구하는 튜토리얼을 따라야 하나요? 텍스트를 붙여넣으면 네 가지 표준 다이제스트가 모두 함께 나타나 복사할 준비가 돼요.

참고: SHA-1은 체크섬과 레거시 호환성을 위해서만 포함됐어요 - 그것은 not 비밀번호나 보안에 안전해요. 보안에는 SHA-256이나 더 강한 것을 사용하세요. 비밀번호에는 bcrypt나 Argon2 같은 적절한 비밀번호 해싱 체계와 함께요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

해시 생성기 사용법

  1. 해시할 텍스트를 입력하거나 붙여넣으세요.
  2. 해시 생성을 클릭하세요.
  3. 결과에서 필요한 다이제스트를 복사하세요.

작동 방식

암호학적 해시는 어떤 입력이든 고정 길이 지문으로 바꿔요. 같은 입력은 항상 같은 지문을 줘요; 한 문자만 바꿔도 완전히 달라져요; 그리고 지문에서 입력을 복원할 수 없어요. 이 도구는 텍스트의 UTF-8 바이트를 Web Crypto API(crypto.subtle.digest)에 공급해요 - JavaScript 재구현이 아니라 기본 제공되는, 감사를 거친 브라우저 암호화예요. SHA-256은 십육진수 64자, SHA-512는 128자, SHA-1은 40자를 만들어요. SHA-1의 충돌 저항성은 깨졌기 때문에, 여전히 요구하는 체크섬과 레거시 시스템용으로만 제공해요.

풀이된 예시

"abc"라는 단어를 SHA-256으로 해시하면 항상 ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad가 나와요 - 전 세계 엔지니어가 해시 구현이 올바른지 확인하는 데 사용하는 공개된 테스트 벡터예요. 여기서 시도하고 비교하세요.

자주 묻는 질문

이 해시 생성기는 무료인가요?

네 - 무료, 회원가입 없음, 제한 없음이에요.

해싱이 암호화와 같은가요?

아니요. 해시는 단방향이에요: 비교할 수 있는 지문을 만들지만, 원래 텍스트로 다시 복호화할 수는 없어요.

SHA-1이 왜 "보안용 아님"으로 표시됐나요?

연구자들이 실제 SHA-1 충돌을 만들었으니, 비밀번호, 서명, 인증서를 보호해서는 안 돼요. 공격이 걱정되지 않는 곳에서 빠른 파일 체크섬으로는 여전히 괜찮아요.

비밀번호를 SHA-256으로 해시해야 하나요?

직접적으로는 아니에요. 비밀번호에는 bcrypt, scrypt, Argon2 같은 느리고 솔트가 있는 비밀번호 해싱 함수가 필요해요 - SHA-256 같은 빠른 해시는 공격자가 초당 수십억 개의 비밀번호를 추측하게 해요.

해시를 위해 제 텍스트가 업로드되나요?

아니요. 해싱은 Web Crypto를 통해 브라우저에서 실행돼요; 텍스트는 기기를 절대 떠나지 않아요.
