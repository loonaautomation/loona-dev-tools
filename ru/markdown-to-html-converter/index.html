Конвертер Markdown в HTML - Чистый HTML из вашего Markdown

Короче говоря: конвертер Markdown в HTML превращает повседневный Markdown — заголовки, выделение, ссылки, изображения, списки, цитаты, код и горизонтальные линии — в чистый HTML, экранирует необработанный HTML для безопасности и показывает предварительный просмотр в реальном времени.

Авторы пишут черновики в Markdown; веб публикует HTML. Этот конвертер соединяет эти два формата для того Markdown, который люди действительно пишут каждый день.

Отрендеренный предпросмотр

Приватность по замыслу: всё в этом инструменте происходит на 100% в вашем браузере с помощью JavaScript. Ваш ввод никогда не загружается на сервер, никогда не хранится и никогда не виден нам: закройте вкладку, и всё исчезнет.

Как использовать конвертер Markdown в HTML

  1. Вставьте или напишите ваш Markdown.
  2. Нажмите «Преобразовать в HTML».
  3. Проверьте, что визуализированный предпросмотр соответствует вашему намерению.
  4. Скопируйте HTML на ваш сайт, в CMS или инструмент для рассылки.

Как это работает

Конвертер честно обрабатывает основную синтаксическую часть Markdown: заголовки ATX (# до ######), жирный и курсив, зачёркивание, встроенный код и блоки кода в ограждениях, ссылки и изображения, упорядоченные и неупорядоченные списки, цитаты и горизонтальные линии, при этом последовательные строки объединяются в абзацы, как указывает Markdown. Необработанный HTML в источнике экранируется, а не пропускается, поэтому вставленное содержимое никогда не может внедрить разметку в вывод: сначала защищаются фрагменты кода, поэтому примеры, содержащие звёздочки или теги, остаются нетронутыми. Экзотические расширения (таблицы, сноски, списки задач) находятся вне его области, и вывод говорит об этом, просто обрабатывая их как абзацы.

Часто задаваемые вопросы

Бесплатен ли этот конвертер?

Да — полностью бесплатно, без регистрации.

Какие возможности Markdown поддерживаются?

Заголовки, жирный шрифт, курсив, зачёркивание, встроенный и ограждённый код, ссылки, изображения, списки, цитаты и горизонтальные линии — повседневное ядро.

А как насчёт таблиц и сносок?

Это расширения в стиле GitHub, и этот инструмент их не конвертирует; они проходят как обычные абзацы.

Сохраняется ли исходный HTML?

Нет — он экранируется для безопасности, поэтому вывод можно вставить на страницу без внедрения разметки.

Загружается ли что-нибудь?

Нет. Преобразование выполняется в вашем браузере.
