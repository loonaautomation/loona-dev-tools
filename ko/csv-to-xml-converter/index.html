CSV를 XML로 변환 - 스프레드시트 행을 깔끔한 XML로

요약하면: CSV를 XML로 변환기는 각 CSV 행을 XML 요소로 바꿔요. 헤더 행을 태그 이름으로 사용하며, 구성 가능한 루트와 행 요소, &, <, >, 따옴표에 대한 올바른 이스케이프와 함께예요.

피드, 사이트맵, 레거시 시스템은 여전히 XML로 말해요. CSV를 붙여넣고, 요소의 이름을 짓고, 모든 파서가 받아들일 올바른 형식의 XML을 얻으세요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

CSV를 XML로 변환 사용법

  1. CSV를 붙여넣으세요 - 첫 행이 요소 이름을 제공해요.
  2. 기본값이 맞지 않으면 루트 요소와 행 요소 이름을 설정하세요.
  3. XML로 변환을 클릭하세요.
  4. 결과를 복사하거나 .xml 파일로 다운로드하세요.

작동 방식

헤더 이름은 유효한 XML 태그 이름으로 바뀌어요: 태그에 나타날 수 없는 문자는 밑줄로 교체되고, 숫자로 시작할 이름에는 접두사가 붙어요. 중복 헤더는 _2, _3 접미사가 붙어 어떤 열도 잃지 않아요. 모든 값은 XML 이스케이프돼요 - 앰퍼샌드, 꺾쇠괄호, 따옴표가 엔터티가 돼요 - 그래서 다음과 같은 값은 Fish & Chips 문서를 절대 깨뜨릴 수 없어요. 출력은 들여쓰기되고, 표준 XML 선언으로 시작하며, 모든 XML 파서에서 깨끗하게 파싱돼요.

풀이된 예시

다음 값 a < b & c 다음으로 내보내져요 a &lt; b &amp; c 요소 안 - XML이 요구하는 대로 정확히 한 번 이스케이프돼요.

자주 묻는 질문

이 CSV를 XML로 변환하는 도구는 무료인가요?

네 - 완전히 무료, 회원가입 없음이에요.

요소 이름을 바꿀 수 있나요?

네. 루트와 행 요소 이름을 설정하세요; 열 요소는 헤더 행에서 와요, 유효한 XML 태그 이름으로 정리돼요.

특수 문자는 어떻게 처리되나요?

XML 엔티티(&, <, >, ", ')로 이스케이프돼 출력이 항상 올바른 형식을 갖춰요.

헤더가 유효한 태그 이름이 아니면 어떻게 되나요?

잘못된 문자는 밑줄이 되고 숫자로 시작하는 이름에는 접두사가 붙어요. 그래서 모든 열이 여전히 나타나요.

제 데이터가 업로드되나요?

아니요. 모든 것이 브라우저에서 실행돼요.
