GZファイル抽出ツール - GZファイルをオンラインで解凍

要するに： GZファイル抽出ツールは単一の .gz ファイルをブラウザで解凍し、元のファイル（ログ、CSVエクスポート、データベースダンプ）を、元の名前が復元されて返します。何もアップロードされません。

.gz ファイルはファイルが詰まったアーカイブではありません。gzipで圧縮された、ちょうど一つのファイルです。gzipはUnixの世界の主力です。サーバーログ、データエクスポート、データベースダンプはこの形でやり取りされ、Windowsには開くための標準機能がありません。このページは、ブラウザ自体に組み込まれたgzipエンジン（DecompressionStream API）でファイルを展開するため、高速で完全にプライベートです。

あなたの .gz ファイルをここにドロップ またはクリックしてデバイスからファイルを選んでください
設計上プライベート： このツールのすべては、ブラウザ自体に組み込まれたgzip解凍を使って、ブラウザで100%行われます。あなたの.gzファイルはサーバーにアップロードされることは決してなく、保存されることも、私たちに見られることもありません。一つの正直な制限：解凍はあなたのデバイスのメモリ内で行われるため、数ギガバイトに膨張する.gzは、低メモリの電話では苦労することがあります。

GZファイル抽出ツールの使い方

  1. あなたの .gz ファイルを上のボックスにドロップするか、クリックしてデバイスからファイルを選んでください。
  2. ファイルは直ちに解凍されます。元のファイル名とその完全なサイズを示す行に注意してください。
  3. 元のファイルを保存するには「展開されたファイルをダウンロード」をクリックしてください（例えば access.log.gz から access.log）。

仕組み

Gzipは小さなヘッダー（作成ツールが記録していれば元のファイル名も含みます）、DEFLATEアルゴリズムで圧縮されたデータ、末尾にチェックサムと元のサイズを保存します。最新のブラウザにはネイティブのgzipデコーダーが組み込まれています。圧縮されたウェブページを受け取るのに使うのと同じものです。このページはDecompressionStream APIでファイルをそれに通します。ライブラリはダウンロードされず、何もどこにも送信されません。ブラウザがデータを展開し、元のバイトを渡します。

実例

サーバーは access.log.gz（2.1 MB）を提供します。ここにドロップすると、約一秒で access.log（18.4 MB）に解凍されます。ダウンロードしてテキストエディタで開き、昨夜のエラーを見つけます。一つのツールもインストールせずにです。

よくある質問

.gz と .tar.gz の違いは何ですか？

.gz ファイルには、圧縮されたファイルがちょうど一つだけ入っています。.tar.gz は、まず多くのファイルをTARアーカイブにまとめ、それからその束をgzipで圧縮するため、ファイルツリー全体を含みます。.tar.gz には、下にリンクされた TAR.GZファイル抽出ツールをお使いください。

解凍されたファイルは正しい名前を持ちますか？

はい - このツールは .gz の終わりを取り除くことで元の名前を復元します（access.log.gz は access.log になります）。これは、ファイルが圧縮されたときに記録された名前と、大多数のケースで一致します。

このツールは、間違って .gz で終わる .zip や .rar ファイルを開けますか？

いいえ。ファイル名を変更しても中身は変わりません。内容が本当にgzipデータでなければ、解凍は分かりやすいメッセージとともに失敗します。ZIP、RAR、その他の本物のアーカイブにはアーカイブファイル抽出ツールを使ってください。

サイズの制限はありますか？

ツールには制限が組み込まれていませんが、解凍されたファイルはブラウザのメモリ内に保持されます。日常のログとエクスポート（数百メガバイトまで）はほとんどのデバイスで問題ありません。複数ギガバイトのダンプは、ネイティブツールのあるデスクトップで処理する方が良いです。

私のファイルはサーバーにアップロードされますか？

いいえ。解凍は、あなたのデバイス上のブラウザ自体の組み込みエンジンを使います。ファイルがマシンから出ることは決してありません。このツールにはライブラリのダウンロードすらありません。
