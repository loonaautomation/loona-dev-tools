JSON ফরম্যাটার ও ভ্যালিডেটর - JSON সুন্দর ছাপা ও মিনিফাই করুন

সংক্ষেপে: JSON Formatter আপনার JSON পরীক্ষা করে, 2-স্পেস, 4-স্পেস বা ট্যাব ইন্ডেন্টেশনসহ এটি সুন্দর-ছাপে, অনুরোধে এটিকে মিনিফাই করে, এবং কিছু ভুল থাকলে এটি আপনাকে সমস্যার হুবহু লাইন এবং কলাম বলে।

ভাঙা JSON হলো একজন ডেভেলপারের দিনে সবচেয়ে সাধারণ পাঁচ-মিনিটের বিলম্ব - একটি কমা অনুপস্থিত থাকলেই পুরো পেলোড ব্যর্থ হয়। আপনার JSON নিচে পেস্ট করুন: এটি বৈধ হলে আপনি পরিষ্কার, পাঠযোগ্য আউটপুট পান; না হলে, একটি অকেজো "parse failed"-এর বদলে আপনি ত্রুটির সুনির্দিষ্ট অবস্থান পান।

নকশায় ব্যক্তিগত: এই টুলে সবকিছু JavaScript দিয়ে আপনার ব্রাউজারে 100% ঘটে। আপনার ইনপুট কখনও একটি সার্ভারে আপলোড হয় না, কখনও সংরক্ষিত হয় না এবং কখনও আমাদের দ্বারা দেখা হয় না - ট্যাব বন্ধ করুন এবং সবকিছু চলে গেছে।

JSON ফরম্যাটার কীভাবে ব্যবহার করবেন

  1. আপনার JSON উপরের বাক্সে পেস্ট করুন বা টাইপ করুন।
  2. একটি ইনডেন্ট ধরন বেছে নিন - 2 স্পেস, 4 স্পেস বা ট্যাব।
  3. পাঠযোগ্য আউটপুটের জন্য ফরম্যাট / যাচাই করুন-এ ক্লিক করুন, বা সবচেয়ে ছোট বৈধ রূপের জন্য মিনিফাই করুন।
  4. ফলাফল কপি করুন বা এটি একটি .json ফাইল হিসেবে ডাউনলোড করুন।

এটি কীভাবে কাজ করে

টুল আপনার ব্রাউজারের অন্তর্নির্মিত JSON পার্সার ব্যবহার করে - একই কঠোর পার্সার যা আপনার নিজের JavaScript কোড ব্যবহার করে - তাই এখানে একটি সবুজ আলো মানে আপনার JSON সত্যিই বৈধ। সুন্দর-মুদ্রণ পার্স করা মান আপনার বেছে নেওয়া ইনডেন্টেশন দিয়ে আবার সিরিয়ালাইজ করে; কী ক্রম ঠিক যেমন লেখা তেমন সংরক্ষিত। মিনিফাই করা প্রতিটি অপ্রয়োজনীয় স্পেস ও নতুন লাইন সরায় একটি মানও না বদলে। পার্সিং ব্যর্থ হলে, টুল পার্সারের অক্ষর অবস্থান একটি লাইন ও কলামে রূপান্তর করে ও আপনাকে অপরাধী লাইন দেখায়।

কাজ করা উদাহরণ

আপনি পেয়েছেন {"user":"ahmed","roles":["admin","editor"],"active":true} একটি API থেকে। 2 স্পেস দিয়ে ফরম্যাট করা হলে এটি একটি পরিষ্কার নয়-লাইনের নথি হয়ে যায় যা আপনি আসলেই পড়তে পারেন - এবং আপনি দুর্ঘটনাক্রমে "ahmed"-এর পরে কমা মুছে ফেললে, টুলটি হুবহু লাইন এবং কলামে ত্রুটি রিপোর্ট করে এটির জন্য শিকার করতে ছেড়ে দেওয়ার বদলে।

প্রায়শই জিজ্ঞাসিত প্রশ্ন

এই JSON ফরম্যাটার কি বিনামূল্যে?

হ্যাঁ - সম্পূর্ণ বিনামূল্যে, কোনো সাইন-আপ ছাড়া, কোনো আকারের সীমা ছাড়া এবং কোনো দৈনিক সীমা ছাড়া।

আমার JSON অবৈধ হলে কী হয়?

আপনি পার্সারের ত্রুটি বার্তা এবং পার্সিং ব্যর্থ হওয়ার হুবহু লাইন ও কলাম, এবং সেই লাইনের টেক্সট পান, যাতে আপনি সেকেন্ডে এটি ঠিক করতে পারেন।

ফরম্যাটিং কি আমার ডেটা বদলায়?

না। ফরম্যাটিং শুধু হোয়াইটস্পেস বদলায়। মিনিফাই করা শুধু হোয়াইটস্পেস সরায়। কী, মান ও তাদের ক্রম অস্পর্শিত।

আমার JSON কি সার্ভারে আপলোড হয়?

না। পার্সিং ও ফরম্যাটিং 100% আপনার ব্রাউজারে হয়। API পেলোড ও কনফিগ ফাইল কখনও আপনার ডিভাইস ছাড়ে না।

আমি কি সত্যিই বড় JSON ফরম্যাট করতে পারি?

হ্যাঁ - ব্যবহারিক সীমা হলো আপনার ডিভাইসের মেমরি। কয়েক মেগাবাইটের ফাইল একটি সাধারণ ল্যাপটপে এক সেকেন্ডের অনেক কম সময়ে ফরম্যাট হয়।
