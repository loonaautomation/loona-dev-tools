CSS Box Shadow जनरेटर — Layered, वास्तविक Shadows visually

संक्षेप में: CSS Box Shadow जनरेटर box-shadow CSS layer by layer बनाता है — offsets, blur, spread, colour, opacity और inset — live preview के साथ, ताकि cards और buttons को एक flat grey blur के बजाय realistic depth मिले।

एक harsh shadow नकली दिखती है; दो या तीन soft layers प्रकाश जैसी दिखती हैं। यह generator layering आसान बनाता है और परिणाम दिखाता है जैसे आप इसे tune करते हैं।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

CSS Box Shadow जनरेटर का उपयोग कैसे करें

  1. पहली layer समायोजित करें: vertical offset और blur ज़्यादातर काम करते हैं।
  2. Softness के लिए colour set करें और opacity कम करें (0.1-0.3 realistic range है)।
  3. Contact depth के लिए दूसरी, tighter layer जोड़ें, या inner shadow के लिए Inset पर tick करें।
  4. Generated CSS copy करें।

यह कैसे काम करता है

box-shadow layer एक offset-x offset-y blur spread colour, और कई layers comma से अलग होती हैं — पहली layer सबसे ऊपर आती है। वास्तविक गहराई आमतौर पर एक छोटी, गहरी contact shadow के साथ एक बड़ी, नरम ambient shadow को जोड़ती है, इसीलिए यह tool एक shadow के बजाय layers के इर्द-गिर्द बना है। रंग rgba() के रूप में निकलते हैं ताकि opacity रंग के साथ रहे, और preview box हर keystroke पर update होता है।

अक्सर पूछे जाने वाले सवाल

क्या यह generator मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, कोई साइन-अप नहीं।

मैं कितनी layers जोड़ सकता हूँ?

जितने आप चाहें — CSS की खुद कोई व्यावहारिक limit नहीं है, हालाँकि 2-3 layers ज़्यादातर designs को cover करती हैं।

कौन सी values shadow को natural दिखाती हैं?

एक मामूली vertical offset, भरपूर blur, और कम opacity (0.1-0.3)। पूरी opacity पर शुद्ध काला लगभग कभी असली नहीं दिखता।

Inset shadow क्या है?

element की border के बाहर के बजाय अंदर बनाई गई shadow — pressed या recessed effects के लिए उपयोग होती है।

क्या कुछ अपलोड होता है?

नहीं। सब कुछ आपके ब्राउज़र में चलता है।
