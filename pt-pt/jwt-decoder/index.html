Descodificador JWT - Leia o Cabeçalho e o Payload, Verifique a Expiração

Em resumo: o Descodificador JWT divide um JSON Web Token no seu cabeçalho e payload, mostra ambos como JSON legível, e traduz os carimbos temporais de expiração e emissão para datas simples. Não prova - e nenhum descodificador pode - que o token é genuíno.

Um JWT parece uma string longa e ilegível, mas as duas primeiras partes são apenas JSON codificado em Base64url. Cole um token para ler o que ele afirma - para quem é, quando expira - durante a depuração. Utilize-o apenas para inspeção; a confiança real exige verificação da assinatura num servidor.

Importante: este descodificador faz NÃO verificar a assinatura. Apenas lê o conteúdo do token. Nunca confie num JWT descodificado por si só - qualquer pessoa pode criar ou alterar um token não verificado. Valide sempre os tokens corretamente no seu servidor.
Privado por conceção: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. A sua entrada nunca é carregada para um servidor, nunca guardada e nunca vista por nós - feche o separador e tudo desaparece.

Como utilizar o Descodificador JWT

  1. Cole o token completo (as três partes) na caixa.
  2. Clique em Descodificar Token.
  3. Leia o cabeçalho e o payload, e verifique a linha de expiração - depois verifique o token devidamente no seu próprio sistema antes de confiar nele.

Como funciona

Um JWT são três strings Base64url unidas por pontos: header.payload.signature. O header indica o algoritmo de assinatura; o payload transporta claims como sub (subject), iat (issued-at) e exp (expiry, como timestamp Unix em segundos). Esta ferramenta descodifica as duas primeiras partes de Base64url para JSON - exatamente a mesma descodificação que o seu próprio código faz - e converte as claims numéricas de tempo em datas legíveis. A terceira parte, a signature, é mostrada como presente mas NÃO é verificada: verificá-la exige o segredo ou a chave pública e tem de acontecer no seu backend.

Perguntas Frequentes

Este descodificador JWT é grátis?

Sim - grátis, sem registo, sem limites.

Esta ferramenta verifica o token?

Não. Apenas descodifica. Um token descodificado não prova nada sobre autenticidade - qualquer pessoa pode escrever qualquer payload e codificá-lo. A verificação da assinatura requer a chave e pertence ao seu servidor.

Porque é que o payload parece legível de todo?

As partes de um JWT são codificadas, não encriptadas. A codificação é para transporte, não para segredo - nunca coloque segredos num payload JWT.

É seguro colar um token real aqui?

O seu token é descodificado 100% no seu navegador e nunca carregado. Mesmo assim, a boa prática é evitar colar tokens de produção ativos em qualquer ferramenta - utilize um token de teste com a mesma forma.

O que significa "exp"?

O tempo de expiração do token como um carimbo temporal Unix em segundos. Esta ferramenta converte-o para uma data legível e diz-lhe se já expirou.
