Ekstraktor File Unzip - Buka dan Ekstrak File ZIP

Singkatnya: Ekstraktor File Unzip membuka arsip .zip langsung di browser Anda dengan JSZip, mencantumkan setiap file di dalamnya beserta path lengkap dan ukurannya, dan memungkinkan Anda mengekstrak file tunggal atau semuanya - tanpa unggah, tanpa pasang.

Seseorang mengirimi Anda ZIP dan Anda hanya membutuhkan satu file darinya - atau Anda ingin mengintip ke dalam sebelum mempercayainya. Ekstraktor berbasis unggah membuat arsip Anda bepergian ke server orang asing terlebih dahulu. Yang ini membaca ZIP di perangkat Anda sendiri: lihat isinya, tarik keluar persis yang Anda butuhkan, selesai.

Jatuhkan file .zip di sini atau klik untuk memilih satu dari perangkat Anda
Path di dalam ZIPUkuran

Ekstrak Semua mengunduh file satu demi satu. Jika browser Anda bertanya apakah akan mengizinkan beberapa unduhan dari situs ini, pilih Izinkan - jika tidak, ekstrak file satu per satu dengan tombol Ekstrak mereka. File yang diekstrak disimpan dengan nama file polosnya (folder ditampilkan dalam daftar agar Anda dapat melihat struktur arsip, tetapi browser menyimpan unduhan secara datar).

Privat berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di browser Anda dengan JavaScript. Arsip Anda tidak pernah diunggah ke server, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang. Satu batas jujur: arsip dibongkar dalam memori perangkat Anda, jadi ZIP yang sangat besar (ratusan megabita) dapat lambat atau gagal di ponsel memori rendah.

Cara menggunakan Ekstraktor File Unzip

  1. Jatuhkan file .zip Anda ke kotak di atas, atau klik dan pilih arsip dari perangkat Anda.
  2. Baca daftar: setiap entri muncul dengan path lengkapnya di dalam arsip dan ukuran sebenarnya (tidak terkompresi). Entri folder ditandai "folder".
  3. Klik Ekstrak di samping file tunggal mana pun untuk mengunduh hanya file itu, atau gunakan Ekstrak Semua File untuk mengunduh semuanya satu file demi satu.

Cara kerja

Setiap ZIP diakhiri dengan direktori pusat yang mencantumkan setiap entri, di mana datanya berada dalam file, dan seberapa besar ukurannya terkompresi dan tidak terkompresi. Halaman ini menggunakan pustaka JSZip di browser Anda untuk membaca direktori itu saat Anda memilih arsip - itulah sebabnya daftar muncul seketika, sebelum apa pun diekstrak. Ketika Anda mengekstrak file, JSZip mengembangkan (membatalkan DEFLATE) datanya di memori dan browser Anda menyimpannya sebagai unduhan normal. Karena semua ini terjadi secara lokal, halaman yang sama berfungsi offline setelah dimuat dan aman untuk arsip yang tidak akan pernah Anda kirim ke situs unggah.

Contoh yang dikerjakan

Anda membuka backup.zip (4.8 MB). Daftar menunjukkan folder photos yang mengandung photos/img1.jpg (1.9 MB) dan photos/img2.jpg (2.1 MB), plus readme.txt (1 KB) di tingkat atas. Anda hanya membutuhkan readme - klik tombol Ekstrak-nya dan hanya file 1 KB itu yang terunduh, tanpa membongkar foto sama sekali.

Pertanyaan yang Sering Diajukan

Apakah alat unzip ini gratis?

Ya - gratis, tanpa pendaftaran, tanpa batas, dan tanpa watermark.

Apakah file saya diunggah ke server?

Tidak. Arsip dibaca oleh JavaScript (JSZip) di dalam browser Anda dan file yang diekstrak langsung masuk ke unduhan Anda. ZIP dan isinya tidak pernah meninggalkan perangkat Anda.

Dapatkah ia membuka ZIP yang dilindungi kata sandi?

Tidak. JSZip tidak dapat membaca arsip terenkripsi, jadi ZIP yang dilindungi kata sandi akan gagal terbuka di sini. Gunakan alat arsip desktop untuk file terenkripsi.

Mengapa Ekstrak Semua berhenti setelah beberapa file?

Browser melindungi dari halaman yang mengunduh banyak file sekaligus. Alat ini mengunduh file satu demi satu dengan jeda singkat; jika browser Anda bertanya, izinkan beberapa unduhan untuk situs ini - atau ekstrak file satu per satu, yang selalu berhasil.

Apakah ia berfungsi untuk file RAR, 7z, atau TAR?

Tidak - ekstraktor ini hanya menangani arsip .zip standar. RAR dan 7z menggunakan format kompresi berbeda yang membutuhkan pustaka berbeda.
