CSV व्यूअर और एडिटर — Table Grid में Spreadsheet डेटा edit करें

संक्षेप में: CSV व्यूअर और एडिटर आपके CSV को असली editable table में load करता है — किसी cell को click करके बदलें, header को click करके sort करें, rows और columns जोड़ें या हटाएँ, फिर cleaned-up CSV download करें।

Spreadsheets एक quick fix के लिए भारी हैं। CSV यहाँ paste करें या load करें, grid में अपने edits करें, और परिणाम download करें — ठीक से parsed, quotes समेत सब।

Ascending / descending sort करने के लिए column header पर click करें। किसी cell पर click करके उसे edit करें। Row या column हटाने के लिए × buttons उपयोग करें।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

CSV व्यूअर और एडिटर का उपयोग कैसे करें

  1. अपना CSV paste करें या .csv फ़ाइल चुनें, फिर Load into table पर click करें।
  2. उसकी value edit करने के लिए किसी cell पर click करें।
  3. उस column से sort करने के लिए column header पर click करें; उलटने के लिए दोबारा click करें।
  4. + Add row / + Add column उपयोग करें, या rows और columns हटाने के लिए × buttons।
  5. परिणाम save करने के लिए Download edited CSV पर click करें।

यह कैसे काम करता है

Viewer उसी RFC 4180-style parser का उपयोग करता है जो हमारे CSV converters का है: quoted fields में commas, doubled quotes और line breaks हो सकते हैं, और CRLF और LF endings दोनों accepted हैं। Sorting values को numerically compare करती है जब column की दोनों cells plain numbers जैसी दिखें, वरना alphabetically, इसलिए score column 87 के बाद के बजाय 9 को पहले sort करती है। जब आप download करते हैं, comma, quote या newline वाले fields फिर quoted होते हैं और quotes doubled होते हैं — फ़ाइल Excel, Google Sheets और किसी standards-based importer से round-trip करती है।

काम किया हुआ उदाहरण

Loading "Ali, A",91 एक cell दिखाता है जिसमें Ali, A — comma नाम के अंदर ही रहता है, उसे दो cells में बाँटने के बजाय।

अक्सर पूछे जाने वाले सवाल

क्या यह CSV viewer मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, बिना साइन-अप और बिना daily cap।

क्या मैं cells को सीधे edit कर सकता हूँ?

हाँ। Grid में हर cell editable है — इसे click करें, type करें, और change शामिल होता है जब आप download करते हैं।

Sorting कैसे काम करती है?

Ascending sort करने के लिए column header पर click करें, descending के लिए दोबारा click करें। सादी संख्याओं के columns numerically sort होते हैं; बाकी सब alphabetically।

क्या quoted fields editing में बचेंगे?

हाँ। Parser CSV quoting rules का पालन करता है, और download किसी field को दोबारा quote करता है जिसे इसकी ज़रूरत हो।

क्या मेरा डेटा अपलोड होता है?

नहीं। Loading, editing और downloading सभी आपके ब्राउज़र में होते हैं।
