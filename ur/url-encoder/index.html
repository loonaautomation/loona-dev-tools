URL انکوڈر اور ڈیکوڈر - فیصد-انکوڈنگ سادہ بنائی گئی

مختصراً: URL انکوڈر متن کو فیصد-انکوڈ کرتا ہے تاکہ یہ ویب ایڈریس کے اندر محفوظ سفر کر سکے، اور فیصد-انکوڈ شدہ متن کو واپس ڈی کوڈ کرتا ہے - component موڈ (query قدروں کے لیے) اور مکمل-URL موڈ دونوں کے ساتھ، علاوہ ہر حرف کی وضاحت کرتی ٹیبل۔

اسپیسز، ایمپرسینڈز اور غیر انگریزی حروف URL کے اندر خام سفر نہیں کر سکتے - یہ بگڑ جاتے ہیں، query اسٹرنگز توڑتے ہیں، یا ایڈریس کا مطلب بدلتے ہیں۔ فیصد-انکوڈنگ اسے ہر غیر محفوظ بائٹ کو % کوڈ سے بدل کر درست کرتی ہے۔ یہ ٹول دونوں طرح کرتا ہے اور آپ کو عین دکھاتا ہے کہ ہر حرف کے ساتھ کیا ہوا۔

فی-حرف تجزیہ

کچھ انکوڈ کریں اور آپ کی ان پٹ کا ہر حرف یہاں بیان ہوگا۔

ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کا ان پٹ کبھی سرور پر اپ لوڈ نہیں ہوتا، کبھی محفوظ نہیں ہوتا اور ہمارے دیکھنے میں نہیں آتا - ٹیب بند کریں اور سب کچھ ختم۔

URL انکوڈر اور ڈیکوڈر کا استعمال کیسے کریں

  1. متن یا URL باکس میں پیسٹ کریں۔
  2. query قدر کے لیے Component موڈ منتخب کریں، یا پورے ایڈریس کے لیے Full URL موڈ۔
  3. انکوڈ یا ڈی کوڈ پر کلک کریں، پھر نتیجہ کاپی کریں۔

یہ کیسے کام کرتا ہے

فیصد-انکوڈنگ ایک حرف کے UTF-8 بائٹس پر کام کرتی ہے: اسپیس %20 بن جاتی ہے، ایک ایمپرسینڈ %26 بن جاتا ہے، اور حرف "é"، %C3%A9 بن جاتا ہے - ایک % کوڈ فی بائٹ۔ دونوں موڈز اس میں مختلف ہیں کہ وہ کیا محفوظ کرتے ہیں: encodeURIComponent (Component) / ? : اور # جیسے حروف بھی انکوڈ کرتا ہے کیونکہ query قدر میں URL کی اپنی اوقاف نہیں ہونی چاہیے؛ encodeURI (مکمل URL) وہ اوقاف برقرار چھوڑتا ہے کیونکہ یہ خود ایڈریس سے تعلق رکھتی ہے۔ غلط موڈ منتخب کرنا کلاسیکی ابتدائی بگ ہے - مکمل URL کو Component موڈ میں انکوڈ کرنا اسے تباہ کرتا ہے، اور query قدر کو مکمل موڈ میں انکوڈ کرنا ایمپرسینڈ اور = کو آپ کے پیرامیٹرز توڑنے کے لیے آزاد چھوڑتا ہے۔

کام شدہ مثال

تلاش متن "loona tools & guides" Component موڈ میں loona%20tools%20%26%20guides بن جاتا ہے - ایڈریس میں ?q= کے بعد رکھنے کے لیے محفوظ۔ وہی متن مکمل URL موڈ میں مشکل سے بدلتا ہے، اسی لیے موڈ انتخاب اہم ہے۔

مجھے کون سا موڈ استعمال کرنا چاہیے؟

Component موڈ ہر اس چیز کے لیے جو URL کے اندر ایک قدر کے طور پر جائے (تلاش متن، نام، redirect اہداف)۔ Full URL موڈ صرف اس وقت جب آپ پورا ایڈریس انکوڈ کر رہے ہوں اور اس کی : / ? # ساخت برقرار رکھنی ہو۔

ایک حرف کبھی دو % کوڈز کیوں بنتا ہے؟

غیر انگریزی حروف کئی UTF-8 بائٹس کے طور پر محفوظ ہوتے ہیں، اور ہر بائٹ کو اپنا % کوڈ ملتا ہے - مثال کے طور پر é، %C3%A9 بن جاتا ہے۔ یہ درست ہے اور ہر سرور اسے سمجھتا ہے۔

ڈی کوڈنگ ٹوٹے % تسلسل کے ساتھ کیا کرتی ہے؟

یہ اندازہ لگانے کے بجائے غلطی رپورٹ کرتا ہے، کیونکہ %zz جیسی خراب ترتیب کا کوئی درست معنی نہیں۔
