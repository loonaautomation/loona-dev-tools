CSV Join - Combine Two Tables on a Key Column

In short: the CSV Join merges two CSVs the way a database JOIN does: pick the key column in each file, choose inner join (matches only) or left join (all left rows, blanks where the right side has no match), and get one combined table.

Orders in one file, customers in another, and the shared column is an ID. This is the VLOOKUP job, done properly - with database join semantics.

Private by design: everything in this tool happens 100% in your browser with JavaScript. Your input is never uploaded to a server, never stored and never seen by us - close the tab and everything is gone.

How to use the CSV Join

  1. Paste the left (main) CSV and the right (lookup) CSV.
  2. Name the key column in each - by header name or its number.
  3. Choose Left join to keep every left row, or Inner join for matches only.
  4. Click Join and download the combined CSV.

How it works

Matching follows database rules: if the right table contains the same key twice, a left row produces one output row per match (try the sample - Ken appears twice). The right key column itself is not repeated in the output, and right-side column names that collide with left-side names get _2 suffixes so nothing overwrites. Keys are compared as exact text, so '001' and '1' are different keys - the safe behaviour for IDs and codes.

Frequently Asked Questions

Is this tool free?

Yes - completely free, no sign-up.

What is the difference between inner and left join?

Inner join keeps only rows that match on both sides. Left join keeps every left row, filling the right-side columns with blanks when there is no match.

What if the right file has a key twice?

You get one output row per match, exactly like a SQL join - nothing is silently dropped.

Is my data uploaded?

No. The join runs 100% in your browser.
