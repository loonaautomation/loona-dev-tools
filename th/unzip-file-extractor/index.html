ตัวแยกไฟล์แบบเปิด zip - เปิดและแยกไฟล์ ZIP

สรุปสั้น ๆ: ตัวแยกไฟล์แบบเปิด zip เปิดไฟล์บีบอัด .zip ในเบราว์เซอร์ของคุณเลยด้วย JSZip แสดงรายการทุกไฟล์ภายในพร้อมเส้นทางเต็มและขนาดของมัน และให้คุณแยกไฟล์เดียวหรือทั้งหมด - ไม่มีการอัปโหลด ไม่มีการติดตั้ง

มีคนส่ง ZIP ให้คุณและคุณต้องการเพียงไฟล์เดียวจากมัน - หรือคุณต้องการแอบดูข้างในก่อนเชื่อถือมัน ตัวแยกไฟล์แบบอัปโหลดทำให้ไฟล์บีบอัดของคุณเดินทางไปยังเซิร์ฟเวอร์ของคนแปลกหน้าก่อน อันนี้อ่าน ZIP บนอุปกรณ์ของคุณเอง: ดูเนื้อหา ดึงสิ่งที่คุณต้องการออกมาอย่างแม่นยำ เสร็จ

วางไฟล์ .zip ที่นี่ หรือคลิกเพื่อเลือกหนึ่งรายการจากอุปกรณ์ของคุณ
เส้นทางภายใน ZIPขนาด

แยกทั้งหมดจะดาวน์โหลดไฟล์ทีละไฟล์ต่อเนื่องกัน หากเบราว์เซอร์ของคุณถามว่าจะอนุญาตการดาวน์โหลดหลายไฟล์จากไซต์นี้หรือไม่ ให้เลือกอนุญาต - มิฉะนั้นให้แยกไฟล์ทีละไฟล์ด้วยปุ่มแยกไฟล์ของพวกมัน ไฟล์ที่แยกออกมาจะถูกบันทึกภายใต้ชื่อไฟล์ธรรมดาของมัน (โฟลเดอร์จะแสดงในรายการเพื่อให้คุณเห็นโครงสร้างของไฟล์บีบอัด แต่เบราว์เซอร์บันทึกไฟล์ดาวน์โหลดแบบแบน)

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ไฟล์บีบอัดของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป ขีดจำกัดที่ซื่อตรงหนึ่งข้อ: ไฟล์บีบอัดถูกแกะในหน่วยความจำของอุปกรณ์ของคุณ ดังนั้น ZIP ที่ใหญ่มาก (หลายร้อยเมกะไบต์) อาจช้าหรือล้มเหลวบนโทรศัพท์ที่มีหน่วยความจำน้อย

วิธีใช้ ตัวเปิดไฟล์ ZIP

  1. วางไฟล์ .zip ของคุณลงบนกล่องด้านบน หรือคลิกมันแล้วเลือกไฟล์บีบอัดจากอุปกรณ์ของคุณ
  2. อ่านรายการ: ทุกรายการปรากฏพร้อมเส้นทางเต็มภายในไฟล์บีบอัดและขนาดจริง (ที่ยังไม่คลาย) ของมัน รายการโฟลเดอร์ถูกทำเครื่องหมายว่า "folder"
  3. คลิกแยกไฟล์ถัดจากไฟล์เดียวใด ๆ เพื่อดาวน์โหลดเพียงไฟล์นั้น หรือใช้แยกไฟล์ทั้งหมดเพื่อดาวน์โหลดทุกอย่างทีละไฟล์ต่อเนื่องกัน

วิธีการทำงาน

ZIP ทุกไฟล์ลงท้ายด้วยไดเรกทอรีกลางที่แสดงรายการทุกรายการ ตำแหน่งที่ข้อมูลของมันอยู่ในไฟล์ และขนาดของมันทั้งที่บีบอัดและไม่บีบอัด หน้านี้ใช้ไลบรารี JSZip ในเบราว์เซอร์ของคุณเพื่ออ่านไดเรกทอรีนั้นในทันทีที่คุณเลือกไฟล์บีบอัด - ซึ่งเป็นเหตุผลว่าทำไมรายการจึงปรากฏทันที ก่อนที่จะมีการแยกอะไรออกมา เมื่อคุณแยกไฟล์ JSZip จะขยาย (ยกเลิก DEFLATE) ข้อมูลของมันในหน่วยความจำ และเบราว์เซอร์ของคุณบันทึกมันเป็นไฟล์ดาวน์โหลดปกติ เพราะทั้งหมดนี้เกิดขึ้นภายในเครื่อง หน้าเดียวกันจึงทำงานแบบออฟไลน์ได้เมื่อโหลดแล้ว และปลอดภัยสำหรับไฟล์บีบอัดที่คุณไม่มีวันส่งไปยังไซต์อัปโหลด

ตัวอย่างที่ทำแล้ว

คุณเปิด backup.zip (4.8 MB) รายการแสดงโฟลเดอร์ photos ที่มี photos/img1.jpg (1.9 MB) และ photos/img2.jpg (2.1 MB) บวก readme.txt (1 KB) ที่ระดับบนสุด คุณต้องการเพียง readme - คลิกปุ่ม แยก ของมันแล้วไฟล์ 1 KB นั้นเพียงไฟล์เดียวจะดาวน์โหลด โดยไม่ต้องแกะรูปภาพเลย

คำถามที่พบบ่อย

เครื่องมือเปิด zip นี้ฟรีหรือไม่?

ใช่ - ฟรี ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดและไม่มีลายน้ำ

ไฟล์ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ ไฟล์บีบอัดถูกอ่านโดย JavaScript (JSZip) ภายในเบราว์เซอร์ของคุณ และไฟล์ที่แยกออกมาจะตรงไปยังไฟล์ดาวน์โหลดของคุณ ZIP และเนื้อหาของมันไม่เคยออกจากอุปกรณ์ของคุณ

มันเปิด ZIP ที่ป้องกันด้วยรหัสผ่านได้หรือไม่?

ไม่ JSZip อ่านไฟล์บีบอัดที่เข้ารหัสไม่ได้ ดังนั้น ZIP ที่ป้องกันด้วยรหัสผ่านจะเปิดที่นี่ไม่สำเร็จ ใช้เครื่องมือบีบอัดบนเดสก์ท็อปสำหรับไฟล์ที่เข้ารหัส

ทำไม แยกทั้งหมด จึงหยุดหลังไฟล์ไม่กี่ไฟล์?

เบราว์เซอร์ป้องกันไม่ให้หน้าดาวน์โหลดหลายไฟล์พร้อมกัน เครื่องมือนี้ดาวน์โหลดไฟล์ทีละไฟล์โดยมีช่วงหยุดสั้น ๆ; หากเบราว์เซอร์ของคุณถาม ให้อนุญาตการดาวน์โหลดหลายไฟล์สำหรับไซต์นี้ - หรือแยกไฟล์ทีละไฟล์ ซึ่งใช้งานได้เสมอ

มันใช้ได้กับไฟล์ RAR, 7z หรือ TAR หรือไม่?

ไม่ - ตัวแยกไฟล์นี้จัดการเฉพาะไฟล์บีบอัด .zip มาตรฐานเท่านั้น RAR และ 7z ใช้รูปแบบการบีบอัดที่แตกต่างกันซึ่งต้องการไลบรารีที่แตกต่างกัน

ตัวเข้ารหัสและถอดรหัส Base64
