JSON-LD 스키마 생성기 - JSON을 손으로 쓰지 않는 구조화 데이터

요약하면: JSON-LD 스키마 생성기는 16가지 타입을 위한 유효한 schema.org 구조화 데이터를 만들어요 - 글, 지역 비즈니스, 제품, 이벤트, 레시피, 사람, 조직, 웹사이트, FAQ 페이지, 방법, 비디오, 책, 코스, 채용 공고, 소프트웨어 앱, 탐색 경로 목록, 그리고 Google이 기대하는 정확한 스크립트 블록으로 감싸요.

구조화된 데이터는 검색 엔진이 페이지를 이해하는 데 도움이 되고 리치 결과를 열 수 있어요. 이 생성기는 JSON을 여러분을 위해 만들어요 - 그리고 복사하기 전에 JSON으로 검증해요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

JSON-LD 스키마 생성기 사용법

  1. 페이지에 맞는 스키마 타입을 선택하세요.
  2. 적용되는 필드를 입력하세요 - 빈 필드는 그냥 빠져요.
  3. 생성을 클릭하고 JSON-LD 블록을 확인하세요.
  4. 페이지 head나 닫는 body 태그 앞에 붙여넣은 뒤, Google의 리치 결과 테스트로 실제 페이지를 테스트하세요.

작동 방식

생성기는 schema.org 어휘로 JavaScript 객체를 조립해요 - @context, @type, 선택한 타입의 속성, Product의 Offer와 AggregateRating, Article의 저자 Person, LocalBusiness PostalAddress 같은 중첩 객체를 포함해요 - 그다음 엄격한 JSON 포맷으로 직렬화하고 표시하기 전에 유효한 JSON임을 증명하기 위해 자체 출력을 다시 파싱해요. 빈 필드는 완전히 생략돼요. 빈 속성이 없는 속성보다 나쁘기 때문이에요. 정직한 범위: 유효한 JSON-LD는 페이지를 적격 리치 결과를 위해; Google이 표시할지 결정하고, 데이터는 페이지에 보이는 것과 일치해야 해요.

자주 묻는 질문

이 생성기는 무료인가요?

네 - 완전히 무료, 회원가입 없음이에요.

이것이 리치 결과를 보장할까요?

어떤 도구도 그것을 보장할 수 없어요. 올바른 JSON-LD는 자격을 갖추게 해줘요; Google은 페이지, 쿼리, 그 정책에 따라 선택해요.

블록을 어디에 붙여넣나요?

페이지의 head 섹션, 또는 닫는 body 태그 바로 앞에요 - Google은 어느 위치에서든 읽어요.

데이터가 제 페이지와 일치해야 하나요?

네. 페이지에 보이지 않는 것을 설명하는 구조화된 데이터는 무시되거나 스팸으로 취급될 수 있어요.

무엇이든 업로드되나요?

아니요. 생성과 검증은 브라우저에서 실행돼요.
