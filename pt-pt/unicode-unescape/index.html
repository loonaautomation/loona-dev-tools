Descodificador de Escapes Unicode

Em resumo: transforme \uXXXX, \u{1F600}, \xXX e os escapes comuns \n / \t de volta em texto real — útil para limpar strings copiadas de código JSON, Java ou JavaScript.
🔒 Privado por conceção: tudo funciona no seu navegador neste dispositivo. A sua entrada nunca é carregada para um servidor.

Exemplo

Entrada:

caf\u00e9 \u2615 \uD83D\uDE00

Resultado:

café ☕ 😀

Sobre este conversor

Texto copiado de código chega cheio de escapes: dumps JSON de serviços Java, ficheiros de localização, saída de registos. Este descodificador inverte as formas padrão — \uXXXX incluindo pares substitutos (que se recombinam em emoji automaticamente), a forma de ponto de código ES6 \u{...}, escapes de bytes \xXX, e os escapes de controlo \n, \t, \r e \\. Deliberadamente não inventa caracteres para escapes malformados: um \u12 perdido na entrada permanece visível na saída, porque eliminar caracteres silenciosamente torna dados fonte avariados mais difíceis de encontrar, não mais fáceis.

Perguntas Frequentes

A saída ainda mostra algumas sequências \u — porquê?

Esses estavam malformados (não quatro dígitos hex) ou com escape duplo na fonte (\\u0041). Descodifique os de escape duplo desfazendo primeiro a barra invertida duplicada.

Pode descodificar um ficheiro JSON inteiro?

Trata bem conteúdos de strings JSON, mas um documento JSON completo é melhor validado pelo Formatador JSON — esta página é para os valores de string dentro dele.

O que é \u{1F600}?

A forma de escape de ponto de código ECMAScript, utilizada quando um carácter excede quatro dígitos hex: \u{1F600} é 😀 sem precisar de um par substituto.
