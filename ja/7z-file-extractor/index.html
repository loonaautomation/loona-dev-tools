7Zファイル抽出ツール - 7Zファイルをオンラインで開く

要するに： 7Zファイル抽出ツールは .7z アーカイブをブラウザで直接開きます。ファイルを選び、内部のすべてを閲覧し、単一ファイルをダウンロードするか、アーカイブ全体をZIPとして再パックしてダウンロードしてください。7-Zipのインストールは不要で、何もアップロードされません。

.7z形式（7-Zipのもの）は、ファイルをほぼ他の何よりも小さく圧縮します。そのため、ゲームアセット、ROMパック、バックアップ、大きなログバンドルが頻繁に.7zとして届きます。問題は、Windowsも電話もそのままでは開けないことです。このページは、完全にあなたのデバイス上で動作するlibarchiveのWebAssembly移植版を使って開きます。

アーカイブ内のファイルサイズ
設計上プライベート： このツールのすべてはブラウザで100%行われます。7zアーカイブは、あなたのデバイス上で動作するWebAssemblyエンジンで読み取られます。アップロードされることは決してなく、保存されることも、私たちに見られることもありません。二つの正直な制限：パスワードで保護された（暗号化された）7zアーカイブは開かれません。このツールはパスワードを要求したり、推測したり、解読したりすることは決してありません。そしてアーカイブはあなたのデバイスのメモリ内で解凍されるため、極めて大きなアーカイブは、低メモリの電話では遅くなることがあります。

7Zファイル抽出ツールの使い方

  1. あなたの .7z ファイルを上のボックスにドロップするか、クリックしてデバイスからファイルを選んでください。
  2. アーカイブが読み取られる間、少しお待ちください。初回使用時に抽出エンジン（約1 MB）が一度読み込まれ、その後はブラウザによってキャッシュされます。
  3. アーカイブ内のファイル一覧を、それぞれのサイズとともに参照します。
  4. 単一ファイルの横の「ダウンロード」をクリックするか、「すべてZIPでダウンロード」を使って、すべてを一つの標準ZIPファイルとして保存してください。

仕組み

7zアーカイブは通常、LZMAまたはLZMA2アルゴリズムでデータを圧縮します。そのため、テキストの多いコンテンツではZIPを上回ります。このページは、WebAssemblyにコンパイルされたlibarchiveでそれらを読み取ります。エンジンは7zヘッダーを解析し、フォルダ構造をデコードして、すべてのエントリを非圧縮サイズとともに一覧表示します。ファイルはダウンロードするときにのみ展開されます。「すべてZIPでダウンロード」オプションは、抽出したファイルをJSZipで詰め直すため、結果は7-Zipなしでどのシステムでも開けます。

実例

ゲームのMODを weapons-pack.7z（42 MB）としてダウンロードします。ページは31ファイルを列挙します：テクスチャ、readme.txt、インストーラーフォルダです。まず、その一つのファイル（12 KB）だけをダウンロードしてreadmeを読み、それが望んだMODであることを確認し、その後でのみ残りをZIPとしてダウンロードします。中を覗くためにソフトウェアをインストールする代わりにです。

よくある質問

これを使うには7-Zipがインストールされている必要がありますか？

いいえ。それがこのページのポイントです。7z形式はブラウザ内のWebAssemblyエンジンでデコードされるため、コンピュータや電話に何もインストールする必要がありません。

どの7z圧縮方式がサポートされていますか？

7-Zipが使う標準的なもの：LZMA、LZMA2、BZIP2、PPMd、通常のコピー（保存）です。デフォルトの7-Zip設定で作られたアーカイブは問題なく開きます。LZMA、LZMA2、BZIP2のバリエーションは、このツールが構築されたときに実際のテストアーカイブに対してすべて検証されました。

私の7zファイルがパスワードを求めます。このツールで開けますか？

いいえ。暗号化された7zアーカイブ（ファイルリストさえ隠される、暗号化ヘッダー付きのものも含みます）は開かれず、ツールはパスワードを推測したり解読したりしようとすることは決してありません。代わりに、パスワードを使って7-Zipで解凍してください。

なぜ抽出されたZIPは時々.7zより大きいのですか？

7zはLZMA2により、通常はZIPのDEFLATEより優れた圧縮を行います。特に、似たファイルをまとめて詰めた場合（ソリッド圧縮）が顕著です。中身のファイルは同一です。詰め方があまりタイトでないだけです。

私のファイルはどこかにアップロードされますか？

いいえ。すべてあなたのデバイス上のブラウザタブで実行されます。アーカイブとその内容がサーバーに触れることは決してありません。そのため、プライベートファイルにも安全です。
