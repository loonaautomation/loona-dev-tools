ตัวตรวจสอบความแตกต่าง - เปรียบเทียบข้อความสองชุดทีละบรรทัด

สรุปสั้น ๆ: ตัวตรวจสอบความแตกต่างเปรียบเทียบข้อความสองเวอร์ชันทีละบรรทัดโดยใช้การเปรียบเทียบลำดับย่อยร่วมที่ยาวที่สุด ไฮไลต์บรรทัดที่เพิ่มเป็นสีเขียวและบรรทัดที่ลบออกเป็นสีแดง และสรุปว่ามีบรรทัดที่เพิ่ม ลบออก และไม่เปลี่ยนแปลงกี่บรรทัด

ไฟล์กำหนดค่าเปลี่ยนไปแล้วมีบางอย่างพัง หรือเอกสารสองเวอร์ชันไม่ตรงกัน - การวางทั้งสองเวอร์ชันที่นี่จะแสดงให้คุณเห็นอย่างชัดเจนว่าบรรทัดใดย้ายไป ภายในไม่กี่วินาที โดยไม่ต้องอัปโหลดเวอร์ชันใดไปที่ใดเลย

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวตรวจสอบความแตกต่าง

  1. วางข้อความต้นฉบับลงในกล่องด้านซ้าย
  2. วางข้อความที่แก้ไขแล้วลงในกล่องด้านขวา
  3. คลิกเปรียบเทียบ
  4. อ่านผลลัพธ์: บรรทัดที่ทำเครื่องหมาย - ถูกลบออก บรรทัดที่ทำเครื่องหมาย + ถูกเพิ่มเข้ามา และบรรทัดที่ไม่มีเครื่องหมายไม่มีการเปลี่ยนแปลง

วิธีการทำงาน

ตัวตรวจสอบแยกข้อความทั้งสองเป็นบรรทัดและคำนวณลำดับย่อยร่วมที่ยาวที่สุด (LCS) ของรายการบรรทัดทั้งสอง - ชุดบรรทัดที่ใหญ่ที่สุดที่ปรากฏในลำดับเดียวกันในทั้งสอง บรรทัดในลำดับย่อยไม่มีการเปลี่ยนแปลง; บรรทัดในต้นฉบับแต่ไม่อยู่ในลำดับย่อยถูกลบออก และบรรทัดที่มีเฉพาะในฉบับแก้ไขถูกเพิ่มเข้ามา นี่คือตระกูลอัลกอริทึมเดียวกับที่อยู่เบื้องหลังเครื่องมืออย่าง Unix diff ดังนั้นการเปรียบเทียบจึงเรียงตัวตามวิธีที่คุณคาดหวังแม้เมื่อบล็อกทั้งหมดเคลื่อนไปหนึ่งหรือสองบรรทัด

ตัวอย่างที่ทำแล้ว

การเปรียบเทียบรายการซื้อของสามบรรทัดสองเวอร์ชันที่ "eggs" กลายเป็น "egg whites" จะแสดงบรรทัดสีแดงหนึ่งบรรทัดและบรรทัดสีเขียวหนึ่งบรรทัด โดยอีกสองบรรทัดไม่เปลี่ยนแปลง - สรุปเป็นเพิ่ม 1 ลบ 1 ไม่เปลี่ยนแปลง 2 แทนที่จะเป็นกำแพงข้อความที่เกือบเหมือนกันให้เพ่งดู

คำถามที่พบบ่อย

ตัวตรวจสอบความแตกต่างนี้ฟรีหรือไม่?

ใช่ - ฟรีทั้งหมด ไม่ต้องสมัครสมาชิกและไม่มีขีดจำกัดรายวัน

การเปรียบเทียบเป็นแบบบรรทัดหรือแบบตัวอักษร?

แบบบรรทัด เหมือน Unix diff: บรรทัดหนึ่งไม่เปลี่ยนแปลง ถูกลบ หรือถูกเพิ่ม หากคำหนึ่งคำเปลี่ยนแปลงภายในบรรทัดยาว ทั้งบรรทัดจะแสดงเป็นการลบหนึ่งรายการบวกการเพิ่มหนึ่งรายการ

มันเปรียบเทียบข้อความได้ใหญ่แค่ไหน?

สูงสุด 1,500 บรรทัดในแต่ละด้าน ตาราง LCS เติบโตตามผลคูณของจำนวนบรรทัดทั้งสอง ดังนั้นไฟล์ที่ใหญ่มากเปรียบเทียบได้ดีกว่าด้วยเครื่องมือเปรียบเทียบบนเดสก์ท็อป

มันเพิกเฉยช่องว่างหรือตัวพิมพ์หรือไม่?

ไม่ - บรรทัดต้องตรงกันพอดีจึงจะนับว่าไม่เปลี่ยนแปลง ดังนั้นบรรทัดที่เพียงมีช่องว่างต่อท้ายเพิ่มขึ้นจะแสดงว่าเปลี่ยนแปลง ความเข้มงวดนั้นเป็นไปโดยจงใจ: มันมักเป็นสิ่งที่คุณต้องการพอดีเมื่อเปรียบเทียบไฟล์กำหนดค่าและโค้ด

ข้อความของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ การเปรียบเทียบเกิดขึ้น 100% ในเบราว์เซอร์ของคุณ ข้อความทั้งสองไม่เคยออกจากอุปกรณ์ของคุณ

เครื่องมือสำหรับนักพัฒนาที่เกี่ยวข้อง

CSV

ตัวแปลง JSON เป็น CSV

เปลี่ยนอาร์เรย์ JSON ของออบเจ็กต์เป็นไฟล์ CSV ที่สะอาด - การรวมกันของทุกคีย์ การใส่เครื่องหมายคำพูดที่เหมาะสม คลิกเดียว

.*

ตัวทดสอบ Regex

ทดสอบ Regular Expression แบบสด - การจับคู่ถูกไฮไลต์ กลุ่มที่จับแสดงรายการ จำนวนแสดงไว้

CSS

ตัวย่อขนาดและจัดรูปแบบ CSS

ย่อขนาด CSS เพื่อลดขนาดไฟล์ หรือจัดรูปแบบมันกลับเป็นโค้ดที่อ่านง่ายและเยื้องเรียบร้อย

ฝังเครื่องมือนี้บนเว็บไซต์ของคุณ — ฟรี

เพิ่มเครื่องมือนี้ลงในเว็บไซต์หรือบล็อกของคุณเอง — มันฟรีทั้งหมด ไม่ต้องสมัครสมาชิก และแสดงเวอร์ชันล่าสุดเสมอ คัดลอกโค้ดด้านล่างแล้ววางลงในหน้าของคุณตรงตำแหน่งที่คุณต้องการให้เครื่องมือปรากฏ การเก็บบรรทัดเครดิตเล็ก ๆ “Powered by Loona Automation” ไว้ใต้ตัวฝังจะช่วยให้เครื่องมือนี้ยังคงฟรีต่อไป — แต่คุณมีอิสระที่จะจัดสไตล์หรือลบมันออกก็ได้; เครื่องมือทำงานได้ทั้งสองแบบ
