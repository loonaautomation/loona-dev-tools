CSV 資料提取工具 - 從混亂資料中提取聯絡方式

簡而言之： CSV 資料提取器掃描凌亂的 CSV——或任何貼上的文字——並提取每個電子郵件地址、電話號碼和 URL，形成乾淨、已去重的列表，可直接下載。

聯絡方式藏在匯出檔案、筆記和日誌中，沒有乾淨的列。貼上這團亂麻；拿回三個整齊的列表。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 CSV 資料提取工具

  1. 貼上您的 CSV 或任何包含聯絡方式的文字。
  2. 點選“解壓”。
  3. 審查三個列表——電子郵件、電話號碼、URL——帶計數。
  4. 把任何列表下載為 .txt 檔案。

它如何工作

提取使用為現實世界的混亂而調校的模式匹配：電子郵件遵循標準地址形態；URL 既捕捉 https:// 連結，也捕捉裸露的 www. 地址，並修剪尾隨標點；電話候選必須包含 7 到 15 個數字，這過濾掉了只是看起來像數字的年份、訂單號和價格。結果以不區分大小寫的方式去重，保留找到的第一個拼寫。模式是誠實的啟發法——ID 內部一個長得像電話號碼的字串仍可能出現，所以在使用之前請快速瀏覽列表。

常見問題

這個工具免費嗎？

是的——完全免費，無需註冊。

這與 Text Tools 的電子郵件提取工具有什麼不同？

那個工具從文字中提取電子郵件。這個提取三種資料型別——電子郵件、電話號碼和 URL——併為 CSV/資料清理工作流構建，每種型別都有可下載的列表。

它能從檔案提取嗎？

貼上檔案的內容——或先在 CSV 檢視器中開啟檔案。無論哪種方式，一切都保留在您的裝置上。

能保證結果乾淨嗎？

它們是模式匹配、去重並經過數字過濾，但在把它們匯入任何地方之前，最後粗略看一遍是明智的。

我的資料會被上傳嗎？

不會。解壓 100% 在您的瀏覽器中執行。
