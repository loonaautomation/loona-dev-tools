منسّق ومدقّق JSON - طباعة جميلة وتصغير JSON

باختصار: يفحص منسّق JSON ‏JSON الخاص بك، يطبّعه جميلاً بمسافة بادئة من 2 مسافة أو 4 مسافات أو علامة جدولة، يصغّره عند الطلب، وإذا كان شيء خاطئاً يخبرك بالسطر والعمود الدقيقين للمشكلة.

‏JSON المكسور هو أكثر تأخير خمس دقائق شيوعاً في يوم المطوّر - فاصلة واحدة مفقودة وتفشل الحمولة كلها. الصق JSON أدناه: إذا كان صالحاً تحصل على ناتج نظيف وقابل للقراءة؛ وإذا لم يكن، تحصل على موضع الخطأ الدقيق بدلاً من "فشل التحليل" عديم الفائدة.

خاص بالتصميم: كل شيء في هذه الأداة يحدث 100% في متصفحك عبر JavaScript. إدخالك لا يُرفع إلى خادم أبداً، لا يُخزّن أبداً ولا نراه أبداً - أغلق علامة التبويب وكل شيء يختفي.

كيفية استخدام منسّق JSON

  1. الصق أو اكتب JSON الخاص بك في المربع العلوي.
  2. اختر أسلوب مسافة بادئة - 2 مسافات، 4 مسافات أو علامة جدولة.
  3. انقر تنسيق / تحقّق لناتج مقروء، أو تصغير لأصغر صيغة صالحة.
  4. انسخ النتيجة أو نزّلها كملف .json.

كيف يعمل

تستخدم الأداة محلّل JSON المدمج في متصفحك - نفس المحلّل الصارم الذي يستخدمه كود JavaScript الخاص بك - لذا الضوء الأخضر هنا يعني أن JSON الخاص بك صالح حقاً. الطباعة الجميلة تعيد تسلسل القيمة المحلّلة بمسافتك البادئة المختارة؛ ترتيب المفاتيح محفوظ بالضبط كما كُتب. التصغير يزيل كل مسافة وسطر جديد غير ضروريين دون تغيير قيمة واحدة. عندما يفشل التحليل، تحوّل الأداة موضع حرف المحلّل إلى سطر وعمود وتُظهر لك السطر المخالف.

مثال محلول

تستلم {"user":"ahmed","roles":["admin","editor"],"active":true} من API. منسّقاً بـ 2 مسافة يصبح مستنداً نظيفاً من تسعة أسطر تستطيع قراءته فعلياً - وإذا حذفت الفاصلة بعد "ahmed" بالخطأ، تبلّغ الأداة عن الخطأ عند السطر والعمود الدقيقين بدلاً من تركك تصطاده.

الأسئلة الشائعة

هل منسّق JSON هذا مجاني؟

نعم - مجاني بالكامل، دون تسجيل، دون حد حجم ودون حد يومي.

ما الذي يحدث عندما يكون JSON الخاص بي غير صالح؟

تحصل على رسالة خطأ المحلّل بالإضافة إلى السطر والعمود الدقيقين حيث فشل التحليل، ونص ذلك السطر، بحيث تستطيع إصلاحه في ثوانٍ.

هل يغيّر التنسيق بياناتي؟

لا. التنسيق يغيّر المسافات البيضاء فقط. التصغير يزيل المسافات البيضاء فقط. المفاتيح والقيم وترتيبها لا تُلمس.

هل يُرفع JSON الخاص بي إلى خادم؟

لا. التحليل والتنسيق يحدثان 100% في متصفحك. حمولات API وملفات التهيئة لا تغادر جهازك أبداً.

هل أستطيع تنسيق JSON كبير فعلاً؟

نعم - الحد العملي هو ذاكرة جهازك. ملفات من عدة ميغابايتات تُنسّق في أقل بكثير من ثانية على حاسوب محمول نموذجي.
