Pemformat & Pengesah JSON - Cetak Rapi dan Minifikasi JSON

Singkatnya: Pemformat JSON menyemak JSON Anda, mencetaknya rapi dengan indentasi 2-ruang, 4-ruang, atau tab, meminifikasinya atas permintaan, dan jika ada yang salah ia memberi tahu Anda baris dan lajur tepat masalahnya.

JSON yang rusak adalah penundaan lima minit paling umum dalam hari seorang pembangun - satu koma yang hilang dan seluruh payload gagal. Tampalkan JSON Anda di bawah: jika valid, Anda mendapatkan output yang bersih dan dapat dibaca; jika tidak, Anda mendapatkan posisi ralat yang tepat alih-alih "parse failed" yang tidak berguna.

Peribadi berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di pelayar Anda dengan JavaScript. Input Anda tidak pernah dimuat naik ke pelayan, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Cara menggunakan Pemformat JSON

  1. Tampal atau taip JSON Anda ke kotak atas.
  2. Pilih gaya indentasi - 2 ruang, 4 ruang, atau tab.
  3. Klik Format / Pengesahan untuk output yang dapat dibaca, atau Minifikasi untuk bentuk valid terkecil.
  4. Salin hasilnya atau muat turun sebagai fail .json.

Cara kerja

Alat ini menggunakan penghurai JSON bawaan pelayar Anda - penghurai ketat yang sama yang digunakan kode JavaScript Anda sendiri - jadi lampu hijau di sini bererti JSON Anda benar-benar valid. Pencetakan rapi menyerialkan ulang nilai yang ter-parsing dengan indentasi pilihan Anda; urutan kunci dipertahankan persis seperti tertulis. Minifikasi mengpadam setiap ruang dan baris baru yang tidak perlu tanpa mengubah satu nilai pun. Ketika parsing gagal, alat ini menukar posisi aksara penghurai menjadi baris dan lajur dan menunjukkan baris yang bermasalah kepada Anda.

Contoh yang dikerjakan

Anda menerima {"user":"ahmed","roles":["admin","editor"],"active":true} dari API. Diformat dengan 2 ruang ia menjadi dokumen sembilan baris bersih yang benar-benar dapat Anda baca - dan jika Anda tidak sengaja mengpadam koma setelah "ahmed", alat melaporkan error pada baris dan lajur tepat alih-alih meninggalkan Anda untuk mencarinya.

Pertanyaan yang Sering Diajukan

Apakah pemformat JSON ini percuma?

Ya - sepenuhnya percuma, tanpa pendaftaran, tanpa batas saiz, dan tanpa batas harian.

Apa yang terjadi ketika JSON saya tidak valid?

Anda mendapatkan pesan error penghurai plus baris dan lajur tepat tempat parsing gagal, dan teks baris itu, jadi Anda dapat memperbaikinya dalam kiraan saat.

Apakah pemformatan mengubah data saya?

Tidak. Pemformatan hanya mengubah whitespace. Minifikasi hanya mengpadam whitespace. Kunci, nilai, dan urutannya tidak disentuh.

Apakah JSON saya dimuat naik ke pelayan?

Tidak. Parsing dan pemformatan terjadi 100% di pelayar Anda. Payload API dan fail konfigurasi tidak pernah meninggalkan peranti Anda.

Dapatkah saya memformat JSON yang sangat besar?

Ya - batas praktis adalah ingatan peranti Anda. Fail beberapa megabait terformat dalam waktu jauh di bawah satu saat di laptop biasa.
