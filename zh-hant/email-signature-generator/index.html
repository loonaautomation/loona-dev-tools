HTML 郵件簽名生成器 - 能在電子郵件客戶端中存活的專業落款

簡而言之： HTML 電子郵件簽名生成器將您的簽名構建為電子郵件安全的表格 HTML——這是 Gmail、Outlook 和 Apple Mail 都能可靠渲染的唯一佈局技術——帶有您的強調色、聯絡連結和可選的標語。

電子郵件客戶端會剝離現代 CSS，這正是用 div 構建的簽名在 Outlook 中分崩離析的原因。這個簽名用老式、正確的方式構建：只有表格和內聯樣式。

預覽

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 HTML 郵件簽名生成器

  1. 填寫您的姓名、職位和公司。
  2. 新增電話、電子郵件和網站——它們會變成可點選的連結。
  3. 選擇一個強調色和一個可選標語。
  4. 檢查預覽，然後複製 HTML（或把渲染好的預覽直接複製到 Gmail 的簽名編輯器中）。

它如何工作

電子郵件 HTML 是一個時間膠囊：Outlook 的 Word 引擎忽略 flexbox、網格和大多數現代 CSS，所以專業的簽名仍然用巢狀表格和內聯樣式構建——這正是本生成器輸出的。聯絡方式變成真實的 tel:、mailto: 和網頁連結，強調條和姓名使用您的顏色，每個文字值都經過轉義，這樣帶 & 的姓名不會破壞標記。不使用任何影象，所以簽名即時顯示，永遠不會觸發“下載圖片”警告。

常見問題

這個生成器免費嗎？

是的——完全免費，無需註冊。

我如何在 Gmail 中新增它？

複製渲染後的預覽（不是程式碼），然後在 Gmail 中進入 設定 → 檢視所有設定 → 簽名，建立一個簽名並貼上。格式會被帶過去。

為什麼用表格而不是 div？

桌面版 Outlook 用 Microsoft Word 的引擎渲染郵件，它只能可靠地支援表格和內聯樣式。

我可以新增標誌照片嗎？

本生成器按設計只生成文字——無影象的簽名即時載入，永不被阻止。如果您需要託管的徽標，可以手工新增到 HTML 中。

有任何東西被上傳嗎？

不會。您的詳細資訊從不離開您的瀏覽器。
