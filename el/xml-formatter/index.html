Μορφοποιητής & Επικυρωτής XML - Ομορφύνετε, Συμπιέστε και Ελέγξτε την Καλή Μορφή

Εν συντομία: ο Μορφοποιητής XML εκτυπώνει ωραία μπλεγμένο XML με καθαρή εσοχή, το συμπιέζει πίσω κάτω, και επικυρώνει την καλή μορφή - ισορροπημένες ετικέτες, σωστή ένθεση - αναφέροντας την ακριβή αναντιστοιχία όταν κάτι είναι λάθος.

Το XML φτάνει ως μία αδιάβαστη γραμμή από API και εξαγωγές ρυθμίσεων. Επικολλήστε το εδώ για να το διαβάσετε, να το συρρικνώσετε, ή να μάθετε γιατί ένας αναλυτής το απέρριψε.

Ιδιωτικό εκ σχεδιασμού: τα πάντα σε αυτό το εργαλείο συμβαίνουν 100% στο πρόγραμμα περιήγησής σας με JavaScript. Η είσοδός σας δεν ανεβαίνει ποτέ σε διακομιστή, δεν αποθηκεύεται ποτέ και δεν φαίνεται ποτέ από εμάς - κλείστε την καρτέλα και τα πάντα χάνονται.

Πώς να χρησιμοποιήσετε τον Μορφοποιητή & Ελεγκτή XML

  1. Επικολλήστε το XML σας.
  2. Κάντε κλικ στο Μορφοποίηση για να το ομορφύνετε, Συμπίεση για να το συμπιέσετε ή μόνο Επικύρωση για να το ελέγξετε.
  3. Διαβάστε τη γραμμή κατάστασης - ονομάζει την ακριβή αναντιστοιχία ετικέτας όταν το XML είναι σπασμένο.
  4. Αντιγράψτε το αποτέλεσμα.

Πώς λειτουργεί

Η επικύρωση εδώ ελέγχει την καλή μορφή XML με έναν αναλυτή στοίβας ετικετών: κάθε ετικέτα ανοίγματος πρέπει να κλείνει με τη σωστή σειρά, οι ετικέτες αυτόματου κλεισίματος και οι δηλώσεις αναγνωρίζονται, τα σχόλια και οι ενότητες CDATA παραλείπονται σωστά, και ένα ακατέργαστο < σε περιεχόμενο κειμένου σημειώνεται επειδή πρέπει να διαφύγει. Αυτός είναι ο έλεγχος που κάθε αναλυτής XML εφαρμόζει πρώτα - ένα έγγραφο που τον αποτυγχάνει δεν μπορεί να αναλυθεί καθόλου. (Δεν είναι επικύρωση σχήματος έναντι ενός DTD ή XSD, που χρειάζεται το ίδιο το σχήμα.) Η μορφοποίηση μετά επαναεσοχίζει ανά βάθος ένθεσης· η συμπίεση αφαιρεί τα κενά μεταξύ ετικετών.
