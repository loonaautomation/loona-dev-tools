RAR 转 ZIP 转换器 - 把 .rar 归档变成 .zip

简而言之： RAR 转 ZIP 转换器在您自己的设备上解压 .rar 归档，并将完全相同的文件和文件夹重新打包为标准的 .zip——每个操作系统无需额外软件就能打开的格式。

有人给您发了一个 .rar 文件，而您的手机——或同事没有 WinRAR 的 Windows 电脑——打不开它。ZIP 是通用格式：Windows、macOS、Android 和 iOS 都内置打开它。本工具完全在您的浏览器中把 RAR 转换为 ZIP，所以归档永远不会先去服务器。

如何使用 RAR 转 ZIP 转换器

  1. 把您的 .rar 文件拖到上面的框中，或点击它从您的设备中选择文件。
  2. 点击“转换为 ZIP”。本工具在您的设备上读取归档，并重新打包每个文件，保持文件夹结构。
  3. 查看摘要：里面有多少文件，以及新 ZIP 的大小。
  4. 点击“下载”保存 .zip 文件。它能用任何现代系统的内置工具打开。

它如何工作

RAR 是由 WinRAR 的制造商创建的专有归档格式，所以大多数系统在没有额外软件的情况下无法打开它。本页加载 libarchive 库的 WebAssembly 构建版本（约 1 MB，只在您转换时加载），在您的浏览器内存中读取 RAR 归档，然后使用 JSZip 把相同的文件和文件夹写入一个全新的、带 DEFLATE 压缩的标准 ZIP。文件本身没有任何改变——只有包装。只有单向：没有免费工具能创建真正的 RAR 归档，因为 RAR 压缩格式是许可授权的——这正是从 RAR 转换出去如此有用的原因。

实例

一位朋友从一台旧 Windows 电脑发来 photos.rar（48 MB）。您的手机拒绝打开它。您把文件拖到这里，工具在 3 个文件夹中找到 126 张照片，并生成 photos.zip（47.8 MB）。这个 ZIP 可以直接从您的文件应用中打开，文件夹完好无损，您可以把它转发给任何人——双方都不需要 WinRAR。

常见问题

这个 RAR 转 ZIP 转换器免费吗？

是的——免费，无需注册，没有限制，也没有水印。

我的文件会被上传到服务器吗？

不会。转换在您的浏览器中用 WebAssembly 归档引擎和 JSZip 运行。您的归档及其内容从不离开您的设备。

本工具能创建 RAR 文件，或把 ZIP 转回 RAR 吗？

不会——而且没有任何免费工具能做到。创建 RAR 归档需要获得许可的 WinRAR 编码器。本工具只从 RAR 转换为 ZIP，这正是让文件更容易打开和分享的方向。

我的 RAR 受密码保护。它能用吗？

不会。受密码保护（加密）的 RAR 归档无法被本工具打开。请先在 WinRAR 或 7-Zip 等桌面归档工具中移除密码，然后转换不受保护的副本。

文件夹结构和文件名会保持不变吗？

是的。每个文件都会按其在 RAR 内的相同路径重新打包，包括嵌套文件夹。不支持多部分 RAR 集（.part1.rar、.part2.rar...）——请先将它们合并为单个归档。
