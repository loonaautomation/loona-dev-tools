Extractor de archivos GZ - Descomprime archivos GZ en línea

En resumen: el Extractor de archivos GZ descomprime un único archivo .gz en tu navegador y te devuelve el archivo original (un registro, una exportación CSV, un volcado de base de datos) con su nombre original restaurado. Nada se sube.

Un archivo .gz no es un archivo lleno de archivos: es exactamente un archivo, comprimido con gzip, el caballo de batalla del mundo Unix. Los registros de servidor, las exportaciones de datos y los volcados de bases de datos viajan así, y Windows no tiene una forma integrada de abrirlos. Esta página descomprime el archivo con el propio motor gzip integrado de tu navegador (la API DecompressionStream), así que es rápido y completamente privado.

Suelta tu archivo .gz aquí o haz clic para elegir un archivo de tu dispositivo
Privado por diseño: todo en esta herramienta sucede 100% en tu navegador, usando la descompresión gzip integrada en el propio navegador. Tu archivo .gz nunca se sube a un servidor, nunca se almacena y nunca lo vemos nosotros. Un límite honesto: la descompresión sucede en la memoria de tu dispositivo, así que un .gz que se expande a varios gigabytes puede tener dificultades en un teléfono con poca memoria.

Cómo usar el Extractor de archivos GZ

  1. Suelta tu archivo .gz en el cuadro de arriba, o haz clic en él y elige el archivo de tu dispositivo.
  2. El archivo se descomprime inmediatamente: busca la línea que muestra el nombre original del archivo y su tamaño completo.
  3. Haz clic en Descargar archivo descomprimido para guardar el archivo original (por ejemplo access.log desde access.log.gz).

Cómo funciona

Gzip guarda un pequeño encabezado (incluido el nombre original del archivo, cuando la herramienta que lo creó registró uno), los datos comprimidos con el algoritmo DEFLATE y una suma de comprobación más el tamaño original al final. Los navegadores modernos traen un decodificador gzip nativo integrado (el mismo que usan para recibir páginas web comprimidas) y esta página pasa tu archivo por él con la API DecompressionStream. No se descarga ninguna biblioteca ni se envía nada a ningún sitio: el navegador infla los datos y te entrega los bytes originales.

Ejemplo resuelto

Tu servidor te da access.log.gz (2.1 MB). Lo sueltas aquí y se descomprime a access.log (18.4 MB) en aproximadamente un segundo. Lo descargas y lo abres en un editor de texto para encontrar el error de anoche, sin instalar una sola herramienta.

Preguntas frecuentes

¿Cuál es la diferencia entre .gz y .tar.gz?

Un archivo .gz contiene exactamente un archivo comprimido. Un .tar.gz primero agrupa muchos archivos en un archivo TAR y luego comprime ese paquete con gzip, así que contiene un árbol de archivos completo. Para .tar.gz, usa el Extractor de archivos TAR.GZ enlazado abajo.

¿Tendrá el archivo descomprimido el nombre correcto?

Sí: esta herramienta restaura el nombre original eliminando la terminación .gz (access.log.gz se convierte en access.log). Eso coincide con el nombre registrado cuando el archivo se comprimió en la gran mayoría de los casos.

¿Esta herramienta puede abrir archivos .zip o .rar que terminan en .gz por error?

No: renombrar un archivo no cambia lo que hay dentro. Si el contenido no es realmente datos gzip, la descompresión falla con un mensaje claro. Usa el Extractor de archivos comprimidos para ZIP, RAR y otros archivos reales.

¿Hay un límite de tamaño?

No hay un límite integrado en la herramienta, pero el archivo descomprimido se mantiene en la memoria de tu navegador. Los registros y exportaciones cotidianos (hasta unos pocos cientos de megabytes) están bien en la mayoría de los dispositivos; los volcados de varios gigabytes se manejan mejor en un escritorio con una herramienta nativa.

¿Mis archivos se suben a un servidor?

No. La descompresión usa el propio motor integrado del navegador en tu dispositivo. El archivo nunca sale de tu máquina: ni siquiera hay una descarga de biblioteca para esta herramienta.
