CSS 박스 섀도우 생성기 - 겹친, 현실적인 그림자를 시각적으로

요약하면: CSS 박스 그림자 생성기는 box-shadow CSS를 층층이 만들어요 - 오프셋, 흐림, 확산, 색상, 불투명도, 인셋 - 실시간 미리보기와 함께, 카드와 버튼이 하나의 평평한 회색 흐림 대신 현실적인 깊이를 얻어요.

거친 그림자 하나는 가짜처럼 보여요; 부드러운 레이어 두세 개는 빛처럼 보여요. 이 생성기는 겹치기를 쉽게 하고 조정하면서 결과를 보여줘요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

CSS 박스 섀도우 생성기 사용법

  1. 첫 번째 레이어를 조정하세요: 수직 오프셋과 블러가 대부분의 일을 해요.
  2. 부드러움을 위해 색상을 설정하고 불투명도를 낮추세요(0.1-0.3이 현실적인 범위예요).
  3. 접촉 깊이를 위한 두 번째, 더 촘촘한 레이어를 추가하거나, 안쪽 그림자는 Inset을 선택하세요.
  4. 생성된 CSS를 복사하세요.

작동 방식

box-shadow 레이어는 offset-x offset-y blur spread colour, 그리고 여러 레이어는 쉼표로 구분돼요 - 첫 번째 레이어가 맨 위에 그려져요. 현실적인 높낮이는 보통 작고 진한 접촉 그림자와 크고 부드러운 주변 그림자를 짝지어 표현하므로, 이 도구는 단일 그림자가 아니라 레이어를 중심으로 만들었어요. 색상은 rgba()로 출력되어 불투명도가 색상과 함께 전달되고, 미리보기 상자는 키를 누를 때마다 업데이트돼요.

자주 묻는 질문

이 생성기는 무료인가요?

네 - 완전히 무료, 회원가입 없음이에요.

레이어를 몇 개 추가할 수 있나요?

원하는 만큼 많이 - CSS 자체에는 실질적인 제한이 없지만, 레이어 2-3개면 대부분의 디자인을 커버해요.

어떤 값이 그림자를 자연스럽게 보이게 하나요?

적당한 수직 오프셋, 넉넉한 블러, 낮은 불투명도(0.1-0.3)예요. 완전한 불투명도의 순수한 검정은 거의 진짜처럼 보이지 않아요.

인셋 그림자란 무엇인가요?

요소의 테두리 바깥이 아니라 안에 그려지는 그림자 - 눌리거나 움푹 들어간 효과에 사용돼요.

무엇이든 업로드되나요?

아니요. 모든 것이 브라우저에서 실행돼요.
