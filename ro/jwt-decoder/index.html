Decodor JWT - Citește antetul și payload-ul, verifică expirarea

Pe scurt: Decodorul JWT împarte un JSON Web Token în antet și încărcătură, le arată pe ambele ca JSON lizibil și traduce marcajele de expirare și de emitere în date simple. Nu - și niciun decodor nu poate - dovedește că tokenul este autentic.

Un JWT arată ca un șir lung ilizibil, dar primele două părți sunt doar JSON codificat Base64url. Lipește un token pentru a citi ce pretinde - pentru cine este, când expiră - în timpul depanării. Folosește-l doar pentru inspecție; încrederea reală necesită verificarea semnăturii pe un server.

Important: acest decodor face NU verifică semnătura. Citește doar conținutul tokenului. Nu avea niciodată încredere într-un JWT decodificat singur - oricine poate crea sau altera un token neverificat. Validează întotdeauna tokenurile corespunzător pe serverul tău.
Privat prin concepție: totul în acest instrument se întâmplă 100% în browserul tău cu JavaScript. Datele tale introduse nu sunt încărcate niciodată pe un server, nu sunt stocate și nu sunt văzute de noi - închide fila și totul a dispărut.

Cum se folosește Decodorul JWT

  1. Lipește tokenul complet (toate cele trei părți) în casetă.
  2. Dă clic pe Decodifică tokenul.
  3. Citește antetul și payload-ul și verifică linia de expirare - apoi verifică tokenul corespunzător în propriul tău sistem înainte de a avea încredere în el.

Cum funcționează

Un JWT este trei șiruri Base64url unite prin puncte: header.payload.signature. Antetul numește algoritmul de semnare; încărcătura poartă pretenții precum sub (subiect), iat (emis la) și exp (expirare, ca marcaj temporal Unix în secunde). Acest instrument decodează primele două părți din Base64url în JSON - exact aceeași decodare pe care o face codul tău - și convertește pretențiile numerice de timp în date umane. A treia parte, semnătura, este arătată ca prezentă, dar NU este verificată: verificarea ei are nevoie de cheia secretă sau publică și trebuie să se întâmple în backend-ul tău.

Exemplu rezolvat

Decodarea tokenului exemplu clasic arată antetul {"alg":"HS256","typ":"JWT"} și o încărcătură cu sub "1234567890" și iat 1516239022 - pe care instrumentul o afișează ca "Thu, 18 Jan 2018 01:30:22 GMT", mult mai ușor de înțeles decât numărul brut.

Întrebări frecvente

Acest decodor JWT este gratuit?

Da - gratuit, fără înregistrare, fără limite.

Acest instrument verifică tokenul?

Nu. Doar decodifică. Un token decodificat nu dovedește nimic despre autenticitate - oricine poate scrie orice payload și îl poate codifica. Verificarea semnăturii cere cheia și aparține serverului tău.

De ce payload-ul pare lizibil?

Părțile JWT sunt codificate, nu criptate. Codificarea este pentru transport, nu pentru secret - nu pune niciodată secrete într-un payload JWT.

Este sigur să lipesc un token real aici?

Tokenul tău este decodificat 100% în browserul tău și nu este încărcat niciodată. Chiar și așa, o bună practică este să eviți lipirea tokenurilor live de producție în orice instrument - folosește un token de test cu aceeași formă.

Ce înseamnă "exp"?

Ora de expirare a tokenului ca marcaj temporal Unix în secunde. Acest instrument o convertește într-o dată lizibilă și îți spune dacă a expirat deja.
