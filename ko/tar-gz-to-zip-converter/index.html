TAR.GZ를 ZIP으로 변환 - .tar.gz와 .tgz를 .zip으로 바꾸기

요약하면: TAR.GZ를 ZIP으로 변환기는 기기에서 .tar.gz(또는 .tgz) 아카이브의 두 층을 모두 풀어요 - gzip 먼저, 그다음 tar - 그리고 파일을 단일 표준 .zip으로 다시 묶어요.

.tar.gz는 하나의 외투를 입은 두 가지 형식이에요: tar로 묶인 파일들을 gzip으로 압축한 것이에요. Linux는 소스 릴리스, 백업, 로그 등 곳곳에서 이를 만들지만 Windows와 휴대폰은 기본적으로 열 수 없어요. 이 변환기는 두 층을 브라우저에서 로컬로 풀어 평범한 ZIP 하나를 건네줘요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 파일은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요. 정직한 제한 하나: 변환은 기기 메모리에서 일어나, 매우 큰 아카이브(수백 메가바이트)는 메모리가 적은 휴대폰에서 느리거나 실패할 수 있어요.

TAR.GZ를 ZIP으로 변환 사용법

  1. .tar.gz 또는 .tgz 파일을 위 상자에 놓거나, 클릭해 기기에서 파일을 고르세요.
  2. ZIP으로 변환을 클릭하세요. gzip과 tar 층이 모두 기기에서 풀리고 파일이 ZIP으로 다시 묶여요.
  3. 요약을 확인하세요: 찾은 파일 수와 새 ZIP의 크기예요.
  4. 다운로드를 클릭해 .zip 파일을 저장하세요 - 모든 시스템의 내장 도구로 열려요.

작동 방식

내부적으로 이 페이지는 파일을 libarchive의 WebAssembly 빌드에 건네, gzip 래퍼와 그 안의 tar 아카이브를 하나의 스트림으로 이해해요 - Linux에서 tar -xzf가 처리하는 방식 그대로예요. 추출된 파일은 그다음 JSZip에 의해 신선한 ZIP에 써져요, 각각 원래 경로에요. 이것과 일반 .gz 파일의 차이에 유의하세요: .tar.gz는 많은 파일을 포함하고, 단독 .gz는 보통 단일 파일을 감싸요(그것이 GZ 파일 추출기가 있는 이유예요). 이 페이지는 .tar.gz와 단축된 .tgz 철자를 모두 받아들여요 - 같은 형식이에요.

풀이된 예시

오픈 소스 도구의 release-2.4.tar.gz(18 MB)를 Windows PC에 다운로드해요. 도구는 여기서 풀고 같은 폴더에 같은 86개 파일이 포함된 release-2.4.zip(19 MB)을 만들어요 - 탐색기에서 열 준비가 됐고, Linux도 추가 소프트웨어도 필요 없어요.

자주 묻는 질문

이 TAR.GZ를 ZIP으로 변환하는 도구는 무료인가요?

네 - 무료, 회원가입 없음, 제한 없음, 워터마크 없음이에요.

파일이 서버에 업로드되나요?

아니요. 두 층이 모두 풀리고 ZIP은 전적으로 브라우저에서 만들어져요; 아무것도 기기를 떠나지 않아요.

.tar.gz와 .tgz의 차이는 무엇인가요?

없어요 - .tgz는 그저 .tar.gz의 짧아진 철자로, 한때 세 글자 확장자만 허용하던 시스템을 위해 만들어졌어요. 이 도구는 둘 다 받아들여요.

제 파일은 .tar.gz가 아니라 일반 .gz예요. 무엇을 사용해야 하나요?

일반 .gz는 단일 압축 파일을 감싸지, 파일이 많은 아카이브가 아니에요. GZ 파일 추출기를 사용해 원래 파일을 다시 꺼내세요.

ZIP이 왜 .tar.gz와 거의 같은 크기인가요?

두 형식 모두 잘 압축돼요 - tar에는 gzip, ZIP 안에는 DEFLATE - 그래서 비슷한 출력 크기가 예상돼요. 이득은 호환성이에요: ZIP은 어디서든 열려요.
