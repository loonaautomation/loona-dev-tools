Descodificador de Base58 para Texto

Em resumo: cole uma string Base58 e descodifique-a de volta para os bytes originais como texto UTF-8, com a regra leading-1 = zero-byte tratada.
🔒 Privado por concepção: tudo funciona no seu navegador neste dispositivo. A sua entrada nunca é carregada para um servidor.

Exemplo

Entrada:

2NEpo7TZRRrLZSi2U

Resultado:

Hello World!

Sobre este conversor

O descodificador inverte Base58 reconstruindo o número grande que a string representa, e depois escrevendo-o de volta como bytes — caracteres "1" iniciais tornam-se bytes zero iniciais, exatamente como o codificador os fez. Valida estritamente contra o alfabeto Bitcoin: os caracteres 0, O, I e l nunca podem aparecer em Base58 válido, pelo que encontrar um significa que a string é outra coisa (ou foi mal escrita — que é precisamente o erro que o alfabeto foi concebido para tornar detetável). Os bytes descodificados são lidos como UTF-8; um payload de hash ou endereço descodificará para texto sem sentido, o que é esperado: esses payloads são números, não mensagens.

Perguntas Frequentes

O meu endereço não descodifica — porquê?

Os endereços de carteira são normalmente base58check (payload + soma de verificação), frequentemente com um byte de versão, e descodificam para binário, não texto. A vista de texto parecerá disparate mesmo quando o próprio Base58 é válido.

Suporta os alfabetos Ripple ou Flickr?

Não — esta página utiliza o alfabeto Bitcoin original, que é de longe o mais comum. As variantes apenas reordenam os caracteres.

E se a string tiver um carácter inválido?

O descodificador nomeia-o — verifique uma troca 0/O ou I/l, o erro clássico de transcrição Base58.
