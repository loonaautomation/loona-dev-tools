منسّق SQL - استعلامات قابلة للقراءة، عبارة واحدة في كل سطر

باختصار: يكبّر منسّق SQL الكلمات المفتاحية، يضع كل عبارة رئيسية (SELECT، FROM، WHERE، GROUP BY، ORDER BY، LIMIT وكل JOIN) على سطرها الخاص، ويساف بادئاً شروط AND / OR - مع ترك حرفيات السلاسل بالضبط كما كُتبت.

استعلام من سطر واحد فيه خمس وصلات صالح تقنياً وغير مقروء عملياً. الصقه أدناه واحصل على نفس الاستعلام بالتنسيق الذي ستكتبه يدوياً في يوم جيد.

خاص بالتصميم: كل شيء في هذه الأداة يحدث 100% في متصفحك عبر JavaScript. إدخالك لا يُرفع إلى خادم أبداً، لا يُخزّن أبداً ولا نراه أبداً - أغلق علامة التبويب وكل شيء يختفي.

كيفية استخدام منسّق SQL

  1. الصق استعلام SQL الخاص بك في المربع العلوي.
  2. اترك "الكلمات المفتاحية الكبيرة" معلّماً للمظهر الكلاسيكي، أو ألغ تعليمه لإبقاء حالة كلماتك المفتاحية الأصلية.
  3. انقر تنسيق SQL.
  4. انسخ الاستعلام المنسّق أو نزّله كملف .sql.

كيف يعمل

يحلّل المنسّق استعلامك إلى رموز أولاً، بحيث تُحمل السلاسل المقتبسة والمعرّفات المقتبسة مزدوجاً والمقتبسة خلفياً دون لمس - حرفي مثل 'select me' لا تُكبَّر أبداً ولا تُقسّم. ثم يمشي عبر تدفق الرموز متعرّفاً على عبارات متعددة الكلمات مثل GROUP BY وORDER BY وLEFT OUTER JOIN، يبدأ كل عبارة رئيسية على سطر جديد، ويضع شروط AND وOR على أسطرها المسافة بادئة الخاصة. التباعد حول المشغّلات والفواصل يُطبّع إلى المسافة الواحدة الاتفاقية.

مثال محلول

السطر الواحد select id, name from users where age > 18 and city = 'New York' order by name limit 10 تصبح ستة أسطر نظيفة - SELECT وFROM وWHERE وAND مسافة بادئة، ORDER BY وLIMIT - جاهزة للصق في مراجعة أو تذكرة.

الأسئلة الشائعة

هل منسّق SQL هذا مجاني؟

نعم - مجاني بالكامل، دون تسجيل، دون حد حجم ودون حد يومي.

ما لهجات SQL المدعومة؟

يعمل المنسّق على بنية العبارات، لا قواعد اللهجات، بحيث تُنسّق SQL قياسية من MySQL وPostgreSQL وSQL Server وSQLite وأخرى كلها بنفس الطريقة. يجمّل التخطيط فقط - لا يتحقق من أن استعلامك سيعمل.

هل يعيد مسافة بادئة للاستعلامات الفرعية؟

لا - الاستعلامات الفرعية بين قوسين تبقى على السطر الذي تظهر فيه. مسافة بادئة الاستعلامات الفرعية العميقة هي حيث تخطئ المنسّقات التخمين غالباً، لذا تلتزم هذه الأداة بتخطيط مستوى العبارات وتقول ذلك بصراحة.

هل سلاسلي الحرفية آمنة؟

نعم. السلاسل مقتبسة مفرداً (شاملة تهريبات الاقتباس المضاعف)، والمعرّفات مقتبسة مزدوجاً ومقتبسة خلفياً تمرّ بايت ببايت؛ الكلمات المفتاحية خارجها فقط تُكبَّر.

هل يُرفع SQL الخاص بي إلى خادم؟

لا. التنسيق يحدث 100% في متصفحك. استعلاماتك - أسماء المخططات وكل شيء - لا تغادر جهازك أبداً.
