ZIP 檔案建立工具 - 從多個檔案製作 ZIP

簡而言之： ZIP 檔案建立工具將任何檔案集捆綁成一個單一的標準 .zip 歸檔，完全在您的瀏覽器中使用 JSZip 構建——新增檔案，可選擇將它們分組到一個資料夾中，選擇壓縮級別並下載。

逐個傳送十個附件、移交專案資料夾，或歸檔一批照片——ZIP 把一堆檔案變成一個整潔的下載。大多數線上壓縮工具先把您的檔案上傳到伺服器。這個不會：歸檔在您自己的裝置上組裝，所以連私人檔案都不去任何地方。

檔名大小

壓縮說明：文字、程式碼和 CSV 檔案用 DEFLATE 會大幅縮小。照片、影片和 PDF 本身已經壓縮過，所以無論哪種方式 ZIP 的大小都差不多——對這些檔案選擇“儲存”即可瞬間完成。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的檔案從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。一個誠實的限制：ZIP 是在您裝置的記憶體中構建的，所以非常大的檔案集（數百兆位元組）在記憶體不足的手機上可能會很慢或失敗。

如何使用 ZIP 檔案建立工具

  1. 把您的檔案拖到上面的框中，或點選它從您的裝置中選擇檔案。您可以分幾輪新增檔案。
  2. 檢查列表——刪除您誤加的任何內容，並留意總大小。
  3. 如果您希望每個檔案都位於歸檔內的一個資料夾中，可選地輸入資料夾名稱，並給 ZIP 起一個名字。
  4. 選擇一個壓縮級別（“已壓縮”對大多數任務都適合），然後點選建立 ZIP 並下載。

它如何工作

ZIP 歸檔儲存每個檔案的資料，並在末尾有一個列出每個條目、其名稱和大小的中央目錄——這正是任何系統上的任何解壓工具都能開啟它的原因。本頁在您的瀏覽器中使用 JSZip 庫：它把您選擇的檔案讀入記憶體，可選擇用 DEFLATE 演算法（與經典 ZIP 工具使用的相同）壓縮每個檔案，寫入目錄，然後把完成的歸檔作為單個下載交還給您。同名檔案會被保留並自動編號——第二個 report.pdf 會變成 report (1).pdf——這樣任何東西都不會被悄悄覆蓋。

例項

您新增了三個檔案：report.pdf（240 KB）、photo.jpg（1.2 MB）和 notes.txt（2 KB），資料夾名稱設定為 "handover"。工具會生成 handover.zip——或您選擇的任何名稱——其中包含一個 handover 資料夾，三個檔案都在裡面。下載檔案約為 1.4 MB，因為 PDF 和 JPG 已經是壓縮過的了；如果這些檔案是純文字和 CSV 匯出，同一個歸檔很容易只有原始大小的三分之一。

常見問題

這個 ZIP 檔案建立工具免費嗎？

是的——免費，無需註冊，沒有限制，也沒有水印。

我的檔案會被上傳到伺服器嗎？

不會。ZIP 由在您瀏覽器中執行的 JavaScript（JSZip）構建。您的檔案從不離開您的裝置，這也使它對私人文件安全。

為什麼我的 ZIP 幾乎與原始檔案一樣大？

像 JPG、PNG、MP4、MP3 和 PDF 這樣的格式已經壓縮過了，所以 ZIP 壓縮無法再把它們縮小多少。基於文字的檔案——TXT、CSV、HTML、JSON、原始碼和日誌——通常會大幅縮小。

有檔案大小限制嗎？

本工具沒有內建限制，但歸檔是在您瀏覽器的記憶體中組裝的。幾百兆位元組在大多數桌面上都沒問題；非常大的集合在低端手機上可能很慢或記憶體不足。如果它吃力，把檔案拆分成更小的 ZIP。

我可以給 ZIP 設定密碼保護，或向現有的 ZIP 新增檔案嗎？

本工具不行。它建立一個全新的、不加密的標準 ZIP。任何拿到檔案的人都能開啟它，所以不要僅靠 ZIP 來保護機密。
