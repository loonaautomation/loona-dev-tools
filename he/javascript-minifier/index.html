ממזער JavaScript - דחיסה שמרנית המכבדת את הקוד שלכם

בקצרה: ממזער ה-JavaScript מסיר הערות ורווחים מיותרים באמצעות טוקנייזר אמיתי, כך שתוכן מחרוזות, ליטרלי תבנית וביטויים רגולריים לעולם לא ניזוקים, ומעברי שורה הנושאים משמעות (כמו זה שאחרי return) תמיד נשמרים.

ממזערים נאיביים המתייחסים ל-JavaScript כטקסט פשוט שוברים קוד ברגע שמחרוזת מכילה "//" או ש-regex מכיל מרכאות. הכלי הזה מפרק את הקוד שלכם לאסימונים קודם ורק אז מחליט מה ניתן להסיר בבטחה.

איך להשתמש בממזער JavaScript

  1. הדביקו או הקלידו את ה-JavaScript שלכם לתיבה העליונה.
  2. לחצו על מזער JavaScript.
  3. בדקו את לוח הגודל כדי לראות כמה נחסך.
  4. העתיקו את התוצאה או הורידו אותה כקובץ .js - וכמו עם כל ממזער, הריצו את הקוד שלכם פעם אחת כדי לאשר שהוא מתנהג אותו דבר.

איך זה עובד

הכלי קודם מפצל את הקוד שלכם לאסימונים: מזהים, מספרים, מחרוזות, ליטרלי תבנית, ביטויים רגולריים ופיסוק. הערות מזוהות במהלך הסריקה הזו ומושלכות, והסורק יודע את ההבדל בין סימן חילוק לתחילת regex, ולעולם לא מחפש בתוך מחרוזת סמני הערות. אסימונים אז מחוברים מחדש, מוסיפים רווח מפריד רק היכן שהסרתו תשנה את המשמעות - בין שתי מילים, בין פלוס לפלוס אחר, וכן הלאה. מעברי שורה נשמרים בכל מקום שהכנסת נקודה-פסיק אוטומטית של JavaScript הופכת אותם למשמעותיים, החשוב ביותר אחרי return, break ו- continue, ולפני תו פותח ++ או --.

דוגמה מעובדת

פונקציית עזר עם הערות של כ-400 בתים בדרך כלל נדחסת לכ-260 בתים - בערך שליש פחות - בעוד מחרוזת כמו "see https://example.com // docs" בפנים הוא מגיע ללא שינוי לחלוטין.

שאלות נפוצות

האם ממזער JavaScript הזה בחינם?

כן - לגמרי בחינם, בלי הרשמה, בלי מגבלת גודל ובלי תקרה יומית.

איך זה שונה מממזער מלא של כלי בנייה?

כלי בנייה כמו Terser גם משנים שמות משתנים וכותבים קוד מחדש, מה שסוחט עוד כמה אחוזים. הכלי הזה שמרני בכוונה: הוא לעולם לא משנה שמות של שום דבר ולעולם לא כותב ביטויים מחדש, כך שהפלט קל לעיון ובטוח לשימוש מהיר וחד-פעמי.

האם הוא יכול לשבור את הקוד שלי?

הוא תוכנן לא לעשות זאת: מחרוזות, ליטרלי תבנית וליטרלי regex מוגנים, ושורות חדשות נושאות-משמעות נשמרות. אף ממזער לא יכול להבטיח שלמות על כל דפוס אקזוטי, כך שתמיד הריצו את חבילת הבדיקות שלכם או פתחו את הדף פעם אחת אחרי מזעור - העצה הזו חלה על כל ממזער, כולל שלנו.

האם הוא מטפל בביטויים רגולריים ובליטרלי תבנית?

כן. הטוקנייזר מזהה ליטרלי regex (כולל מחלקות תווים ובריחות) וליטרלי תבנית, כולל ביטויי ${ } מקוננים, ונושא אותם ללא שינוי.

האם הקוד שלי מועלה לשרת?

לא. הטוקניזציה והמזעור קורים 100% בדפדפן שלכם. קוד המקור שלכם לעולם לא עוזב את המכשיר שלכם.
