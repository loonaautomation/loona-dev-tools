关于

MIME 类型（媒体类型）是服务器告诉浏览器一个文件实际上是什么的方式——从这张表得到的 Content-Type 标头正是阻止 .png 被当作文本提供、或下载被嗅探成 HTML（一种 XSS 向量，这正是 X-Content-Type-Options: nosniff 存在的原因）的东西。这张表涵盖日常 Web 工作的格式。有两个条目值得记住，它们反复引发错误：JavaScript 是 text/javascript（旧的 application/javascript 已弃用），.svg 是 image/svg+xml——提供方式错误，SVG 图标会悄悄失效。

常见问题

为什么我的文件会下载而不是显示？

服务器发送了 application/octet-stream 或错误的类型，或 Content-Disposition: attachment。对照此表检查响应标头。

扩展名和文件头哪个说了算？

标头——浏览器根据 Content-Type 行动（嗅探是 nosniff 禁用的危险回退）。扩展名只对选择标头的服务器重要。
