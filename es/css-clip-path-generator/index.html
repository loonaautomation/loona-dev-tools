Generador de clip-path CSS - Da forma a tus elementos visualmente

En resumen: el Generador de clip-path CSS te da CSS de clip-path listo para polígonos (de triángulo a estrella), círculos, elipses y recuadros: elige una forma, ajusta sus puntos, observa la vista previa en vivo y copia el código. Nota: las herramientas hermanas de Imágenes de este sitio ya cubren los degradados; clip-path vive aquí porque es CSS de diseño, no edición de imágenes.

Clip-path convierte rectángulos en diseño: secciones en ángulo, insignias, flechas y estrellas con una sola propiedad CSS. La parte difícil son las coordenadas: esta herramienta se encarga de ellas.

Privado por diseño: todo en esta herramienta sucede 100% en tu navegador con JavaScript. Tu entrada nunca se sube a un servidor, nunca se almacena y nunca la vemos nosotros: cierra la pestaña y todo desaparece.

Cómo usar el Generador de clip-path CSS

  1. Elige una forma predefinida.
  2. Para polígonos, ajusta los porcentajes x,y de cualquier punto.
  3. Observa cómo la vista previa se actualiza en vivo.
  4. Copia el CSS: se incluyen tanto la propiedad estándar como la -webkit-.

Cómo funciona

Los puntos del polígono son porcentajes del cuadro del elemento, así que las formas escalan con el elemento. Los ajustes predefinidos codifican conjuntos de coordenadas bien conocidos (un pentágono regular, un hexágono, una estrella de diez puntas y más), y el generador emite ambos clip-path y el -webkit- gemelo con prefijo que Safari ha necesitado históricamente. Circle, ellipse e inset cubren las formas no poligonales que la propiedad admite, incluidos los recuadros redondeados.

Preguntas frecuentes

¿Este generador es gratuito?

Sí: completamente gratis, sin registro.

¿Por qué hay también un generador de degradados en el sitio de Imágenes?

Los degradados allí se tratan como activos de imagen/diseño. Clip-path es CSS de maquetación para desarrolladores, así que vive aquí: cada herramienta existe en exactamente un sitio de Loona.

¿Clip-path afecta a los clics?

Sí: el área recortada no es clicable, que es normalmente lo que quieres para botones y tarjetas con forma.

¿Compatibilidad con navegadores?

Todos los navegadores modernos admiten clip-path; el prefijo -webkit- de la salida cubre Safari antiguo.

¿Se sube algo?

No. Todo se ejecuta en tu navegador.
