關於

HTML 有超過 2,200 個命名實體；這張表是開發者每天使用的工作集：結構轉義（& < > "）、排版（破折號、引號、省略號）、貨幣和數學符號、箭頭、對勾和常見的帶重音字母。每個實體還有一個十進位制數字引用（©）和一個十六進位制引用（©），即使不存在名稱時也能工作——這裡的字元和十進位制列為您提供兩種回退方案。完整的官方列表位於 WHATWG HTML 標準中；如果某個實體不在這張表中，它的數字引用是可靠的途徑。

常見問題

為什麼使用實體而不是字元本身？

對於結構性的五個字元（& < > " '），實體是正確性問題，而不是風格——不轉義它們會破壞標記。對於其餘字元，當編碼不確定時，實體是一種可移植性選擇。

如果這裡缺少某個實體怎麼辦？

從任何 Unicode 圖表使用它的十進位制數字引用：&#<code>; 永遠有效。
