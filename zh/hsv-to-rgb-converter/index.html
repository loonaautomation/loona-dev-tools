HSV 转 RGB 转换器

简而言之： 输入 HSV 颜色并获取其确切的 RGB 值——还免费附送一个色板和每种其他常用格式。

关于

HSV（色相、饱和度、明度/亮度）驱动着大多数颜色选择器：明度是原始亮度，所以 HSV 是“多鲜艳、多明亮”的自然模型。转换为 RGB：RGB 是屏幕的原生模型：0–255 的加色红、绿、蓝通道，是每种其他格式在显示前必须落入的空间。本转换器解析 HSV 输入（它也容忍其他记法，因为现实世界的颜色字符串是混合到达的），通过 RGB 用标准颜色数学进行转换，并按 CSS 和设计工具显示的方式四舍五入到整数单位——与其他转换器之间低于百分之一的精度差异是四舍五入，而不是错误。

常见问题

HSV 转 RGB 的转换精确吗？

颜色数学是精确的；显示的值像工具普遍显示的那样四舍五入为整数/整数百分比。通过逆转换返回最多相差一个单位。

为什么印刷（CMYK）颜色看起来更暗淡？

纸上的油墨无法再现最亮的屏幕颜色（色域）。CMYK 值是最接近的可打印近似，而不是相同的颜色。
