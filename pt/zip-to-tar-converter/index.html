Sobre

ZIP e TAR resolvem o mesmo problema com filosofias opostas: o ZIP comprime cada ficheiro individualmente e mantém um diretório central; o TAR é um formato de fita sequencial simples que concatena ficheiros com cabeçalhos de 512-byte e deixa a compressão para uma camada exterior (gzip, xz). Converter desempacota o ZIP por completo e reescreve-o com um escritor ustar conforme às normas (entradas longname GNU para caminhos com mais de 100 caracteres, entradas de diretórios sintetizadas, horas de modificação preservadas). A saída TAR é normalmente maior do que o ZIP — é sem compressão por conceção; acrescente gzip com o conversor ZIP para TAR.GZ neste site se o tamanho importar.

Perguntas Frequentes

Algum conteúdo de ficheiro é alterado?

Não — os bytes dos ficheiros são copiados literalmente; apenas o contentor do arquivo, o seu layout de metadados e a compressão (ausente) mudam.

Porque é que o TAR é maior do que o ZIP?

O TAR sozinho não comprime. Isso é deliberado — TAR é o formato de arquivo/intermédio; a compressão é sobreposta quando se quer.
