Formateur et validateur XML - Embellissez, minifiez et vérifiez la bonne formation

En bref : le Formateur XML met en forme le XML emmêlé avec une indentation propre, le reminifie, et valide la bonne formation - balises équilibrées, imbrication correcte - signalant la discordance exacte lorsque quelque chose ne va pas.

XML arrive en une seule ligne illisible depuis les API et les exports de configurations. Collez-le ici pour le lire, le rétrécir, ou découvrir pourquoi un analyseur l’a rejeté.

Privé par conception : tout dans cet outil se passe à 100 % dans votre navigateur avec JavaScript. Votre entrée n’est jamais téléversée sur un serveur, jamais stockée et jamais vue par nous - fermez l’onglet et tout a disparu.

Comment utiliser le Formateur et validateur XML

  1. Collez votre XML.
  2. Cliquez sur Formater pour l’embellir, Minifier pour le compresser, ou Valider uniquement pour le vérifier.
  3. Lisez la ligne d’état - elle nomme l’inadéquation exacte de balise lorsque le XML est cassé.
  4. Copiez le résultat.

Comment ça fonctionne

La validation vérifie ici la bonne formation du XML avec un analyseur à pile de balises : chaque balise ouvrante doit se fermer dans le bon ordre, les balises auto-fermantes et les déclarations sont reconnues, les commentaires et les sections CDATA sont sautés correctement, et un < brut dans le contenu textuel est signalé car il doit être échappé. C’est la vérification que chaque analyseur XML applique en premier - un document qui y échoue ne peut pas être analysé du tout. (Ce n’est pas une validation de schéma par rapport à un DTD ou un XSD, qui exige le schéma lui-même.) Le formatage réindente ensuite selon la profondeur d’imbrication ; la minification supprime les espaces entre les balises.

Questions fréquemment posées

Ce formateur est-il gratuit ?

Oui - entièrement gratuit, sans inscription.

Que vérifie la validation ?

Bonne formation : balises équilibrées, correctement imbriquées, et texte échappé. Elle ne valide pas par rapport à un schéma DTD ou XSD.

Pourquoi mon XML a-t-il échoué ?

Le message d’état nomme le problème - généralement une balise fermante inadéquate, une balise non fermée, ou un & brut ou < in text that needs escaping.

Le formatage change-t-il mes données ?

Seuls les espaces entre balises. Le texte et les attributs des éléments sont préservés exactement.

Quelque chose est-il téléversé ?

Non. L’analyse se passe dans votre navigateur.
