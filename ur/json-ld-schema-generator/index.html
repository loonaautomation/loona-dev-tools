JSON-LD اسکیما جنریٹر - ہاتھ سے JSON لکھے بغیر ساختی ڈیٹا

مختصراً: JSON-LD اسکیما جنریٹر 16 اقسام کے لیے درست schema.org ساختی ڈیٹا بناتا ہے - Articles, Local Businesses, Products, Events, Recipes, People, Organizations, Websites, FAQ Pages, How-Tos, Videos, Books, Courses, Job Postings, Software Apps اور Breadcrumb Lists، اور اسے عین script بلاک میں لپیٹتا ہے جس کی Google توقع کرتا ہے۔

ساختی ڈیٹا تلاش انجنوں کو صفحہ سمجھنے میں مدد کرتا ہے اور بھرپور نتائج کھول سکتا ہے۔ یہ جنریٹر JSON آپ کے لیے بناتا ہے - اور کاپی کرنے سے پہلے اسے بطور JSON توثیق کرتا ہے۔

ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کا ان پٹ کبھی سرور پر اپ لوڈ نہیں ہوتا، کبھی محفوظ نہیں ہوتا اور ہمارے دیکھنے میں نہیں آتا - ٹیب بند کریں اور سب کچھ ختم۔

JSON-LD اسکیما جنریٹر کا استعمال کیسے کریں

  1. وہ اسکیما قسم منتخب کریں جو آپ کے صفحے سے ملتی ہے۔
  2. وہ فیلڈز بھریں جو لاگو ہوں - خالی فیلڈز بس چھوڑ دیے جاتے ہیں۔
  3. بنائیں پر کلک کریں اور JSON-LD بلاک دیکھیں۔
  4. اسے اپنے صفحہ head میں یا بند body ٹیگ سے پہلے پیسٹ کریں، پھر لائیو صفحہ Google کے Rich Results Test سے ٹیسٹ کریں۔

یہ کیسے کام کرتا ہے

جنریٹر schema.org ذخیرہ الفاظ میں ایک JavaScript آبجیکٹ جمع کرتا ہے - @context, @type اور منتخب قسم کے لیے خصوصیات، بشمول nested آبجیکٹس جیسے Product کا Offer اور AggregateRating, ایک Article کے مصنف Person، یا ایک LocalBusiness PostalAddress - پھر اسے سخت JSON فارمیٹنگ سے لکھتا ہے اور دکھانے سے پہلے ثابت کرنے کے لیے کہ یہ درست JSON ہے اپنی آؤٹ پٹ دوبارہ-parse کرتا ہے۔ خالی فیلڈز مکمل چھوڑ دیے جاتے ہیں، کیونکہ خالی خصوصیت غائب سے بدتر ہے۔ ایماندار دائرہ: درست JSON-LD ایک صفحہ بناتا ہے اہل بھرپور نتائج کے لیے؛ Google فیصلہ کرتا ہے کہ آیا انہیں دکھانا ہے، اور ڈیٹا کو صفحے پر نظر آنے والے سے ملنا چاہیے۔
