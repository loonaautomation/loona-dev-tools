ตัวตรวจสอบความอ่านง่ายสำหรับ SEO - หกคะแนนสำหรับข้อความเว็บ

สรุปสั้น ๆ: ตัวตรวจสอบความอ่านง่ายสำหรับ SEO ให้คะแนนข้อความเว็บที่วางด้วยหกสูตรที่จัดตั้งขึ้น - Flesch Ease, Flesch-Kincaid, Gunning Fog, Coleman-Liau, SMOG และ ARI - บวกสถิติประโยคที่ขับเคลื่อนพวกมันจริง กรอบสำหรับเนื้อหาการค้นหาแทนที่จะเป็นการบ้านโรงเรียน

หมายเหตุขอบเขต: Text Tools มีเครื่องคำนวณระดับการอ่านที่ครอบคลุม Flesch Ease และระดับชั้นสำหรับการเขียนทั่วไป ตัวตรวจสอบนี้คือเวอร์ชันเนื้อหา SEO - หกสูตร การวินิจฉัยความยาวประโยค และเป้าหมายผู้ชมเว็บ - ซึ่งเป็นเหตุผลว่าทำไมมันจึงอยู่กับเครื่องมือเว็บมาสเตอร์

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวตรวจสอบความอ่านง่าย SEO

  1. วางข้อความของหน้าหรือฉบับร่างบทความของคุณ (ไม่กี่ย่อหน้าจะได้คะแนนเชื่อถือได้ที่สุด)
  2. คลิกให้คะแนนความอ่านง่าย
  3. เปรียบเทียบคะแนนทั้งหก - พวกมันควรสอดคล้องกันในวงกว้าง; ค่าผิดปกติที่โดดออกมาอย่างมากชี้ไปที่คำหรือประโยคที่ยาวมาก
  4. แก้ไขประโยคที่ยาวที่สุดก่อน; นั่นจะขยับทุกคะแนนพร้อมกัน

วิธีการทำงาน

แต่ละสูตรชั่งน้ำหนักวัตถุดิบดิบเดียวกันแตกต่างกัน: คะแนน Flesch ใช้ความยาวประโยคและพยางค์ต่อคำ; Gunning Fog นับคำที่มีสามพยางค์ขึ้นไป ('คำซับซ้อน'); Coleman-Liau ใช้ตัวอักษรแทนพยางค์ จึงโกงได้ยากที่สุด; SMOG ถูกออกแบบมาสำหรับข้อความด้านสุขภาพ; ARI ใช้ตัวอักษรต่อคำ พยางค์ถูกนับด้วยวิธีประมาณกลุ่มสระมาตรฐาน ตัวอย่างสั้นจะแกว่งอย่างมาก ดังนั้นให้คะแนนทั้งส่วน ไม่ใช่ประโยคเดี่ยว
