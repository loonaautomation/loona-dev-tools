歸檔檔案解壓工具 - 線上開啟任何歸檔

簡而言之： 歸檔檔案提取器是萬能開啟工具：放入任何常見歸檔——ZIP、RAR、7Z、TAR、TAR.GZ、TAR.BZ2、TAR.XZ 或 ISO——它會自己檢測格式，列出裡面的內容，並讓您下載單個檔案或將所有內容下載為 ZIP。不會上傳任何內容。

不確定您收到的歸檔是什麼型別？這正是本頁的用途。不用猜哪個工具與奇怪的副檔名匹配，把檔案拖到這裡：libarchive 引擎讀取檔案的實際內容（而不只是它的名字），識別出格式，並列出裡面的內容。它是本站專門的 RAR、7Z、TAR 和 ISO 頁面背後的同一個引擎，開啟了每種格式。

把任何歸檔檔案拖到這裡（ZIP、RAR、7Z、TAR、ISO...） 或點選從您的裝置中選擇一個檔案

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中完成。這個歸檔由執行在您自己裝置上的 WebAssembly 引擎讀取——從不上傳，從不儲存，我們也從不見過它。兩個誠實的限制：受密碼保護的歸檔不會被開啟（這個工具從不要求、猜測或破解密碼），並且歸檔在您裝置的記憶體中解壓，所以極大的檔案在記憶體不足的手機上可能會很慢。

如何使用歸檔檔案解壓工具

  1. 把您的歸檔檔案拖到上面的框中，或點選它從您的裝置中選擇檔案——任何常見格式都可以。
  2. 等待片刻，格式正在檢測，內容正在讀取——首次使用時，引擎（約 1 MB）載入一次，然後由您的瀏覽器快取。
  3. 瀏覽歸檔內檔案的列表，包括路徑和大小。
  4. 點選任何單個檔案旁邊的“下載”，或使用“全部下載為 ZIP”把一切儲存為一個標準 ZIP 檔案。

它如何工作

本頁由 libarchive 提供支援——macOS 和 BSD 歸檔工具背後的開源庫——編譯成 WebAssembly。Libarchive 不信任副檔名：它探測實際位元組，依次測試每個格式讀取器（ZIP 簽名、RAR 標記、7z 標頭、TAR 校驗和、ISO9660 卷描述符，以及可以包裹它們的 gzip、bzip2 和 XZ 壓縮層）。一旦識別出格式，同一個讀取器列出每個條目並解壓您下載的那些。全部下載為 ZIP 用 JSZip 重新打包內容。

例項

一位客戶發來 project-files.2026，沒有任何有用的副檔名，您的電腦稱它為未知檔案。您把它拖到這裡：引擎識別出它是一個 TAR.XZ 歸檔，列出 58 個原始檔，您下載需要的兩個。這個神秘格式根本沒有機會。

常見問題

這個通用解壓工具能開啟哪些格式？

ZIP、RAR（RAR4 和 RAR5）、7Z、TAR、TAR.GZ / TGZ、TAR.BZ2、TAR.XZ、ISO 光碟映象，以及 libarchive 引擎理解的幾個較為罕見的格式，如 CPIO 和 XAR。這裡命名的每個格式在構建這個工具時都經過了真實測試歸檔的驗證。

副檔名看起來不對或完全缺失。它還能工作嗎？

通常可以。檢測基於檔案的內容，而不是它的名字，所以改名為 .bin 的 ZIP 或丟失副檔名的下載檔案仍然能開啟。如果內容真的不是歸檔，本工具會報告這一點，而不是猜測。

本工具打不開什麼？

受密碼保護的歸檔（從不詢問、猜測或破解密碼）、多卷分卷歸檔（.part1.rar 風格的集合）、Apple 的 .dmg 映象和自解壓 .exe 歸檔。對於這些，像 7-Zip 這樣的桌面工具是正確的選擇。

為什麼還有 RAR、7Z 和 TAR 的單獨頁面？

專門頁面帶有針對特定格式的指導，是大多數人搜尋的物件；這個通用頁面是其他一切的安全網——混合下載、未知副檔名、以及沒有自己頁面的格式。同一個引擎，同樣的隱私，不同的入口。

我的檔案會被上傳到伺服器進行檢測或解壓嗎？

不會。格式檢測和解壓都在您瀏覽器標籤頁內的 WebAssembly 中執行。您的歸檔從不離開您的裝置，頁面載入後本工具離線也能繼續工作。
