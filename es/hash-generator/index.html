Generador de hashes - SHA-1, SHA-256, SHA-384 y SHA-512

En resumen: el Generador de hashes calcula resúmenes SHA-1, SHA-256, SHA-384 y SHA-512 de tu texto con la criptografía integrada de tu navegador: el mismo motor Web Crypto que usa el sitio web de tu banco. SHA-1 está etiquetado honestamente: para sumas de comprobación, no para seguridad.

¿Necesitas comprobar que dos copias de una cadena son idénticas, producir una huella para invalidar la caché o seguir un tutorial que pide un resumen SHA-256? Pega el texto y los cuatro resúmenes estándar aparecen juntos, listos para copiar.

Nota: SHA-1 se incluye solo para sumas de comprobación y compatibilidad heredada: es no seguro para contraseñas o seguridad. Para seguridad usa SHA-256 o más fuerte, con un esquema adecuado de hash de contraseñas como bcrypt o Argon2 para contraseñas.

Privado por diseño: todo en esta herramienta sucede 100% en tu navegador con JavaScript. Tu entrada nunca se sube a un servidor, nunca se almacena y nunca la vemos nosotros: cierra la pestaña y todo desaparece.

Cómo usar el Generador de hashes

  1. Escribe o pega el texto a calcular el hash.
  2. Haz clic en Generar hashes.
  3. Copia el resumen que necesites de los resultados.

Cómo funciona

Un hash criptográfico convierte cualquier entrada en una huella de longitud fija. La misma entrada siempre da la misma huella; cambiar incluso un carácter la cambia por completo; y la entrada no se puede reconstruir desde la huella. Esta herramienta alimenta los bytes UTF-8 de tu texto a la API Web Crypto (crypto.subtle.digest): criptografía nativa y auditada del navegador, no una reimplementación en JavaScript. SHA-256 produce 64 caracteres hexadecimales, SHA-512 produce 128 y SHA-1 produce 40. La resistencia a colisiones de SHA-1 está rota, y por eso se ofrece solo para sumas de comprobación y sistemas heredados que aún lo piden.

Ejemplo resuelto

Calcular el hash de la palabra "abc" con SHA-256 siempre da ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad: el vector de prueba publicado que los ingenieros de todo el mundo usan para comprobar que una implementación de hash es correcta. Pruébalo aquí y compara.

Preguntas frecuentes

¿Este generador de hashes es gratuito?

Sí: gratis, sin registro, sin límites.

¿El hash es lo mismo que el cifrado?

No. Un hash es unidireccional: crea una huella que puedes comparar, pero no puedes descifrarla de vuelta al texto original.

¿Por qué SHA-1 está marcado como "no para seguridad"?

Los investigadores han producido colisiones SHA-1 reales, así que no debe proteger contraseñas, firmas ni certificados. Aún está bien como una suma de comprobación rápida de archivos donde los ataques no son una preocupación.

¿Debería calcular el hash de las contraseñas con SHA-256?

No directamente. Las contraseñas necesitan funciones de hash de contraseñas lentas y con sal como bcrypt, scrypt o Argon2: los hashes rápidos como SHA-256 permiten a los atacantes adivinar miles de millones de contraseñas por segundo.

¿Mi texto se sube para calcular su hash?

No. El hash se ejecuta en tu navegador mediante Web Crypto; tu texto nunca sale de tu dispositivo.
