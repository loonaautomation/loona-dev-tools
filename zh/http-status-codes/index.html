409冲突状态冲突，例如编辑冲突或重复创建
410已消失（Gone）永久删除（比 404 更强——故意使用）

504网关超时代理/网关等待上游时超时
505不支持 HTTP 版本请求中的 HTTP 版本不受支持

关于

状态码是服务器对每个响应的单数字摘要，按类别分组：1xx 信息性、2xx 成功、3xx 重定向、4xx 客户端出错、5xx 服务器出错。表格给出在职开发者实际遇到的代码，带在实践中重要的细微差别——401 尽管名字如此，含义是未认证；403 是拒绝，与登录无关；422 是 API 验证失败；429 要求退避。未列出的代码（1xx 和实验性代码的长尾）足够罕见，仅类别就告诉您如何处理它们。

常见问题

401 和 403 有什么区别？

401：我们不知道您是谁（请进行身份验证）。403：我们知道您是谁，但您仍然无权访问。

临时重定向用 302 还是 307？

307 会保留请求方法和正文；302 在历史上允许客户端把 POST 切换为 GET。新项目应使用 307（永久重定向则用 308）。
