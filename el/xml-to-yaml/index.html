Μετατροπέας XML σε YAML

Εν συντομία: επικολλήστε XML και πάρτε αναγνώσιμο YAML με τους ίδιους κανόνες αντιστοίχισης με μια προσεκτική μετατροπή JSON — χαρακτηριστικά με πρόθεμα @, λίστες για επαναλαμβανόμενα στοιχεία.
🔒 Ιδιωτικό εκ σχεδιασμού: τα πάντα τρέχουν στο πρόγραμμα περιήγησής σας σε αυτή τη συσκευή. Η είσοδός σας δεν ανεβαίνει ποτέ σε διακομιστή.

Παράδειγμα

Είσοδος:

<person><name>Ali</name><age>30</age></person>

Έξοδος:

person:
  name: Ali
  age: 30

Σχετικά με αυτόν τον μετατροπέα

Το XML-to-YAML εξυπηρετεί τη διαδρομή μετανάστευσης από παλαιές ρυθμίσεις XML (Maven, παλαιότερες ρυθμίσεις Java και .NET, δεδομένα εποχής RSS) στον κόσμο YAML του σύγχρονου DevOps. Μοιράζεται την αντιστοίχισή του με τον μετατροπέα XML σε JSON αυτού του ιστότοπου — χαρακτηριστικά ως @keys, επαναλαμβανόμενα αδέλφια ως λίστες, κείμενο τυποποιημένο όπου είναι σαφές — μετά αποδίδει με τον συγγραφέα YAML, οπότε αυτό που βλέπετε είναι ακριβώς η δομή που θα έπαιρνε ένας καταναλωτής JSON, στη σημειογραφία που οι άνθρωποι προτιμούν να επεξεργάζονται. Η πλευρά XML αναλύεται από έναν πραγματικό αναλυτή που χειρίζεται CDATA, σχόλια, οντότητες και ετικέτες αυτόματου κλεισίματος.

Συχνές Ερωτήσεις

Είναι η αντιστοίχιση η ίδια με το XML σε JSON εδώ;

Ναι — σκόπιμα. Μετατρέψτε XML σε οποιονδήποτε στόχο και η δομή ταιριάζει, οπότε οι ομάδες μπορούν να συγκρίνουν εξόδους.

Τι συμβαίνει στη δήλωση XML και στα σχόλια;

Απορρίπτονται· η έξοδος YAML φέρει μόνο το δέντρο δεδομένων.
