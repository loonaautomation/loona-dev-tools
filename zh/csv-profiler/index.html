CSV 数据剖析工具 - 在信任一个文件之前先了解它

简而言之： CSV 分析器读取整个文件，并为每一列报告：猜测的数据类型、多少单元格为空、多少值是唯一的、数值最小值和最大值，以及三个最常见的值。

有人递给您一个 CSV，第一个问题永远是“里面到底有什么？”剖析器用一次粘贴就能回答它。

按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中使用 JavaScript 完成。您的输入从不上传到服务器，从不存储，我们也从不见过它——关闭标签，一切都消失了。

如何使用 CSV 数据剖析工具

  1. 粘贴带其标题行的 CSV。
  2. 点击“剖析此 CSV”。
  3. 阅读每列的表：类型、空值、唯一值、最小/最大值、热门值。
  4. 在导入之前用它发现脏数据——混合类型、意外空白、近重复的类别。

它如何工作

类型是通过用与我们的 CSV 转 SQL 转换器相同的规则扫描每个值来猜测的：整数、小数、布尔值和 ISO 日期被识别，混合列回退到文本——这本身就是一个有用的警告。唯一值计数和热门值即刻暴露类别问题（一个 1,000 行中有 900 个唯一值的城市列不是类别）。数值最小/最大值只出现在数值列上；文本列改为显示其热门值。

常见问题

这个工具免费吗？

是的——完全免费，无需注册。

类型猜测有多准确？

它是对实际值的扫描，所以它反映您的数据——一列 '001' 代码会猜测为整数，这正是高频值列并排显示以便合理性检查的原因。

什么算空？

一个里面什么都没有的单元格（或者 CSV 解析器读取后什么都不剩）。仅空格也算一个值——如果这对您重要，请先用去重与清理工具修剪。

我的数据会被上传吗？

不会。剖析 100% 在您的浏览器中运行。
