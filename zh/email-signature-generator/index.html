HTML 邮件签名生成器 - 能在电子邮件客户端中存活的专业落款

简而言之： HTML 电子邮件签名生成器将您的签名构建为电子邮件安全的表格 HTML——这是 Gmail、Outlook 和 Apple Mail 都能可靠渲染的唯一布局技术——带有您的强调色、联系链接和可选的标语。

电子邮件客户端会剥离现代 CSS，这正是用 div 构建的签名在 Outlook 中分崩离析的原因。这个签名用老式、正确的方式构建：只有表格和内联样式。

预览

按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中使用 JavaScript 完成。您的输入从不上传到服务器，从不存储，我们也从不见过它——关闭标签，一切都消失了。

如何使用 HTML 邮件签名生成器

  1. 填写您的姓名、职位和公司。
  2. 添加电话、电子邮件和网站——它们会变成可点击的链接。
  3. 选择一个强调色和一个可选标语。
  4. 检查预览，然后复制 HTML（或把渲染好的预览直接复制到 Gmail 的签名编辑器中）。

它如何工作

电子邮件 HTML 是一个时间胶囊：Outlook 的 Word 引擎忽略 flexbox、网格和大多数现代 CSS，所以专业的签名仍然用嵌套表格和内联样式构建——这正是本生成器输出的。联系方式变成真实的 tel:、mailto: 和网页链接，强调条和姓名使用您的颜色，每个文本值都经过转义，这样带 & 的姓名不会破坏标记。不使用任何图像，所以签名即时显示，永远不会触发“下载图片”警告。

常见问题

这个生成器免费吗？

是的——完全免费，无需注册。

我如何在 Gmail 中添加它？

复制渲染后的预览（不是代码），然后在 Gmail 中进入 设置 → 查看所有设置 → 签名，创建一个签名并粘贴。格式会被带过去。

为什么用表格而不是 div？

桌面版 Outlook 用 Microsoft Word 的引擎渲染邮件，它只能可靠地支持表格和内联样式。

我可以添加标志照片吗？

本生成器按设计只生成文本——无图像的签名即时加载，永不被阻止。如果您需要托管的徽标，可以手工添加到 HTML 中。

有任何东西被上传吗？

不会。您的详细信息从不离开您的浏览器。
