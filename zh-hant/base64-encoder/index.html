Base64 編碼器與解碼器 - 文字與檔案，UTF-8 安全

簡而言之： Base64 編碼器將文字和檔案轉換為 Base64，並將 Base64 解碼迴文字——正確處理重音符號、烏爾都語、中文和 emoji，還帶有一個可選的 URL 安全字母表。

Base64 無處不在：API 負載、電子郵件附件、data URI、basic-auth 標頭和 JWT 的各個部分。許多快速編碼器的問題在於它們在非英文文字上會出錯。本編碼器編碼的是您文字的 UTF-8 位元組，所以您能輸入的任何內容都能在往返中完好無損。

檔案轉 Base64

選擇一個檔案以獲取其 Base64 資料字串（對 data URI 和測試負載很有用）。檔案在本地讀取——從不上傳。

按設計保證隱私： 這個工具中的一切都 100% 在您的瀏覽器中使用 JavaScript 完成。您的輸入從不上傳到伺服器，從不儲存，我們也從不見過它——關閉標籤，一切都消失了。

如何使用 Base64 編碼器與解碼器

  1. 輸入或貼上您的文字（或選擇一個檔案進行檔案轉 Base64）。
  2. 如果結果會進入 URL 或 JWT，可選地勾選 URL 安全。
  3. 點選“編碼”或“解碼”，並複製或下載結果。

它如何工作

Base64 使用 64 字元字母表把每 3 個位元組的資料表示為 4 個字元，這使二進位制資料能安全地在 JSON、XML 和 URL 等文字格式中攜帶。本工具先把您的文字轉換成它的 UTF-8 位元組（文字的通用編碼），然後編碼這些位元組——這正是帶重音的字母、阿拉伯文字文字和 emoji 都能完美解碼回來的原因。URL 安全變體把 + 和 / 換成 - 和 _，並去掉 = 填充，正如 JSON Web Tokens 中所使用的那樣。

例項

文字 "Loona" 編碼為 TG9vbmE=。帶烏爾都語文字和一個 emoji 的問候語 "Assalam-o-Alaikum"——السلام علیكم 👋——逐字編碼並解碼回來，這是隻處理普通 ASCII 的天真編碼器無法做到的。

常見問題

這個 Base64 工具免費嗎？

是的——免費，無需註冊，沒有限制。

為什麼一些 Base64 工具會把非英語文字弄亂？

它們把每個字元編碼為單個位元組，這隻對普通 ASCII 有效。本工具改為編碼 UTF-8 位元組，所以每種語言和每個 emoji 都能精確往返。

什麼是 URL 安全選項？

標準 Base64 可以包含 + 和 /，它們是 URL 中的特殊字元。URL 安全字母表用 - 和 _ 替換它們並刪除填充——JWT 中使用的變體。

Base64 是加密嗎？

不是。Base64 是編碼，不是加密——任何人都能瞬間解碼它。永遠不要用它保護機密。

我的檔案會被上傳嗎？

不會。檔案由您裝置上的瀏覽器讀取，從不離開它。
