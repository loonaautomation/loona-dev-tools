Convertisseur CSV vers SQL - Importez les données CSV dans n’importe quelle base de données

En bref : le Convertisseur CSV vers SQL lit votre CSV, déduit un type sensé pour chaque colonne (entier, décimal, booléen, date ou texte), assainit les noms de tables et de colonnes, et émet un CREATE TABLE plus un INSERT par ligne dans le dialecte de votre choix.

Chaque import de base de données commence comme un CSV et un tas d’INSERT écrits à la main. Collez le CSV, choisissez MySQL, PostgreSQL ou SQLite, et obtenez du SQL prêt à importer en un clic.

Privé par conception : tout dans cet outil se passe à 100 % dans votre navigateur avec JavaScript. Votre entrée n’est jamais téléversée sur un serveur, jamais stockée et jamais vue par nous - fermez l’onglet et tout a disparu.

Comment utiliser le Convertisseur CSV vers SQL

  1. Collez votre CSV - la première ligne doit être les noms de colonnes.
  2. Saisissez un nom de table et choisissez votre dialecte SQL.
  3. Laissez CREATE TABLE coché si vous voulez aussi la définition du tableau.
  4. Cliquez sur Générer le SQL, puis copiez-le ou téléchargez le fichier .sql.
  5. Exécutez le SQL dans votre client de base de données pour importer les données.

Comment ça fonctionne

Les types de colonnes sont déduits en balayant chaque valeur de la colonne : les nombres entiers deviennent des entiers, les décimaux deviennent des nombres à virgule flottante, true/false deviennent des booléens, et les dates ISO (YYYY-MM-DD, avec une heure facultative) deviennent des colonnes de date/horodatage. Une colonne qui mélange les types retombe sur le type le plus large, et une colonne de nombres et de texte mélangés devient TEXT afin que rien ne se perde. Les cellules vides deviennent NULL. Les identifiants sont assainis - mis en minuscules, espaces et ponctuation remplacés par des traits de soulignement, un chiffre en tête préfixé - puis cités pour le dialecte : accents graves pour MySQL, guillemets doubles pour PostgreSQL et SQLite. Les valeurs de chaînes sont mises entre guillemets simples, les guillemets internes étant doublés : l’échappement standard du SQL.

Exemple travaillé

La ligne Ali,30,true sous name,age,active devient INSERT INTO "my_table" ("name", "age", "active") VALUES ('Ali', 30, TRUE); dans le dialecte PostgreSQL.

Questions fréquemment posées

Ce convertisseur CSV vers SQL est-il gratuit ?

Oui - entièrement gratuit, sans inscription, sans plafond.

Comment les types de colonnes sont-ils choisis ?

En balayant toutes les valeurs de chaque colonne. Les entiers, décimaux, booléens et dates ISO sont détectés ; les colonnes mixtes retombent sur TEXT.

Qu’arrive-t-il aux cellules vides ?

Ils deviennent NULL dans les instructions INSERT.

Quels dialectes sont pris en charge ?

MySQL (citation par accents graves), PostgreSQL et SQLite (citation par guillemets doubles), avec des noms de types adaptés au dialecte.

Mes données sont-elles téléversées ?

Non. La conversion se passe entièrement dans votre navigateur.
