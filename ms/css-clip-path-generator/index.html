Penjana Clip-Path CSS - Bentuk Elemen Anda Secara Visual

Singkatnya: Penjana Clip-Path CSS memberi Anda CSS clip-path siap untuk poligon (segitiga hingga bintang), lingkaran, elips, dan inset - pilih bentuk, anjak titiknya, saksikan pratonton langsung dan salin kode. Nota: alat Imej saudara laman web ini sudah mencakup gradien; clip-path hidup di sini kerana ia adalah CSS tata letak, bukan penyuntingan imej.

Clip-path mengubah persegi panjang menjadi desain: bagian miring, lencana, panah, dan bintang dengan satu properti CSS. Bagian sukarnya adalah koordinat - alat ini menanganinya.

Peribadi berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di pelayar Anda dengan JavaScript. Input Anda tidak pernah dimuat naik ke pelayan, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Cara menggunakan Penjana Clip-Path CSS

  1. Pilih preset bentuk.
  2. Untuk poligon, sesuaikan peratusan x,y titik mana pun.
  3. Saksikan pratonton dikemaskini secara langsung.
  4. Salin CSS - properti standard dan -webkit- keduanya disertakan.

Cara kerja

Titik poligon adalah peratusan kotak elemen, jadi bentuk berskala dengan elemen. Preset meng-encode set koordinat yang dikenal luas (pentagon beraturan, heksagon, bintang sepuluh titik, dan lain-lain), dan penjana memancarkan keduanya clip-path dan yang -webkit- kembar berawalan yang secara historis diperlukan Safari. Lingkaran, elips, dan inset mencakup bentuk non-poligon yang didukung properti, termasuk inset membulat.

Pertanyaan yang Sering Diajukan

Apakah penjana ini percuma?

Ya - sepenuhnya percuma, tanpa pendaftaran.

Mengapa ada juga penjana gradien di laman web Imej?

Gradien di sana diperlakukan sebagai aset imej/desain. Clip-path adalah CSS tata letak untuk pembangun, jadi ia tinggal di sini - setiap alat ada di tepat satu laman web Loona.

Apakah clip-path memengaruhi klik?

Ya - area yang terpotong tidak dapat diklik, yang biasanya Anda inginkan untuk butang dan kad berbentuk.

Sokongan pelayar?

Semua pelayar modern menyokong clip-path; awalan -webkit- pada output mencakup Safari lama.

Apakah ada yang dimuat naik?

Tidak. Semuanya berjalan di pelayar Anda.
