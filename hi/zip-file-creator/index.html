ZIP फ़ाइल निर्माता — कई फ़ाइलों से ZIP बनाएँ

संक्षेप में: ZIP फ़ाइल निर्माता किसी files के set को एक single standard .zip archive में bundle करता है, पूरी तरह आपके browser में JSZip से built — फ़ाइलें जोड़ें, वैकल्पिक रूप से उन्हें folder में group करें, compression level चुनें और download करें।

दस attachments एक-एक करके भेजना, एक project folder सौंपना, या photos के batch को archive करना — एक ZIP फ़ाइलों के ढेर को एक tidy download में बदल देता है। ज़्यादातर online zippers आपकी फ़ाइलें पहले server पर upload करते हैं। यह नहीं करता: archive आपके अपने device पर assemble होता है, इसलिए private फ़ाइलें भी कभी कहीं travel नहीं करतीं।

Compression note: text, code और CSV files DEFLATE से बहुत सिकुड़ती हैं। Photos, videos और PDFs पहले से compressed होते हैं, इसलिए ZIP दोनों हालतों में लगभग एक ही size का रहेगा - उनके लिए Stored चुनें ताकि काम तुरंत पूरा हो।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपकी फ़ाइलें कभी server पर upload नहीं होतीं, कभी stored नहीं होतीं और कभी हमारे द्वारा नहीं देखी जातीं — tab बंद करें और सब चला गया। एक ईमानदार limit: ZIP आपके device की memory में built होता है, इसलिए बहुत बड़े file sets (सैकड़ों megabytes) low-memory phone पर slow या fail हो सकते हैं।

ZIP फ़ाइल क्रिएटर का उपयोग कैसे करें

  1. अपनी फ़ाइलें ऊपर के box पर डालें, या उस पर click करें और अपने device से फ़ाइलें चुनें। आप कई rounds में फ़ाइलें जोड़ सकते हैं।
  2. List check करें — जो कुछ आपने ग़लती से जोड़ा हो उसे हटाएँ, और total size पर नज़र रखें।
  3. वैकल्पिक रूप से folder name type करें अगर आप चाहते हैं कि हर फ़ाइल archive में एक folder के अंदर रहे, और ZIP को नाम दें।
  4. एक compression level चुनें (Compressed ज़्यादातर कामों के लिए सही है) और Create ZIP & Download पर click करें।

यह कैसे काम करता है

ZIP archive हर फ़ाइल का डेटा रखता है और अंत में एक central directory जो हर entry, उसका नाम और उसके sizes सूचीबद्ध करती है — इसीलिए किसी भी system का कोई भी unzip tool इसे खोल सकता है। यह पेज आपके ब्राउज़र में JSZip library का उपयोग करता है: यह आपकी चुनी हुई फ़ाइलों को memory में पढ़ता है, वैकल्पिक रूप से हर एक को DEFLATE algorithm से compress करता है (वही जो classic ZIP tools उपयोग करते हैं), directory लिखता है, और तैयार archive को एक single download के रूप में आपको वापस देता है। एक ही नाम वाली फ़ाइलें रखी जाती हैं और अपने आप number दी जाती हैं — दूसरी report.pdf, report (1).pdf बन जाती है — ताकि कुछ भी चुपचाप overwrite न हो।

काम किया हुआ उदाहरण

आप तीन फ़ाइलें जोड़ते हैं: report.pdf (240 KB), photo.jpg (1.2 MB) और notes.txt (2 KB), folder name "handover" set के साथ। Tool handover.zip बनाता है — या जो नाम आपने चुना — एक handover folder रखते हुए सभी तीन फ़ाइलों के साथ अंदर। Download लगभग 1.4 MB है, क्योंकि PDF और JPG पहले से compressed थे; अगर फ़ाइलें plain text और CSV exports होतीं, तो वही archive आसानी से original size का एक तिहाई हो सकता था।

अक्सर पूछे जाने वाले सवाल

क्या यह ZIP file creator मुफ़्त है?

हाँ — मुफ़्त, कोई साइन-अप नहीं, कोई limits नहीं और कोई watermarks नहीं।

क्या मेरी फ़ाइलें किसी server पर अपलोड होती हैं?

नहीं। ZIP आपके ब्राउज़र में चल रहे JavaScript (JSZip) द्वारा बनता है। आपकी फ़ाइलें कभी आपके device से बाहर नहीं जातीं, जो इसे private documents के लिए भी सुरक्षित बनाता है।

मेरी ZIP मूल फ़ाइलों के लगभग same size क्यों है?

JPG, PNG, MP4, MP3 और PDF जैसे formats पहले से compressed हैं, इसलिए ZIP compression उन्हें ज़्यादा नहीं सिकोड़ सकता। Text-based फ़ाइलें — TXT, CSV, HTML, JSON, source code और logs — आम तौर पर बहुत सिकुड़ती हैं।

क्या कोई file size limit है?

Tool में कोई limit built नहीं है, लेकिन archive आपके browser की memory में assemble होता है। कुछ सौ megabytes ज़्यादातर desktops पर ठीक हैं; बहुत बड़े sets low-end phone पर slow हो सकते हैं या memory ख़त्म हो सकती है। अगर यह संघर्ष करे, तो फ़ाइलों को छोटे ZIPs में बाँटें।

क्या मैं ZIP को password-protect कर सकता हूँ या मौजूदा ZIP में फ़ाइलें जोड़ सकता हूँ?

इस tool से नहीं। यह बिना encryption के एक fresh, standard ZIP बनाता है। जो भी फ़ाइल पाए वह इसे खोल सकता है, इसलिए secrets की रक्षा के लिए अकेले ZIP पर भरोसा न करें।
