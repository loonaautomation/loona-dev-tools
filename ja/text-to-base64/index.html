テキスト→Base64エンコーダー

要するに： 任意のテキスト（英語、ウルドゥー語、アラビア語、中国語、絵文字）を貼り付けて、そのBase64エンコーディングを取得してください。エンコーダーはUTF-8バイトに作用するため、すべての文字が残ります。そして任意のURLセーフモードは、URLやJWTでの使用のために + と / を - と _ に交換します。
🔒 設計上プライベート： すべてはこのデバイス上のブラウザで動作します。あなたの入力がサーバーにアップロードされることは決してありません。

例

入力：

Hello, World!

出力：

SGVsbG8sIFdvcmxkIQ==

この変換ツールについて

Base64は、64文字のアルファベット（A–Z、a–z、0–9、+、/）から、データの3バイトごとに4文字で表現し、= のパディングで四の倍数に揃えます。テキストだけの経路（メール（MIME）、JSONやXMLのペイロード、data URI、HTTP基本認証）を通じて、バイナリや非ASCIIデータを安全に運ぶために存在します。アルファベットが小さいため、Base64の出力は入力より約33%大きくなります。決定的に重要なのは、Base64はエンコーディングであって暗号化ではないということです。誰でも即座にデコードできるため、秘密の保護として扱ってはいけません。このエンコーダーは、まずあなたのテキストをUTF-8バイト（普遍的なテキストエンコーディング）に変換します。そのため、アクセント付き文字、アラビア文字のテキスト、絵文字が、疑問符に化けることなく正しくエンコードされます。

よくある質問

なぜ私のテキストはBase64エンコードすると約三分の一増えますか？

3バイトごとに4文字になるため、出力は入力の4/3のサイズになります。それが安全な64文字のアルファベットを使う代償です。

URLセーフBase64とは何ですか？

標準Base64は + と / を使います。これらはURLでは他の意味を持ちます。URLセーフバリエーションはそれらを - と _ に置き換え、通常は = パディングを落とします。すべてのJWT内部のエンコーディングです。

Base64はテキストだけでなくファイルをエンコードできますか？

はい — このサイトの統合Base64ツールはファイルも受け付けます。このページはテキストに焦点を当てたバージョンです。ファイルバージョンはファイルをローカルで読み、アップロードすることは決してありません。
