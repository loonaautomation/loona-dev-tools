GZ 파일 추출기 - GZ 파일을 온라인에서 압축 해제

요약하면: GZ 파일 추출기는 브라우저에서 단일 .gz 파일을 압축 해제하고 원래 파일을 돌려줘요 - 로그, CSV 내보내기, 데이터베이스 덤프 - 원래 이름이 복원돼요. 업로드되는 것은 없어요.

.gz 파일은 파일이 가득한 아카이브가 아니에요 - Unix 세계의 일꾼인 gzip으로 압축된 정확히 하나의 파일이에요. 서버 로그, 데이터 내보내기, 데이터베이스 덤프가 이런 방식으로 이동하고, Windows에는 이를 열 내장 방법이 없어요. 이 페이지는 브라우저 자체의 내장 gzip 엔진(DecompressionStream API)으로 파일의 압축을 풀므로 빠르고 완전히 비공개예요.

여기에 .gz 파일을 놓으세요 또는 클릭해 기기에서 파일을 선택하세요
설계상 비공개: 이 도구의 모든 것은 브라우저 자체에 내장된 gzip 압축 해제를 사용해, 브라우저에서 100% 일어나요. .gz 파일은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요. 정직한 제한 하나: 압축 해제는 기기 메모리에서 일어나, 수 기가바이트로 확장되는 .gz는 메모리가 적은 휴대폰에서 어려움을 겪을 수 있어요.

GZ 파일 추출기 사용법

  1. .gz 파일을 위 상자에 놓거나, 클릭해 기기에서 파일을 고르세요.
  2. 파일은 즉시 압축 해제돼요 - 원래 파일 이름과 전체 크기를 표시하는 줄을 보세요.
  3. 압축 해제 파일 다운로드를 클릭해 원래 파일을 저장하세요(예: access.log.gz에서 access.log).

작동 방식

Gzip은 작은 헤더(만든 도구가 기록했을 경우 원래 파일 이름 포함), DEFLATE 알고리즘으로 압축된 데이터, 그리고 끝에 체크섬과 원래 크기를 저장해요. 최신 브라우저에는 기본 gzip 디코더가 내장되어 제공돼요 - 압축된 웹 페이지를 받는 데 사용하는 바로 그것이에요 - 그리고 이 페이지는 DecompressionStream API로 파일을 그곳에 통과시켜요. 라이브러리가 다운로드되지 않고 아무것도 어디에도 전송되지 않아요: 브라우저가 데이터를 부풀려 원래 바이트를 건네줘요.

풀이된 예시

서버가 access.log.gz(2.1 MB)를 줘요. 여기에 놓으면 약 일 초 만에 access.log(18.4 MB)로 압축이 풀려요. 다운로드하고 텍스트 편집기에서 열어 어젯밤의 오류를 찾아요 - 도구 하나도 설치하지 않고요.

자주 묻는 질문

.gz와 .tar.gz의 차이는 무엇인가요?

.gz 파일에는 압축된 파일이 정확히 하나 들어 있어요. .tar.gz는 먼저 여러 파일을 TAR 아카이브로 묶은 뒤 그 묶음을 gzip으로 압축하므로 전체 파일 트리를 담고 있어요. .tar.gz는 아래에 링크된 TAR.GZ 파일 추출기를 사용하세요.

압축 해제된 파일이 올바른 이름을 가질까요?

네 - 이 도구는 .gz 끝을 제거해 원래 이름을 복원해요(access.log.gz는 access.log가 돼요). 그것은 파일이 압축될 때 기록된 이름과 대다수의 경우에 일치해요.

이 도구가 실수로 .gz로 끝나는 .zip이나 .rar 파일을 열 수 있나요?

아니요 - 파일 이름을 바꾸는 것은 안에 있는 것을 바꾸지 않아요. 내용이 실제로 gzip 데이터가 아니면, 압축 해제가 명확한 메시지와 함께 실패해요. ZIP, RAR과 다른 실제 아카이브에는 아카이브 파일 추출기를 사용하세요.

크기 제한이 있나요?

도구에 내장된 제한은 없지만, 압축 해제된 파일은 브라우저 메모리에 보관돼요. 일상적인 로그와 내보내기(수백 메가바이트까지)는 대부분의 기기에서 괜찮아요; 수 기가바이트 덤프는 네이티브 도구가 있는 데스크톱에서 처리하는 것이 더 좋아요.

파일이 서버에 업로드되나요?

아니요. 압축 해제는 기기에서 브라우저 자체의 내장 엔진을 사용해요. 파일은 기계를 절대 떠나지 않아요 - 이 도구를 위한 라이브러리 다운로드조차 없어요.
