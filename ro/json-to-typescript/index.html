JSON în interfețe TypeScript

Pe scurt: lipește un obiect JSON (sau un tablou de obiecte) și obține interfețe TypeScript — obiecte imbricate extrase ca interfețe numite, chei lipsă din unele elemente ale tabloului marcate opțional cu ?.
🔒 Privat prin concepție: totul rulează în browserul tău pe acest dispozitiv. Datele tale introduse nu sunt încărcate niciodată pe un server.

Exemplu

Intrare:

{"name": "Ali", "age": 30, "skills": ["ts", "go"]}

Ieșire:

interface Root {
  name: string;
  age: number;
  skills: string[];
}

Despre acest convertizor

Generarea de tipuri din JSON eșantion este inferență, nu citire a gândurilor: convertizorul parcurge valoarea, mapează tipurile JSON în tipuri TypeScript (numerele unifică int/float în number, deoarece JSON însuși nu le distinge), extrage obiectele imbricate ca interfețe proprii numite după cheia lor și — când intrarea este un tablou de obiecte — fuzionează obiectele, marcând orice cheie care nu apare în fiecare element ca opțională. Câmpurile care sunt null în eșantion se tipează ca null; dacă datele tale reale au uneori un șir acolo, lărgește tipul. Tratează rezultatul ca o primă schiță puternică a tipurilor tale: revizuiește-o așa cum ai revizui pull request-ul unui coleg.

Întrebări frecvente

De ce numărul meu întreg a devenit pur și simplu "number"?

JSON are un singur tip numeric; interfețele TypeScript îl urmează. Distincția int/float apare doar în rezultatul Go (int64/float64).

Ce înseamnă ?-ul de pe un câmp?

Câmpul lipsea în cel puțin un obiect al tabloului de intrare, așa că este opțional în interfața îmbinată.
