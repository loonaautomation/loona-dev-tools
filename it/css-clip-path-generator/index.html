Generatore di clip-path CSS - Modella i tuoi elementi visivamente

In breve: il Generatore di clip-path CSS ti dà CSS clip-path pronto per poligoni (da triangolo a stella), cerchi, ellissi e inset - scegli una forma, regola i suoi punti, guarda l'anteprima live e copia il codice. Nota: gli strumenti Immagini gemelli di questo sito coprono già i gradienti; clip-path vive qui perché è CSS di layout, non modifica immagini.

Clip-path trasforma i rettangoli in design: sezioni angolate, badge, frecce e stelle con una proprietà CSS. La parte difficile sono le coordinate - questo strumento le gestisce.

Privato per design: tutto in questo strumento accade al 100% nel tuo browser con JavaScript. Il tuo input non viene mai caricato su un server, mai memorizzato e mai visto da noi - chiudi la scheda e tutto è andato.

Come usare il Generatore di clip-path CSS

  1. Scegli un preset di forma.
  2. Per i poligoni, regola le percentuali x,y di qualsiasi punto.
  3. Osserva l'anteprima aggiornarsi live.
  4. Copia il CSS - sono incluse sia la proprietà standard sia quella -webkit-.

Come funziona

I punti poligono sono percentuali della casella dell'elemento, quindi le forme si scalano con l'elemento. I preset codificano set di coordinate noti (un pentagono regolare, esagono, una stella a dieci punte e altro), e il generatore emette entrambi clip-path e il -webkit- gemello con prefisso che Safari ha storicamente richiesto. Cerchio, ellisse e inset coprono le forme non poligono che la proprietà supporta, inclusi inset arrotondati.

Domande frequenti

Questo generatore è gratuito?

Sì - completamente gratuito, nessuna registrazione.

Perché c'è anche un generatore di gradienti sul sito Immagini?

I gradienti lì sono trattati come asset immagine/design. Clip-path è CSS di layout per sviluppatori, quindi vive qui - ogni strumento esiste su esattamente un sito Loona.

clip-path influenza i clic?

Sì - l'area tagliata via non è cliccabile, che di solito è ciò che vuoi per pulsanti e schede sagomate.

Supporto browser?

Tutti i browser moderni supportano clip-path; il prefisso -webkit- nell'output copre Safari più vecchio.

Qualcosa viene caricato?

No. Tutto funziona nel tuo browser.
