CSV-zu-SQL-Konverter - CSV-Daten in jede Datenbank importieren

Kurz gesagt: das CSV-zu-SQL-Konverter liest Ihre CSV, leitet einen sinnvollen Typ für jede Spalte ab (Ganzzahl, Dezimalzahl, Boolean, Datum oder Text), bereinigt Tabellen- und Spaltennamen und gibt ein CREATE TABLE plus ein INSERT pro Zeile in Ihrem gewählten Dialekt aus.

Jeder Datenbank-Import beginnt als CSV und einem Stapel handgeschriebener INSERTs. Fügen Sie die CSV ein, wählen Sie MySQL, PostgreSQL oder SQLite und erhalten Sie importfertiges SQL mit einem Klick.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Eingabe wird niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg.

So verwenden Sie den CSV-zu-SQL-Konverter

  1. Fügen Sie Ihre CSV ein – die erste Zeile muss die Spaltennamen sein.
  2. Tippen Sie einen Tabellennamen ein und wählen Sie Ihren SQL-Dialekt.
  3. Lassen Sie CREATE TABLE aktiviert, wenn Sie auch die Tabellendefinition wollen.
  4. Klicken Sie auf „SQL generieren“ und kopieren Sie es dann oder laden Sie die .sql-Datei herunter.
  5. Führen Sie das SQL in Ihrem Datenbank-Client aus, um die Daten zu importieren.

So funktioniert es

Spaltentypen werden abgeleitet, indem jeder Wert in der Spalte gescannt wird: Ganze Zahlen werden zu Ganzzahlen, Dezimalzahlen zu Gleitkommazahlen, true/false zu Booleans und ISO-Daten (YYYY-MM-DD, mit optionaler Zeit) zu Datums-/Zeitstempelspalten. Eine Spalte mit gemischten Typen fällt auf den breitesten Typ zurück, und eine Spalte aus gemischten Zahlen und Text wird zu TEXT, damit nichts verloren geht. Leere Zellen werden zu NULL. Kennungen werden bereinigt – kleingeschrieben, Leerzeichen und Satzzeichen durch Unterstriche ersetzt, eine führende Ziffer vorangestellt – und dann für den Dialekt in Anführungszeichen gesetzt: Backticks für MySQL, doppelte Anführungszeichen für PostgreSQL und SQLite. String-Werte werden einfach angeführt, mit verdoppelten inneren Anführungszeichen, dem SQL-Standard-Escape.

Durchgerechnetes Beispiel

Die Zeile Ali,30,true unter name,age,active wird zu INSERT INTO "my_table" ("name", "age", "active") VALUES ('Ali', 30, TRUE); im PostgreSQL-Dialekt.

Häufig gestellte Fragen

Ist dieser CSV-zu-SQL-Konverter kostenlos?

Ja – völlig kostenlos, keine Registrierung, keine Obergrenze.

Wie werden Spaltentypen gewählt?

Durch Scannen aller Werte in jeder Spalte. Ganzzahlen, Dezimalzahlen, Booleans und ISO-Daten werden erkannt; gemischte Spalten fallen auf TEXT zurück.

Was geschieht mit leeren Zellen?

Sie werden in den INSERT-Anweisungen zu NULL.

Welche Dialekte werden unterstützt?

MySQL (Backtick-Anführung), PostgreSQL und SQLite (Doppel-Anführungszeichen-Anführung), mit dialektgerechten Typnamen.

Werden meine Daten hochgeladen?

Nein. Die Konvertierung geschieht vollständig in Ihrem Browser.
