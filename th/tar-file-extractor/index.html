ตัวแยกไฟล์ TAR - เปิดไฟล์ TAR ออนไลน์

สรุปสั้น ๆ: ตัวแยกไฟล์ TAR เปิดไฟล์บีบอัด .tar ในเบราว์เซอร์ของคุณ - รวมถึงรสชาติที่บีบอัด .tar.bz2 และ .tar.xz เรียกดูไฟล์ภายใน ดาวน์โหลดไฟล์เดียว หรือหยิบทุกอย่างที่แพ็กใหม่เป็น ZIP ไม่มีการอัปโหลด; งานเกิดขึ้นบนอุปกรณ์ของคุณ

TAR คือปู่ของรูปแบบไฟล์บีบอัดจากยุคเทป: บนเซิร์ฟเวอร์ Linux และ macOS ซอร์สโค้ด ข้อมูลสำรอง และชุดบันทึกยังคงเคลื่อนย้ายไปมาเป็นไฟล์ .tar - และ Windows ยังคงเปิดพวกมันโดยตรงไม่ได้ หน้านี้เปิด TAR ธรรมดาบวกกับรูปแบบที่บีบอัดด้วย BZIP2 และ XZ ของมันด้วยรุ่นพอร์ต WebAssembly ของ libarchive ทั้งหมดบนอุปกรณ์ของคุณ (สำหรับ .tar.gz ที่พบได้บ่อยยิ่งกว่า มีหน้าเฉพาะที่ลิงก์ไว้ด้านล่าง)

วางไฟล์ .tar, .tar.bz2 หรือ .tar.xz ของคุณที่นี่ หรือคลิกเพื่อเลือกไฟล์จากอุปกรณ์ของคุณ
ไฟล์ภายในไฟล์บีบอัดขนาด
เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณ ไฟล์บีบอัด TAR ถูกอ่านโดยกลไก WebAssembly บนอุปกรณ์ของคุณเอง - ไม่เคยถูกอัปโหลด ไม่เคยถูกจัดเก็บ ไม่เคยถูกเห็นโดยเรา ขีดจำกัดที่ซื่อตรงหนึ่งข้อ: ไฟล์บีบอัดถูกแกะในหน่วยความจำของอุปกรณ์ของคุณ ดังนั้นไฟล์บีบอัดที่ใหญ่มาก (หลายร้อยเมกะไบต์) อาจช้าหรือล้มเหลวบนโทรศัพท์ที่มีหน่วยความจำน้อย - แยกไฟล์เหล่านั้นบนคอมพิวเตอร์แทน

วิธีใช้ ตัวแยกไฟล์ TAR

  1. วางไฟล์ .tar, .tar.bz2 หรือ .tar.xz ของคุณลงบนกล่องด้านบน หรือคลิกมันแล้วเลือกไฟล์จากอุปกรณ์ของคุณ
  2. รอสักครู่ขณะที่ไฟล์บีบอัดถูกอ่าน - ในการใช้งานครั้งแรก กลไกการแยกไฟล์ (ประมาณ 1 MB) โหลดหนึ่งครั้งและจากนั้นถูกแคชโดยเบราว์เซอร์ของคุณ
  3. เรียกดูรายการไฟล์ภายในไฟล์บีบอัด พร้อมเส้นทางและขนาด
  4. คลิกดาวน์โหลดถัดจากไฟล์เดียวใด ๆ หรือใช้ดาวน์โหลดทั้งหมดเป็น ZIP เพื่อบันทึกทุกอย่างเป็นไฟล์ ZIP มาตรฐานเดียว

วิธีการทำงาน

ไฟล์ TAR ไม่ได้บีบอัดเลยแม้แต่น้อย - มันคือลำดับของบล็อกส่วนหัวขนาด 512 ไบต์และข้อมูลไฟล์ ที่เติมให้เต็มขนาดเรคคอร์ดตายตัว ซึ่งทำให้มันเหมาะอย่างยิ่งสำหรับเทปไดรฟ์ หน้านี้จะลบชั้นการบีบอัดด้านนอกออกก่อน (BZIP2 หรือ XZ) จากนั้นเดินสำรวจส่วนหัวของ TAR ด้วย libarchive ที่คอมไพล์เป็น WebAssembly พร้อมแสดงรายการทุกรายการพร้อมเส้นทางและขนาด ไฟล์จะถูกแยกออกมาเฉพาะเมื่อคุณดาวน์โหลดเท่านั้น ตัวเลือกดาวน์โหลดทั้งหมดเป็น ZIP จะบรรจุมันใหม่ด้วย JSZip

ตัวอย่างที่ทำแล้ว

ข้อมูลสำรองของเซิร์ฟเวอร์มาถึงในรูป logs-2026.tar.xz (9 MB) คุณเปิดมันที่นี่แล้วเห็นไฟล์ล็อก 143 ไฟล์ในโฟลเดอร์ที่แยกตามวันที่ แทนที่จะแกะทุกอย่างออกมา คุณดาวน์โหลดเพียงล็อกสองไฟล์จากวันที่ระบบล่ม (ประมาณไฟล์ละ 300 KB) แล้วปล่อยส่วนที่เหลือให้แพ็กอยู่เหมือนเดิม

คำถามที่พบบ่อย

อะไรคือความแตกต่างระหว่าง .tar, .tar.bz2 และ .tar.xz?

ภายในเป็นโครงสร้าง TAR เดียวกัน; มีเพียงการบีบอัดด้านนอกเท่านั้นที่ต่างกัน .tar ธรรมดาไม่บีบอัด .tar.bz2 ใช้ BZIP2 (การบีบอัดที่ดี ช้ากว่า) และ .tar.xz ใช้ XZ/LZMA2 (โดยปกติผลลัพธ์ที่เล็กที่สุด) ทั้งสามเปิดได้บนหน้านี้

แล้ว .tar.gz อยู่ที่ไหน? มันคืออันที่พบบ่อยที่สุดที่ฉันเห็น

มันมีหน้าเฉพาะของตัวเอง - ตัวแยกไฟล์ TAR.GZ ที่ลิงก์ไว้ด้านล่าง - เพราะ .tar.gz คือสิ่งที่คนส่วนใหญ่ได้รับจริง ในทางเทคนิคกลไกของหน้านี้ก็อ่าน .tar.gz ได้เช่นกัน; หน้าเฉพาะเพียงพูดถึงการค้นหานั้นและประเภทไฟล์นั้นโดยตรง

เครื่องมือนี้เปิดไฟล์ .tgz, .tbz2 หรือ .txz ได้หรือไม่?

.tbz2 และ .txz เป็นเพียงชื่อย่อของ .tar.bz2 และ .tar.xz และรองรับทั้งคู่ที่นี่ .tgz คือชื่อย่อของ .tar.gz - สำหรับไฟล์เหล่านั้นให้ใช้หน้า ตัวแยกไฟล์ TAR.GZ

ทำไมไฟล์ .tar ของฉันจึงใหญ่มากเมื่อเทียบกับ ZIP ของไฟล์เดียวกัน?

เพราะ TAR ธรรมดาไม่บีบอัดเลยแม้แต่น้อย - มันแค่มัดรวมเท่านั้น โฟลเดอร์ 100 MB กลายเป็น .tar ประมาณ 100 MB หากขนาดมีความสำคัญ รูปแบบที่บีบอัดแล้ว (.tar.gz, .tar.xz) หรือ ZIP เป็นตัวเลือกที่ดีกว่า

ไฟล์ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ กลไกคือ WebAssembly ที่ทำงานในแท็บเบราว์เซอร์ของคุณ; ไฟล์บีบอัดไม่เคยออกจากอุปกรณ์ของคุณ และเครื่องมือยังคงทำงานแบบออฟไลน์ได้เมื่อหน้าโหลดแล้ว
