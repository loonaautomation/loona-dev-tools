Μορφοποιητής & Ελεγκτής JSON - Όμορφη Εκτύπωση και Συμπίεση JSON

Εν συντομία: ο Μορφοποιητής JSON ελέγχει το JSON σας, το εκτυπώνει ωραία με εσοχή 2 κενών, 4 κενών ή tab, το συμπιέζει κατ' αίτηση, και αν κάτι είναι λάθος σας λέει την ακριβή γραμμή και στήλη του προβλήματος.

Το χαλασμένο JSON είναι η πιο συνηθισμένη πεντάλεπτη καθυστέρηση στη μέρα ενός προγραμματιστή - ένα κόμμα που λείπει και ολόκληρο το ωφέλιμο φορτίο αποτυγχάνει. Επικολλήστε το JSON σας παρακάτω: αν είναι έγκυρο παίρνετε καθαρή, αναγνώσιμη έξοδο· αν δεν είναι, παίρνετε την ακριβή θέση του σφάλματος αντί για ένα άχρηστο "η ανάλυση απέτυχε".

Ιδιωτικό εκ σχεδιασμού: τα πάντα σε αυτό το εργαλείο συμβαίνουν 100% στο πρόγραμμα περιήγησής σας με JavaScript. Η είσοδός σας δεν ανεβαίνει ποτέ σε διακομιστή, δεν αποθηκεύεται ποτέ και δεν φαίνεται ποτέ από εμάς - κλείστε την καρτέλα και τα πάντα χάνονται.

Πώς να χρησιμοποιήσετε τον Μορφοποιητή JSON

  1. Επικολλήστε ή πληκτρολογήστε το JSON σας στο επάνω πλαίσιο.
  2. Επιλέξτε στυλ εσοχής - 2 κενά, 4 κενά ή tab.
  3. Κάντε κλικ στο Μορφοποίηση / Επικύρωση για αναγνώσιμη έξοδο ή στο Συμπίεση για τη μικρότερη έγκυρη μορφή.
  4. Αντιγράψτε το αποτέλεσμα ή κατεβάστε το ως αρχείο .json.

Πώς λειτουργεί

Το εργαλείο χρησιμοποιεί τον ενσωματωμένο αναλυτή JSON του προγράμματος περιήγησής σας - τον ίδιο αυστηρό αναλυτή που χρησιμοποιεί ο δικός σας κώδικας JavaScript - οπότε ένα πράσινο φως εδώ σημαίνει ότι το JSON σας είναι πραγματικά έγκυρο. Η ωραία εκτύπωση επανασειριοποιεί την αναλυμένη τιμή με την επιλεγμένη εσοχή σας· η σειρά κλειδιών διατηρείται ακριβώς όπως γράφτηκε. Η συμπίεση αφαιρεί κάθε περιττό κενό και νέα γραμμή χωρίς να αλλάζει ούτε μία τιμή. Όταν η ανάλυση αποτυγχάνει, το εργαλείο μετατρέπει τη θέση χαρακτήρα του αναλυτή σε γραμμή και στήλη και σάς δείχνει τη γραμμή που παραβιάζει.

Παράδειγμα με επεξεργασία

Λαμβάνετε {"user":"ahmed","roles":["admin","editor"],"active":true} από ένα API. Μορφοποιημένο με 2 κενά γίνεται ένα καθαρό έγγραφο εννέα γραμμών που μπορείτε πραγματικά να διαβάσετε - και αν διαγράψετε κατά λάθος το κόμμα μετά το "ahmed", το εργαλείο αναφέρει το σφάλμα στην ακριβή γραμμή και στήλη αντί να σας αφήσει να το κυνηγήσετε.

Συχνές Ερωτήσεις

Είναι αυτός ο μορφοποιητής JSON δωρεάν;

Ναι - εντελώς δωρεάν, χωρίς εγγραφή, χωρίς όριο μεγέθους και χωρίς ημερήσιο όριο.

Τι συμβαίνει όταν το JSON μου είναι μη έγκυρο;

Παίρνετε το μήνυμα σφάλματος του αναλυτή συν την ακριβή γραμμή και στήλη όπου η ανάλυση απέτυχε, και το κείμενο αυτής της γραμμής, οπότε μπορείτε να το διορθώσετε σε δευτερόλεπτα.

Αλλάζει η μορφοποίηση τα δεδομένα μου;

Όχι. Η μορφοποίηση αλλάζει μόνο τα κενά. Η συμπίεση αφαιρεί μόνο τα κενά. Τα κλειδιά, οι τιμές και η σειρά τους μένουν ανέπαφα.

Μεταφορτώνεται το JSON μου σε διακομιστή;

Όχι. Η ανάλυση και η μορφοποίηση συμβαίνουν 100% στο πρόγραμμα περιήγησής σας. Τα φορτία API και τα αρχεία ρυθμίσεων δεν φεύγουν ποτέ από τη συσκευή σας.

Μπορώ να μορφοποιήσω πραγματικά μεγάλο JSON;

Ναι - το πρακτικό όριο είναι η μνήμη της συσκευής σας. Αρχεία πολλών megabytes μορφοποιούνται σε πολύ λιγότερο από ένα δευτερόλεπτο σε έναν τυπικό φορητό υπολογιστή.
