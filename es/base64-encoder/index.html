Codificador y decodificador Base64 - Texto y archivos, seguro con UTF-8

En resumen: el Codificador Base64 convierte texto y archivos a Base64 y decodifica Base64 de vuelta a texto, manejando correctamente acentos, urdu, chino y emoji, con un alfabeto opcional seguro para URL.

Base64 aparece en todas partes: cargas de API, adjuntos de correo, URI de datos, encabezados de autenticación básica y partes de JWT. El problema de muchos codificadores rápidos es que se rompen con texto que no está en inglés. Este codifica los bytes UTF-8 de tu texto, así que todo lo que puedas escribir sobrevive al viaje de ida y vuelta.

Archivo a Base64

Elige un archivo para obtener su cadena de datos Base64 (útil para URI de datos y cargas de prueba). El archivo se lee localmente: nunca se sube.

Privado por diseño: todo en esta herramienta sucede 100% en tu navegador con JavaScript. Tu entrada nunca se sube a un servidor, nunca se almacena y nunca la vemos nosotros: cierra la pestaña y todo desaparece.

Cómo usar el Codificador y decodificador Base64

  1. Escribe o pega tu texto (o elige un archivo para archivo a Base64).
  2. Opcionalmente marca seguro para URL si el resultado va a una URL o a un JWT.
  3. Haz clic en Codificar o Decodificar y copia o descarga el resultado.

Cómo funciona

Base64 representa cada 3 bytes de datos como 4 caracteres de un alfabeto de 64 caracteres, lo que hace seguro transportar datos binarios dentro de formatos de texto como JSON, XML y URL. Esta herramienta primero convierte tu texto a sus bytes UTF-8 (la codificación universal para texto) y luego codifica esos bytes: por eso las letras acentuadas, el texto en alfabeto árabe y los emoji se decodifican de vuelta perfectamente. La variante segura para URL cambia + y / por - y _ y elimina el relleno =, exactamente como se usa en los JSON Web Tokens.

Ejemplo resuelto

El texto «Loona» se codifica a TG9vbmE=. El saludo «Assalam-o-Alaikum» con escritura urdu y un emoji (السلام علیكم 👋) se codifica y se decodifica de vuelta letra por letra, algo que los codificadores ingenuos que solo manejan ASCII simple no pueden hacer.

Preguntas frecuentes

¿Esta herramienta Base64 es gratuita?

Sí: gratis, sin registro, sin límites.

¿Por qué algunas herramientas Base64 desfiguran el texto no inglés?

Codifican cada carácter como un solo byte, lo que solo funciona para ASCII simple. Esta herramienta codifica en su lugar los bytes UTF-8, así que cada idioma y emoji hace el viaje de ida y vuelta exactamente.

¿Qué es la opción segura para URL?

El Base64 estándar puede contener + y /, que son caracteres especiales en las URL. El alfabeto seguro para URL los reemplaza por - y _ y elimina el relleno: la variante usada en los JWT.

¿Base64 es cifrado?

No. Base64 es una codificación, no un cifrado: cualquiera puede decodificarlo al instante. Nunca lo uses para proteger secretos.

¿Mis archivos se suben?

No. Los archivos los lee tu navegador en tu dispositivo y nunca salen de él.
