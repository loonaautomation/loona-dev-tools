ตัวแยกวิเคราะห์ User Agent

สรุปสั้น ๆ: วางสตริง User-Agent ใด ๆ แล้วรับรายละเอียดที่อ่านได้ — เบราว์เซอร์ เวอร์ชัน กลไกเรนเดอร์ ระบบปฏิบัติการ และคลาสอุปกรณ์
🔒 เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างทำงานในเบราว์เซอร์ของคุณบนอุปกรณ์นี้ อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์

เกี่ยวกับ

การแยกวิเคราะห์ User-Agent คือการจับคู่แพทเทิร์นกับสตริงที่ไม่เคยเป็นมาตรฐานและตอนนี้ถูกตรึงโดยเจตนาโดยเบราว์เซอร์ (Chrome ลดความละเอียด UA เพื่อสนับสนุน Client Hints) เพื่อตัดการทำลายนิ้วมือ ตัวแยกวิเคราะห์นี้ใช้กฎการตรวจจับกระแสหลักในลำดับความสำคัญที่ถูกต้อง — Edge ก่อน Chrome (UA ของมันมี "Chrome") Opera ก่อน Chrome, Safari ที่มีเวอร์ชันผ่านโทเค็น Version ของมัน — และตั้งชื่อตระกูลกลไกและระบบปฏิบัติการ มันคือเครื่องมือที่ถูกต้องสำหรับการอ่านบันทึกและตั๋วสนับสนุน; มันคือเครื่องมือที่ผิดสำหรับการตัดสินใจด้านความปลอดภัย เนื่องจากสตริง UA คืออะไรก็ตามที่ไคลเอนต์อ้างว่าเป็น

คำถามที่พบบ่อย

ทำไม UA ของ Edge จึงบอกว่า Chrome และ Safari?

ความเข้ากันได้ทางประวัติศาสตร์: เบราว์เซอร์ทุกตัวอ้างมรดก Mozilla และ WebKit เพื่อให้การดมกลิ่นเซิร์ฟเวอร์เก่าส่งไซต์สมัยใหม่ให้มัน ตัวแยกวิเคราะห์ต้องตรวจสอบโทเค็นที่โดดเด่นก่อน

UA เชื่อถือได้สำหรับการควบคุมการเข้าถึงหรือไม่?

ไม่เคย — มันปลอมแปลงได้ง่ายมาก ใช้มันสำหรับการวิเคราะห์และการดีบัก ไม่ใช่การยืนยันตัวตน

{ }

ตรวจสอบความถูกต้อง พิมพ์อย่างสวยงาม และย่อขนาด JSON พร้อมตำแหน่งที่แม่นยำของข้อผิดพลาดใด ๆ

.*
