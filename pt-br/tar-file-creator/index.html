Criador de Arquivos TAR - Crie um Arquivo .tar a Partir dos Seus Arquivos

Em resumo: o Criador de Arquivos TAR agrupa qualquer conjunto de arquivos num único arquivo .tar padrão utilizando um escritor ustar correto segundo a especificação no seu navegador - acrescente arquivos, agrupe-os opcionalmente numa pasta, e transfira.

TAR continua a ser a língua franca de Linux, servidores e cópias de segurança - mas os usuários Windows que precisam de produzir um tarball normalmente têm de instalar algo primeiro. Esta página escreve arquivos TAR genuínos no seu navegador: cabeçalhos ustar adequados, somas de verificação e carimbos temporais, construídos no seu dispositivo sem nada carregado.

Lembre-se: TAR não comprime. O .tar terá cerca do tamanho de todos os arquivos somados (arredondado para blocos de 512-byte). Precisa dele mais pequeno? Passe depois o resultado pelo Compressor GZIP, ou utilize antes o Criador de Arquivos ZIP.

Privado por concepção: tudo nesta ferramenta acontece 100% no seu navegador com JavaScript. Os seus arquivos nunca são carregados para um servidor, nunca salvos e nunca vistos por nós - feche a aba e tudo desaparece. Um limite honesto: a conversão acontece na memória do seu dispositivo, pelo que arquivos muito grandes (centenas de megabytes) podem ser lentos ou falhar num celular com pouca memória.

Como utilizar o Criador de Arquivos TAR

  1. Largue os seus arquivos na caixa acima, ou clique nela e escolha arquivos do seu dispositivo. Pode adicionar arquivos em várias rondas.
  2. Verifique a lista - remova tudo o que foi adicionado por engano e observe o tamanho total.
  3. Opcionalmente escreva um nome de pasta para que todos os arquivos fiquem dentro de uma pasta no arquivo, e dê um nome ao TAR.
  4. Clique em Criar TAR e Transferir. O .tar abre com tar em Linux/macOS e com 7-Zip ou WinRAR em Windows.

Como funciona

Um arquivo TAR é um fluxo de registros: para cada arquivo, um bloco de cabeçalho ustar de 512-byte (nome do arquivo, tamanho em octal, hora de modificação, uma soma de verificação do próprio cabeçalho, a magia 'ustar' e um campo de prefixo que permite caminhos com mais de 100 caracteres - com entradas GNU longname para caminhos ainda maiores), seguido do conteúdo do arquivo preenchido até um número inteiro de blocos de 512-byte. Dois blocos zero fecham o arquivo. Esta página implementa esse formato diretamente - sem biblioteca, sem servidor - e o escritor foi verificado fazendo o módulo tarfile do Python ler o seu resultado byte a byte. O TAR armazena arquivos sem compressão, pelo que o arquivo é a soma das suas partes; a compressão é um passo separado (é isso que o .tar.gz acrescenta).

Exemplo resolvido

Acrescenta três arquivos: deploy.sh (1 KB), config.yml (3 KB) e logo.png (48 KB), com o nome da pasta definido como 'release'. A ferramenta produz release.tar - ou o nome que escolher - contendo uma pasta release com os três arquivos, cada um mantendo a sua hora de modificação real. Com 52 KB de conteúdo, o TAR sai com cerca de 54 KB: os próprios arquivos, três cabeçalhos e preenchimento, sem compressão - exatamente o que o tar produziria no Linux.

Perguntas Frequentes

Este criador de arquivos TAR é grátis?

Sim - grátis, sem registro, sem limites e sem marcas de água.

Os meus arquivos são carregados para um servidor?

Não. O TAR é escrito por JavaScript a funcionar no seu navegador, no seu dispositivo. Os seus arquivos nunca saem dele.

Porque é que o TAR tem o mesmo tamanho que os meus arquivos - ou um pouco maior?

O TAR não comprime nada; apenas agrupa. Cada arquivo também acrescenta um cabeçalho de 512-byte e é preenchido até um limite de 512-byte, pelo que o arquivo é ligeiramente maior do que o total em bruto. Para um tarball comprimido, crie o TAR aqui e depois passe-o pelo Compressor GZIP - é literalmente assim que o .tar.gz é feito.

O Linux e o GNU tar aceitarão arquivos feitos aqui?

Sim. O escritor segue a especificação ustar - campos octais e soma de verificação de cabeçalho corretos, a magia ustar, divisão de prefixos para caminhos longos e entradas longname GNU para os muito longos - e a sua saída foi verificada lendo-a de volta com o módulo tarfile do Python durante os testes.

Posso adicionar arquivos a um TAR existente ou criar um .tar.gz diretamente?

Não nesta ferramenta - cria um arquivo novo de cada vez. Para transformar um ZIP existente num .tar.gz num passo, utilize o Conversor de ZIP para TAR.GZ; para comprimir este TAR para um .tar.gz, utilize depois o Compressor GZIP e renomeie o resultado para .tar.gz.
