무작위 비밀번호 생성기

요약하면: 브라우저의 암호학적 무작위 출처로 진정으로 무작위한 비밀번호를 생성하세요 — 길이와 문자 집합을 선택하고, 비트 단위 엔트로피를 보세요.
🔒 설계상 비공개: 모든 것이 이 기기의 브라우저에서 실행돼요. 입력은 서버에 절대 업로드되지 않아요.

소개

비밀번호 강도는 엔트로피예요: 길이에 문자 풀의 로그를 곱한 것이에요. 이 생성기는 crypto.getRandomValues를 사용해요 — 운영 체제의 암호학적 무작위 출처로, 브라우저 보안 내부와 같은 품질이에요 — Math.random은 절대 아니에요. 예측 가능하고 실제 토큰/비밀번호 침해의 근본 원인이었어요. 솔직한 틀: 웹 페이지의 생성기는 일회용과 가치가 낮은 계정에는 괜찮아요; 중요한 모든 것에는 비밀번호 관리자의 내장 생성기를 사용하고, 결과를 거기에 저장하고(절대 텍스트 파일이나 스크린샷에는 안 돼요), 관리자가 기억하도록 16자 이상을 선호해 직접 기억할 필요가 없게 하세요.

자주 묻는 질문

비밀번호는 얼마나 길어야 하나요?

중요한 계정은 최소 16자; 길이가 복잡성 요령보다 강해요. 이 페이지의 무작위 비밀번호 20자는 모든 집합을 켰을 때 약 130 bits의 엔트로피를 가져요.

웹 페이지에서 생성하는 것이 안전한가요?

이 페이지는 WebCrypto로 로컬에서 생성하고 아무것도 어디로도 보내지 않아요. 가치가 높은 비밀에는, 검증된 비밀번호 관리자'의 생성기가 여전히 가장 좋은 방법이에요.
