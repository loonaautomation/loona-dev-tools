Estrattore di file TAR.GZ - Apri file TAR.GZ e TGZ online

In breve: l'Estrattore di file TAR.GZ apre archivi .tar.gz e .tgz direttamente nel tuo browser - esplora i file dentro, scarica singoli file, o salva tutto reimpacchettato come ZIP. Nessuna installazione, nessun caricamento: l'estrazione gira sul tuo dispositivo.

Se scarichi codice sorgente, backup WordPress, snapshot server o qualsiasi cosa dal mondo Linux, arriva come .tar.gz - un pacchetto TAR stretto con gzip. Windows Explorer non può aprirlo, il che lascia molte persone bloccate con un file in cui non possono nemmeno sbirciare. Questa pagina lo apre con un port WebAssembly di libarchive, interamente nel tuo browser.

Privato per design: tutto in questo strumento accade al 100% nel tuo browser. L'archivio viene decompresso da un motore WebAssembly sul tuo stesso dispositivo - mai caricato, mai memorizzato, mai visto da noi. Un limite onesto: l'archivio viene spacchettato nella memoria del tuo dispositivo, quindi un enorme archivio di backup (centinaia di megabyte non compressi) può essere lento o fallire su un telefono con poca memoria.

Come usare l'Estrattore di file TAR.GZ

  1. Trascina il tuo file .tar.gz o .tgz sulla casella sopra, o fai clic e scegli il file dal tuo dispositivo.
  2. Aspetta un momento mentre l'archivio viene letto - al primo uso il motore di estrazione (circa 1 MB) si carica una volta ed è poi memorizzato nella cache dal tuo browser.
  3. Sfoglia l'elenco dei file dentro l'archivio, con le loro cartelle e dimensioni.
  4. Fai clic su Scarica accanto a qualsiasi singolo file, o usa Scarica tutto come ZIP per salvare l'intero archivio come un unico file ZIP standard.

Come funziona

Un .tar.gz ha due strati: uno strato gzip esterno che comprime, e uno strato TAR interno che raggruppa molti file in un unico flusso. Questa pagina li rimuove entrambi con libarchive compilato in WebAssembly - prima la decompressione gzip, poi una passeggiata sulle intestazioni TAR per elencare ogni voce con il suo percorso e la dimensione non compressa. I file vengono estratti solo quando li scarichi, e l'opzione Scarica tutto come ZIP li reimpacchetta con JSZip così il risultato si apre ovunque.

Esempio pratico

Il pannello di hosting ti dà un backup completo del sito come backup-2026-11-01.tar.gz (260 MB). Lo apri qui, navighi l'elenco fino a wp-content/uploads, e scarichi le tre foto che hai eliminato accidentalmente (4 MB totali) - invece di ripristinare l'intero backup o installare strumenti per guardarci dentro.

Domande frequenti

Qual è la differenza tra .tar.gz e .tgz?

Nessuno - sono esattamente lo stesso formato. Il nome .tgz è solo una versione abbreviata dai giorni in cui le estensioni file erano limitate a tre caratteri. Questa pagina accetta entrambi.

Ho un file .gz semplice, non .tar.gz. Funzionerà qui?

Un semplice .gz contiene esattamente un file compresso, non un archivio. Usa l'Estrattore di file GZ collegato sotto per quelli - decomprime il singolo file direttamente. Questa pagina è per gli archivi che contengono molti file.

Questo strumento può creare file .tar.gz?

No, questa pagina è solo un estrattore. Per raggruppare file in un archivio qui, usa il Creatore di file ZIP - ZIP si apre ovunque, inclusi i sistemi Linux che producono file .tar.gz.

Perché il mio archivio si è aperto ma mostra nomi lunghi strani o link?

Gli archivi TAR dai server spesso contengono link simbolici e voci dispositivo accanto ai file regolari. Questo strumento elenca ed estrae file regolari; i link sono mostrati nell'elenco dove il formato li registra, ma non vengono ricreati come link nei tuoi download.

I miei file vengono caricati da qualche parte per l'estrazione?

No. La decompressione funziona in WebAssembly dentro la scheda del tuo browser. Il backup e tutto al suo interno restano sul tuo dispositivo dall'inizio alla fine.
