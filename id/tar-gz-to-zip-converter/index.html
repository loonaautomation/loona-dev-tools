Konverter TAR.GZ ke ZIP - Ubah .tar.gz dan .tgz menjadi .zip

Singkatnya: Konverter TAR.GZ ke ZIP membuka kedua lapisan arsip .tar.gz (atau .tgz) di perangkat Anda - gzip terlebih dahulu, lalu tar - dan mengemas ulang file sebagai .zip standar tunggal.

File .tar.gz adalah dua format dalam satu mantel: file digabungkan dengan tar, lalu dikompresi dengan gzip. Linux menghasilkannya di mana-mana - rilis sumber, cadangan, log - tetapi Windows dan ponsel tidak dapat membukanya secara bawaan. Konverter ini membuka kedua lapisan secara lokal di browser Anda dan memberikan satu ZIP biasa kepada Anda.

Privat berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di browser Anda dengan JavaScript. File Anda tidak pernah diunggah ke server, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang. Satu batas jujur: konversi terjadi dalam memori perangkat Anda, jadi arsip yang sangat besar (ratusan megabita) dapat lambat atau gagal di ponsel memori rendah.

Cara menggunakan Konverter TAR.GZ ke ZIP

  1. Jatuhkan file .tar.gz atau .tgz Anda ke kotak di atas, atau klik dan pilih file dari perangkat Anda.
  2. Klik Konversi ke ZIP. Kedua lapisan gzip dan tar dibuka di perangkat Anda dan file dikemas ulang sebagai ZIP.
  3. Periksa ringkasan: jumlah file yang ditemukan dan ukuran ZIP baru.
  4. Klik Unduh untuk menyimpan file .zip - file itu terbuka dengan alat bawaan sistem apa pun.

Cara kerja

Di balik layar halaman ini menyerahkan file Anda ke build WebAssembly libarchive, yang memahami pembungkus gzip dan arsip tar di dalamnya sebagai satu aliran - persis seperti tar -xzf memperlakukannya di Linux. File yang diekstrak kemudian ditulis ke ZIP baru oleh JSZip, masing-masing pada path aslinya. Perhatikan perbedaan antara ini dan file .gz polos: .tar.gz mengandung banyak file, sementara .gz tunggal biasanya membungkus satu file (untuk itulah Ekstraktor File GZ). Halaman ini menerima ejaan .tar.gz dan .tgz yang disingkat - mereka format yang sama.

Contoh yang dikerjakan

Anda mengunduh release-2.4.tar.gz (18 MB) alat open-source ke PC Windows. Alat membuka bungkusnya di sini dan menghasilkan release-2.4.zip (19 MB) yang mengandung 86 file yang sama dalam folder yang sama - siap dibuka di Explorer, tanpa Linux dan tanpa perangkat lunak tambahan yang terlibat.

Pertanyaan yang Sering Diajukan

Apakah konverter TAR.GZ ke ZIP ini gratis?

Ya - gratis, tanpa pendaftaran, tanpa batas, dan tanpa watermark.

Apakah file saya diunggah ke server?

Tidak. Kedua lapisan dibuka dan ZIP dibangun sepenuhnya di browser Anda; tidak ada yang meninggalkan perangkat Anda.

Apa perbedaan antara .tar.gz dan .tgz?

Tidak ada - .tgz hanyalah ejaan singkat dari .tar.gz, dibuat untuk sistem yang pernah hanya mengizinkan ekstensi tiga huruf. Alat ini menerima keduanya.

File saya .gz biasa, bukan .tar.gz. Apa yang sebaiknya saya gunakan?

File .gz biasa membungkus satu file terkompresi, bukan arsip berisi banyak file. Gunakan Ekstraktor File GZ untuk mengambil kembali file aslinya.

Mengapa ZIP kira-kira sama ukurannya dengan .tar.gz?

Kedua format mengompresi dengan baik - gzip pada tar, DEFLATE di dalam ZIP - jadi ukuran output yang mirip memang diharapkan. Kemenangannya adalah kompatibilitas: ZIP terbuka di mana-mana.
