สรุปสั้น ๆ: Loona Developer Tools มอบเครื่องมือฟรี 71 รายการให้คุณเพื่อจัดรูปแบบ เข้ารหัส ถอดรหัส สร้าง และแปลงข้อมูลที่นักพัฒนาจัดการทุกวัน - ทั้งหมดประมวลผลเป็นส่วนตัวภายในเบราว์เซอร์ของคุณ

เลือกเครื่องมือด้านล่างและทำงานให้เสร็จในไม่กี่วินาที ไม่มีบัญชี ไม่มีคิว ไม่มีลายน้ำ

ฟรี 100%ไม่ต้องสมัครสมาชิกข้อมูลไม่เคยออกจากอุปกรณ์ของคุณใช้งานบนมือถือได้

เครื่องมือสำหรับนักพัฒนาทั้งหมด 71 รายการ

⇄

คลังตัวแปลงและตัวสร้าง

ตัวแปลงและตัวสร้างใหม่ 126 รายการ: การเข้ารหัส รูปแบบข้อมูล (JSON, YAML, XML, TOML, CSV) แฮช สี ไฟล์บีบอัด ตัวสร้างโค้ด และข้อมูลอ้างอิง
{ }

ตัวจัดรูปแบบ JSON

ตรวจสอบความถูกต้อง พิมพ์อย่างสวยงาม และย่อขนาด JSON พร้อมตำแหน่งที่แม่นยำของข้อผิดพลาดใด ๆ

64

ตัวเข้ารหัสและถอดรหัส Base64

เข้ารหัสข้อความและไฟล์เป็น Base64 หรือถอดรหัสกลับ - ปลอดภัยกับ UTF-8 รวมตัวเลือกแบบปลอดภัยสำหรับ URL

%20

ตัวเข้ารหัสและถอดรหัส URL

เข้ารหัสเปอร์เซ็นต์ข้อความและ URL อย่างปลอดภัย พร้อมตารางรายละเอียดแยกตามตัวอักษร

ID

ตัวสร้าง UUID

สร้าง UUID เวอร์ชัน 4 แบบสุ่ม - ทีละตัวหรือจำนวนมากสูงสุด 100 ตัว

#

ตัวสร้างแฮช

ค่าแฮช SHA-1, SHA-256, SHA-384 และ SHA-512 ของข้อความใด ๆ คำนวณในเบราว์เซอร์ของคุณ

JWT

ตัวถอดรหัส JWT

ถอดรหัสส่วนหัวและ payload ของ JSON Web Token แล้วอ่านวันหมดอายุของมันเป็นคำธรรมดา

TS

ตัวแปลงการประทับเวลา

แปลง Unix timestamp เป็นวันที่มนุษย์อ่านได้และกลับกัน - UTC เวลาท้องถิ่นของคุณ และเวลาสัมพัทธ์

&

ตัวเข้ารหัส HTML Entity

Escape ข้อความเป็น HTML entity (แบบมีชื่อหรือแบบตัวเลข) และถอดรหัส entity กลับเป็นข้อความ

CSS

ตัวย่อขนาดและจัดรูปแบบ CSS

ย่อขนาด CSS เพื่อลดขนาดไฟล์ หรือจัดรูปแบบมันกลับเป็นโค้ดที่อ่านง่ายและเยื้องเรียบร้อย

JS

ตัวย่อขนาด JavaScript

ย่อขนาด JavaScript อย่างระมัดระวัง - คอมเมนต์และช่องว่างที่ไร้ประโยชน์ถูกลบออก สตริงและ regex ยังคงสมบูรณ์

.*

ตัวทดสอบ Regex

ทดสอบ Regular Expression แบบสด - การจับคู่ถูกไฮไลต์ กลุ่มที่จับแสดงรายการ จำนวนแสดงไว้

±

ตัวตรวจสอบความแตกต่าง

เปรียบเทียบข้อความสองชุดทีละบรรทัด - บรรทัดที่เพิ่มและลบถูกไฮไลต์ พร้อมบทสรุปการเปลี่ยนแปลง

CSV

ตัวแปลง JSON เป็น CSV

เปลี่ยนอาร์เรย์ JSON ของออบเจ็กต์เป็นไฟล์ CSV ที่สะอาด - การรวมกันของทุกคีย์ การใส่เครื่องหมายคำพูดที่เหมาะสม คลิกเดียว

JSON

ตัวแปลง CSV เป็น JSON

แปลง CSV เป็นอาร์เรย์ JSON ของออบเจ็กต์ - ตัวแยกวิเคราะห์จริงที่จัดการจุลภาคในเครื่องหมายคำพูดและเครื่องหมายคำพูดที่ escape

YAML

ตัวแปลง YAML ⇄ JSON

แปลงชุดย่อยทั่วไปของ YAML (แมป รายการ ค่าสเกลาร์) เป็น JSON และ JSON กลับเป็น YAML - ขอบเขตที่ระบุอย่างซื่อตรง

SQL

ตัวจัดรูปแบบ SQL

จัดรูปแบบ SQL ด้วยคีย์เวิร์ดตัวพิมพ์ใหญ่และแต่ละประโยคหลักอยู่บนบรรทัดของตัวเอง - คิวรีที่อ่านง่ายในคลิกเดียว

01

ตัวแปลงเลขฐาน

แปลงระหว่างเลขฐานสอง เลขฐานแปด เลขฐานสิบ และเลขฐานสิบหก ด้วยความแม่นยำจำนวนเต็มเต็มรูปแบบ - ไม่มีขีดจำกัด 2^53

755

เครื่องคำนวณ Chmod

ติ๊กช่องอ่าน/เขียน/เรียกใช้สำหรับเจ้าของ กลุ่ม และอื่น ๆ - รับสิทธิ์เลขฐานแปดและแบบสัญลักษณ์ทันที

***

ตัวตรวจสอบความแข็งแกร่งของรหัสผ่าน

ดูการประมาณเอนโทรปีของรหัสผ่านในหน่วยบิต อะไรทำให้มันอ่อนแอลง และการโจมตีแบบออฟไลน์อย่างรวดเร็วจะใช้เวลานานเท่าใด

* *

ตัวสร้างนิพจน์ Cron

สร้างนิพจน์ cron แบบ 5 ฟิลด์จากเมนูดรอปดาวน์ธรรมดา และรับคำอธิบายนิพจน์ cron ใด ๆ เป็นภาษาไทยที่เข้าใจง่าย

URL

ตัวแยกวิเคราะห์และสร้าง URL

แยก URL ออกเป็นโปรโตคอล โฮสต์ พอร์ต เส้นทาง พารามิเตอร์คิวรี และแฮช - จากนั้นแก้ไขพารามิเตอร์และสร้างมันใหม่

ZIP

ตัวสร้างไฟล์ ZIP

รวมหลายไฟล์เป็นไฟล์บีบอัด ZIP เดียว - สร้างในเบราว์เซอร์ของคุณ ไม่มีการอัปโหลดใด ๆ

UNZIP

ตัวแยกไฟล์แบบเปิด zip

เปิด ZIP ดูทุกไฟล์ภายในพร้อมขนาดของมัน และแยกไฟล์เดียวหรือทั้งหมด

RAR

ตัวแยกไฟล์ RAR

เปิดไฟล์ RAR (RAR4 และ RAR5) ในเบราว์เซอร์ของคุณ - ดูทุกไฟล์ภายใน ดาวน์โหลดไฟล์เดียวหรือทุกอย่างเป็น ZIP

7Z

ตัวแยกไฟล์ 7Z

เปิดไฟล์บีบอัด 7z ในเบราว์เซอร์ของคุณ - ดูเนื้อหาและแยกไฟล์เดียวหรือทุกอย่างเป็น ZIP

TAR

ตัวแยกไฟล์ TAR

เปิดไฟล์บีบอัด .tar, .tar.bz2 และ .tar.xz ในเบราว์เซอร์ของคุณและแยกไฟล์ภายใน - ไม่มีการอัปโหลด

TGZ

ตัวแยกไฟล์ TAR.GZ

เปิดไฟล์บีบอัด .tar.gz และ .tgz ในเบราว์เซอร์ของคุณ - เรียกดูไฟล์ภายในและแยกสิ่งที่คุณต้องการ

GZ

ตัวแยกไฟล์ GZ

คลายการบีบอัดไฟล์ .gz เดียวในเบราว์เซอร์ของคุณและดาวน์โหลดไฟล์ต้นฉบับ - ล็อก การส่งออกข้อมูล และดัมป์ฐานข้อมูล

ISO

ตัวแยกไฟล์ ISO

เปิดอิมเมจดิสก์ ISO ในเบราว์เซอร์ของคุณ เรียกดูระบบไฟล์ที่เก็บบนแผ่นดิสก์เสมือน และดาวน์โหลดไฟล์

ARC

ตัวแยกไฟล์บีบอัด

ตัวเปิดไฟล์บีบอัดสากลหนึ่งเดียวสำหรับ ZIP, RAR, 7Z, TAR, ISO และอื่น ๆ - รูปแบบถูกตรวจจับโดยอัตโนมัติ

R→ZIP

ตัวแปลง RAR เป็น ZIP

แปลงไฟล์บีบอัด RAR เป็น ZIP ในเบราว์เซอร์ของคุณ - โครงสร้างโฟลเดอร์ถูกรักษาไว้ ไม่มีการอัปโหลด

7→ZIP

ตัวแปลง 7Z เป็น ZIP

แปลงไฟล์บีบอัด 7Z เป็น ZIP ที่เปิดได้ทุกที่ - ไม่ต้องใช้ 7-Zip ไม่มีการอัปโหลด

T→ZIP

ตัวแปลง TAR เป็น ZIP

แปลงไฟล์บีบอัด TAR จาก Linux หรือ Unix เป็น ZIP ที่เปิดโดยตรงได้บน Windows, macOS และโทรศัพท์

G→ZIP

ตัวแปลง TAR.GZ เป็น ZIP

แปลง .tar.gz หรือ .tgz เป็น ZIP เดียว - ทั้งชั้น gzip และ tar จะถูกแกะบนอุปกรณ์ของคุณ

Z→TGZ

ตัวแปลง ZIP เป็น TAR.GZ

แปลงไฟล์บีบอัด ZIP เป็น tarball .tar.gz - รูปแบบที่เซิร์ฟเวอร์ Linux, Docker และเครื่องมือ build คาดหวัง

+TAR

ตัวสร้างไฟล์ TAR

สร้างไฟล์บีบอัด .tar ที่ถูกต้องตามข้อกำหนดจากหลายไฟล์ในเบราว์เซอร์ของคุณ - เปิดด้วยเครื่องมือ tar ใดก็ได้

GZIP

ตัวบีบอัด GZIP

บีบอัดไฟล์เดียวใด ๆ เป็น .gz ด้วยกลไก gzip ในตัวของเบราว์เซอร์ของคุณ - ขนาดก่อน/หลังทันที

▦

ตัวดูและแก้ไข CSV

โหลด CSV เข้าสู่กริดตารางที่แก้ไขได้ - แก้ไขเซลล์ จัดเรียงคอลัมน์ เพิ่มหรือลบแถวและคอลัมน์ จากนั้นดาวน์โหลด

SQL→

ตัวแปลง CSV เป็น SQL

เปลี่ยน CSV เป็น CREATE TABLE บวกคำสั่ง INSERT พร้อมประเภทที่อนุมาน สำหรับ MySQL, PostgreSQL หรือ SQLite

XML

ตัวแปลง CSV เป็น XML

แปลงแถว CSV เป็น XML ที่รูปแบบถูกต้อง พร้อมองค์ประกอบรูตและแถวที่กำหนดค่าได้ และการ escape ที่เหมาะสม

MD

ตัวแปลง CSV เป็นตาราง Markdown

แปลง CSV เป็นตาราง Markdown ที่พร้อมสำหรับ GitHub - คอลัมน์ตัวเลขจัดชิดขวา ไปป์ถูก escape

CSV✓

ตัวลบซ้ำและล้างข้อมูล CSV

ลบแถว CSV ที่ซ้ำตามทั้งแถวหรือคอลัมน์คีย์ ตัดช่องว่าง และทิ้งแถวว่าง พร้อมจำนวน

✂

ตัวแยกและรวม CSV

แยก CSV เป็นส่วน ๆ ตามจำนวนแถวโดยส่วนหัวซ้ำ หรือรวมไฟล์ CSV ที่มีส่วนหัวร่วมกัน

< >

ตัวสร้างเมตาแท็ก

สร้างบล็อกเมตา HTML ที่พร้อมใช้ - ชื่อเรื่อง คำอธิบาย robots canonical - พร้อมตัวอย่าง SERP แบบสด

OG

ตัวสร้าง Open Graph และ Twitter Card

สร้างแท็ก OG และ Twitter Card พร้อมตัวอย่างการ์ดโซเชียลแบบสด เพื่อให้ลิงก์ที่แชร์ดูถูกต้อง

🤖

ตัวสร้าง Robots.txt

สร้าง robots.txt ที่ถูกต้องจากค่าที่ตั้งไว้ล่วงหน้าและกฎรายตัวแทน พร้อมการตรวจสอบความสมเหตุสมผลของผลลัพธ์

MAP

ตัวสร้างแผนผังเว็บไซต์ XML

เปลี่ยนรายการ URL เป็น sitemap.xml ที่ถูกต้องพร้อมค่าเริ่มต้น lastmod, changefreq และ priority

UTM

ตัวสร้างลิงก์ UTM

แท็ก URL แคมเปญด้วยพารามิเตอร์ UTM - การเข้ารหัสที่ถูกต้อง พารามิเตอร์ที่มีอยู่ถูกเก็บไว้ ประวัติภายในเครื่อง

/24

เครื่องคำนวณ IP Subnet

IPv4 CIDR เป็นเครือข่าย บรอดแคสต์ เน็ตมาสก์ ไวลด์การ์ด ช่วงโฮสต์ และจำนวน บวกมุมมองการแยกซับเน็ต

LD

ตัวสร้างสคีมา JSON-LD

สร้างข้อมูลที่มีโครงสร้างของ schema.org - Article, Product, LocalBusiness, Event, Recipe และอื่น ๆ - เป็น JSON-LD ที่ถูกต้อง

G

ตัวแสดงตัวอย่าง SERP ของ Google

ดูตัวอย่างชื่อเรื่องและคำอธิบายของคุณในฐานะผลลัพธ์ของ Google พร้อมคำเตือนการตัดตามความกว้างพิกเซล เดสก์ท็อปและมือถือ

%

ตัวตรวจสอบความหนาแน่นของคีย์เวิร์ด

นับคำเดี่ยวบวกวลี 2 คำและ 3 คำ พร้อมความหนาแน่นเป็นเปอร์เซ็นต์และการกรองคำหยุด

ตัวสร้างตาราง HTML

สร้างตารางแบบเห็นภาพในกริดและรับ HTML เชิงความหมายที่สะอาดพร้อมการรองรับ thead, th และ caption

✉

ตัวสร้างลายเซ็นอีเมล HTML

สร้างลายเซ็นอีเมลระดับมืออาชีพเป็น HTML ตารางที่ปลอดภัยสำหรับอีเมลซึ่งทำงานได้ใน Gmail และ Outlook

@✓

ตัวตรวจสอบอีเมล

ตรวจสอบที่อยู่อีเมลจำนวนมากเพื่อหาข้อผิดพลาดทางไวยากรณ์และตัวพิมพ์ผิดในโดเมนที่พบบ่อยอย่าง gmial.com พร้อมคำแนะนำ

◣

ตัวสร้าง CSS Clip-Path

สร้าง CSS clip-path - ค่าที่ตั้งไว้ล่วงหน้าแบบรูปหลายเหลี่ยมพร้อมจุดที่ปรับได้ บวกกับรูปทรงวงกลม วงรี และ inset

▓

ตัวสร้าง CSS Box Shadow

สร้าง CSS box-shadow แบบหลายชั้นพร้อมการรองรับ inset การควบคุมสีและความทึบแสง และตัวอย่างแบบสด

XML✓

ตัวจัดรูปแบบและตรวจสอบ XML

จัดรูปแบบให้สวยงาม ย่อขนาด และตรวจสอบ XML - การตรวจสอบความสมบูรณ์ของแท็กที่สมดุลพร้อมข้อความแสดงข้อผิดพลาดที่ชัดเจน

MD→

ตัวแปลง Markdown เป็น HTML

แปลง Markdown ประจำวันเป็น HTML ที่สะอาดพร้อมตัวอย่างที่เรนเดอร์แบบสด - หัวเรื่อง รายการ โค้ด และอื่น ๆ

⇄

ตัวสลับแถวคอลัมน์ CSV

สลับแถวและคอลัมน์ CSV ด้วยตัวแยกวิเคราะห์ที่เหมาะสม - การสลับสองครั้งจะคืนค่าต้นฉบับ

รวม CSV สองไฟล์ด้วยคอลัมน์คีย์ - inner หรือ left join คีย์ที่ซ้ำถูกจัดการในแบบฐานข้อมูล

PIVOT

ตัวสรุปและจัดกลุ่ม CSV

จัดกลุ่มแถว CSV ตามคอลัมน์ ด้วยผลรวม จำนวน ค่าเฉลี่ย ค่าต่ำสุด หรือค่าสูงสุดของคอลัมน์ค่า

DIFF

ตัวเปรียบเทียบ CSV

เปรียบเทียบ CSV สองไฟล์ด้วยคอลัมน์คีย์ - แถวที่เพิ่ม ลบ และเปลี่ยนแปลงพร้อมเซลล์ที่แม่นยำ

@

ตัวดึงข้อมูล CSV

ดึงอีเมล หมายเลขโทรศัพท์ และ URL ออกจาก CSV หรือข้อความที่ยุ่งเหยิงให้เป็นรายการที่สะอาดและตัดรายการซ้ำออก

PROF

ตัววิเคราะห์โปรไฟล์ CSV

การคาดเดาประเภทตามคอลัมน์ จำนวนที่ว่าง จำนวนที่ไม่ซ้ำ ค่าต่ำสุด/สูงสุดเชิงตัวเลข และค่าสูงสุด

✓

ตัวทดสอบ Robots.txt

ทดสอบ URL และ user-agent กับกฎ robots.txt - คำตัดสินบวกกฎที่ตรงกันอย่างแม่นยำ

Aa

ตัวตรวจสอบความอ่านง่ายสำหรับ SEO

สูตรความอ่านง่ายหกสูตรบวกสถิติประโยคสำหรับข้อความเว็บ กรอบสำหรับงานเนื้อหา SEO

LLM

ตัวสร้าง llms.txt

สร้างไฟล์ llms.txt สำหรับ AI - blockquote บทสรุปพร้อมลิงก์หน้าที่คัดสรรในรูปแบบตามข้อกำหนด

🌐

ตัวสร้างแท็ก Hreflang

สร้างชุดลิงก์สำรอง hreflang พร้อม x-default และการตรวจสอบ BCP 47 / URL แบบสัมบูรณ์

DOC

ตัวดูเมทาดาทาเอกสาร Office

อ่านคุณสมบัติ DOCX, XLSX และ PPTX - ชื่อเรื่อง ผู้แต่ง บริษัท วันที่ - ดูอย่างเดียว บนอุปกรณ์

🔍

ตัวตรวจชนิดไฟล์

ตรวจจับชนิดจริงของไฟล์จากไบต์มหัศจรรย์ของมันและเตือนเมื่อนามสกุลไม่ตรงกัน

เครื่องมือสำหรับนักพัฒนายอดนิยม
