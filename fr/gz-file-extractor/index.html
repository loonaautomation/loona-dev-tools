Extracteur de fichiers GZ - Décompressez les fichiers GZ en ligne

En bref : l’Extracteur de fichiers GZ décompresse un seul fichier .gz dans votre navigateur et vous rend le fichier d’origine - un journal, un export CSV, un vidage de base de données - avec son nom d’origine restauré. Rien n’est téléversé.

Un fichier .gz n’est pas une archive pleine de fichiers - c’est exactement un fichier, compressé avec gzip, le cheval de trait du monde Unix. Les journaux de serveurs, les exports de données et les vidages de bases de données voyagent ainsi, et Windows n’a aucun moyen intégré de les ouvrir. Cette page décompresse le fichier avec le moteur gzip intégré de votre propre navigateur (l’API DecompressionStream) : elle est donc rapide et entièrement privée.

Déposez votre fichier .gz ici ou cliquez pour choisir un fichier depuis votre appareil
Privé par conception : tout dans cet outil se passe à 100 % dans votre navigateur, à l’aide de la décompression gzip intégrée au navigateur lui-même. Votre fichier .gz n’est jamais téléversé sur un serveur, jamais stocké et jamais vu par nous. Une limite honnête : la décompression se passe dans la mémoire de votre appareil, donc un .gz qui s’étend à plusieurs gigaoctets peut peiner sur un téléphone à faible mémoire.

Comment utiliser l’Extracteur de fichiers GZ

  1. Déposez votre fichier .gz sur la boîte ci-dessus, ou cliquez dessus et choisissez le fichier depuis votre appareil.
  2. Le fichier est décompressé immédiatement - guettez la ligne affichant le nom du fichier d’origine et sa taille complète.
  3. Cliquez sur Télécharger le fichier décompressé pour enregistrer le fichier d’origine (par exemple access.log à partir de access.log.gz).

Comment ça fonctionne

Gzip stocke un petit en-tête (y compris le nom du fichier d’origine, lorsque l’outil créateur l’a enregistré), les données compressées avec l’algorithme DEFLATE, et une somme de contrôle plus la taille d’origine à la fin. Les navigateurs modernes sont livrés avec un décodeur gzip natif intégré - le même qu’ils utilisent pour recevoir des pages web compressées - et cette page y fait passer votre fichier avec l’API DecompressionStream. Aucune bibliothèque n’est téléchargée et rien n’est envoyé nulle part : le navigateur gonfle les données et vous remet les octets d’origine.

Exemple travaillé

Votre serveur vous donne access.log.gz (2.1 MB). Vous le déposez ici et il se décompresse en access.log (18.4 MB) en environ une seconde. Vous le téléchargez et l’ouvrez dans un éditeur de texte pour trouver l’erreur de la nuit dernière - sans installer un seul outil.

Questions fréquemment posées

Quelle est la différence entre .gz et .tar.gz ?

Un fichier .gz contient exactement un fichier compressé. Un .tar.gz regroupe d’abord de nombreux fichiers dans une archive TAR, puis compresse ce paquet avec gzip : il contient donc une arborescence de fichiers entière. Pour les .tar.gz, utilisez l’Extracteur de fichiers TAR.GZ lié ci-dessous.

Le fichier décompressé aura-t-il le bon nom ?

Oui - cet outil restaure le nom d’origine en retirant la fin .gz (access.log.gz devient access.log). Cela correspond au nom enregistré lorsque le fichier a été compressé dans la grande majorité des cas.

Cet outil peut-il ouvrir les fichiers .zip ou .rar qui se terminent en .gz par erreur ?

Non - renommer un fichier ne change pas ce qu’il contient. Si le contenu n’est pas réellement des données gzip, la décompression échoue avec un message clair. Utilisez l’Extracteur de fichiers d’archive pour les ZIP, RAR et autres vraies archives.

Y a-t-il une limite de taille ?

Il n’y a aucune limite intégrée à l’outil, mais le fichier décompressé est conservé dans la mémoire de votre navigateur. Les journaux et exports quotidiens (jusqu’à quelques centaines de mégaoctets) conviennent sur la plupart des appareils ; les vidages de plusieurs gigaoctets se traitent mieux sur un bureau avec un outil natif.

Mes fichiers sont-ils téléversés vers un serveur ?

Non. La décompression utilise le moteur intégré propre du navigateur sur votre appareil. Le fichier ne quitte jamais votre machine - il n’y a même pas de téléchargement de bibliothèque pour cet outil.
