منشئ مسار قصّ CSS - شكّل عناصرك بصرياً

باختصار: يمنحك منشئ مسار قصّ CSS ‏CSS clip-path جاهزاً للمضلّعات (مثلث إلى نجمة)، الدوائر، القطع الناقصة والداخليات - اختر شكلاً، حرّك نقاطه، راقب المعاينة الحية وانسخ الكود. ملاحظة: أدوات الصور الشقيقة لهذا الموقع تغطي التدرّجات أصلاً؛ clip-path يعيش هنا لأنه CSS تخطيط، لا تحرير صور.

يحوّل مسار القصّ المستطيلات إلى تصميم: أقسام مائلة، وشارات، وأسهم ونجوم بخاصية CSS واحدة. الجزء الصعب هو الإحداثيات - هذه الأداة تتعامل معها.

خاص بالتصميم: كل شيء في هذه الأداة يحدث 100% في متصفحك عبر JavaScript. إدخالك لا يُرفع إلى خادم أبداً، لا يُخزّن أبداً ولا نراه أبداً - أغلق علامة التبويب وكل شيء يختفي.

كيفية استخدام منشئ مسار قصّ CSS

  1. اختر إعداد شكل مسبقاً.
  2. بالنسبة للمضلّعات، عدّل نسب x,y لأي نقطة.
  3. راقب تحديث المعاينة مباشرة.
  4. انسخ CSS - كلتا الخاصيتين القياسية و-webkit- مشمولتان.

كيف يعمل

نقاط المضلّع نسب مئوية من صندوق العنصر، لذا تتدرّج الأشكال مع العنصر. تشفّر الإعدادات المسبقة مجموعات إحداثيات معروفة (خماسي منتظم، سداسي، نجمة عشرية النقاط والمزيد)، ويصدر المنشئ كليهما clip-path و الـ -webkit- توأم مسبوق احتاجه Safari تاريخياً. الدائرة والقطع الناقص والداخلي يغطون الأشكال غير المضلّعة التي تدعمها الخاصية، شاملة الداخليات المستديرة.
