ZIP 文件创建工具 - 从多个文件制作 ZIP

简而言之： ZIP 文件创建工具将任何文件集捆绑成一个单一的标准 .zip 归档，完全在您的浏览器中使用 JSZip 构建——添加文件，可选择将它们分组到一个文件夹中，选择压缩级别并下载。

逐个发送十个附件、移交项目文件夹，或归档一批照片——ZIP 把一堆文件变成一个整洁的下载。大多数在线压缩工具先把您的文件上传到服务器。这个不会：归档在您自己的设备上组装，所以连私人文件都不去任何地方。

压缩说明：文本、代码和 CSV 文件用 DEFLATE 会大幅缩小。照片、视频和 PDF 本身已经压缩过，所以无论哪种方式 ZIP 的大小都差不多——对这些文件选择“存储”即可瞬间完成。

按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中使用 JavaScript 完成。您的文件从不上传到服务器，从不存储，我们也从不见过它——关闭标签，一切都消失了。一个诚实的限制：ZIP 是在您设备的内存中构建的，所以非常大的文件集（数百兆字节）在内存不足的手机上可能会很慢或失败。

如何使用 ZIP 文件创建工具

  1. 把您的文件拖到上面的框中，或点击它从您的设备中选择文件。您可以分几轮添加文件。
  2. 检查列表——删除您误加的任何内容，并留意总大小。
  3. 如果您希望每个文件都位于归档内的一个文件夹中，可选地输入文件夹名称，并给 ZIP 起一个名字。
  4. 选择一个压缩级别（“已压缩”对大多数任务都适合），然后点击创建 ZIP 并下载。

它如何工作

ZIP 归档存储每个文件的数据，并在末尾有一个列出每个条目、其名称和大小的中央目录——这正是任何系统上的任何解压工具都能打开它的原因。本页在您的浏览器中使用 JSZip 库：它把您选择的文件读入内存，可选择用 DEFLATE 算法（与经典 ZIP 工具使用的相同）压缩每个文件，写入目录，然后把完成的归档作为单个下载交还给您。同名文件会被保留并自动编号——第二个 report.pdf 会变成 report (1).pdf——这样任何东西都不会被悄悄覆盖。

实例

您添加了三个文件：report.pdf（240 KB）、photo.jpg（1.2 MB）和 notes.txt（2 KB），文件夹名称设置为 "handover"。工具会生成 handover.zip——或您选择的任何名称——其中包含一个 handover 文件夹，三个文件都在里面。下载文件约为 1.4 MB，因为 PDF 和 JPG 已经是压缩过的了；如果这些文件是纯文本和 CSV 导出，同一个归档很容易只有原始大小的三分之一。

常见问题

这个 ZIP 文件创建工具免费吗？

是的——免费，无需注册，没有限制，也没有水印。

我的文件会被上传到服务器吗？

不会。ZIP 由在您浏览器中运行的 JavaScript（JSZip）构建。您的文件从不离开您的设备，这也使它对私人文档安全。

为什么我的 ZIP 几乎与原始文件一样大？

像 JPG、PNG、MP4、MP3 和 PDF 这样的格式已经压缩过了，所以 ZIP 压缩无法再把它们缩小多少。基于文本的文件——TXT、CSV、HTML、JSON、源代码和日志——通常会大幅缩小。

有文件大小限制吗？

本工具没有内置限制，但归档是在您浏览器的内存中组装的。几百兆字节在大多数桌面上都没问题；非常大的集合在低端手机上可能很慢或内存不足。如果它吃力，把文件拆分成更小的 ZIP。

我可以给 ZIP 设置密码保护，或向现有的 ZIP 添加文件吗？

本工具不行。它创建一个全新的、不加密的标准 ZIP。任何拿到文件的人都能打开它，所以不要仅靠 ZIP 来保护机密。
