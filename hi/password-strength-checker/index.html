पासवर्ड मज़बूती चेकर — Entropy, Feedback और Crack Time

संक्षेप में: पासवर्ड मज़बूती चेकर आपके password entropy को उसकी length और character pool से bits में estimate करता है, repeats और sequences के लिए open penalties लगाता है, और specific fixes साथ में crack-time estimate दिखाता है। आपका password locally analysed होता है और कभी कहीं भेजा, saved या logged नहीं होता।

ज़्यादातर strength meters एक black box हैं जो "weak" कहते हैं और आपको अंदाज़ा लगाते छोड़ देते हैं। यह अपना काम दिखाता है: ठीक pool maths, penalties, और क्या बदलना है — पूरी तरह आपके अपने device पर computed, जो इकलौती जगह है जहाँ password किसी tool में type होना चाहिए।

*Crack time एक तेज़ offline हमले को मानता है — खराब सुरक्षा वाले hash के ख़िलाफ़ 10 billion guesses प्रति second — सबसे बुरा वास्तविक मामला। ठीक से hash किया गया पासवर्ड (bcrypt/argon2) कहीं ज़्यादा समय लेता है।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

पासवर्ड मज़बूती चेकर का उपयोग कैसे करें

  1. Password को box में type करें या paste करें — विश्लेषण live होता है, पूरी तरह आपके device पर।
  2. Entropy bits में और strength label पढ़ें।
  3. Feedback list पर काम करें: हर item एक concrete fix है जो estimate बढ़ाता है।
  4. काम पूरा होने पर box साफ़ करें। कुछ भी कभी transmit या store नहीं हुआ।

यह कैसे काम करता है

Checker standard information-theory estimate उपयोग करता है, खुले में: यह detect करता है कि आपका password किन character pools से लेता है (lowercase 26, uppercase 26, digits 10, symbols 33), और entropy = length x log2(pool) compute करता है। फिर यह दो transparent penalties लगाता है: 3 या अधिक repeated characters का run, और 4 या अधिक characters का ascending या descending sequence, हर एक effective entropy को 20% कम करता है, क्योंकि guessing attacks वे shapes पहले आज़माते हैं। Score bands हैं <28 bits बहुत कमज़ोर, <36 कमज़ोर, <60 ठीक, <90 मज़बूत, और 90+ उत्कृष्ट। Crack time 10 billion guesses प्रति second मानता है — एक तेज़ offline attack — और keyspace को आधा करता है, क्योंकि attacker औसतन आधे रास्ते में password खोज लेता है।

काम किया हुआ उदाहरण

"password" 8 छोटे अक्षरों वाला है: pool 26, raw entropy 37.6 bits — पहले से ही सिर्फ़ ठीक-ठाक, और यह सोचे बिना कि यह हर leaked-password सूची में सबसे ऊपर रहता है, जिसे कोई फ़ॉर्मूला नहीं देख सकता। एक अंक और एक चिह्न वाले चार random शब्द आसानी से 90 bits पार कर जाते हैं, और याद रखना भी आसान होता है: लंबाई आपके पास सबसे मज़बूत हथियार है।

अक्सर पूछे जाने वाले सवाल

क्या यह password strength checker मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, बिना साइन-अप और बिना daily cap।

क्या यहाँ असली password type करना सुरक्षित है?

विश्लेषण 100% आपके ब्राउज़र में चलता है: password कभी server को नहीं भेजा जाता, कभी stored नहीं होता, और कभी किसी log में नहीं लिखा जाता — आप पेज load करके type करने से पहले offline जाकर इसे verify कर सकते हैं। फिर भी, best practice यह है कि अपने जैसा shaped password test करें अपने exact banking password के बजाय।

Entropy estimate कितना accurate है?

यह एक ईमानदार model है, oracle नहीं। Pool-based entropy random characters मानती है; इंसानों के चुने passwords में patterns होते हैं जिन्हें formula पूरी तरह नहीं देख सकता — इसीलिए यह checker repeats और sequences को भी flag करता है, और इसीलिए सच में random passwords बनाने वाला password manager हमेशा सबसे मज़बूत विकल्प है।

Dictionary या zxcvbn check क्यों नहीं है?

यह tool जानबूझकर एक छोटा, transparent scoring function उपयोग करता है जिसकी maths आप इस page पर पढ़ सकते हैं, एक बड़ी opaque library के बजाय। Dictionary words gap हैं: "correct horse battery staple" length पर high score करता है फिर भी असली words उपयोग करता है — estimate को human-chosen passwords के लिए ceiling मानें।

सबसे बड़ा अंतर क्या बनाता है?

लंबाई। हर अतिरिक्त character guessing work को pool size से multiply करता है। एक लंबा passphrase जो आप याद रख सकें, symbols के छोटे उलझाव से बेहतर है जो आप नहीं रख सकते।
