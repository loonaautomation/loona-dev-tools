正则表达式测试器 - 实时匹配、分组和高亮

简而言之： 正则表达式测试器在您输入时对测试文本运行您的模式，突出显示每个匹配，列出每个捕获组并显示总匹配数——并用浏览器错误消息报告无效的模式。

正则表达式是写一次、永远解谜。在下方粘贴一个模式和一些示例文本，确切地查看什么匹配、在哪里匹配、每个捕获组捕获了什么——在模式到达您的代码之前。

如何使用正则表达式测试器

  1. 在模式框中输入您的模式（不带周围的斜杠）。
  2. 在标志框中设置诸如 g（全局）、i（忽略大小写）或 m（多行）等标志。
  3. 输入或粘贴测试文本——结果随您输入实时更新。
  4. 阅读高亮的文本和匹配表：每个匹配及其位置和捕获组。

它如何工作

该工具构建一个 JavaScript RegExp 根据您的模式和标志，并对测试文本执行它。设置了全局标志时，它按顺序遍历每个匹配；未设置时，它只报告第一个匹配，与您自己的代码完全一样。零宽度匹配（例如来自 x*）都会被安全处理——遍历器在每次空匹配后前进一个字符，因此永远不会陷入无限循环。高亮视图会先将您的文本转义为安全的 HTML，然后把每个匹配项包裹在高亮标记中，所以您看到的正是匹配到的内容。

实例

模式 (\d{4})-(\d{2})-(\d{2}) 对 "Release on 2026-11-08, hotfix on 2026-11-09" 查找得到 2 个匹配，表格显示第一个匹配的组 1 = 2026，组 2 = 11，组 3 = 08——可直接在日期解析器中重复使用。

常见问题

这个正则表达式测试器免费吗？

是的——完全免费，无需注册，没有每日上限。

它使用哪种正则表达式风格？

JavaScript 正则表达式——浏览器和 Node.js 使用的风味。来自其他风味（PCRE、Python）的大多数模式工作原理相同，但少数构造不同，例如命名组，JavaScript 写为 (?<name>...)。

为什么我只看到一个匹配？

没有 g 标志，正则表达式在第一个匹配处停止。在标志框中添加 g 以找到全部。

什么是捕获组？

您的模式中的每一对括号都捕获它匹配的文本。表格按每次匹配列出它们——第 1 组是第一个左括号，依此类推。写为 (?:...) 的组不捕获。

我的文本会被上传到服务器吗？

不会。模式 100% 在您的浏览器中运行，针对的文本从不离开您的设备。
