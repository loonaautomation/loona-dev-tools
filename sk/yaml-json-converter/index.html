Prevodník YAML ⇄ JSON - Pre každodenné konfiguračné súbory

Skrátka: Prevodník YAML ⇄ JSON prekladá podmnožinu YAML, ktorá pokrýva takmer každý skutočný konfiguračný súbor - dvojice kľúč: hodnota, vnorené mapy podľa odsadenia, zoznamy s pomlčkami a skaláry reťazec, číslo, booleovská hodnota a null - v oboch smeroch a povie vám jednoducho, čo nepodporuje.

Konfiguračné súbory žijú v YAML; API a kód žijú v JSON. Vložte jedno z nich nižšie a získajte druhé – s úprimným analyzátorom podmnožiny, ktorý zvláda konštrukcie, ktoré skutočné konfigurácie naozaj používajú.

Súkromné konštrukciou: všetko v tomto nástroji sa deje 100% vo vašom prehliadači pomocou JavaScriptu. Váš vstup sa nikdy nenahráva na server, nikdy sa neukladá a nikdy ho nevidíme - zatvorte kartu a všetko je preč.

Ako používať Prevodník YAML na JSON

  1. Vložte YAML alebo JSON do horného poľa.
  2. Kliknite na YAML → JSON alebo JSON → YAML podľa vášho vstupu.
  3. Prezrite si výsledok - vstup YAML sa stane pekne formátovaným JSON; vstup JSON sa stane čistým YAML v blokovom štýle.
  4. Skopírujte alebo stiahnite výsledok.

Ako to funguje

Čítačka YAML pracuje v dvoch prechodoch: najprv normalizuje váš dokument na riadky s ich odsadením (odstraňujúc komentáre mimo úvodzoviek), potom rekurzívne analyzuje bloky - beh riadkov na tom istom odsadení je zoznam, ak riadky začínajú pomlčkou, mapa, ak nesú kľúče, alebo jeden skalár. Kľúče bez hodnoty na tom istom riadku berú hlbšie odsadený blok, ktorý nasleduje, ako svoju hodnotu. Skaláry sa typujú spôsobom YAML: text v úvodzovkách zostáva reťazcom, true/false sa stanú booleovskými hodnotami, null a ~ sa stanú null a obyčajné čísla sa stanú číslami JSON. Zapisovač v druhom smere vydáva tú istú podmnožinu: dvojmedzerové odsadenie, pomlčky pre zoznamy a úvodzovky iba tam, kde by sa reťazec inak prečítal nesprávne.

Vypracovaný príklad

Fragment v štýle docker-compose – názov služby, obraz, zoznam dvoch portov – sa prevedie na objekt JSON s vnorenou mapou a skutočným poľom a priamy spätný prevod tohto JSON vráti ten istý YAML, čo je presne ten obojsmerný test, ktorý kontroluje testovacia sada.

Často kladené otázky

Je tento prevodník YAML na JSON zadarmo?

Áno - úplne zadarmo, bez registrácie, bez limitu veľkosti a bez denného limitu.

Ktoré funkcie YAML sú podporované?

Každodenná podmnožina: vnorené mapy podľa odsadenia, zoznamy s pomlčkami (vrátane zoznamov máp), skaláry v úvodzovkách a obyčajné, čísla, booleovské hodnoty, null a komentáre. To pokrýva veľkú väčšinu ručne písaných konfiguračných súborov.

Ktoré funkcie YAML NIE sú podporované?

Kotvy a aliasy (&a / *a), viacriadkové blokové skaláry (| a >), tokový štýl ({a: 1} / [1, 2]), značky a viacdokumentové súbory (---) sa neanalyzujú. Ak ich váš súbor používa, preveďte ho namiesto toho plnou knižnicou YAML – radšej to povieme, než aby sme vytvorili nesprávny prevod.

Uvádza JSON → YAML reťazce do úvodzoviek?

Iba keď treba: reťazec, ktorý vyzerá ako číslo alebo booleovská hodnota, je prázdny alebo obsahuje znaky ako dvojbodka, po ktorej nasleduje medzera, sa uvedie do dvojitých úvodzoviek, aby sa prečítal späť ako ten istý reťazec.

Nahrávajú sa moje údaje na server?

Nie. Prevod sa deje 100% vo vašom prehliadači. Vaše konfiguračné súbory nikdy neopustia vaše zariadenie.
