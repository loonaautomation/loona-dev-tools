JSON فارمیٹر اور ویلیڈیٹر - خوبصورت پرنٹ اور JSON منی فائی کریں

مختصراً: JSON فارمیٹر آپ کے JSON کو جانچتا ہے، اسے 2-space, 4-space یا ٹیب indentation سے خوبصورت-پرنٹ کرتا ہے، درخواست پر منی فائی کرتا ہے، اور اگر کچھ غلط ہو تو آپ کو مسئلے کی عین لائن اور کالم بتاتا ہے۔

ٹوٹا JSON ڈویلپر کے دن کی سب سے عام پانچ منٹ کی تاخیر ہے - ایک غائب کاما اور پورا پے لوڈ ناکام۔ اپنا JSON نیچے پیسٹ کریں: اگر یہ درست ہے تو آپ کو صاف، پڑھنے کے قابل آؤٹ پٹ ملتا ہے؛ اگر نہیں، تو آپ کو بیکار 'parse failed' کے بجائے غلطی کی عین پوزیشن ملتی ہے۔

ڈیزائن سے نجی: اس ٹول میں سب کچھ 100% آپ کے براؤزر میں JavaScript سے ہوتا ہے۔ آپ کا ان پٹ کبھی سرور پر اپ لوڈ نہیں ہوتا، کبھی محفوظ نہیں ہوتا اور ہمارے دیکھنے میں نہیں آتا - ٹیب بند کریں اور سب کچھ ختم۔

JSON فارمیٹر کا استعمال کیسے کریں

  1. اپنا JSON اوپر والے باکس میں پیسٹ کریں یا لکھیں۔
  2. ایک indent اسٹائل منتخب کریں - 2 اسپیس، 4 اسپیس یا tab۔
  3. پڑھنے کے قابل آؤٹ پٹ کے لیے فارمیٹ / توثیق پر کلک کریں، یا سب سے چھوٹی درست شکل کے لیے منی فائی کریں۔
  4. نتیجہ کاپی کریں یا اسے .json فائل کے طور پر ڈاؤن لوڈ کریں۔

یہ کیسے کام کرتا ہے

ٹول آپ کے براؤزر کا بنا ہوا JSON پارسر استعمال کرتا ہے - وہی سخت پارسر جو آپ کا اپنا JavaScript کوڈ استعمال کرتا ہے - لہٰذا یہاں سبز روشنی کا مطلب ہے آپ کا JSON اصل میں درست ہے۔ خوبصورت-پرنٹنگ parsed قدر کو آپ کی منتخب indentation سے دوبارہ لکھتی ہے؛ کنجی ترتیب عین لکھی گئی محفوظ ہے۔ منی فائی کرنا ہر غیر ضروری اسپیس اور نئی لائن ہٹاتا ہے بغیر ایک قدر بدلے۔ جب parsing ناکام ہو، تو ٹول parser کی حرف پوزیشن کو لائن اور کالم میں بدلتا ہے اور آپ کو مجرم لائن دکھاتا ہے۔

کام شدہ مثال

آپ وصول کرتے ہیں {"user":"ahmed","roles":["admin","editor"],"active":true} ایک API سے۔ 2 اسپیسز سے فارمیٹ شدہ یہ صاف نو-لائن دستاویز بن جاتا ہے جسے آپ اصل میں پڑھ سکتے ہیں - اور اگر آپ غلطی سے "ahmed" کے بعد کاما حذف کر دیں، تو ٹول غلطی عین لائن اور کالم پر رپورٹ کرتا ہے بجائے آپ کو اس کی تلاش میں چھوڑنے کے۔
