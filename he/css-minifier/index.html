ממזער ומייפה CSS - דחסו CSS או הפכו אותו לקריא

בקצרה: ממזער ה-CSS מפשיט הערות ורווחים מיותרים כדי לכווץ את גיליון הסגנון שלכם ומדווח על החיסכון המדויק בגודל, בעוד מצב יפה הופך CSS ממוזער בחזרה לקוד נקי ומוזח.

כל קילו-בייט של CSS מעכב את הציור הראשון של הדף שלכם. הדביקו גיליון סגנונות למטה כדי לדחוס אותו לייצור, או הריצו קובץ ממוזער דרך ייפוי כשאתם צריכים לקרוא ולערוך אותו שוב.

איך להשתמש בממזער CSS

  1. הדביקו או הקלידו את ה-CSS שלכם לתיבה העליונה.
  2. לחצו על מזער CSS כדי לדחוס אותו, או ייפה CSS כדי לעצב אותו עם הזחה.
  3. בדקו את לוח הגודל - הוא מציג את הגודל המקורי, גודל התוצאה ואחוז החיסכון.
  4. העתיקו את התוצאה או הורידו אותה כקובץ .css.

איך זה עובד

הממזער קודם הולך על ה-CSS שלכם תו אחר תו ומסיר הערות - תוך השארת מחרוזות ממוסגרות ללא שינוי לחלוטין, כך ש תוכן ערך שקורה להכיל טקסט דמוי-הערה שורד שלם. הוא אז מכווץ רצפי רווחים ומסיר רווחים סביב סוגריים מסולסלים, נקודות-פסיק, פסיקים ומשלבים, ובנוסף את הרווח אחרי נקודתיים. הוא בכוונה לעולם לא נוגע בפנים של calc() ביטויים או ערכי מחרוזות, שבהם רווחים נושאים משמעות. מצב יפה הופך את התהליך: הוא פותח מחדש את ה-CSS הדחוס להכרזה אחת בשורה עם הזחה של שני רווחים לרמת קינון.

דוגמה מעובדת

כלל טיפוסי בכתב יד של גיליון סגנונות עם הערות ורווחים נדיבים - נאמר בלוק כותרת של 240 בתים - בדרך כלל מתמזער לכ-150 בתים, חיסכון של כ-35-40%. על פני אתר שלם זה מצטבר לרינדור ראשון מהיר באופן נראה לעין, במיוחד בחיבורי מובייל.

שאלות נפוצות

האם ממזער ה-CSS הזה בחינם?

כן - לגמרי בחינם, בלי הרשמה, בלי מגבלת גודל ובלי תקרה יומית.

האם CSS ממוזער בטוח לפריסה?

הממזער מסיר רק הערות ורווחים ש-CSS אינו צריך. בוררים, מאפיינים וערכים לא משתנים, וערכי מחרוזות וביטויי calc() לעולם לא משתנים. כמו עם כל ממזער, בדקו את הדף פעם אחת אחרי פריסה.

מדוע הוא שומר רווח לפני נקודתיים בבוררים?

רווח לפני נקודתיים יכול להיות משמעותי ב-CSS - ".a :hover" בוחר צאצאים שעוברים מעליהם עם העכבר, בעוד ".a:hover" בוחר את האלמנט עצמו. כדי להישאר בטוח, הכלי מסיר את הרווח שאחרי נקודתיים אבל לעולם לא מנחש לגבי הרווח שלפניהם.

האם הוא יכול גם לייפות CSS?

כן. מצב יפה לוקח CSS דחוס ומרחיב אותו להכרזה אחת בשורה עם הזחה עקבית, שזה אידיאלי כשאתם יורשים קובץ ממוזער וצריכים לערוך אותו.

האם ה-CSS שלי מועלה לשרת?

לא. המזעור והייפוי קורים 100% בדפדפן שלכם. גיליונות הסגנון שלכם לעולם לא עוזבים את המכשיר שלכם.
