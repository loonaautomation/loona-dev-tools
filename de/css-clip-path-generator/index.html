CSS-Clip-Path-Generator - Formen Sie Ihre Elemente visuell

Kurz gesagt: das CSS-Clip-Path-Generator gibt Ihnen fertiges clip-path-CSS für Polygone (Dreieck bis Stern), Kreise, Ellipsen und Insets – wählen Sie eine Form, schieben Sie ihre Punkte, beobachten Sie die Live-Vorschau und kopieren Sie den Code. Hinweis: Die Schwester-Image-Tools dieser Website decken bereits Farbverläufe ab; clip-path lebt hier, weil es Layout-CSS ist, keine Bildbearbeitung.

Clip-path verwandelt Rechtecke in Design: abgewinkelte Abschnitte, Badges, Pfeile und Sterne mit einer CSS-Eigenschaft. Der schwierige Teil sind die Koordinaten – dieses Tool übernimmt sie.

Privat per Design: alles in diesem Tool geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Eingabe wird niemals auf einen Server hochgeladen, niemals gespeichert und niemals von uns gesehen – schließen Sie den Tab und alles ist weg.

So verwenden Sie den CSS-Clip-Path-Generator

  1. Wählen Sie ein Form-Preset.
  2. Passen Sie bei Polygonen die x,y-Prozentsätze eines beliebigen Punktes an.
  3. Beobachten Sie, wie sich die Vorschau live aktualisiert.
  4. Kopieren Sie das CSS – sowohl die Standard- als auch die -webkit--Eigenschaft sind enthalten.

So funktioniert es

Polygonpunkte sind Prozentsätze der Element-Box, sodass Formen mit dem Element skalieren. Die Presets codieren bekannte Koordinatensätze (ein regelmäßiges Fünfeck, Sechseck, einen Zehn-Punkt-Stern und mehr), und der Generator gibt beides aus clip-path und das -webkit- präfixierter Zwilling, den Safari historisch gebraucht hat. Kreis, Ellipse und Inset decken die Nicht-Polygon-Formen ab, die die Eigenschaft unterstützt, inklusive abgerundete Insets.

Häufig gestellte Fragen

Ist dieser Generator kostenlos?

Ja – völlig kostenlos, keine Registrierung.

Warum gibt es auch einen Farbverlauf-Generator auf der Image-Website?

Verläufe dort werden als Bild-/Design-Assets behandelt. Clip-path ist Layout-CSS für Entwickler, also lebt es hier – jedes Tool existiert auf genau einer Loona-Website.

Beeinflusst clip-path Klicks?

Ja – der weggeclippte Bereich ist nicht klickbar, was üblicherweise das ist, was Sie für geformte Schaltflächen und Karten wollen.

Browser-Unterstützung?

Alle modernen Browser unterstützen clip-path; das -webkit--Präfix in der Ausgabe deckt ältere Safari-Versionen ab.

Wird irgendetwas hochgeladen?

Nein. Alles läuft in Ihrem Browser.
