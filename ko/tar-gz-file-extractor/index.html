TAR.GZ 파일 추출기 - TAR.GZ & TGZ 파일을 온라인에서 열기

요약하면: TAR.GZ 파일 추출기는 .tar.gz와 .tgz 아카이브를 브라우저에서 직접 열어요 - 안의 파일을 살펴보고, 단일 파일을 다운로드하거나, ZIP으로 다시 묶인 모든 것을 저장하세요. 설치 없음, 업로드 없음: 추출은 기기에서 실행돼요.

소스 코드, WordPress 백업, 서버 스냅샷 또는 Linux 세계의 모든 것을 다운로드하면 .tar.gz로 도착해요 - gzip으로 쥐어짠 TAR 묶음이에요. Windows 탐색기는 열 수 없어서, 많은 사람이 들여다볼 수도 없는 파일을 들고 막혀요. 이 페이지는 libarchive의 WebAssembly 포트로 이를 열어요, 전적으로 브라우저에서요.

여기에 .tar.gz 또는 .tgz 파일을 놓으세요 또는 클릭해 기기에서 파일을 선택하세요
아카이브 안의 파일크기
설계상 비공개: 이 도구의 모든 것은 브라우저에서 100% 일어나요. 아카이브는 자체 기기의 WebAssembly 엔진이 압축 해제해요 - 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요. 정직한 제한 하나: 아카이브는 기기 메모리에서 풀려, 거대한 백업 아카이브(압축 해제 시 수백 메가바이트)는 메모리가 적은 휴대폰에서 느리거나 실패할 수 있어요.

TAR.GZ 파일 추출기 사용법

  1. .tar.gz 또는 .tgz 파일을 위 상자에 놓거나, 클릭해 기기에서 파일을 고르세요.
  2. 아카이브가 읽히는 동안 잠시 기다리세요 - 처음 사용할 때 추출 엔진(약 1 MB)이 한 번 로드되고 그다음 브라우저가 캐시해요.
  3. 아카이브 안 파일 목록을 폴더와 크기와 함께 살펴보세요.
  4. 단일 파일 옆의 다운로드를 클릭하거나, ZIP으로 모두 다운로드를 사용해 전체 아카이브를 하나의 표준 ZIP 파일로 저장하세요.

작동 방식

.tar.gz는 두 개의 층이에요: 압축하는 바깥쪽 gzip 층과, 여러 파일을 하나의 스트림으로 묶는 안쪽 TAR 층이에요. 이 페이지는 WebAssembly로 컴파일된 libarchive로 둘 다 벗겨내요 - 먼저 gzip 압축을 풀고, 그다음 TAR 헤더를 순회하며 경로와 압축 해제 크기와 함께 모든 항목을 나열해요. 파일은 다운로드할 때만 추출되고, ZIP으로 모두 다운로드 옵션은 JSZip으로 다시 묶어주므로 결과는 어디서든 열려요.

풀이된 예시

호스팅 패널은 전체 사이트 백업을 backup-2026-11-01.tar.gz(260 MB)로 줘요. 여기서 열고, 목록을 wp-content/uploads로 이동해, 실수로 삭제한 사진 세 장(총 4 MB)을 다운로드해요 - 전체 백업을 복원하거나 안을 보기 위해 도구를 설치하는 대신이에요.

자주 묻는 질문

.tar.gz와 .tgz의 차이는 무엇인가요?

없어요 - 정확히 같은 형식이에요. .tgz 이름은 파일 확장자가 세 글자로 제한되던 시절의 짧아진 버전일 뿐이에요. 이 페이지는 둘 다 받아들여요.

일반 .gz 파일이 있고 .tar.gz가 아니에요. 여기서 작동하나요?

일반 .gz에는 압축된 파일이 정확히 하나 들어 있지 아카이브가 아니에요. 그런 파일은 아래에 링크된 GZ 파일 추출기를 사용하세요 - 단일 파일의 압축을 직접 풀어요. 이 페이지는 파일이 많이 들어 있는 아카이브용이에요.

이 도구가 .tar.gz 파일을 만들 수 있나요?

아니요, 이 페이지는 추출 전용이에요. 여기서 파일을 아카이브로 묶으려면 ZIP 파일 생성기를 사용하세요 - ZIP은 .tar.gz 파일을 만드는 Linux 시스템을 포함해 어디서든 열려요.

아카이브가 열렸는데 왜 이상한 긴 이름이나 링크가 표시됐나요?

서버의 TAR 아카이브는 종종 일반 파일과 함께 심볼릭 링크와 기기 항목을 포함해요. 이 도구는 일반 파일을 나열하고 추출해요; 링크는 형식이 기록하는 곳에서 목록에 표시되지만, 다운로드에서 링크로 다시 만들어지지 않아요.

추출을 위해 파일이 어디에 업로드되나요?

아니요. 압축 해제는 브라우저 탭 안의 WebAssembly에서 실행돼요. 백업과 그 안의 모든 것은 처음부터 끝까지 기기에 남아요.
