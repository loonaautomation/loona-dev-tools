Roman Numerals से Number कन्वर्टर

संक्षेप में: एक Roman numeral डालें और उसका value पाएँ — standard rules के विरुद्ध validated, इसलिए IIII और VV rejected होते हैं, चुपके से misread नहीं।
🔒 Design से निजी: सब कुछ इस device पर आपके browser में चलता है। आपका input कभी server पर upload नहीं होता।

Example

Input:

MCMXCIV

Output:

1994

इस converter के बारे में

Roman numerals अक्षर values जोड़ते हैं (I=1, V=5, X=10, L=50, C=100, D=500, M=1000) एक twist के साथ: बड़े से पहले छोटा अक्षर घटाता है (IV=4, CM=900)। Standard form के सख्त नियम हैं — ज़्यादा से ज़्यादा तीन repeats, घटाव सिर्फ़ powers of ten का अगले दो sizes से पहले — और यह converter उन्हें validate करता है, क्योंकि loose parsers IC (99 ग़लत लिखा; यह XCIX होना चाहिए) जैसी बकवास स्वीकार करते हैं और ग़लत system सिखाते हैं। 1–3999 range वह सब cover करती है जो classical notation vinculum (overline) extensions के बिना व्यक्त करता है: buildings पर साल, book chapters, film copyright dates, clock faces और monarch numbers।

अक्सर पूछे जाने वाले सवाल

मेरा numeral क्यों rejected हुआ?

यह standard formation rules तोड़ता है — आम तौर पर बहुत ज़्यादा repeats (IIII) या एक illegal subtraction (IC, VX)। Error का मतलब है numeral malformed है, यह नहीं कि tool मज़े के लिए सख़्त है।

सबसे बड़ा valid value क्या है?

3999 = MMMCMXCIX. बड़ी values के लिए overline notation चाहिए, जिसे classical Roman numerals ने मानकीकृत नहीं किया था।
