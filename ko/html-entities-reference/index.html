소개

HTML에는 이름 있는 엔터티가 2,200개가 넘어요; 이 표는 개발자가 매일 찾는 작업 집합이에요: 구조적 이스케이프(& < > "), 타이포그래피(대시, 따옴표, 줄임표), 통화와 수학 기호, 화살표, 체크 표시, 일반적인 악센트 문자예요. 모든 엔터티에는 이름이 없을 때도 작동하는 십진수 숫자 참조(©)와 십육진수 참조(©)도 있어요 — 여기의 문자와 십진수 열이 두 대체안을 모두 제공해요. 전체 공식 목록은 WHATWG HTML 표준에 살아요; 엔터티가 이 표에 없으면 그 숫자 참조가 믿을 만한 경로예요.

자주 묻는 질문

문자 자체 대신 왜 엔티티를 사용하나요?

구조적인 다섯(& < > " ')에 대해 엔터티는 스타일이 아니라 올바름이에요 — 이스케이프하지 않으면 마크업이 깨져요. 나머지에 대해 엔터티는 인코딩이 불확실할 때 이식성 선택이에요.

여기에 엔티티가 없으면 어떻게 되나요?

모든 유니코드 차트에서 십진수 숫자 참조를 사용하세요: &#<code>; 항상 작동해요.
