Generátor podpisu e-mailu HTML - Profesionální podpisy, které přežijí e-mailové klienty

Stručně: generátor podpisů e-mailů HTML sestaví váš podpis jako tabulkové HTML bezpečné pro e-maily – jedinou techniku rozvržení, kterou Gmail, Outlook a Apple Mail všechny spolehlivě vykreslují – s vaší akcentní barvou, kontaktními odkazy a volitelným sloganem.

E-mailoví klienti odstraňují moderní CSS, a proto se podpisy postavené z divů v Outlooku rozpadají. Tento je postaven starým, správným způsobem: pouze tabulky a vložené styly.

Náhled

Soukromé už designem: vše v tomto nástroji probíhá 100% ve vašem prohlížeči pomocí JavaScriptu. Váš vstup se nikdy nenahrává na server, nikdy se neukládá a nikdy ho nevidíme – zavřete kartu a vše je pryč.

Jak používat Generátor podpisu e-mailu HTML

  1. Vyplňte své jméno, pozici a společnost.
  2. Přidejte telefon, e-mail a web - stanou se z nich odkazy, na které lze klepnout.
  3. Vyberte barvu zvýraznění a volitelný slogan.
  4. Zkontrolujte náhled a poté zkopírujte HTML (nebo zkopírujte vykreslený náhled rovnou do editoru podpisů v Gmailu).

Jak to funguje

HTML e-mailů je časová kapsle: engine Wordu v Outlooku ignoruje flexbox, mřížky a většinu moderního CSS, takže profesionální podpisy se stále staví z vnořených tabulek a vložených stylů - přesně to tento generátor vydává. Kontaktní údaje se stanou skutečnými odkazy tel:, mailto: a webovými, akcentní lišta a jméno používají vaši barvu a každá textová hodnota je escapovaná, takže jméno s ampersandem nemůže rozbít značkování. Nepoužívají se žádné obrázky, takže se podpis zobrazí okamžitě a nikdy nespustí varování 'stáhněte obrázky'.

Často kladené otázky

Je tento generátor zdarma?

Ano – zcela zdarma, bez registrace.

Jak to přidám v Gmailu?

Zkopírujte vykreslený náhled (ne kód), poté v Gmailu přejděte do Nastavení → Zobrazit všechna nastavení → Podpis, vytvořte podpis a vložte. Formátování se přenese.

Proč tabulky místo divů?

Outlook pro stolní počítače vykresluje poštu enginem Microsoft Word, který spolehlivě podporuje pouze tabulky a vložené styly.

Mohu přidat fotografii loga?

Tento generátor je záměrně pouze textový - podpisy bez obrázků se načítají okamžitě a nikdy nejsou blokovány. Hostované logo lze do HTML přidat ručně, pokud ho potřebujete.

Nahrává se něco?

Ne. Vaše údaje nikdy neopustí váš prohlížeč.
