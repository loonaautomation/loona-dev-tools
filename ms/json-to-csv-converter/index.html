Penukar JSON ke CSV - Ubah Array JSON menjadi Spreadsheet

Singkatnya: Penukar JSON ke CSV mengambil array JSON berisi objek dan menghasilkan fail CSV yang tepat: lajur adalah gabungan setiap kunci dalam array, nilai dengan koma atau tanda kutip dikutip dengan benar, dan objek bersarang disimpan sebagai JSON ringkas di dalam selnya.

API berbicara JSON; spreadsheet, import, dan pengurus berbicara CSV. Tampalkan array JSON di bawah dan dapatkan fail CSV yang terbuka dengan bersih di Excel, Google Sheets, atau importter mana pun - tanpa koma yang rusak, tanpa tanda kutip yang jebol.

Peribadi berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di pelayar Anda dengan JavaScript. Input Anda tidak pernah dimuat naik ke pelayan, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Cara menggunakan Penukar JSON ke CSV

  1. Tampal array JSON berisi objek ke kotak atas (objek tunggal juga berfungsi - ia menjadi satu baris).
  2. Klik Penukaran ke CSV.
  3. Tinjau CSV: baris pertama adalah header, dibina dari setiap kunci yang dijumpai dalam array.
  4. Salin atau muat turun sebagai fail .csv, siap untuk Excel atau Google Sheets.

Cara kerja

Penukar mem-parsing JSON Anda dengan penghurai bawaan pelayar, lalu menelusuri setiap objek dalam array dan mengumpulkan gabungan semua kunci, dalam urutan kemunculan pertama mereka - jadi objek dengan medan ekstra tidak pernah kehilangannya. Setiap sel di-escape dengan aturan CSV: nilai yang mengandung koma, tanda kutip, atau baris baru dibungkus dalam tanda kutip ganda, dan tanda kutip di dalamnya digandakan. Angka dan boolean ditulis polos, null dan kunci yang hilang menjadi sel kosong, dan objek atau array bersarang ditulis sebagai JSON ringkas di dalam selnya agar tidak ada data yang dibuang diam-diam.

Contoh yang dikerjakan

Array [{"name":"Ali","city":"Lahore"},{"name":"Ana","city":"Porto","vip":true}] menjadi tiga lajur (name, city, vip): Ali mendapatkan sel vip kosong, dan Ana mendapatkan true - pendekatan gabungan kunci menjaga kedua baris lengkap.

Pertanyaan yang Sering Diajukan

Apakah penukar JSON ke CSV ini percuma?

Ya - sepenuhnya percuma, tanpa pendaftaran, tanpa batas saiz, dan tanpa batas harian.

Bentuk JSON apa yang diterima?

Array objek adalah kasus utama. Objek tunggal menjadi CSV satu baris, dan array nilai polos (angka, string) menjadi satu lajur "value". Hal lain ditolak dengan penjelasan.

Apa yang terjadi pada objek dan array bersarang?

Mereka ditulis sebagai teks JSON ringkas di dalam selnya. Tidak ada yang diratakan atau dibuang, dan menukar kembali dengan alat CSV ke JSON kami menjaga mereka tetap mudah dibaca.

Mengapa beberapa sel memiliki tanda kutip di sekitarnya?

Aturan CSV mengmestikan pengutipan ketika nilai mengandung koma, tanda kutip ganda, atau baris baru - jika tidak, lajur akan beranjak. Excel dan Google Sheets membaca pengutipan standard ini dengan benar.

Apakah data saya dimuat naik ke pelayan?

Tidak. Parsing dan penukaran terjadi 100% di pelayar Anda. Data Anda tidak pernah meninggalkan peranti Anda.
