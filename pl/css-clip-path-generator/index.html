Generator clip-path CSS - Kształtuj elementy wizualnie

W skrócie: Generator ścieżki przycinania CSS (Clip-Path) daje gotowy CSS clip-path dla wielokątów (od trójkąta do gwiazdy), kół, elips oraz insetów - wybierz kształt, dostrój jego punkty, obserwuj podgląd na żywo i kopiuj kod. Uwaga: siostrzane narzędzia Obrazów tej witryny już obejmują gradienty; clip-path żyje tutaj, ponieważ jest to CSS układu, a nie edycja obrazów.

Clip-path zamienia prostokąty w projektowanie: skośne sekcje, odznaki, strzałki i gwiazdy jedną właściwością CSS. Trudną częścią są współrzędne - to narzędzie zajmuje się nimi.

Prywatne z założenia: wszystko w tym narzędziu dzieje się w 100% w przeglądarce przy użyciu JavaScript. Dane wejściowe nigdy nie są przesyłane na serwer, nigdy nie są przechowywane i nigdy nie są przez nas widziane - zamknij kartę, a wszystko znika.

Jak korzystać z Generatora clip-path CSS

  1. Wybierz preset kształtu.
  2. Dla wielokątów dostosuj procenty x,y dowolnego punktu.
  3. Obserwuj, jak podgląd aktualizuje się na żywo.
  4. Skopiuj CSS - dołączone są zarówno właściwość standardowa, jak i -webkit-.

Jak to działa

Punkty wielokąta są procentami pola elementu, więc kształty skalują się wraz z elementem. Presety kodują dobrze znane zbiory współrzędnych (regularny pięciokąt, sześciokąt, dziesięcioramienną gwiazdę i nie tylko), a generator wypisuje oba clip-path a ten -webkit- prefiksowany bliźniak, którego Safari historycznie potrzebowało. Koło, elipsa oraz inset obejmują kształty niebędące wielokątami, które właściwość obsługuje, w tym zaokrąglone insety.

Często zadawane pytania

Czy ten generator jest bezpłatny?

Tak - całkowicie za darmo, bez rejestracji.

Dlaczego istnieje też generator gradientu na witrynie Obrazów?

Gradienty tam są traktowane jako zasoby graficzne/projektowe. Clip-path to CSS układu dla deweloperów, więc żyje tutaj - każde narzędzie istnieje na dokładnie jednej witrynie Loona.

Czy clip-path wpływa na kliknięcia?

Tak - wycięty obszar nie jest klikalny, co zwykle jest tym, czego chcesz dla ukształtowanych przycisków i kart.

Obsługa przez przeglądarki?

Wszystkie nowoczesne przeglądarki obsługują clip-path; prefiks -webkit- w wynikach obejmuje starsze Safari.

Czy cokolwiek jest przesyłane?

Nie. Wszystko działa w przeglądarce.
