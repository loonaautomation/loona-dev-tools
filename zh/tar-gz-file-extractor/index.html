TAR.GZ 文件解压工具 - 在线打开 TAR.GZ 与 TGZ 文件

简而言之： TAR.GZ 文件提取器直接在您的浏览器中打开 .tar.gz 和 .tgz 归档——浏览里面的文件，下载单个文件，或将所有内容重新打包为 ZIP 保存。无需安装，无需上传：提取在您的设备上运行。

如果您下载源代码、WordPress 备份、服务器快照或任何来自 Linux 世界的东西，它会以 .tar.gz 的形式到达——一个用 gzip 挤压的 TAR 捆绑包。Windows 资源管理器无法打开它，这让许多人对一个连看都看不了的文件束手无策。本页使用 libarchive 的 WebAssembly 移植版本打开它，完全在您的浏览器中完成。

如何使用 TAR.GZ 文件解压工具

  1. 把您的 .tar.gz 或 .tgz 文件拖到上面的框中，或点击它从您的设备中选择文件。
  2. 等待片刻，归档正在读取——首次使用时，解压引擎（约 1 MB）加载一次，然后由您的浏览器缓存。
  3. 浏览归档内文件的列表，包括它们的文件夹和大小。
  4. 点击任何单个文件旁边的“下载”，或使用“全部下载为 ZIP”把整个归档保存为一个标准 ZIP 文件。

它如何工作

.tar.gz 有两层：外层是负责压缩的 gzip 层，内层是把许多文件捆绑成一个流的 TAR 层。本页使用编译为 WebAssembly 的 libarchive 剥开这两层——先解压 gzip，然后遍历 TAR 标头，列出每个条目及其路径和未压缩大小。文件只有在您下载时才会被解压，“全部下载为 ZIP”选项会用 JSZip 重新打包它们，这样结果在任何地方都能打开。

实例

您的主机面板为您提供了一个完整的站点备份 backup-2026-11-01.tar.gz（260 MB）。您在这里打开它，在列表中导航到 wp-content/uploads，下载您意外删除的三张照片（总共 4 MB）——而不是恢复整个备份或安装工具来查看内部。

常见问题

.tar.gz 和 .tgz 有什么区别？

没有区别——它们是完全相同的格式。.tgz 名称只是文件扩展名被限制为三个字符的年代的缩短版本。本页两者都接受。

我有一个普通的 .gz 文件，不是 .tar.gz。它能在这里用吗？

普通的 .gz 恰好包含一个压缩文件，而不是一个归档。这类文件请使用下方链接的 GZ 文件解压工具——它直接解压单个文件。本页用于包含许多文件的归档。

本工具能创建 .tar.gz 文件吗？

不，本页只是一个解压工具。要在这里把文件捆绑成归档，请使用 ZIP 文件创建工具——ZIP 在任何地方都能打开，包括产生 .tar.gz 文件的 Linux 系统。

为什么我的归档打开了，却显示奇怪的长名称或链接？

来自服务器的 TAR 归档常常在普通文件之外包含符号链接和设备条目。本工具列出并解压普通文件；链接在格式记录它们的地方显示在列表中，但在您的下载中不会被重建为链接。

我的文件会被上传到任何地方进行解压吗？

不会。解压在您浏览器标签页内的 WebAssembly 中运行。备份及其内部的一切从头到尾都保留在您的设备上。
