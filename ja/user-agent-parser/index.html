ユーザーエージェントパーサー

要するに： 任意のユーザーエージェント文字列を貼り付けて、読める内訳を取得してください。ブラウザ、バージョン、レンダリングエンジン、オペレーティングシステム、デバイスクラスです。
🔒 設計上プライベート： すべてはこのデバイス上のブラウザで動作します。あなたの入力がサーバーにアップロードされることは決してありません。

私たちについて

ユーザーエージェントの解析は、標準化されたことがなく、今ではフィンガープリントを減らすためにブラウザによって意図的に凍結されつつある文字列に対するパターンマッチングです（ChromeはClient Hintsを優先してUAの粒度を減らしています）。このパーサーは主流の検出ルールを正しい優先順序で適用します。Chromeの前にEdge（そのUAは「Chrome」を含みます）、Chromeの前にOpera、Versionトークンによるバージョンを持つSafari。そしてエンジンとOSのファミリーに名前を付けます。ログやサポートチケットを読むための正しいツールです。セキュリティ判断のための間違ったツールです。UA文字列はクライアントが主張するものが何でもあるためです。

よくある質問

なぜ Edge's のUAはChromeとSafariと言うのですか？

歴史的な互換性：すべてのブラウザはMozillaとWebKitの系譜を主張するため、古いサーバースニッフィングでも最新のサイトが提供されます。パーサーはまず特徴的なトークンをチェックしなければなりません。

UAはアクセス制御に信頼できますか？

決してそうではありません。簡単に偽装できます。分析とデバッグに使い、認証には使わないでください。
