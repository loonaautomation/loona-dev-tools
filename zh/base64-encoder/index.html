Base64 编码器与解码器 - 文本与文件，UTF-8 安全

简而言之： Base64 编码器将文本和文件转换为 Base64，并将 Base64 解码回文本——正确处理重音符号、乌尔都语、中文和 emoji，还带有一个可选的 URL 安全字母表。

Base64 无处不在：API 负载、电子邮件附件、data URI、basic-auth 标头和 JWT 的各个部分。许多快速编码器的问题在于它们在非英文文本上会出错。本编码器编码的是您文本的 UTF-8 字节，所以您能输入的任何内容都能在往返中完好无损。

文件转 Base64

选择一个文件以获取其 Base64 数据字符串（对 data URI 和测试负载很有用）。文件在本地读取——从不上传。

按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中使用 JavaScript 完成。您的输入从不上传到服务器，从不存储，我们也从不见过它——关闭标签，一切都消失了。

如何使用 Base64 编码器与解码器

  1. 输入或粘贴您的文本（或选择一个文件进行文件转 Base64）。
  2. 如果结果会进入 URL 或 JWT，可选地勾选 URL 安全。
  3. 点击“编码”或“解码”，并复制或下载结果。

它如何工作

Base64 使用 64 字符字母表把每 3 个字节的数据表示为 4 个字符，这使二进制数据能安全地在 JSON、XML 和 URL 等文本格式中携带。本工具先把您的文本转换成它的 UTF-8 字节（文本的通用编码），然后编码这些字节——这正是带重音的字母、阿拉伯文字文本和 emoji 都能完美解码回来的原因。URL 安全变体把 + 和 / 换成 - 和 _，并去掉 = 填充，正如 JSON Web Tokens 中所使用的那样。

实例

文本 "Loona" 编码为 TG9vbmE=。带乌尔都语文字和一个 emoji 的问候语 "Assalam-o-Alaikum"——السلام علیكم 👋——逐字编码并解码回来，这是只处理普通 ASCII 的天真编码器无法做到的。

常见问题

这个 Base64 工具免费吗？

是的——免费，无需注册，没有限制。

为什么一些 Base64 工具会把非英语文本弄乱？

它们把每个字符编码为单个字节，这只对普通 ASCII 有效。本工具改为编码 UTF-8 字节，所以每种语言和每个 emoji 都能精确往返。

什么是 URL 安全选项？

标准 Base64 可以包含 + 和 /，它们是 URL 中的特殊字符。URL 安全字母表用 - 和 _ 替换它们并删除填充——JWT 中使用的变体。

Base64 是加密吗？

不是。Base64 是编码，不是加密——任何人都能瞬间解码它。永远不要用它保护机密。

我的文件会被上传吗？

不会。文件由您设备上的浏览器读取，从不离开它。
