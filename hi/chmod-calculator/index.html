Chmod कैलकुलेटर — Permissions से Octal और Symbolic, दोनों तरफ़

संक्षेप में: Chmod कैलकुलेटर owner, group और others के लिए परिचित read/write/execute checkboxes को octal value (जैसे 755) और symbolic string (जैसे rwxr-xr-x) में बदलता है — और किसी octal value को वापस boxes में बदलता है, common values के लिए plain-language meanings के साथ।

हर कोई याद रखता है कि 755 "folder वाला" है और 644 "file वाला" — उस दिन तक जब deploy को 750 या 640 चाहिए। नीचे boxes पर tick करें, या octal value type करें, और अंदाज़ा लगाना बंद करें।

Chmod कैलकुलेटर का उपयोग कैसे करें

  1. Owner, Group और Others के लिए Read, Write और Execute पर tick करें — या preset उपयोग करें।
  2. Octal value, symbolic string और paste करने के लिए तैयार chmod command पढ़ें।
  3. या कोई 3-digit octal value type करें (जैसे 750) और इसे checkboxes के रूप में देखने के लिए Apply octal पर click करें।
  4. Command को अपने terminal में copy करें।

यह कैसे काम करता है

Unix permissions तीन bits के तीन groups हैं। हर group के अंदर, Read की worth 4, Write की 2 और Execute की 1 है, इसलिए एक group 0 (---) से 7 (rwx) तक एक single octal digit है। Calculator तीन-digit octal बनाने के लिए प्रति group ticked values जोड़ता है, और उन्हीं boxes को symbolic string के रूप में render करता है जो आप देखते हैं इसमें ls -l output। Octal value लगाना maths को उल्टा चलाता है: हर digit अपने 4-2-1 parts में वापस split होता है checkboxes set करने के लिए।

काम किया हुआ उदाहरण

Owner read+write+execute (4+2+1 = 7), group read+execute (4+1 = 5), others read+execute (5) octal 755 देता है, symbolic rwxr-xr-x — वह classic setting जो हर किसी को फ़ाइल या folder पढ़ने और चलाने देती है जबकि सिर्फ़ owner इसे बदल सकता है।

अक्सर पूछे जाने वाले सवाल

क्या यह chmod calculator मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, बिना साइन-अप और बिना daily cap।

Octal और symbolic के बीच क्या अंतर है?

वे समान permissions describe करते हैं। Octal (755) वह है जो आप chmod के बाद type करते हैं; symbolic (rwxr-xr-x) वह है जो ls -l आपको दिखाता है। यह tool दोनों दिशाओं में उनके बीच बदलता है।

Setuid, setgid और sticky bit (4755, 1777) के बारे में क्या?

वे special bits के लिए एक चौथा, leading digit हैं। यह calculator मुख्य तीन permission digits cover करता है, जो day-to-day chmod काम उपयोग करता है; अगर आप कहीं और 4-digit value type करते हैं, तो आखिरी तीन digits वही हैं जो यहाँ दिखाए गए हैं।

Folders को Execute क्यों चाहिए?

Folder पर, "execute" का मतलब है उसमें प्रवेश करने और अंदर की फ़ाइलों तक पहुँचने की अनुमति — read वाला लेकिन execute के बिना folder उन नामों को दिखाता है जिन्हें आप सच में खोल नहीं सकते। इसीलिए folders आम तौर पर 755 होते हैं जबकि files 644।
