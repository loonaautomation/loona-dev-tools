JSON 포맷터 & 검사기 - JSON 보기 좋게 출력하고 축소하기

요약하면: JSON 포맷터는 JSON을 검사하고, 공백 2개, 공백 4개, 탭 들여쓰기로 예쁘게 인쇄하고, 요청 시 축소하며, 무언가 잘못되면 문제의 정확한 줄과 열을 알려줘요.

깨진 JSON은 개발자의 하루에서 가장 흔한 오 분 지연이에요 - 쉼표 하나가 빠지면 전체 페이로드가 실패해요. 아래에 JSON을 붙여넣으세요: 유효하면 깔끔하고 읽기 쉬운 출력을 얻어요; 유효하지 않으면 쓸모없는 "parse failed" 대신 오류의 정확한 위치를 얻어요.

설계상 비공개: 이 도구의 모든 것은 JavaScript로 브라우저에서 100% 일어나요. 입력은 서버에 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요 - 탭을 닫으면 모든 것이 사라져요.

JSON 포맷터 사용법

  1. JSON을 위 상자에 붙여넣거나 입력하세요.
  2. 들여쓰기 스타일을 선택하세요 - 공백 2개, 공백 4개 또는 탭이에요.
  3. 읽기 쉬운 출력에는 포맷 / 검증을, 가장 작은 유효 형태에는 축소를 클릭하세요.
  4. 결과를 복사하거나 .json 파일로 다운로드하세요.

작동 방식

도구는 브라우저 내장 JSON 파서를 사용해요 - 자체 JavaScript 코드가 사용하는 같은 엄격한 파서예요 - 그래서 여기서 초록불은 JSON이 정말 유효하다는 뜻이에요. 예쁘게 인쇄하기는 선택한 들여쓰기로 파싱된 값을 다시 직렬화해요; 키 순서는 쓴 그대로 정확히 보존돼요. 축소하기는 단일 값도 바꾸지 않고 모든 불필요한 공백과 줄바꿈을 제거해요. 파싱이 실패하면, 도구는 파서의 문자 위치를 줄과 열로 변환하고 문제가 있는 줄을 보여줘요.

풀이된 예시

수신해요 {"user":"ahmed","roles":["admin","editor"],"active":true} API에서요. 공백 2개로 포맷하면 실제로 읽을 수 있는 깨끗한 아홉 줄 문서가 돼요 - 그리고 "ahmed" 뒤의 쉼표를 실수로 삭제하면, 도구는 찾게 내버려 두는 대신 정확한 줄과 열에서 오류를 보고해요.

자주 묻는 질문

이 JSON 포맷터는 무료인가요?

네 - 완전히 무료, 회원가입 없음, 크기 제한 없음, 일일 상한 없음이에요.

JSON이 유효하지 않으면 어떻게 되나요?

파서의 오류 메시지와 파싱이 실패한 정확한 줄과 열, 그리고 그 줄의 텍스트를 얻어요. 그래서 몇 초 안에 고칠 수 있어요.

포맷이 데이터를 바꾸나요?

아니요. 포맷은 공백만 바꿔요. 축소는 공백만 제거해요. 키, 값, 그 순서는 건드려지지 않아요.

제 JSON이 서버에 업로드되나요?

아니요. 파싱과 포맷은 브라우저에서 100% 일어나요. API 페이로드와 구성 파일은 기기를 절대 떠나지 않아요.

정말 큰 JSON을 포맷할 수 있나요?

네 - 실제 제한은 기기의 메모리예요. 수 메가바이트 파일은 일반적인 노트북에서 일 초도 채 안 돼 포맷돼요.
