JSON 转 CSV 转换器 - 把 JSON 数组变成电子表格

简而言之： JSON 转 CSV 转换器采用一个 JSON 对象数组并生成一个适当的 CSV 文件：列是数组中每个键的并集，带有逗号或引号的值会被正确地引用，嵌套对象在其单元格内保持为紧凑的 JSON。

API 说 JSON；电子表格、导入工具和管理器说 CSV。把一个 JSON 数组粘贴到下面，就能得到一个能在 Excel、Google Sheets 或任何导入工具中干净打开的 CSV 文件——没有乱掉的逗号，没有破损的引号。

按设计保证隐私： 这个工具中的一切都 100% 在您的浏览器中使用 JavaScript 完成。您的输入从不上传到服务器，从不存储，我们也从不见过它——关闭标签，一切都消失了。

如何使用 JSON 转 CSV 转换器

  1. 把一个 JSON 对象数组粘贴到上方框中（单个对象也可以——它会变成一行）。
  2. 点击“转换为 CSV”。
  3. 审查 CSV：第一行是标题，由数组中找到的每个键构成。
  4. 复制它，或把它下载为 .csv 文件，随时可用于 Excel 或 Google Sheets。

它如何工作

转换器用浏览器内置解析器解析您的 JSON，然后遍历数组中的每个对象，收集所有键的并集，按它们首次出现的顺序——所以带额外字段的对象永远不会丢失它。每个单元格按 CSV 规则转义：包含逗号、引号或换行的值被双引号包裹，内部的引号被翻倍。数字和布尔值以普通方式写入，null 和缺失的键变成空单元格，嵌套对象或数组以紧凑 JSON 的形式写入其单元格内，这样没有任何数据被悄悄丢弃。

实例

数组 [{"name":"Ali","city":"Lahore"},{"name":"Ana","city":"Porto","vip":true}] 变成三列（name、city、vip）：Ali 的 vip 单元格为空，Ana 的为 true——并集键方法使两行都保持完整。

常见问题

这个 JSON 转 CSV 转换器免费吗？

是的——完全免费，无需注册，没有大小限制，也没有每日上限。

接受哪些 JSON 形状？

对象数组是主要情况。单个对象会变成一行的 CSV，普通值（数字、字符串）的数组会变成单个 "value" 列。其他任何内容都会被拒绝并附上说明。

嵌套对象和数组会怎样？

它们以紧凑 JSON 文本的形式写入其单元格内部。没有什么被压平或丢弃，用我们的 CSV 转 JSON 工具转换回来使它们保持可读。

为什么一些单元格周围有引号？

CSV 规则要求：当值包含逗号、双引号或换行时必须加引号——否则列会错位。Excel 和 Google Sheets 能正确读取这种标准引号。

我的数据会被上传到服务器吗？

不会。解析和转换 100% 在您的浏览器中进行。您的数据从不离开您的设备。
