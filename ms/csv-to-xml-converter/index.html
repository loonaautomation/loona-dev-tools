Penukar CSV ke XML - Baris Spreadsheet sebagai XML yang Bersih

Singkatnya: Penukar CSV ke XML mengubah setiap baris CSV menjadi elemen XML, menggunakan baris header Anda sebagai nama tag, dengan elemen root dan baris yang dapat dikonfigurasi dan escaping yang benar untuk &, <, >, dan tanda kutip.

Feed, sitemap, dan sistem lama masih berbicara XML. Tampalkan CSV Anda, beri nama elemennya, dan dapatkan XML well-formed yang akan diterima penghurai mana pun.

Peribadi berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di pelayar Anda dengan JavaScript. Input Anda tidak pernah dimuat naik ke pelayan, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Cara menggunakan Penukar CSV ke XML

  1. Tampal CSV Anda - baris pertama menyediakan nama elemen.
  2. Atur nama elemen root dan elemen baris jika default tidak cocok.
  3. Klik Penukaran ke XML.
  4. Salin hasilnya atau muat turun sebagai fail .xml.

Cara kerja

Nama header diubah menjadi nama tag XML yang valid: aksara yang tidak dapat muncul dalam tag diganti dengan garis bawah, dan nama yang akan dimulai dengan digit diberi awalan. Header duplikat mendapat akhiran _2, _3 agar tidak ada lajur yang hilang. Setiap nilai di-escape XML - ampersand, kurung siku, dan tanda kutip menjadi entitas - jadi nilai seperti Fish & Chips tidak pernah dapat merusak dokumen. Output berindentasi, dimulai dengan deklarasi XML standard, dan terparsing bersih di penghurai XML mana pun.

Contoh yang dikerjakan

Nilai sebesar a < b & c dipancarkan sebagai a &lt; b &amp; c di dalam elemennya - di-escape tepat sekali, seperti yang diperlukan XML.

Pertanyaan yang Sering Diajukan

Apakah penukar CSV ke XML ini percuma?

Ya - sepenuhnya percuma, tanpa pendaftaran.

Dapatkah saya mengubah nama elemen?

Ya. Atur nama elemen root dan baris; elemen lajur berasal dari baris header Anda, disanitasi menjadi nama tag XML yang valid.

Bagaimana aksara khusus ditangani?

Mereka di-escape sebagai entitas XML (&, <, >, ", ') jadi output selalu terbentuk dengan baik.

Bagaimana jika header bukan nama tag yang valid?

Aksara tidak valid menjadi garis bawah dan nama yang dimulai dengan digit mendapat awalan, jadi setiap lajur tetap muncul.

Apakah data saya dimuat naik?

Tidak. Semuanya berjalan di pelayar Anda.
