ตัวทดสอบ Regex - การจับคู่แบบสด กลุ่ม และไฮไลต์

สรุปสั้น ๆ: ตัวทดสอบ Regex รันแพทเทิร์นของคุณเทียบกับข้อความทดสอบของคุณขณะที่คุณพิมพ์ ไฮไลต์ทุกการจับคู่ แสดงรายการแต่ละกลุ่มที่จับ และแสดงจำนวนการจับคู่รวม - และรายงานแพทเทิร์นที่ไม่ถูกต้องพร้อมข้อความข้อผิดพลาดของเบราว์เซอร์

Regular expression คือเขียนครั้งเดียว งงตลอดไป วางแพทเทิร์นและข้อความตัวอย่างด้านล่าง แล้วดูอย่างแม่นยำว่าอะไรตรงกัน ตรงที่ไหน และแต่ละกลุ่มที่จับได้จับอะไร - ก่อนที่แพทเทิร์นจะไปถึงโค้ดของคุณ

(ยังไม่มีอะไร)
เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวทดสอบ Regex

  1. พิมพ์แพทเทิร์นของคุณในกล่องแพทเทิร์น (โดยไม่มีเครื่องหมายทับล้อมรอบ)
  2. ตั้งค่าแฟล็กอย่าง g (global), i (ignore case) หรือ m (multiline) ในกล่องแฟล็ก
  3. พิมพ์หรือวางข้อความทดสอบ - ผลลัพธ์อัปเดตแบบสดขณะที่คุณพิมพ์
  4. อ่านข้อความที่ไฮไลต์และตารางการจับคู่: ทุกการจับคู่พร้อมตำแหน่งและกลุ่มที่จับของมัน

วิธีการทำงาน

เครื่องมือสร้าง JavaScript RegExp จากแพทเทิร์นและแฟล็กของคุณและดำเนินการมันเทียบกับข้อความทดสอบ โดยตั้งค่าแฟล็ก global มันจะเดินผ่านทุกการจับคู่ตามลำดับ; หากไม่มีมัน มันจะรายงานการจับคู่แรกเท่านั้น อย่างแม่นยำเหมือนที่โค้ดของคุณเองจะทำ การจับคู่ความกว้างศูนย์ (ตัวอย่างเช่นจาก x*) ได้รับการจัดการอย่างปลอดภัย - ตัวท่องเดินจะเลื่อนไปหนึ่งตัวอักษรหลังการจับคู่ที่ว่างเปล่าแต่ละครั้ง จึงไม่มีทางวนซ้ำไม่รู้จบ มุมมองไฮไลต์จะแปลงข้อความของคุณให้เป็น HTML ที่ปลอดภัยก่อน จากนั้นจึงห่อแต่ละผลการจับคู่ด้วยเครื่องหมายไฮไลต์ ดังนั้นสิ่งที่คุณเห็นคือสิ่งที่ตรงกันอย่างแม่นยำ

ตัวอย่างที่ทำแล้ว

แพทเทิร์น (\d{4})-(\d{2})-(\d{2}) เทียบกับ "Release on 2026-11-08, hotfix on 2026-11-09" พบ 2 การจับคู่ และตารางแสดงกลุ่ม 1 = 2026 กลุ่ม 2 = 11 กลุ่ม 3 = 08 สำหรับรายการแรก - พร้อมนำไปใช้ซ้ำในตัวแยกวิเคราะห์วันที่

คำถามที่พบบ่อย

ตัวทดสอบ regex นี้ฟรีหรือไม่?

ใช่ - ฟรีทั้งหมด ไม่ต้องสมัครสมาชิกและไม่มีขีดจำกัดรายวัน

มันใช้ regex รสชาติใด?

นิพจน์ปกติของ JavaScript - รสชาติที่ใช้โดยเบราว์เซอร์และ Node.js แพทเทิร์นส่วนใหญ่จากรสชาติอื่น (PCRE, Python) ทำงานเหมือนกัน แต่โครงสร้างบางอย่างแตกต่างกัน อย่างกลุ่มที่มีชื่อซึ่ง JavaScript เขียนเป็น (?<name>...)

ทำไมฉันจึงเห็นการจับคู่เพียงครั้งเดียว?

หากไม่มีแฟล็ก g regex จะหยุดที่การจับคู่แรก เพิ่ม g ในกล่องแฟล็กเพื่อค้นหาพวกมันทั้งหมด

กลุ่มที่จับคืออะไร?

วงเล็บแต่ละคู่ในแพทเทิร์นของคุณจับข้อความที่มันตรงกัน ตารางแสดงรายการพวกมันตามแต่ละผลการจับคู่ - กลุ่ม 1 คือวงเล็บเปิดตัวแรก และอื่น ๆ ในทำนองเดียวกัน กลุ่มที่เขียนเป็น (?:...) จะไม่จับข้อความ

ข้อความของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ แพทเทิร์นทำงาน 100% ในเบราว์เซอร์ของคุณกับข้อความที่ไม่เคยออกจากอุปกรณ์ของคุณ
