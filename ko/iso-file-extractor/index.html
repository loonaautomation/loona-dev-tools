ISO 파일 추출기 - ISO 디스크 이미지를 온라인으로 열기

요약하면: ISO 파일 추출기는 .iso 디스크 이미지를 브라우저에서 열어요 - 가상 CD나 DVD에 저장된 폴더와 파일을 살펴보고, 단일 파일을 다운로드하거나, 모든 것을 ZIP으로 저장하세요. 디스크 마운트 없음, 설치 없음, 업로드 없음이에요.

.iso 파일은 CD나 DVD의 완전한 복사본을 단일 파일에 담은 것이에요: Linux 설치 파일, 예전 소프트웨어 디스크, 보관된 게임이나 드라이버 CD가 모두 ISO로 살아요. Windows는 마운트할 수 있지만 관리자로서만, 그리고 둘러보기만 가능해요 - 파일 하나를 추출하는 일은 여전히 번거로워요. 이 페이지는 libarchive의 WebAssembly 포트로 이미지 안의 ISO9660 파일 시스템을 읽어요, 바로 여러분의 브라우저에서요.

여기에 .iso 파일을 놓으세요 또는 클릭해 기기에서 파일을 선택하세요
아카이브 안의 파일크기
설계상 비공개: 이 도구의 모든 것은 브라우저에서 100% 일어나요. 디스크 이미지는 자체 기기의 WebAssembly 엔진이 읽어요 - 절대 업로드되지 않고, 절대 저장되지 않으며, 저희가 절대 보지 않아요. 정직한 제한 하나: 디스크 이미지는 본질적으로 크고 목록은 기기 메모리에서 만들어져, 전체 듀얼 레이어 DVD 이미지(8 GB)는 RAM이 풍부한 데스크톱에서만 현실적이에요.

ISO 파일 추출기 사용법

  1. .iso 파일을 위 상자에 놓거나, 클릭해 기기에서 파일을 고르세요.
  2. 이미지가 읽히는 동안 잠시 기다리세요 - 처음 사용할 때 엔진(약 1 MB)이 한 번 로드되고 그다음 브라우저가 캐시해요.
  3. 가상 디스크에 저장된 파일을 폴더와 크기와 함께 살펴보세요.
  4. 단일 파일 옆의 다운로드를 클릭하거나, ZIP으로 모두 다운로드를 사용해 디스크의 내용을 하나의 표준 ZIP 파일로 저장하세요.

작동 방식

ISO 이미지는 ISO9660 파일 시스템을 저장해요: 시작 부분 근처의 볼륨 설명자가 레코드의 디렉터리 트리를 가리키고, 각 레코드는 파일 데이터를 담고 있는 디스크 섹터를 가리켜요. 이 페이지는 WebAssembly로 컴파일된 libarchive로 그 구조를 읽어요 - Windows에서 만든 디스크가 길고 대소문자가 섞인 파일 이름에 사용하는 Joliet 확장 포함 - 그리고 경로와 크기와 함께 모든 파일을 나열해요. 파일은 다운로드할 때만 복사되어 나와요; ZIP으로 모두 다운로드는 JSZip으로 다시 묶어줘요.

풀이된 예시

노트북이 디스크 드라이브를 잃은 지 오래 지난 뒤에도 오래된 어학 코스 CD를 course.iso(640 MB)로 보관해요. 여기서 이미지를 열고, 오디오 폴더를 찾아, 필요한 열두 개의 레슨 MP3(180 MB)를 다운로드해요 - 마운트 없음, 굽기 없음, 외부 드라이브 없음이에요.

자주 묻는 질문

이 도구가 Linux나 Windows 설치 파일 같은 부팅 가능한 설치 ISO를 열 수 있나요?

네, 파일을 살펴보고 추출하는 데는 - 안의 파일 시스템은 같은 ISO9660 형식이에요. 파일을 추출해도 부팅 가능한 USB 스틱을 얻을 수 없다는 점에 유의하세요; 운영 체제를 설치하려면 여전히 Rufus나 Balena Etcher 같은 적절한 이미징 도구가 필요해요.

일부 파일 이름이 왜 SETUP.EXE;1처럼 크고 짧아 보이나요?

그것은 오래된 마스터링 소프트웨어가 사용한 일반 ISO9660 이름 지정 스타일(대문자, 제한된 문자, ;1 버전 태그)이에요. Joliet 또는 Rock Ridge 확장으로 마스터링된 디스크는 일반적인 긴 이름을 유지하고, 이 도구는 그것들이 있을 때마다 표시해요.

.img, .bin 또는 .dmg 파일을 열 수 있나요?

일부 .img 파일은 다른 이름 아래의 원시 ISO 이미지라 내용이 정말 ISO9660이면 열려요. .dmg는 Apple 자체의 압축 형식이라 이 엔진이 지원하지 않아요 - 파일이 ISO 이미지가 아니면, 도구는 추측하는 대신 열 수 없었다고 말해요.

ISO 전체가 메모리에 로드되나요?

파일은 기기에서 브라우저가 읽고 목록은 메모리에서 만들어져요. 일상적인 CD 크기 이미지(약 1 GB까지)는 대부분의 데스크톱에서 괜찮아요; 매우 큰 DVD 이미지는 휴대폰이나 메모리가 적은 기계에서 느릴 수 있어요.

파일이 어디에 업로드되나요?

아니요. 이미지는 브라우저 탭 안의 WebAssembly가 파싱해요. ISO도 그 안의 파일도 기기를 절대 떠나지 않아요.
