ตัวจัดรูปแบบและตรวจสอบ JSON - พิมพ์ให้สวยงามและย่อขนาด JSON

สรุปสั้น ๆ: ตัวจัดรูปแบบ JSON ตรวจสอบ JSON ของคุณ พิมพ์อย่างสวยงามด้วยการเยื้อง 2 ช่องว่าง 4 ช่องว่าง หรือแท็บ ย่อขนาดมันเมื่อร้องขอ และหากมีอะไรผิด มันจะบอกบรรทัดและคอลัมน์ที่แม่นยำของปัญหาแก่คุณ

JSON ที่พังคือความล่าช้าห้านาทีที่พบบ่อยที่สุดในหนึ่งวันของนักพัฒนา - จุลภาคหายไปตัวเดียว ข้อมูลทั้งหมดก็ล้มเหลว วาง JSON ของคุณด้านล่าง: หากมันถูกต้อง คุณจะได้รับผลลัพธ์ที่สะอาดและอ่านง่าย; หากไม่ถูกต้อง คุณจะได้รับตำแหน่งที่แม่นยำของข้อผิดพลาดแทนที่จะเป็น "parse failed" ที่ไร้ประโยชน์

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวจัดรูปแบบ JSON

  1. วางหรือพิมพ์ JSON ของคุณลงในกล่องด้านบน
  2. เลือกรูปแบบการเยื้อง - 2 ช่องว่าง, 4 ช่องว่าง หรือแท็บ
  3. คลิกจัดรูปแบบ / ตรวจสอบ เพื่อผลลัพธ์ที่อ่านง่าย หรือย่อขนาดเพื่อรูปแบบที่ถูกต้องที่เล็กที่สุด
  4. คัดลอกผลลัพธ์หรือดาวน์โหลดเป็นไฟล์ .json

วิธีการทำงาน

เครื่องมือใช้ตัวแยกวิเคราะห์ JSON ในตัวของเบราว์เซอร์ของคุณ - ตัวแยกวิเคราะห์ที่เข้มงวดเดียวกันกับที่โค้ด JavaScript ของคุณเองใช้ - ดังนั้นไฟเขียวที่นี่หมายความว่า JSON ของคุณถูกต้องจริง ๆ การพิมพ์อย่างสวยงามจัดลำดับค่าที่แยกวิเคราะห์แล้วใหม่ด้วยการเยื้องที่คุณเลือก; ลำดับคีย์ถูกเก็บไว้อย่างแม่นยำตามที่เขียน การย่อขนาดลบทุกช่องว่างและการขึ้นบรรทัดใหม่ที่ไม่จำเป็นโดยไม่เปลี่ยนค่าแม้แต่ค่าเดียว เมื่อการแยกวิเคราะห์ล้มเหลว เครื่องมือแปลงตำแหน่งตัวอักษรของตัวแยกวิเคราะห์เป็นบรรทัดและคอลัมน์และแสดงบรรทัดที่มีปัญหาให้คุณเห็น

ตัวอย่างที่ทำแล้ว

คุณได้รับ {"user":"ahmed","roles":["admin","editor"],"active":true} จาก API จัดรูปแบบด้วย 2 ช่องว่างมันกลายเป็นเอกสารเก้าบรรทัดที่สะอาดซึ่งคุณสามารถอ่านได้จริง - และหากคุณลบบังเอิญจุลภาคหลัง "ahmed" เครื่องมือจะรายงานข้อผิดพลาดที่บรรทัดและคอลัมน์ที่แม่นยำแทนที่จะปล่อยให้คุณไล่หามัน

คำถามที่พบบ่อย

ตัวจัดรูปแบบ JSON นี้ฟรีหรือไม่?

ใช่ - ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดขนาดและไม่มีขีดจำกัดรายวัน

เกิดอะไรขึ้นเมื่อ JSON ของฉันไม่ถูกต้อง?

คุณได้รับข้อความข้อผิดพลาดของตัวแยกวิเคราะห์บวกบรรทัดและคอลัมน์ที่แม่นยำที่การแยกวิเคราะห์ล้มเหลว และข้อความของบรรทัดนั้น เพื่อให้คุณแก้ไขมันได้ในไม่กี่วินาที

การจัดรูปแบบเปลี่ยนข้อมูลของฉันหรือไม่?

ไม่ การจัดรูปแบบเปลี่ยนเฉพาะช่องว่าง การย่อขนาดลบเฉพาะช่องว่าง คีย์ ค่า และลำดับของพวกมันไม่ถูกแตะต้อง

JSON ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ การแยกวิเคราะห์และการจัดรูปแบบเกิดขึ้น 100% ในเบราว์เซอร์ของคุณ ข้อมูล API และไฟล์กำหนดค่าไม่เคยออกจากอุปกรณ์ของคุณ

ฉันจัดรูปแบบ JSON ที่ใหญ่มากได้หรือไม่?

ใช่ - ขีดจำกัดในทางปฏิบัติคือหน่วยความจำของอุปกรณ์ของคุณ ไฟล์หลายเมกะไบต์จัดรูปแบบในเวลาน้อยกว่าหนึ่งวินาทีมากบนแล็ปท็อปทั่วไป

เครื่องมือสำหรับนักพัฒนาที่เกี่ยวข้อง

64

ตัวเข้ารหัสและถอดรหัส Base64

เข้ารหัสข้อความและไฟล์เป็น Base64 หรือถอดรหัสกลับ - ปลอดภัยกับ UTF-8 รวมตัวเลือกแบบปลอดภัยสำหรับ URL

%20

ตัวเข้ารหัสและถอดรหัส URL

เข้ารหัสเปอร์เซ็นต์ข้อความและ URL อย่างปลอดภัย พร้อมตารางรายละเอียดแยกตามตัวอักษร

ID

ตัวสร้าง UUID

สร้าง UUID เวอร์ชัน 4 แบบสุ่ม - ทีละตัวหรือจำนวนมากสูงสุด 100 ตัว
