Semver موازنہ کنندہ اور چیکر

مختصراً: دو ورژن نمبر درج کریں اور جانیں کہ آیا ہر ایک درست semver ہے، کون سا نیا ہے، اور آیا خلا بڑا، چھوٹا یا patch مرحلہ ہے۔
🔒 ڈیزائن سے نجی: اس آلے پر سب کچھ آپ کے براؤزر میں چلتا ہے۔ آپ کا ان پٹ کبھی سرور پر اپ لوڈ نہیں ہوتا۔

بارے میں

Semantic Versioning (semver.org) ورژن نمبروں کو ایک معاہدہ دیتا ہے: توڑنے والی تبدیلیوں کے لیے MAJOR، پسماندہ-مطابق خصوصیات کے لیے MINOR، پسماندہ-مطابق درستگیوں کے لیے PATCH — علاوہ pre-release لاحقے (1.0.0-alpha < 1.0.0-alpha.1 < 1.0.0-beta < 1.0.0) and +build metadata that never affects precedence. The comparator implements the spec's precedence algorithm exactly, including the fiddly pre-release rules (numeric identifiers compare numerically and rank below alphanumeric ones; a version with a pre-release is older than the same version without). It is the check CI pipelines and package managers run millions of times a day.

اکثر پوچھے گئے سوالات

کیا 1.0.0-alpha، 1.0.0 سے نیا ہے؟

نہیں — ایک pre-release اپنے release سے پرانا ہے: 1.0.0-alpha < 1.0.0۔ یہ وہ قاعدہ ہے جو package managers کو betas محفوظ پیش کرنے دیتا ہے۔

کیا +build میٹا ڈیٹا اہم ہے؟

ترتیب کے لیے نہیں: 1.0.0+exp اور 1.0.0 ترتیب میں برابر ہیں، اگرچہ میٹا ڈیٹا معلومات کے لیے محفوظ ہے۔
