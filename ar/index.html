{ }

منسّق JSON

تحقّق، طبّع جميلاً وصغّر JSON، مع الموضع الدقيق لأي خطأ.

64

مشفّر وفاكّ تشفير Base64

رمّز النصوص والملفات إلى Base64، أو فكّها عودة - آمن لـ UTF-8، خيار آمن للـ URL مشمول.

%20

مشفّر وفاكّ تشفير URL

رمّز النص والروابط بالنسبة المئوية بأمان، مع جدول تفصيل لكل حرف.

ID

منشئ UUID

أنشئ معرّفات UUID عشوائية من الإصدار 4 - واحد في المرة أو دفعة حتى 100.

#

منشئ التجزئة

خلاصات SHA-1 وSHA-256 وSHA-384 وSHA-512 لأي نص، محسوبة في متصفحك.

JWT

فاكّ تشفير JWT

فكّ ترويسة وحمولة رمز JSON Web Token واقرأ انتهاءه بكلمات بسيطة.

TS

محوّل الطوابع الزمنية

حوّل طوابع Unix الزمنية إلى تواريخ بشرية وعوداً - UTC، وقتك المحلي والوقت النسبي.

&

مشفّر كيان HTML

هرّب النص إلى كيانات HTML (مسمّاة أو مرقّمة) وفكّ الكيانات عودة إلى نص.

CSS

مصغّر ومجمّل CSS

صغّر CSS لتقليص حجم الملف، أو جمّله عودة إلى كود مقروء ومُساف بادئاً.

JS

مصغّر JavaScript

صغّر JavaScript بحذر - تُزال التعليقات والمسافات البيضاء الميتة، وتُحفظ السلاسل والتعابير النمطية سليمة.

.*

مختبِر التعابير النمطية

اختبر التعابير النمطية مباشرة - التطابقات مُبرزة، مجموعات الالتقاط مدرجة، العدد معروض.

±

فاحص الفروق

قارن نصين سطراً بسطر - أسطر مضافة ومزالة مميّزة، مع ملخّص تغييرات.

CSV

محوّل JSON إلى CSV

حوّل مصفوفة JSON من الكائنات إلى ملف CSV نظيف - اتحاد كل المفاتيح، اقتباس صحيح، نقرة واحدة.

JSON

محوّل CSV إلى JSON

حوّل CSV إلى مصفوفة JSON من الكائنات - محلّل حقيقي يتعامل مع الفواصل المقتبسة والاقتباسات المهرّبة.

YAML

محوّل YAML ⇄ JSON

حوّل مجموعة YAML الفرعية الشائعة (خرائط، قوائم، قياسات) إلى JSON وJSON عودة إلى YAML - بنطاق صادق.

SQL

منسّق SQL

نسّق SQL بكلمات مفتاحية كبيرة وكل عبارة رئيسية على سطرها الخاص - استعلامات مقروءة بنقرة واحدة.

01

محوّل قواعد الأرقام

التحويل بين الثنائي والثماني والعشري والسداسي العشري بدقة أعداد صحيحة كبيرة كاملة - بلا حد 2^53.

755

حاسبة Chmod

حدّد مربعات القراءة/الكتابة/التنفيذ للمالك والمجموعة والآخرين - احصل على الأذونات الثمانية والرمزية فوراً.

***

فاحص قوة كلمة المرور

اطّلع على تقدير إنتروبيا كلمة المرور بالبتات، وما يضعّفها، وكم سيستغرق هجوم سريع دون اتصال.

* *

منشئ تعبيرات Cron

ابنِ تعبير cron من 5 حقول من قوائم منسدلة عادية، واحصل على أي تعبير cron مشروحاً بلغة عربية بسيطة.

URL

محلّل ومنشئ URL

قسّم URL إلى البروتوكول والمضيف والمنفذ والمسار ومعاملات الاستعلام والتجزئة - ثم عدّل المعاملات وأعد بناءه.

ZIP

منشئ ملفات ZIP

احزم ملفات متعددة في أرشيف ZIP واحد - يُبنى في متصفحك، لا يُرفع شيء.

فكّ الضغط

مستخرج ملفات فكّ الضغط

افتح ZIP، اطّلع على كل ملف بداخله مع حجمه، واستخرج ملفاً واحداً أو كلها.

RAR

مستخرج ملفات RAR

افتح ملفات RAR ‏(RAR4 وRAR5) في متصفحك - اطّلع على كل ملف بداخلها، نزّل ملفاً واحداً أو كل شيء كـ ZIP.

7Z

مستخرج ملفات 7Z

افتح أرشيفات 7z في متصفحك - اعرض المحتويات واستخرج ملفات مفردة أو كل شيء كـ ZIP.

TAR

مستخرج ملفات TAR

افتح أرشيفات .tar و.tar.bz2 و.tar.xz في متصفحك واستخرج الملفات بداخلها - لا يُرفع شيء.

TGZ

مستخرج ملفات TAR.GZ

افتح أرشيفات .tar.gz و.tgz في متصفحك - تصفّح الملفات بداخلها واستخرج ما تحتاج.

GZ

مستخرج ملفات GZ

فكّ ضغط ملف .gz واحد في متصفحك ونزّل الأصلي - السجلات، صادرات البيانات وتفريغات قواعد البيانات.

ISO

مستخرج ملفات ISO

افتح صور أقراص ISO في متصفحك، تصفّح نظام الملفات المخزّن على القرص الافتراضي ونزّل الملفات.

ARC

مستخرج ملفات الأرشيف

فاتح أرشيفات عالمي واحد لملفات ZIP وRAR و7Z وTAR وISO والمزيد - يُكتشف التنسيق تلقائياً.

R→ZIP

محوّل RAR إلى ZIP

حوّل أرشيف RAR إلى ZIP قياسي في متصفحك - بنية المجلدات محفوظة، لا يُرفع شيء.

7→ZIP

محوّل 7Z إلى ZIP

حوّل أرشيف 7Z إلى ZIP يُفتح في أي مكان - دون حاجة إلى 7-Zip، لا يُرفع شيء.

T→ZIP

محوّل TAR إلى ZIP

حوّل أرشيف TAR من Linux أو Unix إلى ZIP يُفتح أصلياً على Windows وmacOS والهواتف.

G→ZIP

محوّل TAR.GZ إلى ZIP

حوّل .tar.gz أو .tgz إلى ZIP واحد - تُفكّ طبقتي gzip وtar على جهازك.

Z→TGZ

محوّل ZIP إلى TAR.GZ

حوّل أرشيف ZIP إلى كرة tar بصيغة .tar.gz - التنسيق الذي تتوقعه خوادم Linux وDocker وأدوات البناء.

+TAR

منشئ ملفات TAR

أنشئ أرشيف .tar صحيح المواصفة من ملفات متعددة في متصفحك - يُفتح بأي أداة tar.

GZIP

ضاغط GZIP

اضغط أي ملف واحد إلى .gz عبر محرّك gzip المدمج في متصفحك - أحجام فورية قبل/بعد.

▦

عارض ومحرّر CSV

حمّل CSV إلى شبكة جدول قابلة للتحرير - حرّر الخلايا، رتّب الأعمدة، أضف أو أزل صفوفاً وأعمدة، ثم نزّل.

SQL→

محوّل CSV إلى SQL

حوّل CSV إلى عبارات CREATE TABLE بالإضافة إلى INSERT مع أنواع مستنتجة، لـ MySQL أو PostgreSQL أو SQLite.

XML

محوّل CSV إلى XML

حوّل صفوف CSV إلى XML سليم التشكّل مع عناصر جذر وصف قابلة للتهيئة وتهريب صحيح.

MD

محوّل CSV إلى جدول Markdown

حوّل CSV إلى جدول Markdown جاهز لـ GitHub - أعمدة رقمية محاذاة لليمين، وخطوط عمودية مهرّبة.

CSV✓

مزيل تكرار ومنظّف CSV

أزل صفوف CSV المكرّرة بالصف كاملاً أو أعمدة المفاتيح، قلّم المسافات البيضاء وأسقط الصفوف الفارغة، مع الأعداد.

✂

تقسيم ودمج CSV

قسّم CSV إلى أجزاء بعدد الصفوف مع تكرار الترويسة، أو ادمج ملفات CSV تشترك في ترويسة.

< >

منشئ وسوم Meta

أنشئ كتلة HTML وصفية جاهزة - العنوان، الوصف، الروبوتات، الرابط القانوني - مع معاينة SERP حية.

OG

منشئ Open Graph وبطاقة Twitter

ابنِ وسوم OG وبطاقات Twitter مع معاينة حية للبطاقة الاجتماعية، بحيث تبدو الروابط المشتركة صحيحة.

🤖

منشئ Robots.txt

ابنِ robots.txt صالحاً من إعدادات مسبقة وقواعد لكل وكيل، مع فحوص سلامة للناتج.

MAP

منشئ خريطة موقع XML

حوّل قائمة روابط إلى sitemap.xml صالح مع افتراضيات lastmod وchangefreq وpriority.

UTM

منشئ روابط UTM

وسم روابط الحملات بمعلمات UTM - ترميز صحيح، معلمات موجودة محفوظة، تاريخ محلي.

/24

حاسبة الشبكات الفرعية IP

‏IPv4 CIDR إلى الشبكة والبث وقناع الشبكة وقناع البدل ونطاق المضيف والعدد، زائد عرض تقسيم الشبكات الفرعية.

LD

منشئ مخطط JSON-LD

أنشئ بيانات schema.org منظمة - Article، Product، LocalBusiness، Event، Recipe والمزيد - كـ JSON-LD صالح.

G

معاينة نتائج بحث Google

عاين عنوانك ووصفك كنتيجة Google، مع تحذيرات قصّ عرض البكسل، سطح المكتب والهاتف.

%

فاحص كثافة الكلمات المفتاحية

عدّ الكلمات المفردة زائد عبارات 2 و3 كلمات مع كثافة النسبة المئوية وتصفية كلمات الإيقاف.

منشئ جداول HTML

ابنِ الجداول بصرياً في شبكة واحصل على HTML دلالي نظيف مع دعم thead وth وcaption.

✉

منشئ توقيع بريد HTML

أنشئ توقيع بريد مهنياً كـ HTML جدول آمن للبريد يعمل في Gmail وOutlook.

@✓

مدقّق البريد الإلكتروني

افحص عناوين بريد كثيرة دفعة واحدة بحثاً عن أخطاء الصياغة وأخطاء النطاقات الشائعة مثل gmial.com، مع اقتراحات.

◣

منشئ مسار قصّ CSS

أنشئ CSS مسار قصّ - إعدادات مضلّعة مسبقة بنقاط قابلة للتعديل، زائد أشكال الدائرة والقطع الناقص والإطار الداخلي.

▓

منشئ ظل صندوق CSS

ابنِ CSS ظل صندوق متعدد الطبقات مع دعم الظل الداخلي، وتحكّم في اللون والعتامة، ومعاينة حية.

XML✓

منسّق ومدقّق XML

تجميل وتصغير والتحقق من XML - فحوص سلامة تشكّل الوسوم المتوازنة مع رسائل خطأ واضحة.

MD→

محوّل Markdown إلى HTML

حوّل Markdown اليومي إلى HTML نظيف مع معاينة حية معروضة - العناوين، القوائم، الكود والمزيد.

⇄

تبديل صفوف وأعمدة CSV

بدّل صفوف CSV وأعمدته بمحلّل صحيح - التبديل مرتين يعيد الأصلي.

JOIN

ربط CSV

ادمج ملفي CSV على عمود مفتاح - ربط داخلي أو أيسر، مفاتيح مكرّرة معالجة بطريقة قواعد البيانات.

PIVOT

جدول محوري / تجميع CSV

جمّع صفوف CSV حسب عمود مع المجموع أو العدد أو المتوسط أو الأدنى أو الأقصى لعمود قيم.

DIFF

مقارنة CSV

قارن ملفي CSV بعمود مفتاح - صفوف مضافة ومزالة ومتغيّرة مع الخلايا الدقيقة.

@

مستخرج بيانات CSV

اسحب رسائل البريد الإلكتروني وأرقام الهواتف والروابط من CSV أو نص فوضوي إلى قوائم نظيفة وخالية من التكرار.

PROF

محلّل ملف CSV

تخمينات نوع لكل عمود، أعداد الفارغة، أعداد الفريدة، أدنى/أقصى رقمي وقيم عليا.

✓

مختبِر Robots.txt

اختبر رابطاً ووكيل مستخدم مقابل قواعد robots.txt - الحكم بالإضافة إلى قاعدة المطابقة الدقيقة.

Aa

فاحص قابلية قراءة SEO

ست صيغ قابلية قراءة بالإضافة إلى إحصاءات الجمل لنسخ الويب، مؤطّرة لعمل محتوى SEO.

LLM

منشئ llms.txt

ابنِ ملف llms.txt المواجه للذكاء الاصطناعي - اقتباس ملخّص زائد روابط صفحات منتقاة بصيغة المواصفة.

🌐

منشئ وسوم Hreflang

ابنِ مجموعات روابط بديلة hreflang مع x-default وفحوص BCP 47 / الروابط المطلقة.

DOC

عارض بيانات مستند Office الوصفية

اقرأ خصائص DOCX وXLSX وPPTX - العنوان، المؤلف، الشركة، التواريخ - للعرض فقط، على الجهاز.

🔍

اكتشف النوع الحقيقي لملف من بايتاته السحرية وحذّر عندما يختلف الامتداد.

  1. افتح أي أداة والصق أو اكتب أو حمّل بياناتك - لا شيء لتثبيته ولا شيء للتسجيل فيه.
