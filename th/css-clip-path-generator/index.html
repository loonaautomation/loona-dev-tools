ตัวสร้าง CSS Clip-Path - จัดรูปทรงองค์ประกอบของคุณแบบเห็นภาพ

สรุปสั้น ๆ: ตัวสร้าง Clip-Path CSS ให้ CSS clip-path ที่พร้อมสำหรับรูปหลายเหลี่ยม (สามเหลี่ยมถึงดาว) วงกลม วงรี และแบบฝัง - เลือกรูปทรง ขยับจุดของมัน ดูตัวอย่างแบบสด และคัดลอกโค้ด โปรดทราบ: เครื่องมือรูปภาพในเครือเดียวกันของไซต์นี้ครอบคลุมการไล่ระดับสีแล้ว; clip-path อยู่ที่นี่เพราะมันคือ CSS เลย์เอาต์ ไม่ใช่การแก้ไขรูปภาพ

Clip-path เปลี่ยนสี่เหลี่ยมให้เป็นงานออกแบบ: ส่วนที่เอียง ป้าย ลูกศร และดาว ด้วยคุณสมบัติ CSS เพียงตัวเดียว ส่วนที่ยากคือพิกัด - เครื่องมือนี้จัดการมันให้

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวสร้าง CSS Clip-Path

  1. เลือกค่าที่ตั้งไว้ล่วงหน้าของรูปทรง
  2. สำหรับรูปหลายเหลี่ยม ให้ปรับเปอร์เซ็นต์ x,y ของจุดใดก็ได้
  3. ดูตัวอย่างอัปเดตแบบสด
  4. คัดลอก CSS - รวมคุณสมบัติทั้งมาตรฐานและ -webkit- ไว้ด้วย

วิธีการทำงาน

จุดของรูปหลายเหลี่ยมเป็นเปอร์เซ็นต์ของกล่ององค์ประกอบ ดังนั้นรูปทรงจึงปรับขนาดตามองค์ประกอบ ค่าที่ตั้งไว้ล่วงหน้าเข้ารหัสชุดพิกัดที่เป็นที่รู้จักดี (รูปห้าเหลี่ยมปกติ รูปหกเหลี่ยม ดาวสิบแฉก และอื่น ๆ) และตัวสร้างจะแสดงออกมาทั้งสองอย่าง clip-path and the -webkit- คู่แฝดที่มีคำนำหน้าซึ่ง Safari เคยต้องการในอดีต วงกลม วงรี และแบบฝังครอบคลุมรูปทรงที่ไม่ใช่รูปหลายเหลี่ยมที่คุณสมบัติรองรับ รวมถึงแบบฝังที่โค้งมน

คำถามที่พบบ่อย

ตัวสร้างนี้ฟรีหรือไม่?

ใช่ - ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก

ทำไมจึงมีตัวสร้างการไล่ระดับสีบนไซต์รูปภาพด้วย?

การไล่ระดับสีที่นั่นถือเป็นสินทรัพย์รูปภาพ/การออกแบบ Clip-path คือ CSS เลย์เอาต์สำหรับนักพัฒนา ดังนั้นมันจึงอยู่ที่นี่ - แต่ละเครื่องมือมีอยู่บนไซต์ Loona เพียงแห่งเดียวพอดี

clip-path ส่งผลต่อการคลิกหรือไม่?

ใช่ - พื้นที่ที่ถูกตัดออกไม่สามารถคลิกได้ ซึ่งโดยปกติคือสิ่งที่คุณต้องการสำหรับปุ่มและบัตรที่มีรูปทรง

เบราว์เซอร์รองรับหรือไม่?

เบราว์เซอร์สมัยใหม่ทุกตัวรองรับ clip-path; คำนำหน้า -webkit- ในผลลัพธ์ครอบคลุม Safari รุ่นเก่า

มีอะไรถูกอัปโหลดหรือไม่?

ไม่ ทุกอย่างทำงานในเบราว์เซอร์ของคุณ
