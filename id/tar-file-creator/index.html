Pembuat File TAR - Buat Arsip .tar dari File Anda

Singkatnya: Pembuat File TAR menggabungkan set file apa pun menjadi satu arsip .tar standar menggunakan penulis ustar yang benar menurut spesifikasi di browser Anda - tambah file, secara opsional kelompokkan dalam folder, dan unduh.

TAR masih merupakan lingua franca Linux, server, dan cadangan - tetapi pengguna Windows yang perlu menghasilkan tarball biasanya harus memasang sesuatu terlebih dahulu. Halaman ini menulis arsip TAR asli di browser Anda: header ustar yang tepat, checksum, dan timestamp, dibangun di perangkat Anda tanpa ada yang diunggah.

Jatuhkan file di sini atau klik untuk memilih file dari perangkat Anda
Nama fileUkuran

Ingat: TAR tidak mengompres. File .tar akan berukuran sekitar semua file yang ditambahkan bersama (dibulatkan ke blok 512-byte). Perlu lebih kecil? Jalankan hasilnya melalui Kompresor GZIP setelahnya, atau gunakan Pembuat File ZIP sebagai gantinya.

Privat berdasarkan desain: segala sesuatu dalam alat ini terjadi 100% di browser Anda dengan JavaScript. File Anda tidak pernah diunggah ke server, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang. Satu batas jujur: konversi terjadi dalam memori perangkat Anda, jadi arsip yang sangat besar (ratusan megabita) dapat lambat atau gagal di ponsel memori rendah.

Cara menggunakan Pembuat File TAR

  1. Jatuhkan file Anda ke kotak di atas, atau klik dan pilih file dari perangkat Anda. Anda dapat menambahkan file dalam beberapa putaran.
  2. Periksa daftar - hapus apa pun yang ditambahkan karena kesalahan, dan perhatikan ukuran totalnya.
  3. Secara opsional ketik nama folder agar setiap file berada di dalam satu folder dalam arsip, dan beri TAR sebuah nama.
  4. Klik Buat TAR & Unduh. File .tar terbuka dengan tar di Linux/macOS, dan dengan 7-Zip atau WinRAR di Windows.

Cara kerja

Arsip TAR adalah aliran record: untuk setiap file, satu blok header ustar 512-byte (nama file, ukuran dalam oktal, waktu modifikasi, checksum dari header itu sendiri, magic 'ustar', dan field prefix yang memungkinkan jalur lebih panjang dari 100 karakter - dengan entri longname GNU untuk jalur yang bahkan melebihi itu), diikuti isi file yang di-padding ke kelipatan utuh blok 512-byte. Dua blok nol menutup arsip. Halaman ini mengimplementasikan format itu secara langsung - tanpa pustaka, tanpa server - dan penulisnya diverifikasi dengan meminta modul tarfile Python membaca kembali outputnya byte-per-byte. TAR menyimpan file tanpa kompresi, jadi arsip adalah jumlah dari bagian-bagiannya; kompresi adalah langkah terpisah (itulah yang ditambahkan .tar.gz).

Contoh yang dikerjakan

Anda menambahkan tiga file: deploy.sh (1 KB), config.yml (3 KB), dan logo.png (48 KB), dengan nama folder diatur ke 'release'. Alat menghasilkan release.tar - atau nama pilihan Anda - memegang folder release dengan ketiga file, masing-masing mempertahankan waktu modifikasi sebenarnya. Pada 52 KB konten TAR keluar sekitar 54 KB: file itu sendiri, tiga header dan padding, tanpa kompresi - persis yang akan dihasilkan tar di Linux.

Pertanyaan yang Sering Diajukan

Apakah pembuat file TAR ini gratis?

Ya - gratis, tanpa pendaftaran, tanpa batas, dan tanpa watermark.

Apakah file saya diunggah ke server?

Tidak. TAR ditulis oleh JavaScript yang berjalan di browser Anda, di perangkat Anda. File Anda tidak pernah meninggalkannya.

Mengapa TAR sama ukurannya dengan file saya - atau sedikit lebih besar?

TAR tidak mengompres apa pun; ia hanya menggabungkan. Setiap file juga menambahkan header 512-byte dan di-padding ke batas 512-byte, jadi arsip sedikit lebih besar dari total mentah. Untuk tarball terkompresi, buat TAR di sini lalu jalankan melalui Kompresor GZIP - itulah secara harfiah cara .tar.gz dibuat.

Apakah Linux dan GNU tar akan menerima arsip yang dibuat di sini?

Ya. Penulis mengikuti spesifikasi ustar - field oktal dan checksum header yang benar, sihir ustar, pemisahan awalan untuk path panjang, dan entri longname GNU untuk yang sangat panjang - dan outputnya diverifikasi dengan membacanya kembali dengan modul tarfile Python selama pengujian.

Dapatkah saya menambahkan file ke TAR yang ada atau membuat .tar.gz secara langsung?

Tidak di alat ini - ia membuat arsip baru setiap kali. Untuk mengubah ZIP yang ada menjadi .tar.gz dalam satu langkah, gunakan Konverter ZIP ke TAR.GZ; untuk mengompres TAR ini menjadi .tar.gz, gunakan Kompresor GZIP setelahnya dan ganti nama hasilnya menjadi .tar.gz.
