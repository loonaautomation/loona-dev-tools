UTM Link बिल्डर — Campaign URLs जो Analytics पढ़ सके

संक्षेप में: UTM Link बिल्डर किसी URL पर utm_source, utm_medium, utm_campaign और वैकल्पिक term/content parameters correct percent-encoding के साथ append करता है, URL पर पहले से मौजूद query parameters सुरक्षित रखता है, और आपके browser में छोटी history रखता है।

Untagged campaign links analytics में सभी 'direct' के रूप में दिखते हैं। उन्हें यहाँ ठीक से tag करें — encoding handled, existing parameters रखे गए, और आपके recent links locally saved।

Saved history (सिर्फ़ यह browser)

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

UTM लिंक बिल्डर का उपयोग कैसे करें

  1. अपने landing page का base URL paste करें।
  2. Source (कहाँ से), medium (किस तरह का link) और campaign (कौन सी push) भरें — तीन standard fields।
  3. Term या content तभी जोड़ें जब आपको एक ही campaign के दो links में फ़र्क़ बताना हो।
  4. Build पर click करें, tagged URL copy करें, और इसे अपने post, ad या email में उपयोग करें।

यह कैसे काम करता है

Builder browser के standard URL parser का उपयोग करता है, इसलिए encoding ठीक सही है: spaces %20 बन जाते हैं (या query values में + URLSearchParams rules के अनुसार), value के अंदर ampersands कभी fake parameters में नहीं बँट सकते, और base URL पर पहले से मौजूद कोई query string — जैसे ?ref=nav — सुरक्षित रहता है, और उसी key के मौजूदा utm_ values duplicate होने के बजाय बदल दिए जाते हैं। #fragment बिल्कुल अंत में रहता है, parameters के बाद, जैसा URL के लिए ज़रूरी है। History सिर्फ़ आपके ब्राउज़र के localStorage में रखी जाती है (आख़िरी 20 links), कभी कहीं भेजी नहीं जाती।

Naming tip

एक convention चुनें और इसे कभी न बदलें: lowercase, spaces के बजाय hyphens, और हर बार वही source names (facebook, FB या Facebook नहीं) — analytics हर spelling को अलग source मानता है।

अक्सर पूछे जाने वाले सवाल

क्या यह builder मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, कोई साइन-अप नहीं।

कौन से UTM fields आवश्यक हैं?

Convention के अनुसार: source, medium और campaign। Term (paid keywords) और content (दो creatives में फ़र्क़) वैकल्पिक हैं।

मेरे URL पर पहले से मौजूद parameters का क्या होता है?

वे सुरक्षित रहते हैं। अगर URL में पहले से utm_source है, तो नई value parameter को duplicate करने के बजाय इसे replace करती है।

History कहाँ stored है?

सिर्फ़ आपके अपने ब्राउज़र में (localStorage), 20 links तक। इसे साफ़ करना या browsers बदलना इसे हटा देता है।

क्या मुझे internal links पर UTM tags उपयोग करने चाहिए?

नहीं — अपनी site के अंदर links को tag करना analytics में मूल session source को overwrite कर देता है। UTMs बाहर से आने वाले inbound links के लिए हैं।
