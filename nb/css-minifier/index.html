CSS-minimerer og -forskjønner - Komprimer CSS eller gjør den lesbar

Kort sagt: CSS-minimereren fjerner kommentarer og unødvendig mellomrom for å krympe stilarket ditt og rapporterer den nøyaktige størrelsesbesparelsen, mens Forskjønningsmodus gjør minimert CSS tilbake til ren, innrykket kode.

Hver kilobyte CSS forsinker sidens første gjengivelse. Lim inn et stilark nedenfor for å komprimere det for produksjon, eller kjør en minimert fil gjennom Forskjønn når du trenger å lese og redigere den igjen.

Slik bruker du CSS-minimereren

  1. Lim inn eller skriv CSS-en din i den øverste boksen.
  2. Klikk Minimer CSS for å komprimere den, eller Forskjønn CSS for å formatere den med innrykk.
  3. Sjekk størrelsespanelet - det viser original størrelse, resultatstørrelse og prosent spart.
  4. Kopier resultatet eller last det ned som en .css-fil.

Slik fungerer det

Minimereren vandrer først CSS-en din tegn for tegn og fjerner kommentarer - mens den lar anførede strenger stå helt urørt, slik at en content verdi som tilfeldigvis inneholder kommentarliknende tekst overlever intakt. Den slår deretter sammen mellomromskjøringer og fjerner mellomrom rundt klammer, semikolon, kommaer og kombinatorer, pluss mellomrommet etter kolon. Den rører bevisst aldri innsiden av calc() uttrykk eller strengverdier, der mellomrom bærer betydning. Forskjønningsmodus reverserer prosessen: den åpner den komprimerte CSS-en på nytt til én deklarasjon per linje med to-mellomroms innrykk per nestenivå.

Gjennomarbeidet eksempel

En typisk håndskrevet stilarkregel med kommentarer og generøs avstand - si en topptekstblokk på 240 bytes - minimeres vanligvis til rundt 150 bytes, en besparelse på omtrent 35-40 %. Over et helt nettsted summerer det seg til en merkbart raskere første gjengivelse, særlig på mobile forbindelser.

Ofte stilte spørsmål

Er denne CSS-minimereren gratis?

Ja - helt gratis, uten registrering, uten størrelsesgrense og uten daglig grense.

Er minimert CSS trygg å distribuere?

Minimereren fjerner bare kommentarer og mellomrom CSS ikke trenger. Selektorer, egenskaper og verdier er uendrede, og strengverdier og calc()-uttrykk endres aldri. Som med enhver minimerer, test siden én gang etter distribusjon.

Hvorfor beholder den et mellomrom før et kolon i selektorer?

Et mellomrom før et kolon kan ha betydning i CSS - ".a :hover" velger svevende etterkommere, mens ".a:hover" velger selve elementet. For å være trygg fjerner verktøyet mellomrommet etter kolon, men gjetter aldri med mellomrommet før ett.

Kan den forskjønne CSS også?

Ja. Forskjønningsmodus tar komprimert CSS og utvider den til én deklarasjon per linje med konsistent innrykk, som er ideelt når du arver en minimert fil og trenger å redigere den.

Lastes CSS-en min opp til en server?

Nei. Minimering og forskjønning skjer 100 % i nettleseren din. Stilarkene dine forlater aldri enheten din.
