JavaScriptミニファイア - コードを尊重する保守的な圧縮

要するに： JavaScriptミニファイアは、実際のトークナイザーを使ってコメントと不要な空白を除去します。そのため、文字列の内容、テンプレートリテラル、正規表現が損傷することは決してなく、意味を持つ改行（return の後のようなもの）は常に保持されます。

JavaScriptをプレーンテキストとして扱う素朴なミニファイアは、文字列に「//」が含まれたり、正規表現に引用符が含まれたりした瞬間にコードを壊します。このツールはまずコードをトークンに字句解析し、その後に何を安全に除去できるかを判断します。

JavaScriptミニファイアの使い方

  1. JavaScriptを上のボックスに貼り付けるか入力してください。
  2. 「JavaScriptをミニファイ」をクリックしてください。
  3. サイズパネルを確認して、どれだけ節約されたかを見てください。
  4. 結果をコピーするか、.js ファイルとしてダウンロードしてください — そして、どのミニファイアでもそうであるように、コードを一度実行して、同じように動作することを確認してください。

仕組み

このツールはまずコードをトークンに分割します：識別子、数値、文字列、テンプレートリテラル、正規表現、句読点です。コメントはこのスキャン中に認識されて落とされ、スキャナーは除算記号と正規表現の開始の違いを知っており、文字列の中にコメントマーカーを探すことは決してありません。トークンはその後再結合され、除去すると意味が変わる場所にのみ区切りスペースが追加されます。二つの単語の間、プラスと別のプラスの間などです。改行は、JavaScriptの自動セミコロン挿入が意味を持たせる場所では保持されます。最も重要なのは次の後です return, ブレーク と 続行、そして先頭の ++ or --.

実例

コメント付きの約400バイトのユーティリティ関数は、通常、約260バイトまで圧縮されます。およそ三分の一小さくなります。一方、次のような文字列は "see https://example.com // docs" その内部は完全に無傷で通過します。

よくある質問

このJavaScriptミニファイアは無料ですか？

はい - 完全に無料、登録不要で、サイズ制限も毎日の上限もありません。

完全なビルドツール型ミニファイアとはどう違いますか？

Terserのようなビルドツールは、変数名を変更したりコードを書き換えたりもするため、さらに数パーセントを絞り出します。このツールは意図的に保守的です。何の名前も変更せず、式も書き換えません。そのため、出力は目で確認しやすく、素早い一回限りの使用にも安全です。

私のコードを壊すことがありますか？

そうならないよう設計されています。文字列、テンプレートリテラル、正規表現リテラルは保護され、意味を持つ改行は保持されます。どのミニファイアも、あらゆる特殊なパターンでの完璧さを約束できません。そのため、ミニファイ後は必ずテストスイートを実行するか、ページを一度開いてください。このアドバイスは、私たちのものを含むすべてのミニファイアに当てはまります。

正規表現とテンプレートリテラルを扱えますか？

はい。トークナイザーは正規表現リテラル（文字クラスとエスケープを含む）とテンプレートリテラル（ネストした ${ } 式を含む）を認識し、変更せずに運びます。

私のコードはサーバーにアップロードされますか？

いいえ。トークン化とミニファイはブラウザで100%行われます。ソースコードがデバイスから出ることは決してありません。
