หน้าแรก › เครื่องมือสำหรับนักพัฒนา › ตัวสร้างสคีมา JSON-LD

ตัวสร้างสคีมา JSON-LD - ข้อมูลที่มีโครงสร้างโดยไม่ต้องเขียน JSON ด้วยมือ

สรุปสั้น ๆ: ตัวสร้างสคีมา JSON-LD สร้างข้อมูลที่มีโครงสร้าง schema.org ที่ถูกต้องสำหรับ 16 ประเภท - บทความ ธุรกิจท้องถิ่น ผลิตภัณฑ์ กิจกรรม สูตรอาหาร ผู้คน องค์กร เว็บไซต์ หน้า FAQ วิธีทำ วิดีโอ หนังสือ คอร์ส ประกาศงาน แอปซอฟต์แวร์ และรายการ Breadcrumb และห่อมันในบล็อกสคริปต์ที่ Google คาดหวังอย่างแม่นยำ

ข้อมูลที่มีโครงสร้างช่วยให้เครื่องมือค้นหาเข้าใจหน้าและสามารถปลดล็อกผลลัพธ์ที่สมบูรณ์ได้ ตัวสร้างนี้สร้าง JSON ให้คุณ - และตรวจสอบความถูกต้องของมันในฐานะ JSON ก่อนที่คุณจะคัดลอกมัน

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวสร้างสคีมา JSON-LD

  1. เลือกประเภทสคีมาที่ตรงกับหน้าของคุณ
  2. กรอกฟิลด์ที่เกี่ยวข้อง - ฟิลด์ที่ว่างจะถูกเว้นไว้เฉย ๆ
  3. คลิกสร้างและตรวจสอบบล็อก JSON-LD
  4. วางมันลงใน head ของหน้าของคุณหรือก่อนแท็กปิด body จากนั้นทดสอบหน้าแบบสดด้วย Rich Results Test ของ Google

วิธีการทำงาน

ตัวสร้างประกอบออบเจ็กต์ JavaScript ในคำศัพท์ schema.org - @context, @type และคุณสมบัติสำหรับประเภทที่เลือก รวมถึงออบเจ็กต์ที่ซ้อนอย่าง Offer และ AggregateRating ของ Product, Person ผู้แต่งของ Article หรือ PostalAddress ของ LocalBusiness - จากนั้นจัดลำดับมันด้วยการจัดรูปแบบ JSON ที่เข้มงวดและแยกวิเคราะห์ผลลัพธ์ของมันเองอีกครั้งเพื่อพิสูจน์ว่ามันเป็น JSON ที่ถูกต้องก่อนแสดง ฟิลด์ว่างถูกละเว้นทั้งหมด เพราะคุณสมบัติที่ว่างเปล่าแย่กว่าคุณสมบัติที่ขาดหายไป ขอบเขตที่ซื่อตรง: JSON-LD ที่ถูกต้องทำให้หน้า มีสิทธิ์ สำหรับผลลัพธ์ที่สมบูรณ์; Google ตัดสินใจว่าจะแสดงพวกมันหรือไม่ และข้อมูลต้องตรงกับสิ่งที่มองเห็นได้บนหน้า

คำถามที่พบบ่อย

ตัวสร้างนี้ฟรีหรือไม่?

ใช่ - ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก

สิ่งนี้จะรับประกันผลลัพธ์ที่สมบูรณ์หรือไม่?

ไม่มีเครื่องมือใดรับประกันสิ่งนั้นได้ JSON-LD ที่ถูกต้องทำให้คุณมีสิทธิ์; Google เลือกตามหน้า คิวรี และนโยบายของมัน

ฉันวางบล็อกที่ไหน?

ในส่วน head ของหน้า หรือก่อนแท็กปิด body - Google อ่านมันได้ทั้งสองตำแหน่ง

ข้อมูลต้องตรงกับหน้าของฉันหรือไม่?

ใช่ ข้อมูลที่มีโครงสร้างซึ่งอธิบายสิ่งที่มองไม่เห็นบนหน้าสามารถถูกละเว้นหรือถือว่าเป็นสแปมได้

มีอะไรถูกอัปโหลดหรือไม่?

ไม่ การสร้างและการตรวจสอบความถูกต้องทำงานในเบราว์เซอร์ของคุณ
