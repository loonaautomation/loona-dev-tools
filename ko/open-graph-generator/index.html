Open Graph & Twitter Card 생성기 - 제대로 보이는 소셜 공유

요약하면: Open Graph & Twitter Card 생성기는 Facebook, LinkedIn, X, 채팅 앱에서 공유될 때 페이지가 어떻게 보이는지 제어하는 og:와 twitter: 메타 태그를 만들어요, 실시간 카드 미리보기와 함께예요.

이미지 없고 제목이 무작위인 공유 링크는 무시당해요. 필드를 채우고, 미리보기를 확인하고, 모든 공유가 의도적으로 보이게 하는 태그를 붙여넣으세요.

Open Graph & Twitter Card 생성기 사용법

  1. 소셜 플랫폼에 표시되길 원하는 제목과 설명을 입력하세요.
  2. 페이지 URL과 이미지 URL을 추가하세요 - 1200×630 픽셀이 표준 소셜 크기예요.
  3. og:type과 Twitter 카드 스타일을 선택하세요.
  4. 카드 미리보기를 확인한 뒤 블록을 페이지 <head>에 복사하세요.

작동 방식

Open Graph 태그(og:title, og:description, og:image, og:url, og:type)는 Facebook, LinkedIn, WhatsApp과 대부분의 채팅 앱이 읽어요; Twitter Card 태그는 X에 자체 필드를 주고, twitter: 태그가 없으면 OG 값으로 대체해요 - 그래서 이 생성기가 제목, 설명, 이미지를 반영하며 둘 다 내보내요. 모든 값은 속성 이스케이프돼요. 미리보기는 큰 이미지 카드 레이아웃을 근사해요; 정확한 자르기는 플랫폼마다 달라요. 그래서 1200×630(1.91:1) 이미지 크기가 권장돼요 - 모든 주요 플랫폼이 측면을 자르지 않고 받아들이는 비율이에요.

자주 묻는 질문

이 생성기는 무료인가요?

네 - 완전히 무료, 회원가입 없음이에요.

어떤 이미지 크기를 사용해야 하나요?

1200×630 픽셀 (1.91:1). Facebook, LinkedIn, X에서 어색하게 잘리지 않고 올바르게 표시돼요.

OG와 Twitter 태그가 왜 둘 다인가요?

X는 twitter: 태그를 먼저 읽고 OG 태그로 대체해요. 둘 다 내보내면 의도한 제목, 설명, 이미지가 모든 곳에서 보장돼요.

제 공유 미리보기가 오래됐어요 - 왜인가요?

플랫폼은 미리보기를 캐시해요. 태그를 업데이트한 뒤 Facebook의 공유 디버거 또는 X의 카드 검사기를 사용해 다시 스크랩하도록 강제하세요.

무엇이든 업로드되나요?

아니요. 태그는 브라우저에서 생성돼요; 미리보기 이미지는 입력한 URL에서 직접 로드돼요.
