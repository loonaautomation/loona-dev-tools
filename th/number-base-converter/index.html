ตัวแปลงเลขฐาน - เลขฐานสอง เลขฐานแปด เลขฐานสิบ และเลขฐานสิบหก อย่างแม่นยำ

สรุปสั้น ๆ: ตัวแปลงเลขฐานแปลงจำนวนเต็มระหว่างเลขฐานสอง เลขฐานแปด เลขฐานสิบ และเลขฐานสิบหกโดยใช้การคำนวณความแม่นยำไม่จำกัด ดังนั้นค่าที่ไกลเกินกว่าขีดจำกัด JavaScript ปกติ 2^53 จึงแปลงอย่างแม่นยำ ทีละหลัก - และหลักที่ไม่ถูกต้องถูกเรียกออกมาตามชื่อ

สิทธิ์ไฟล์ รหัสสี ที่อยู่หน่วยความจำ แฟล็กแบบบิต - เลขฐานอยู่ทุกที่ในการพัฒนา พิมพ์ค่าด้วยฐานใดก็ได้แล้วอ่านมันในทั้งสี่ฐาน ด้วยความแม่นยำที่ไม่ปัดตัวเลขจำนวนมากของคุณทิ้งอย่างเงียบ ๆ

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript อินพุตของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป

วิธีใช้ ตัวแปลงเลขฐาน

  1. พิมพ์หรือวางตัวเลขลงในกล่องค่า
  2. เลือกว่ากำลังเขียนค่าด้วยฐานใด
  3. อ่านค่าเดียวกันในเลขฐานสอง เลขฐานแปด เลขฐานสิบ และเลขฐานสิบหก - ผลลัพธ์อัปเดตขณะที่คุณพิมพ์
  4. ใช้ปุ่มคัดลอกเพื่อนำรูปแบบใด ๆ ไปกับคุณ

วิธีการทำงาน

ตัวแปลงก่อนอื่นตรวจสอบความถูกต้องของตัวอักษรทุกตัวเทียบกับตัวเลขที่อนุญาตในฐานที่คุณเลือก - ป้อน 2 ในค่าเลขฐานสองแล้วมันจะบอกคุณอย่างนั้นพอดี แทนที่จะเดา จากนั้นมันสร้างค่าด้วยการคำนวณจำนวนเต็มความแม่นยำไม่จำกัด (BigInt): แต่ละหลักคูณยอดรวมที่กำลังดำเนินด้วยฐานและบวกตัวมันเอง กระบวนการที่คงความแม่นยำสำหรับตัวเลขทุกความยาว ในที่สุดมันเรนเดอร์ค่าที่แม่นยำนั้นในแต่ละฐานทั้งสี่ ค่าลบรักษาเครื่องหมายของพวกมันไว้ในทุกขั้นตอน

ตัวอย่างที่ทำแล้ว

ค่าทศนิยม 18446744073709551617 - มากกว่าหนึ่งของ 2^64 - ใหญ่กว่าตัวเลข JavaScript ปกติใด ๆ ที่จะถือได้อย่างแม่นยำ ที่นี่มันยังคงแปลงอย่างแม่นยำ: เลขฐานสิบหก 10000000000000001 และสตริงเลขฐานสอง 65 หลักที่ลงท้ายด้วย 1 ในที่ที่ตัวแปลงจุดลอยตัวจะปัดเศษมันอย่างเงียบ ๆ

คำถามที่พบบ่อย

ตัวแปลงเลขฐานนี้ฟรีหรือไม่?

ใช่ - ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดขนาดและไม่มีขีดจำกัดรายวัน

มันแปลงตัวเลขได้ใหญ่แค่ไหน?

ไม่จำกัดในทางปฏิบัติ การแปลงใช้การคำนวณ BigInt ดังนั้นค่าที่มีตัวเลขนับร้อยหลักจึงแปลงได้อย่างแม่นยำ ขีดจำกัด 2^53 ที่คุ้นเคยของตัวเลข JavaScript ธรรมดาไม่มีผล

มันจัดการเศษส่วนอย่าง 3.14 ได้หรือไม่?

ไม่ - ตัวแปลงนี้มีไว้สำหรับจำนวนเต็ม ซึ่งเป็นสิ่งที่เลขฐานถูกใช้ในทางปฏิบัติ (ที่อยู่ สิทธิ์ สี แฟล็ก) จุดทศนิยมในอินพุตจะถูกรายงานว่าเป็นหลักที่ไม่ถูกต้องแทนที่จะถูกทิ้งอย่างเงียบ ๆ

จะเกิดอะไรขึ้นหากฉันพิมพ์ตัวเลขที่ไม่มีอยู่ในฐาน?

คุณได้รับข้อผิดพลาดเฉพาะที่ระบุชื่อหลักและฐาน - ตัวอย่างเช่น หลัก "8" ไม่สามารถปรากฏในค่าเลขฐานแปดได้ และ "g" ไม่สามารถปรากฏในเลขฐานสิบหกได้

อินพุตของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ การแปลงเกิดขึ้น 100% ในเบราว์เซอร์ของคุณ ค่าของคุณไม่เคยออกจากอุปกรณ์ของคุณ
