ตัวแปลง ZIP เป็น TAR.GZ - เปลี่ยน .zip ให้เป็น tarball .tar.gz

สรุปสั้น ๆ: ตัวแปลง ZIP เป็น TAR.GZ แพ็กไฟล์บีบอัด ZIP ใหม่เป็น tarball ustar ที่เหมาะสมและบีบอัดมันด้วย gzip บนอุปกรณ์ของคุณเอง - สร้างรูปแบบ .tar.gz ที่โลก Linux ใช้งาน

กำลังปรับใช้ไปยังเซิร์ฟเวอร์ Linux ป้อนให้กับ Docker build หรือส่งไฟล์ให้เครื่องมือที่คาดหวัง tarball? ZIP คือตัวแปลกในโลกนั้น - .tar.gz คือภาษาแม่ ตัวแปลงนี้อ่าน ZIP ของคุณในเบราว์เซอร์ เขียนไฟล์บีบอัด TAR ที่ถูกต้องตามข้อกำหนด และ gzip มัน ทั้งหมดโดยไม่ต้องอัปโหลดอะไรเลย

วางไฟล์ .zip ของคุณที่นี่ หรือคลิกเพื่อเลือกมันจากอุปกรณ์ของคุณ
ไฟล์ภายใน-
ขนาดต้นฉบับ-
ขนาดใหม่-
เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ไฟล์ของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป ขีดจำกัดที่ซื่อตรงหนึ่งข้อ: การแปลงเกิดขึ้นในหน่วยความจำของอุปกรณ์ของคุณ ดังนั้นไฟล์บีบอัดที่ใหญ่มาก (หลายร้อยเมกะไบต์) อาจช้าหรือล้มเหลวบนโทรศัพท์ที่มีหน่วยความจำน้อย

วิธีใช้ ตัวแปลง ZIP เป็น TAR.GZ

  1. วางไฟล์ .zip ของคุณลงบนกล่องด้านบน หรือคลิกมันแล้วเลือกไฟล์จากอุปกรณ์ของคุณ
  2. คลิกแปลงเป็น TAR.GZ ไฟล์ ZIP จะถูกอ่านบนอุปกรณ์ของคุณ ไฟล์บีบอัด TAR จะถูกเขียนด้วยเส้นทางเดียวกัน และ gzip จะบีบอัดมัน
  3. ตรวจสอบบทสรุป: จำนวนไฟล์ที่แปลงและขนาดของ tarball ใหม่
  4. คลิกดาวน์โหลดเพื่อบันทึกไฟล์ .tar.gz - tar -xzf เปิดมันได้บนทุกระบบ Linux หรือ macOS

วิธีการทำงาน

หน้านี้อ่าน ZIP ด้วย JSZip จากนั้นเขียนเนื้อหาออกมาเป็นไฟล์บีบอัด TAR โดยใช้ตัวเขียน ustar ที่ถูกต้องตามข้อกำหนดซึ่งสร้างไว้ในหน้า: ทุกไฟล์ได้รับบล็อกส่วนหัว 512 ไบต์ (ชื่อ ขนาด โหมด เช็กซัม และฟิลด์คำนำหน้าสำหรับเส้นทางยาว - พร้อมรายการ GNU longname สำหรับเส้นทางที่ยาวเกินกว่านั้นด้วย) เนื้อหาของมันถูกเติมให้ถึงขอบเขต 512 ไบต์ และบล็อกศูนย์สองบล็อกเพื่อปิดไฟล์บีบอัด TAR ที่เสร็จแล้วถูกบีบอัดด้วยกลไก gzip ในตัวของเบราว์เซอร์ของคุณ (Compression Streams API) ผลลัพธ์ได้รับการยืนยันเทียบกับโมดูล tarfile ของ Python และข้อตกลง GNU tar ระหว่างการทดสอบ - มันคือ tarball จริง ไม่ใช่ ZIP ที่เปลี่ยนชื่อ

ตัวอย่างที่ทำแล้ว

คุณมี site-assets.zip (12 MB, 240 files) ที่จะอัปโหลดไปยัง Linux VPS ที่สคริปต์ปรับใช้ของมันรัน tar -xzf แปลงที่นี่ คุณจะได้รับ site-assets.tar.gz (11.6 MB) พร้อมไฟล์ 240 ไฟล์เดียวกันที่เส้นทางเดียวกันและการประทับเวลา ZIP ของพวกมันถูกเก็บไว้ เซิร์ฟเวอร์แยกมันอย่างแม่นยำราวกับว่า tarball ถูกสร้างบน Linux

คำถามที่พบบ่อย

ตัวแปลง ZIP เป็น TAR.GZ นี้ฟรีหรือไม่?

ใช่ - ฟรี ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดและไม่มีลายน้ำ

ไฟล์ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ JSZip อ่าน ZIP, TAR ถูกเขียนโดยโค้ดในหน้านี้ และ gzip ทำโดยกลไกในตัวของเบราว์เซอร์ของคุณ ทุกอย่างอยู่บนอุปกรณ์ของคุณ

GNU tar และเครื่องมือ Linux จะยอมรับผลลัพธ์หรือไม่?

ใช่ ตัวเขียน TAR ทำตามข้อกำหนด ustar - เช็กซัมส่วนหัวที่ถูกต้อง ฟิลด์ขนาดเลขฐานแปด การแยกคำนำหน้า ustar สำหรับเส้นทางยาว และรายการ GNU longname เมื่อเส้นทางเกินกว่านั้นด้วย - และผลลัพธ์ได้รับการยืนยันจากการทดสอบโดยการอ่านมันกลับด้วยโมดูล tarfile ของ Python

การประทับเวลาและสิทธิ์ของไฟล์ถูกเก็บไว้หรือไม่?

การประทับเวลาที่จัดเก็บใน ZIP ถูกพาเข้าไปในส่วนหัว TAR สิทธิ์ถูกเขียนเป็นค่าเริ่มต้นมาตรฐาน (ไฟล์ 0644 โฟลเดอร์ 0755) เพราะ ZIP จัดเก็บสิทธิ์ Unix ไม่เชื่อถือได้ - หากคุณต้องการโหมดที่แม่นยำ ให้ตั้งค่าพวกมันหลังการแยกไฟล์ด้วย chmod

ทำไมไม่แปลงเป็น .tar ธรรมดาแทน?

TAR ธรรมดาไม่ได้รับการบีบอัด ดังนั้นมันจะมีขนาดประมาณผลรวมของไฟล์ทั้งหมดที่รวมกัน .tar.gz คือสิ่งที่เครื่องมือ Linux คาดหวังและมีขนาดใกล้เคียงกับ ZIP สำหรับ TAR ธรรมดาของไฟล์ที่แยกกันอยู่ ให้ใช้ ตัวสร้างไฟล์ TAR
