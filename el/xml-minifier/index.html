Συμπιεστής XML

Εν συντομία: συμπιέστε XML αφαιρώντας σχόλια και τα κενά μεταξύ ετικετών — τη μορφοποίηση που κοστίζει bytes αλλά δεν φέρει δεδομένα.
🔒 Ιδιωτικό εκ σχεδιασμού: τα πάντα τρέχουν στο πρόγραμμα περιήγησής σας σε αυτή τη συσκευή. Η είσοδός σας δεν ανεβαίνει ποτέ σε διακομιστή.

Παράδειγμα

Είσοδος:

<a>  <b>x</b>  </a>

Έξοδος:

<a><b>x</b></a>

Σχετικά με αυτόν τον μετατροπέα

Για XML δεδομένων (χάρτες ιστότοπων, ροές, ωφέλιμα φορτία ρυθμίσεων, SVG), η εσοχή είναι για ανθρώπους και τα byte για μηχανές. Αυτός ο συμπιεστής αφαιρεί μόνο σχόλια και κενά ανάμεσα σε στοιχεία — το περιεχόμενο κειμένου μέσα στα στοιχεία διατηρείται, επειδή στο XML, σε αντίθεση με το HTML, τα κενά μπορούν να είναι σημαντικά (το xml:space="preserve" υπάρχει για κάποιο λόγο), και το εργαλείο δεν θα μαντέψει διαφορετικά. Αν το XML σας είναι μορφή εγγράφου (DocBook, XHTML), κρατήστε τη μορφοποίησή σας· αν είναι δεδομένα, η συμπιεσμένη έξοδος αναλύεται στο ίδιο ακριβώς δέντρο.

Συχνές Ερωτήσεις

Αγγίζονται τα κενά μέσα στα στοιχεία;

Όχι — αφαιρούνται μόνο τα κενά αυστηρά μεταξύ ετικετών και τα σχόλια. Το κείμενο των στοιχείων διατηρείται αυτολεξεί.

Παραμένει η έξοδος καλώς μορφοποιημένη;

Η μετατροπή δεν μπορεί να ανισορροπήσει ετικέτες· αν η είσοδος αναλύθηκε, η έξοδος αναλύεται στο ίδιο δέντρο.
