CSV प्रोफ़ाइलर — भरोसा करने से पहले फ़ाइल को समझें

संक्षेप में: CSV Profiler पूरी फ़ाइल पढ़ता है और हर column के लिए report करता है: guessed data type, कितनी cells empty हैं, कितनी values unique हैं, numeric minimum और maximum, और तीन सबसे frequent values।

कोई आपको CSV देता है और पहला सवाल हमेशा होता है 'सच में इसमें क्या है?' Profiler एक paste में इसका जवाब देता है।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

CSV प्रोफ़ाइलर का उपयोग कैसे करें

  1. अपना CSV उसकी header row के साथ paste करें।
  2. Profile this CSV पर click करें।
  3. प्रति-column table पढ़ें: type, empties, uniques, min/max, top values।
  4. इसे dirty data देखने के लिए उपयोग करें — mixed types, unexpected blanks, near-duplicate categories — import करने से पहले।

यह कैसे काम करता है

Types हर value को उन्हीं नियमों से scan करके guessed होती हैं जो हमारे CSV से SQL converter के हैं: integers, decimals, booleans और ISO dates पहचाने जाते हैं, और mixed column text पर लौटता है — जो स्वयं एक उपयोगी warning है। Unique counts और top values category समस्याएँ तुरंत expose करते हैं (1,000 rows के लिए 900 uniques वाला city column category नहीं है)। Numeric min/max सिर्फ़ numeric columns के लिए आता है; text column इसके बजाय अपने top values दिखाता है।

अक्सर पूछे जाने वाले सवाल

क्या यह tool मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, कोई साइन-अप नहीं।

Type guessing कितना accurate है?

यह actual values का scan है, इसलिए यह आपके डेटा को दर्शाता है — '001' codes का column integer अंदाज़ा लगाता है, इसीलिए sanity check के लिए top-values column साथ दिखाया जाता है।

Empty किसे गिना जाता है?

एक cell जिसमें कुछ नहीं है (या CSV parser के पढ़ने के बाद कुछ नहीं बचता)। सिर्फ़ spaces एक value मानी जाती हैं — अगर यह मायने रखता है तो पहले Dedupe & Cleaner से trim करें।

क्या मेरा डेटा अपलोड होता है?

नहीं। Profiling 100% आपके ब्राउज़र में चलती है।
