CSV से SQL कन्वर्टर — CSV डेटा किसी भी Database में Import करें

संक्षेप में: CSV से SQL कन्वर्टर आपका CSV पढ़ता है, हर column के लिए sensible type infer करता है (integer, decimal, boolean, date या text), table और column names sanitise करता है, और आपकी चुनी dialect में CREATE TABLE साथ में प्रति row एक INSERT emit करता है।

हर database import एक CSV और हाथ से लिखे INSERTs के ढेर से शुरू होता है। CSV paste करें, MySQL, PostgreSQL या SQLite चुनें, और एक click में import-ready SQL पाएँ।

Design से निजी: इस tool में सब कुछ JavaScript के साथ 100% आपके browser में होता है। आपका input कभी server पर upload नहीं होता, कभी stored नहीं होता और कभी हमारे द्वारा नहीं देखा जाता — tab बंद करें और सब चला गया।

CSV से SQL कन्वर्टर का उपयोग कैसे करें

  1. अपना CSV paste करें — पहली row column names होनी चाहिए।
  2. Table name type करें और अपना SQL dialect चुनें।
  3. CREATE TABLE ticked छोड़ें अगर आप table definition भी चाहते हैं।
  4. Generate SQL पर click करें, फिर इसे copy करें या .sql फ़ाइल download करें।
  5. Data import करने के लिए SQL को अपने database client में run करें।

यह कैसे काम करता है

Column types हर value को scan करके inferred होते हैं: whole numbers integers बन जाते हैं, decimals floating point, true/false booleans, और ISO dates (YYYY-MM-DD, optional time के साथ) date/timestamp columns बन जाते हैं। मिली-जुली types वाला column सबसे चौड़ी type पर fallback करता है, और mixed numbers और text वाला column TEXT बन जाता है ताकि कुछ खोए नहीं। खाली cells NULL बन जाते हैं। Identifiers sanitised होते हैं - lowercase किए गए, spaces और punctuation underscores से बदले गए, आगे वाला अंक prefixed - और फिर dialect के लिए quoted: MySQL के लिए backticks, PostgreSQL और SQLite के लिए double quotes। String values single-quoted होती हैं, अंदर के quotes doubled - SQL-standard escape।

काम किया हुआ उदाहरण

Row Ali,30,true name,age,active के नीचे बनता है INSERT INTO "my_table" ("name", "age", "active") VALUES ('Ali', 30, TRUE); PostgreSQL dialect में।

अक्सर पूछे जाने वाले सवाल

क्या यह CSV से SQL converter मुफ़्त है?

हाँ — पूरी तरह मुफ़्त, कोई साइन-अप नहीं, कोई cap नहीं।

Column types कैसे चुने जाते हैं?

हर column में सभी values को scan करके। Integers, decimals, booleans और ISO dates पहचाने जाते हैं; mixed columns TEXT पर लौटते हैं।

Empty cells का क्या होता है?

वे INSERT statements में NULL बन जाते हैं।

कौन सी dialects supported हैं?

MySQL (backtick quoting), PostgreSQL और SQLite (double-quote quoting), dialect-appropriate type names के साथ।

क्या मेरा डेटा अपलोड होता है?

नहीं। Conversion पूरी तरह आपके ब्राउज़र में होती है।
