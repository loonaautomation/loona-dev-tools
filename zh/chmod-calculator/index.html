Chmod 计算器 - 权限转八进制和符号形式，双向转换

简而言之： Chmod 计算器将所有者、组和其他人的熟悉的读/写/执行复选框变成八进制值（如 755）和符号字符串（如 rwxr-xr-x）——并将任何八进制值转换回复选框，还提供常见值的通俗含义。

每个人都记得 755 是“文件夹那个”、644 是“文件那个”——直到某次部署需要 750 或 640 的那一天。勾选下面的框，或输入一个八进制值，不要再猜了。

如何使用 Chmod 计算器

  1. 为所有者、组和其他人勾选读、写和执行——或使用预设。
  2. 阅读八进制值、符号字符串和可直接粘贴的 chmod 命令。
  3. 或者输入任意 3 位八进制值（如 750），然后点击“应用八进制”以复选框形式查看它。
  4. 把命令复制到您的终端中。

它如何工作

Unix 权限是三组、每组三个位。在每组内，读值 4、写值 2、执行值 1，所以一组是一个从 0（---）到 7（rwx）的单个八进制数字。计算器把每组勾选的值相加构建三位数八进制，并把相同的框渲染为您在……中看到的符号字符串 ls -l 输出。应用八进制值则反向运行数学：每个数字被拆回其 4-2-1 部分以设置复选框。

实例

所有者读+写+执行（4+2+1 = 7）、组读+执行（4+1 = 5）、其他人读+执行（5）得到八进制 755，符号表示 rwxr-xr-x——经典设置，让每个人都能读取和运行文件或文件夹，而只有所有者能更改它。

常见问题

这个 chmod 计算器免费吗？

是的——完全免费，无需注册，没有每日上限。

八进制和符号表示有什么区别？

它们描述相同的权限。八进制（755）是您在 chmod 之后输入的；符号表示（rwxr-xr-x）是 ls -l 向您展示的。本工具在两方向上在两者之间转换。

setuid、setgid 和粘滞位（4755、1777）呢？

那些是特殊位的第四个、前导数字。本计算器涵盖主要的三个权限数字，这是日常 chmod 工作使用的；如果您在别处输入 4 位值，最后三位是在这里显示的。

为什么文件夹需要执行权限？

对文件夹来说，“执行”意味着进入它并访问内部文件的权限——一个有读权限但没有执行权限的文件夹会显示您实际上打不开的名称。这正是文件夹通常是 755、而文件是 644 的原因。

有任何东西被上传到服务器吗？

不会。计算器 100% 在您的浏览器中运行。
