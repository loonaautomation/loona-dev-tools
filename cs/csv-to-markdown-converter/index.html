Převodník CSV na tabulku Markdown - Tabulky pro README a dokumentaci

Stručně: převodník CSV na Markdown promění vaše CSV v tabulku Markdown připravenou pro GitHub, číselné sloupce automaticky zarovná doprava a svislé čáry uvnitř hodnot escapuje, takže se tabulka nikdy nerozbije.

README, dokumentace a komentáře úkolů všechny vykreslují tabulky Markdown. Vložte CSV a získejte tabulku, která se správně vykreslí napoprvé - zarovnání a escapování zvládnuty.

Soukromé už designem: vše v tomto nástroji probíhá 100% ve vašem prohlížeči pomocí JavaScriptu. Váš vstup se nikdy nenahrává na server, nikdy se neukládá a nikdy ho nevidíme – zavřete kartu a vše je pryč.

Jak používat Převodník CSV na tabulku Markdown

  1. Vložte své CSV - první řádek se stane záhlavím tabulky.
  2. Klikněte na Převést na Markdown.
  3. Zkopírujte tabulku do svého README, dokumentu nebo komentáře.
  4. Číselné sloupce se zarovnávají doprava automaticky.

Jak to funguje

Zarovnání se zjišťuje pro každý sloupec: pokud každá neprázdná hodnota ve sloupci vypadá jako číslo (oddělovače tisíců a koncové % jsou povoleny), oddělovací řádek použije ---: zarovnat ho doprava, jak se čísla mají řadit; ostatní sloupce používají výchozí zarovnání doleva. Svislé čáry uvnitř hodnoty se escapují jako \| takže hodnota nikdy nemůže rozdělit buňku a zalomení řádků uvnitř uvozených polí se stanou <br>, které renderery Markdownu ponechávají uvnitř řádku tabulky.

Často kladené otázky

Je tento převodník zdarma?

Ano – zcela zdarma, bez registrace.

Kde mohu výstup použít?

Kdekoli se vykreslují tabulky Markdown: README na GitHubu a GitLabu, weby s dokumentací, nástroje ve stylu Notion a sledovače úkolů.

Jak se rozhoduje o zarovnání?

Sloupec, jehož hodnoty jsou všechny číselné, je zarovnán doprava; všechny ostatní sloupce jsou zarovnány doleva.

Co když hodnota obsahuje znak svislítka?

Je escapováno jako \| , takže zůstává uvnitř své buňky, místo aby rozbilo tabulku.

Nahrávají se moje data?

Ne. Převod běží zcela ve vašem prohlížeči.
