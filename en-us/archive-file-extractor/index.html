Archive File Extractor - Open Any Archive Online

In short: the Archive File Extractor is the universal opener: drop any common archive - ZIP, RAR, 7Z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ or ISO - and it detects the format itself, lists what is inside, and lets you download single files or everything as a ZIP. Nothing is uploaded.

Not sure what kind of archive you were sent? That is exactly what this page is for. Instead of guessing which tool matches a strange extension, drop the file here: the libarchive engine reads the file's actual content (not just its name), recognizes the format, and lists what is inside. It is the same engine behind the dedicated RAR, 7Z, TAR and ISO pages on this site, with every format switched on.

Private by design: everything in this tool happens 100% in your browser. The archive is read by a WebAssembly engine on your own device - never uploaded, never stored, never seen by us. Two honest limits: password-protected archives are not opened (this tool never asks for, guesses or cracks passwords), and archives are unpacked in your device's memory, so extremely large files can be slow on a low-memory phone.

How to use the Archive File Extractor

  1. Drop your archive file onto the box above, or click it and pick the file from your device - any common format works.
  2. Wait a moment while the format is detected and the contents are read - on first use the engine (about 1 MB) loads once and is then cached by your browser.
  3. Browse the list of files inside the archive, with paths and sizes.
  4. Click Download next to any single file, or use Download all as ZIP to save everything as one standard ZIP file.

How it works

This page is powered by libarchive - the open-source library behind the archive tools of macOS and BSD - compiled to WebAssembly. Libarchive does not trust the file extension: it probes the actual bytes, testing each format reader in turn (ZIP signatures, the RAR marker, the 7z header, TAR checksums, ISO9660 volume descriptors, and the gzip, bzip2 and XZ compression layers that can wrap them). Once the format is identified, the same reader lists every entry and decompresses the ones you download. Download all as ZIP re-packs the contents with JSZip.

Worked example

A client sends project-files.2026 with no helpful extension, and your computer calls it an unknown file. You drop it here: the engine recognizes a TAR.XZ archive, lists 58 source files, and you download the two you need. The mystery format never stood a chance.

Frequently Asked Questions

Which formats can this universal extractor open?

ZIP, RAR (RAR4 and RAR5), 7Z, TAR, TAR.GZ / TGZ, TAR.BZ2, TAR.XZ, ISO disc images, and several rarer ones the libarchive engine understands, such as CPIO and XAR. Every format named here was verified against real test archives when this tool was built.

The file extension looks wrong or is missing entirely. Will it still work?

Usually, yes. Detection is based on the file's content, not its name, so a ZIP renamed to .bin or a download that lost its extension still opens. If the content is genuinely not an archive, the tool reports that instead of guessing.

What can this tool NOT open?

Password-protected archives (no password is ever asked for, guessed or cracked), multi-volume split archives (.part1.rar style sets), Apple's .dmg images, and self-extracting .exe archives. For those, a desktop tool like 7-Zip is the right choice.

Why are there also separate pages for RAR, 7Z and TAR?

The dedicated pages carry format-specific guidance and are what most people search for; this universal page is the safety net for everything else - mixed downloads, unknown extensions, and formats without their own page. Same engine, same privacy, different front door.

Are my files uploaded to a server for detection or extraction?

No. Format detection and extraction both run in WebAssembly inside your browser tab. Your archive never leaves your device, and the tool keeps working offline once the page has loaded.
