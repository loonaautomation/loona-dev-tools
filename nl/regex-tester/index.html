Regex-tester - Live matches, groepen en markeringen

Kortom: de Regex Tester draait je patroon tegen je testtekst terwijl je typt, markeert elke match, vermeldt elke capture group en toont het totale matchaantal - en meldt ongeldige patronen met het foutbericht van de browser.

Reguliere expressies zijn write-once, puzzle-over-forever. Plak hieronder een patroon en wat voorbeeldtekst en zie precies wat matcht, waar, en wat elke capture group ving - voordat het patroon ooit je code bereikt.

(nog niets)
Privacy in het ontwerp: alles in deze tool gebeurt 100% in je browser met JavaScript. Je invoer wordt nooit naar een server geüpload, nooit opgeslagen en nooit door ons gezien - sluit het tabblad en alles is weg.

De regex-tester gebruiken

  1. Typ je patroon in het vak Patroon (zonder de omringende slashes).
  2. Stel vlaggen in zoals g (global), i (ignore case) of m (multiline) in het vak Vlaggen.
  3. Typ of plak de testtekst - resultaten werken live bij terwijl je typt.
  4. Lees de gemarkeerde tekst en de matchtabel: elke match met zijn positie en capture groups.

Hoe het werkt

De tool bouwt een JavaScript RegExp uit je patroon en vlaggen en voert het uit tegen de testtekst. Met de globale vlag gezet loopt hij in volgorde door elke match; zonder meldt hij alleen de eerste match, precies zoals je eigen code zou doen. Nul-breedte matches (bijvoorbeeld van x*) worden veilig verwerkt - de walker gaat na elke lege match één teken verder, zodat hij nooit eeuwig kan loopen. De markeerview escapet je tekst eerst naar veilige HTML en wikkelt dan elke match in een markeermarker, dus wat je ziet is precies wat matchte.

Uitgewerkt voorbeeld

Het patroon (\d{4})-(\d{2})-(\d{2}) tegen "Release on 2026-11-08, hotfix on 2026-11-09" vindt 2 matches, en de tabel toont groep 1 = 2026, groep 2 = 11, groep 3 = 08 voor de eerste - klaar om opnieuw te gebruiken in een datumparser.

Veelgestelde vragen

Is deze regex-tester gratis?

Ja - volledig gratis, zonder registratie en zonder daglimiet.

Welke regex-variant gebruikt het?

JavaScript reguliere expressies - de smaak gebruikt door browsers en Node.js. De meeste patronen uit andere smaken (PCRE, Python) werken hetzelfde, maar een paar constructies verschillen, zoals benoemde groepen die JavaScript schrijft als (?<name>...).

Waarom zie ik maar één match?

Zonder de g-vlag stopt een regex bij de eerste match. Voeg g toe in het vak Vlaggen om ze allemaal te vinden.

Wat zijn capture groups?

Elk paar haakjes in je patroon vangt de tekst die het matchte. De tabel vermeldt ze per match - groep 1 is de eerste openingshaak, enzovoort. Groepen geschreven als (?:...) vangen niet.

Wordt mijn tekst naar een server geüpload?

Nee. Het patroon draait 100% in je browser op tekst die je apparaat nooit verlaat.
