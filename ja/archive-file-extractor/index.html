アーカイブファイル抽出ツール - あらゆるアーカイブをオンラインで開く

要するに： アーカイブファイル抽出ツールは汎用の開くツールです：一般的なアーカイブ（ZIP、RAR、7Z、TAR、TAR.GZ、TAR.BZ2、TAR.XZ、ISO）をドロップすると、形式自体を検出し、内部のものを一覧表示し、単一ファイルまたはすべてをZIPとしてダウンロードできます。何もアップロードされません。

送られたアーカイブの種類が分かりませんか？このページはまさにそのためのものです。奇妙な拡張子にどのツールが合うか推測する代わりに、ファイルをここにドロップしてください。libarchiveエンジンがファイルの実際の内容（名前だけでなく）を読み、形式を認識して、中身を一覧表示します。このサイトの専用のRAR、7Z、TAR、ISOページの背後にあるのと同じエンジンで、すべての形式が有効になっています。

アーカイブファイルをここにドロップ（ZIP、RAR、7Z、TAR、ISO...） またはクリックしてデバイスからファイルを選んでください
アーカイブ内のファイルサイズ
設計上プライベート： このツールのすべてはブラウザで100%行われます。アーカイブは、あなたのデバイス上のWebAssemblyエンジンで読み取られます。アップロードされることは決してなく、保存されることも、私たちに見られることもありません。二つの正直な制限：パスワードで保護されたアーカイブは開かれません（このツールはパスワードを要求したり、推測したり、解読したりすることは決してありません）。そしてアーカイブはあなたのデバイスのメモリ内で解凍されるため、極めて大きなファイルは、低メモリの電話では遅くなることがあります。

アーカイブファイル抽出ツールの使い方

  1. アーカイブファイルを上のボックスにドロップするか、ボックスをクリックしてデバイスからファイルを選んでください。一般的な形式ならどれでも使えます。
  2. 形式が検出され内容が読み取られる間、少しお待ちください。初回使用時にエンジン（約1 MB）が一度読み込まれ、その後はブラウザによってキャッシュされます。
  3. アーカイブ内のファイル一覧を、パスとサイズとともに参照します。
  4. 単一ファイルの横の「ダウンロード」をクリックするか、「すべてZIPでダウンロード」を使って、すべてを一つの標準ZIPファイルとして保存してください。

仕組み

このページはlibarchiveによって駆動されます。macOSとBSDのアーカイブツールの背後にあるオープンソースライブラリで、WebAssemblyにコンパイルされています。libarchiveはファイル拡張子を信頼しません。実際のバイトを調べ、各形式リーダーを順にテストします（ZIPシグネチャ、RARマーカー、7zヘッダー、TARチェックサム、ISO9660ボリューム記述子、そしてそれらを包むことができるgzip、bzip2、XZ圧縮層）。形式が特定されると、同じリーダーがすべてのエントリを一覧表示し、ダウンロードするものを解凍します。すべてZIPとしてダウンロードすると、JSZipで内容を再パックします。

実例

クライアントから project-files.2026 が送られてきました。役立つ拡張子はなく、コンピュータは不明なファイルと呼びます。ここにドロップすると、エンジンがTAR.XZアーカイブを認識し、58個のソースファイルを一覧表示します。あなたは必要な二つをダウンロードします。謎のフォーマットに勝ち目は最初からありませんでした。

よくある質問

この汎用抽出ツールはどの形式を開けますか？

ZIP、RAR（RAR4とRAR5）、7Z、TAR、TAR.GZ / TGZ、TAR.BZ2、TAR.XZ、ISOディスクイメージ、そしてCPIOやXARのような、libarchiveエンジンが理解するいくつかの希少なもの。ここに名前が挙げられたすべての形式は、このツールが構築されたときに実際のテストアーカイブに対して検証されました。

ファイル拡張子が間違って見えるか、完全に欠けています。それでも動作しますか？

通常は、はい。検出はファイルの名前ではなく内容に基づくため、.binに名前を変更されたZIPや、拡張子を失ったダウンロードでも開きます。内容が本当にアーカイブでない場合、ツールは推測する代わりにそれを報告します。

このツールが開けないものは何ですか？

パスワード保護されたアーカイブ（パスワードは決して尋ねられず、推測も解読もされません）、マルチボリューム分割アーカイブ（.part1.rarスタイルのセット）、Appleの.dmgイメージ、自己解凍.exeアーカイブです。これらについては、7-Zipのようなデスクトップツールが適切な選択です。

なぜRAR、7Z、TARの別ページもあるのですか？

専用ページは形式固有のガイダンスを備えており、ほとんどの人が検索するものです。この汎用ページは、その他のすべてのための安全網です。混在したダウンロード、未知の拡張子、独自のページを持たない形式です。同じエンジン、同じプライバシー、異なる入口です。

検出や抽出のために、私のファイルはサーバーにアップロードされますか？

いいえ。形式の検出と解凍はどちらもブラウザタブ内のWebAssemblyで実行されます。アーカイブがデバイスから出ることは決してありません。ページが読み込まれれば、ツールはオフラインでも動作し続けます。
