ตัวสร้างไฟล์ TAR - สร้างไฟล์บีบอัด .tar จากไฟล์ของคุณ

สรุปสั้น ๆ: ตัวสร้างไฟล์ TAR รวมชุดไฟล์ใด ๆ เป็นไฟล์บีบอัด .tar มาตรฐานเดียวโดยใช้ตัวเขียน ustar ที่ถูกต้องตามข้อกำหนดในเบราว์เซอร์ของคุณ - เพิ่มไฟล์ เลือกจัดกลุ่มพวกมันในโฟลเดอร์ และดาวน์โหลด

TAR ยังคงเป็นภาษากลางของ Linux เซิร์ฟเวอร์ และข้อมูลสำรอง - แต่ผู้ใช้ Windows ที่ต้องการสร้าง tarball มักต้องติดตั้งอะไรบางอย่างก่อน หน้านี้เขียนไฟล์บีบอัด TAR แท้ในเบราว์เซอร์ของคุณ: ส่วนหัว ustar ที่เหมาะสม เช็กซัม และเวลาประทับ สร้างบนอุปกรณ์ของคุณโดยไม่มีการอัปโหลดอะไรเลย

วางไฟล์ที่นี่ หรือคลิกเพื่อเลือกหลายไฟล์จากอุปกรณ์ของคุณ
ชื่อไฟล์ขนาด

จำไว้ว่า: TAR ไม่บีบอัด .tar จะมีขนาดประมาณขนาดของไฟล์ทั้งหมดรวมกัน (ปัดขึ้นเป็นบล็อก 512 ไบต์) ต้องการให้เล็กลง? รันผลลัพธ์ผ่าน ตัวบีบอัด GZIP หลังจากนั้น หรือใช้ ตัวสร้างไฟล์ ZIP แทน

เป็นส่วนตัวโดยการออกแบบ: ทุกอย่างในเครื่องมือนี้เกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ไฟล์ของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเห็นโดยเรา - ปิดแท็บแล้วทุกอย่างหายไป ขีดจำกัดที่ซื่อตรงหนึ่งข้อ: การแปลงเกิดขึ้นในหน่วยความจำของอุปกรณ์ของคุณ ดังนั้นไฟล์บีบอัดที่ใหญ่มาก (หลายร้อยเมกะไบต์) อาจช้าหรือล้มเหลวบนโทรศัพท์ที่มีหน่วยความจำน้อย

วิธีใช้ ตัวสร้างไฟล์ TAR

  1. วางไฟล์ของคุณลงบนกล่องด้านบน หรือคลิกมันแล้วเลือกไฟล์จากอุปกรณ์ของคุณ คุณสามารถเพิ่มไฟล์ได้หลายรอบ
  2. ตรวจสอบรายการ - ลบสิ่งที่เพิ่มเข้ามาโดยไม่ได้ตั้งใจ และดูขนาดรวม
  3. เลือกที่จะพิมพ์ชื่อโฟลเดอร์เพื่อให้ทุกไฟล์อยู่ภายในโฟลเดอร์เดียวในไฟล์บีบอัด และตั้งชื่อให้ TAR
  4. คลิกสร้าง TAR และดาวน์โหลด ไฟล์ .tar เปิดด้วย tar บน Linux/macOS และด้วย 7-Zip หรือ WinRAR บน Windows

วิธีการทำงาน

ไฟล์บีบอัด TAR คือสตรีมของเรคคอร์ด: สำหรับแต่ละไฟล์ จะมีบล็อกส่วนหัว ustar ขนาด 512 ไบต์ (ชื่อไฟล์ ขนาดในเลขฐานแปด เวลาแก้ไข ค่าเช็กซัมของส่วนหัวเอง ค่ามหัศจรรย์ 'ustar' และฟิลด์นำหน้าที่ทำให้เส้นทางยาวกว่า 100 ตัวอักษรได้ - พร้อมรายการ GNU longname สำหรับเส้นทางที่ยาวเกินกว่านั้นอีก) ตามด้วยเนื้อหาของไฟล์ที่เติมให้เต็มจำนวนบล็อก 512 ไบต์ บล็อกศูนย์สองบล็อกปิดท้ายไฟล์บีบอัด หน้านี้ใช้งานรูปแบบนั้นโดยตรง - ไม่มีไลบรารี ไม่มีเซิร์ฟเวอร์ - และตัวเขียนได้รับการยืนยันด้วยการให้โมดูล tarfile ของ Python อ่านผลลัพธ์กลับมาเทียบทีละไบต์ TAR เก็บไฟล์โดยไม่บีบอัด ดังนั้นไฟล์บีบอัดจึงเป็นผลรวมของส่วนประกอบ; การบีบอัดเป็นขั้นตอนแยกต่างหาก (นั่นคือสิ่งที่ .tar.gz เพิ่มเข้ามา)

ตัวอย่างที่ทำแล้ว

คุณเพิ่มไฟล์สามไฟล์: deploy.sh (1 KB), config.yml (3 KB) และ logo.png (48 KB) โดยชื่อโฟลเดอร์ตั้งเป็น 'release' เครื่องมือสร้าง release.tar - หรือชื่อที่คุณเลือก - ซึ่งมีโฟลเดอร์ release พร้อมไฟล์ทั้งสามไฟล์ แต่ละไฟล์เก็บเวลาแก้ไขจริงของมันไว้ ที่เนื้อหา 52 KB TAR ออกมาประมาณ 54 KB: ตัวไฟล์เอง ส่วนหัวสามส่วน และการเติม โดยไม่มีการบีบอัด - อย่างแม่นยำกับสิ่งที่ tar จะสร้างบน Linux

คำถามที่พบบ่อย

ตัวสร้างไฟล์ TAR นี้ฟรีหรือไม่?

ใช่ - ฟรี ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดและไม่มีลายน้ำ

ไฟล์ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ TAR ถูกเขียนโดย JavaScript ที่ทำงานในเบราว์เซอร์ของคุณ บนอุปกรณ์ของคุณ ไฟล์ของคุณไม่เคยออกจากมัน

ทำไม TAR จึงมีขนาดเท่ากับไฟล์ของฉัน - หรือใหญ่กว่าเล็กน้อย?

TAR ไม่บีบอัดอะไรเลย; มันเพียงรวมกลุ่มเท่านั้น แต่ละไฟล์ยังเพิ่มส่วนหัว 512 ไบต์และถูกเติมให้ถึงขอบเขต 512 ไบต์ ดังนั้นไฟล์บีบอัดจึงใหญ่กว่ายอดรวมดิบเล็กน้อย สำหรับ tarball ที่บีบอัด ให้สร้าง TAR ที่นี่แล้วรันมันผ่าน ตัวบีบอัด GZIP - นั่นคือวิธีสร้าง .tar.gz ตามตัวอักษร

Linux และ GNU tar จะยอมรับไฟล์บีบอัดที่สร้างที่นี่หรือไม่?

ใช่ ตัวเขียนทำตามข้อกำหนด ustar - ฟิลด์เลขฐานแปดและเช็กซัมส่วนหัวที่ถูกต้อง เวทมนตร์ ustar การแยกคำนำหน้าสำหรับเส้นทางยาวและรายการ GNU longname สำหรับเส้นทางที่ยาวมาก - และผลลัพธ์ของมันได้รับการยืนยันโดยการอ่านมันกลับด้วยโมดูล tarfile ของ Python ระหว่างการทดสอบ

ฉันเพิ่มไฟล์ลงใน TAR ที่มีอยู่หรือสร้าง .tar.gz โดยตรงได้หรือไม่?

ไม่ใช่ในเครื่องมือนี้ - มันสร้างไฟล์บีบอัดใหม่ทุกครั้ง หากต้องการเปลี่ยน ZIP ที่มีอยู่เป็น .tar.gz ในขั้นตอนเดียว ให้ใช้ ตัวแปลง ZIP เป็น TAR.GZ; หากต้องการบีบอัด TAR นี้เป็น .tar.gz ให้ใช้ ตัวบีบอัด GZIP หลังจากนั้นและเปลี่ยนชื่อผลลัพธ์เป็น .tar.gz

เครื่องมือสำหรับนักพัฒนาที่เกี่ยวข้อง

GZ

ตัวบีบอัด GZIP

บีบอัดไฟล์เดียวเป็น .gz ด้วยกลไก gzip ในตัวของเบราว์เซอร์ของคุณ - เหมาะมากสำหรับ TAR ใหม่ ๆ

ZIP

ตัวสร้างไฟล์ ZIP

สร้าง ZIP จากหลายไฟล์ - เพิ่มไฟล์ ตั้งชื่อไฟล์บีบอัด และดาวน์โหลด .zip หนึ่งไฟล์

TAR

ตัวแปลง TAR เป็น ZIP

แพ็กไฟล์บีบอัด .tar ใหม่เป็น .zip โดยไม่ต้องอัปโหลดไปยังเซิร์ฟเวอร์
